## Как пользоваться руководствами

Выберите категорию и откройте нужное руководство. Адаптируйте примеры к своей лаборатории: версии, требования и права доступа могут отличаться. Названия инструментов, параметры, пути и необходимые технические термины сохранены в исходном виде. Для работы без интернета скачайте или клонируйте репозиторий.

```bash
git clone https://github.com/Ilias1988/Hacking-Cheatsheets.git
cd Hacking-Cheatsheets
```
