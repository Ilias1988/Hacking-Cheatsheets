## Πριν ξεκινήσετε

Το **Nikto** στέλνει αιτήματα σε έναν **web server** και συγκρίνει τις αποκρίσεις με γνωστά μοτίβα προβλημάτων. Μπορεί να εντοπίσει εκτεθειμένα αρχεία, παλιές εκδόσεις ή ενδείξεις λανθασμένων ρυθμίσεων. Τα αποτελέσματα χρειάζονται επιβεβαίωση: ένα **false positive** είναι ένδειξη προβλήματος που τελικά δεν ισχύει. Η απουσία ευρημάτων επίσης δεν αποδεικνύει ότι μια εφαρμογή είναι ασφαλής.

Ξεκινήστε από τον στόχο και το πρωτόκολλο HTTP/HTTPS, διαβάστε τις κατηγορίες ελέγχου και τις απαιτήσεις ταυτοποίησης και έπειτα εξετάστε τις μορφές αναφοράς. Τα παραδείγματα δεν αντικαθιστούν τον χειροκίνητο έλεγχο της εφαρμογής. Οι εντολές παραμένουν όπως στο αγγλικό πρωτότυπο· ορισμένες επιλογές του είναι παλιές και συνοδεύονται από διευκρινίσεις.

**Όροι:** *plugin* = πρόσθετο ελέγχου, *database* = βάση μοτίβων ελέγχου, *authentication* = ταυτοποίηση χρήστη, *proxy* = ενδιάμεσος διακομιστής, *TLS* = πρωτόκολλο κρυπτογράφησης της σύνδεσης HTTPS. Οι IP, τα domains και τα στοιχεία σύνδεσης είναι ενδεικτικά.

## 🎯 Εισαγωγή

**Το Nikto** είναι εργαλείο ανοιχτού κώδικα που εκτελεί ελέγχους ασφάλειας σε web servers. Αναζητά, μεταξύ άλλων, τα παρακάτω:

### Τι ελέγχει το Nikto

| Κατηγορία | Περιγραφή |
| ---------- | ------------- |
| **Δυνητικά επικίνδυνα αρχεία** | Αρχεία που μπορεί να εκθέτουν δεδομένα, όπως αντίγραφα ασφαλείας |
| **Παλιές εκδόσεις** | Μη ενημερωμένο λογισμικό διακομιστή |
| **Έλεγχοι ανά έκδοση** | Ευπάθειες που αφορούν συγκεκριμένες εκδόσεις |
| **Ρυθμίσεις διακομιστή** | Λανθασμένες ρυθμίσεις |
| **Scripts CGI** | Δυνητικά επικίνδυνα scripts CGI |
| **SSL/TLS** | Προβλήματα πιστοποιητικών SSL/TLS |
| **Κεφαλίδες HTTP** | Ελλιπείς ή μη ασφαλείς κεφαλίδες HTTP |
| **Μέθοδοι HTTP** | Δυνητικά επικίνδυνες μέθοδοι HTTP |

### Αριθμοί της βάσης ελέγχων στο πρωτότυπο

> **Αριθμοί του πρωτοτύπου:** Οι παρακάτω μετρήσεις διατηρούνται για πιστότητα και δεν αποτελούν επιβεβαιωμένη απογραφή της τρέχουσας έκδοσης ή εγγύηση κάλυψης.


```
✅ 6,700+ δυνητικά επικίνδυνα αρχεία/CGIs
✅ 1,250+ παλιές εκδόσεις διακομιστών
✅ 270+ προβλήματα συγκεκριμένων εκδόσεων
✅ 1,000+ προβλήματα ρυθμίσεων διακομιστών
```

### Δυνατότητες

| Χαρακτηριστικό | Περιγραφή |
| --------- | ------------- |
| **Εκτενείς έλεγχοι** | Χιλιάδες έλεγχοι για ενδείξεις ευπαθειών |
| **Βασισμένο σε πρόσθετα (plugins)** | Αρχιτεκτονική που επιτρέπει επέκταση |
| **Πολλαπλές μορφές αποτελεσμάτων** | Έξοδος σε HTML, XML, CSV και JSON ανάλογα με την έκδοση |
| **Υποστήριξη SSL/TLS** | Έλεγχοι διακομιστών μέσω HTTPS |
| **Τεχνικές αποφυγής IDS** | Ενσωματωμένες τεχνικές μεταβολής αιτημάτων |
| **Ταυτοποίηση** | Υποστήριξη Basic, Digest και NTLM ανάλογα με την έκδοση |

## ⌨️ Βασική σύνταξη

### Γενική σύνταξη
```bash
nikto -h <host> [options]
```

### Πρώτη γνωριμία
```bash
# Βασική σάρωση
nikto -h http://target.com

# Σάρωση με καθορισμένη θύρα
nikto -h target.com -p 80

# Σάρωση μέσω HTTPS
nikto -h https://target.com

# Σάρωση διεύθυνσης IP
nikto -h 192.168.1.1
```

## 🎯 Καθορισμός στόχων

### Ένας στόχος
```bash
# Με όνομα συστήματος
nikto -h target.com

# Με διεύθυνση IP
nikto -h 192.168.1.1

# Με καθορισμένο πρωτόκολλο
nikto -h http://target.com
nikto -h https://target.com
```

### Πολλαπλοί στόχοι
```bash
# Από αρχείο
nikto -h targets.txt

# targets.txt:
# http://target1.com
# http://target2.com:8080
# https://target3.com
```

### Στόχος με συγκεκριμένη διαδρομή URL
```bash
# Σάρωση συγκεκριμένης διαδρομής
nikto -h http://target.com/app

# Σάρωση συγκεκριμένου καταλόγου
nikto -h http://target.com/admin/
```

## 🔌 Επιλογές θυρών και SSL/TLS

### Επιλογές θυρών
```bash
# Μία θύρα
nikto -h target.com -p 80

# Πολλαπλές θύρες
nikto -h target.com -p 80,443,8080

# Εύρος θυρών
nikto -h target.com -p 80-90

# Συνήθεις θύρες web servers
nikto -h target.com -p 80,443,8000,8080,8443
```

### Επιλογές SSL/TLS

| Επιλογή | Περιγραφή |
| -------- | ------------- |
| `-ssl` | Υποχρεωτική χρήση SSL/TLS |
| `-nossl` | Απενεργοποίηση SSL/TLS |
| `-maxtime` | Μέγιστη διάρκεια σάρωσης |

```bash
# Υποχρεωτική χρήση SSL/TLS
nikto -h target.com -ssl

# Απενεργοποίηση SSL/TLS, μόνο HTTP
nikto -h target.com -nossl

# SSL/TLS σε μη συνήθη θύρα
nikto -h target.com -p 8443 -ssl
```

### Εικονικοί ιστότοποι (Virtual Hosts)
```bash
# Καθορισμός εικονικού ιστοτόπου
nikto -h 192.168.1.1 -vhost target.com

# Χρήσιμο όταν:
# - Στόχος πίσω από κατανεμητή φορτίου
# - Πολλαπλοί ιστότοποι στην ίδια IP
```

## 🎚️ Επιλογή κατηγοριών ελέγχου

> **Κατηγορίες, όχι επιβεβαιωμένα αποτελέσματα:** Το `-Tuning 9` επιλέγει ελέγχους που σχετίζονται με SQL Injection· δεν αποδεικνύει ότι υπάρχει τέτοια ευπάθεια ούτε καλύπτει κάθε δυνατή περίπτωση. Η εξαίρεση της κατηγορίας DoS με `x6` δεν εγγυάται ότι οι υπόλοιποι έλεγχοι δεν θα επιβαρύνουν την υπηρεσία.


### Κατηγορίες ελέγχου (-Tuning)

| Κωδικός | Περιγραφή |
| ------ | ------------- |
| `0` | Μεταφόρτωση αρχείων |
| `1` | Αρχεία ενδιαφέροντος ή γνωστά από αρχεία καταγραφής |
| `2` | Λανθασμένες ρυθμίσεις ή προεπιλεγμένα αρχεία |
| `3` | Αποκάλυψη πληροφοριών |
| `4` | Έγχυση περιεχομένου (XSS/Script/HTML) |
| `5` | Απομακρυσμένη ανάκτηση αρχείων μέσα στον βασικό κατάλογο του ιστοτόπου |
| `6` | Άρνηση υπηρεσίας (DoS) |
| `7` | Απομακρυσμένη ανάκτηση αρχείων σε επίπεδο διακομιστή |
| `8` | Εκτέλεση εντολών ή απομακρυσμένη κονσόλα |
| `9` | Έγχυση SQL (SQL Injection) |
| `a` | Παράκαμψη ταυτοποίησης |
| `b` | Αναγνώριση λογισμικού |
| `c` | Συμπερίληψη απομακρυσμένου πηγαίου κώδικα |
| `d` | Διαδικτυακή υπηρεσία (Web Service) |
| `e` | Κονσόλα διαχείρισης |
| `x` | Αντιστροφή επιλογής: εξαίρεση των καθορισμένων κατηγοριών |

### Χρήση κατηγοριών ελέγχου
```bash
# Επιλογή κατηγορίας ελέγχων SQL Injection
nikto -h target.com -Tuning 9

# Επιλογή ελέγχων XSS και SQL Injection
nikto -h target.com -Tuning 49

# Έλεγχος πολλαπλών κατηγοριών
nikto -h target.com -Tuning 1234

# Εξαίρεση συγκεκριμένων κατηγοριών με πρόθεμα x
nikto -h target.com -Tuning x6    # Εξαίρεση ελέγχων κατηγορίας DoS

# Εξαίρεση της κατηγορίας DoS, όχι εγγύηση ακίνδυνου ελέγχου
nikto -h target.com -Tuning x6
```

### Πρόσθετα (plugins)
```bash
# Προβολή διαθέσιμων προσθέτων
nikto -list-plugins

# Εκτέλεση συγκεκριμένου προσθέτου
nikto -h target.com -Plugins apacheusers

# Εκτέλεση πολλαπλών προσθέτων
nikto -h target.com -Plugins "apacheusers;robots"

# Εξαίρεση προσθέτων
nikto -h target.com -Plugins "@@ALL;-robots"
```

### Συνήθη πρόσθετα

| Πρόσθετο | Περιγραφή |
| -------- | ------------- |
| `apacheusers` | Αναζήτηση χρηστών Apache |
| `cgi` | Έλεγχος scripts CGI |
| `robots` | Ανάλυση robots.txt |
| `headers` | Ανάλυση κεφαλίδων HTTP |
| `httpoptions` | Έλεγχος μεθόδων HTTP |
| `outdated` | Έλεγχος για μη ενημερωμένο λογισμικό |
| `ssl` | Ανάλυση SSL/TLS |
| `dictionary` | Δοκιμές βάσει λίστας λέξεων |

## 🔐 Ταυτοποίηση

### Βασική ταυτοποίηση HTTP (Basic Authentication)

> **Διόρθωση περιγραφής:** Η γραφή `"admin:password"` του παραδείγματος είναι τα στοιχεία σύνδεσης μέσα σε εισαγωγικά. Δεν είναι συμβολοσειρά κωδικοποιημένη σε Base64, όπως αναφέρει το σχόλιο του πρωτοτύπου.

```bash
# Όνομα χρήστη και κωδικός
nikto -h target.com -id admin:password

# Ίδια στοιχεία σύνδεσης σε εισαγωγικά· δεν είναι κωδικοποίηση Base64
nikto -h target.com -id "admin:password"
```

### Ταυτοποίηση HTTP Digest
```bash
# Ταυτοποίηση Digest εφόσον υποστηρίζεται και αναγνωριστεί
nikto -h target.com -id admin:password
```

### Ταυτοποίηση NTLM
```bash
# Ταυτοποίηση NTLM
nikto -h target.com -id admin:password:domain
```

### Ταυτοποίηση μέσω cookies
```bash
# Αποστολή cookies
nikto -h target.com -cookies "session=abc123; token=xyz789"

# Από αρχείο
nikto -h target.com -cookies cookies.txt
```

## 🛡️ Proxy και τεχνικές μεταβολής αιτημάτων

> **Καταγραφή αιτημάτων:** Οι τεχνικές `-evasion`, ο διαφορετικός User-Agent και οι παύσεις αλλάζουν τα αιτήματα ή τον ρυθμό τους· δεν εγγυώνται αποφυγή IDS/WAF ή μη καταγραφή. Ένα WAF είναι μηχανισμός φιλτραρίσματος αιτημάτων web.


### Χρήση ενδιάμεσου διακομιστή (proxy)
```bash
# Proxy HTTP
nikto -h target.com -useproxy http://127.0.0.1:8080

# Proxy με ταυτοποίηση
nikto -h target.com -useproxy http://user:pass@proxy:8080

# Μέσω Burp Suite
nikto -h target.com -useproxy http://127.0.0.1:8080
```

### Τεχνικές αποφυγής IDS (-evasion)

| Κωδικός | Τεχνική |
| ------ | ----------- |
| `1` | Τυχαία κωδικοποίηση URI χωρίς UTF-8 |
| `2` | Αναφορά του καταλόγου στον εαυτό του (/./) |
| `3` | Πρόωρος τερματισμός URL |
| `4` | Προσθήκη μεγάλης τυχαίας συμβολοσειράς στην αρχή |
| `5` | Εικονική παράμετρος |
| `6` | Χρήση TAB ως διαχωριστικού στο αίτημα |
| `7` | Εναλλαγή πεζών και κεφαλαίων στο URL |
| `8` | Χρήση διαχωριστικού καταλόγων Windows (\) |
| `A` | Χρήση χαρακτήρα επιστροφής δρομέα (0x0d) |
| `B` | Χρήση της δυαδικής τιμής 0x0b |

```bash
# Μία τεχνική μεταβολής αιτημάτων
nikto -h target.com -evasion 1

# Συνδυασμός τεχνικών μεταβολής αιτημάτων
nikto -h target.com -evasion 1234

# Συνδυασμός των τεχνικών μεταβολής αιτημάτων του παραδείγματος
nikto -h target.com -evasion 12345678AB
```

### User-Agent
```bash
# Προσαρμοσμένη κεφαλίδα User-Agent
nikto -h target.com -useragent "Mozilla/5.0 (Windows NT 10.0)"

# Googlebot
nikto -h target.com -useragent "Googlebot/2.1"
```

### Χρονισμός αιτημάτων
```bash
# Παύση μεταξύ αιτημάτων σε δευτερόλεπτα
nikto -h target.com -Pause 2

# Μέγιστη διάρκεια σάρωσης σε δευτερόλεπτα
nikto -h target.com -maxtime 3600

# Χρονικό όριο ανά αίτημα
nikto -h target.com -timeout 10
```

## 📄 Αποτελέσματα και αναφορές

### Μορφές αποτελεσμάτων

| Επιλογή | Μορφή |
| -------- | -------- |
| `-o file` | Αποθήκευση σε αρχείο |
| `-Format htm` | Μορφή HTML |
| `-Format xml` | Μορφή XML |
| `-Format csv` | Μορφή CSV |
| `-Format txt` | Μορφή απλού κειμένου |
| `-Format json` | Μορφή JSON |
| `-Format nbe` | Μορφή NBE |
| `-Format sql` | Μορφή SQL |

### Αποθήκευση αποτελεσμάτων
```bash
# Έξοδος απλού κειμένου
nikto -h target.com -o report.txt

# Αναφορά HTML
nikto -h target.com -o report.html -Format htm

# Αναφορά XML
nikto -h target.com -o report.xml -Format xml

# Αναφορά JSON
nikto -h target.com -o report.json -Format json

# Αναφορά CSV
nikto -h target.com -o report.csv -Format csv
```

### Επιλογές αναλυτικής εξόδου
```bash
# Εμφάνιση επιλογών
nikto -h target.com -Display V    # Αναλυτική έξοδος
nikto -h target.com -Display D    # Διαγνωστική έξοδος
nikto -h target.com -Display E    # Σφάλματα HTTP
nikto -h target.com -Display P    # Πρόοδος
nikto -h target.com -Display S    # Απόκρυψη IP στην έξοδο, όχι ανωνυμοποίηση της σάρωσης
nikto -h target.com -Display 1    # Εμφάνιση ανακατευθύνσεων
nikto -h target.com -Display 2    # Εμφάνιση cookies
nikto -h target.com -Display 3    # Εμφάνιση αποκρίσεων 200/OK
nikto -h target.com -Display 4    # Εμφάνιση URL που απαιτούν ταυτοποίηση

# Πολλαπλές επιλογές εμφάνισης
nikto -h target.com -Display VEP
```

### Αποθήκευση και συνέχιση: περιορισμοί του παραδείγματος

> **Το παράδειγμα δεν είναι έγκυρη οδηγία συνέχισης:** Στην επίσημη τεκμηρίωση το `-Save` αποθηκεύει αποκρίσεις που συνδέονται με ευρήματα σε κατάλογο. Δεν αποθηκεύει την πρόοδο ως checkpoint. Η επιλογή `-Resume` του πρωτοτύπου δεν εμφανίζεται στην τρέχουσα τεκμηρίωση. Οι δύο γραμμές διατηρούνται ως παραδείγματα του πρωτοτύπου, όχι ως επιβεβαιωμένη διαδικασία. Δείτε την [επίσημη λίστα επιλογών](https://github.com/sullo/nikto/wiki/Annotated-Option-List).

```bash
# Παράδειγμα -Save του πρωτοτύπου· δεν αποτελεί αποθήκευση προόδου για συνέχιση
nikto -h target.com -Save scan_state.txt

# Παράδειγμα συνέχισης του πρωτοτύπου· η επιλογή χρειάζεται έλεγχο υποστήριξης
nikto -Resume scan_state.txt
```

## 🔄 Ενημέρωση βάσης ελέγχων

> **Παλαιά διαδικασία ενημέρωσης:** Το `-update` και τα URL με `2.1.5` είναι ιστορικά παραδείγματα. Η επίσημη τεκμηρίωση αναφέρει ενημέρωση μέσω Git από την έκδοση 2.1.6. Για εγκατάσταση από πακέτο ακολουθήστε τον αντίστοιχο διαχειριστή πακέτων. Μην θεωρείτε τα παλιά URL πηγή τρέχουσας βάσης. Δείτε τις [οδηγίες ενημέρωσης Nikto](https://github.com/sullo/nikto/wiki/Updating).


### Ενημέρωση της βάσης ελέγχων Nikto
```bash
# Παράδειγμα ενημέρωσης βάσεων ελέγχων
nikto -update

# Παλιό παράδειγμα χειροκίνητης ενημέρωσης· δείτε τη σχετική σημείωση
cd /var/lib/nikto
```

## 🎬 Παραδείγματα σεναρίων ελέγχου

### Παράδειγμα 1: Βασική σάρωση web server
```bash
nikto -h http://target.com
```

### Παράδειγμα 2: Εκτενής σάρωση μέσω HTTPS
```bash
nikto -h https://target.com -ssl -p 443 -o report.html -Format htm
```

### Παράδειγμα 3: Σάρωση πολλαπλών θυρών
```bash
nikto -h target.com -p 80,443,8080,8443 -o results.txt
```

### Παράδειγμα 4: Σάρωση με ταυτοποίηση
```bash
nikto -h http://target.com/admin \
    -id admin:password \
    -o auth_scan.html \
    -Format htm
```

### Παράδειγμα 5: Παράδειγμα μεταβολής αιτημάτων για αποφυγή IDS
```bash
nikto -h target.com \
    -evasion 1234 \
    -Pause 2 \
    -useragent "Mozilla/5.0 (Windows NT 10.0)" \
    -o stealth_scan.txt
```

### Παράδειγμα 6: Μέσω του proxy του Burp Suite
```bash
nikto -h https://target.com \
    -useproxy http://127.0.0.1:8080 \
    -o proxy_scan.html \
    -Format htm
```

### Παράδειγμα 7: Εστίαση σε ελέγχους SQL Injection
```bash
nikto -h target.com \
    -Tuning 9 \
    -o sqli_scan.txt
```

### Παράδειγμα 8: Εκτενής έλεγχος
```bash
nikto -h https://target.com \
    -ssl \
    -p 443 \
    -Tuning x6 \
    -Display VEP \
    -o full_audit.html \
    -Format htm
```

### Παράδειγμα 9: Έλεγχος εικονικού ιστοτόπου
```bash
nikto -h 192.168.1.10 \
    -vhost app.target.com \
    -p 80,443 \
    -o vhost_scan.txt
```

### Παράδειγμα 10: Σάρωση στόχων από αρχείο
```bash
nikto -h targets.txt \
    -o batch_scan.html \
    -Format htm
```

## 📊 Γρήγορη αναφορά

### Βασικές εντολές

| Εργασία | Εντολή |
| ------ | --------- |
| Βασική σάρωση | `nikto -h target.com` |
| Σάρωση μέσω HTTPS | `nikto -h target.com -ssl` |
| Πολλαπλές θύρες | `nikto -h target.com -p 80,443,8080` |
| Με στοιχεία ταυτοποίησης | `nikto -h target.com -id user:pass` |
| Αναφορά HTML | `nikto -h target.com -o report.html -Format htm` |
| Μεταβολή αιτημάτων για αποφυγή εντοπισμού | `nikto -h target.com -evasion 123` |
| Μέσω ενδιάμεσου διακομιστή (proxy) | `nikto -h target.com -useproxy http://127.0.0.1:8080` |
| Ενημέρωση βάσης ελέγχων | `nikto -update` |

### Συνηθισμένες επιλογές

| Επιλογή | Περιγραφή |
| -------- | ------------- |
| `-h` | Σύστημα στόχος |
| `-p` | Θύρες προς σάρωση |
| `-ssl` | Υποχρεωτική χρήση SSL/TLS |
| `-id` | Στοιχεία ταυτοποίησης |
| `-o` | Αρχείο εξόδου |
| `-Format` | Μορφή αποτελεσμάτων |
| `-Tuning` | Επιλογή κατηγοριών ελέγχου |
| `-evasion` | Τεχνικές αποφυγής IDS |
| `-useproxy` | Ενδιάμεσος διακομιστής (proxy) |
| `-vhost` | Εικονικός ιστότοπος |
| `-Pause` | Καθυστέρηση μεταξύ ελέγχων |
| `-timeout` | Χρονικό όριο αιτήματος |

### Συνοπτικός πίνακας κατηγοριών ελέγχου

| Κωδικός | Κατηγορία |
| ------ | ---------- |
| 1-4 | Πληροφορίες και λανθασμένες ρυθμίσεις |
| 4-5 | Έγχυση περιεχομένου και ανάκτηση αρχείων |
| 6 | Άρνηση υπηρεσίας (να αποφεύγεται σε παραγωγικά συστήματα) |
| 7-8 | Απομακρυσμένη πρόσβαση |
| 9 | Έγχυση SQL (SQL Injection) |
| a | Παράκαμψη ταυτοποίησης |
| b | Αναγνώριση λογισμικού |
| x | Εξαίρεση |

## 💡 Συμβουλές και καλές πρακτικές

### Συμβουλές απόδοσης

1. **Ξεκινήστε με βασική σάρωση**
   ```bash
   nikto -h target.com
   ```

2. **Εξαιρέστε ελέγχους άρνησης υπηρεσίας**
   ```bash
   nikto -h target.com -Tuning x6
   ```

3. **Ορίστε κατάλληλα χρονικά όρια**
   ```bash
   nikto -h target.com -timeout 15 -Pause 1
   ```

### Συμβουλές ακρίβειας

1. **Ενημερώνετε τακτικά τη βάση ελέγχων**
   ```bash
   nikto -update
   ```

2. **Χρησιμοποιήστε αναλυτική έξοδο**
   ```bash
   nikto -h target.com -Display VE
   ```

3. **Συνδυάστε το με άλλα εργαλεία**
   ```bash
   # Αρχικά Nmap και στη συνέχεια Nikto
   nmap -sV -p 80,443 target.com
   nikto -h target.com -p 80,443
   ```

### Συνηθισμένα προβλήματα

> **Αντιμετώπιση προβλημάτων:** Μεγαλύτερο timeout βοηθά σε αργές αποκρίσεις, αλλά μπορεί να αυξήσει τη διάρκεια της σάρωσης. Η επιλογή `-ssl` καθορίζει χρήση TLS· δεν διορθώνει κάθε πρόβλημα πιστοποιητικού ή διαπραγμάτευσης TLS. Εξετάστε την πραγματική αιτία του σφάλματος.


| Πρόβλημα | Ενδεικτική προσέγγιση |
| ------- | ---------- |
| Αργή σάρωση | Εξετάστε μείωση του `-Pause` για μικρότερες παύσεις ή αύξηση του `-timeout` αν χάνονται αργές αποκρίσεις |
| Σφάλματα SSL/TLS | Ελέγξτε ότι απαιτείται TLS και δηλώστε ρητά την επιλογή `-ssl` |
| Προβλήματα ταυτοποίησης | Ελέγξτε τη μορφή των στοιχείων στην επιλογή `-id` |
| Αποτελέσματα που λείπουν | Ενημερώστε τη βάση ελέγχων και ελέγξτε τα πρόσθετα |
