## Πριν ξεκινήσετε

Το **Wireshark** εμφανίζει και αναλύει πακέτα δικτύου. Μπορεί να καταγράφει ζωντανή κίνηση από μια **interface** (διεπαφή δικτύου) ή να ανοίγει αποθηκευμένο αρχείο **pcap/pcapng**. Το τι μπορείτε να δείτε εξαρτάται από το σημείο καταγραφής, την τοπολογία, τα φίλτρα, την πληρότητα της καταγραφής και την κρυπτογράφηση.

**Βασικοί όροι:** *packet/frame* = πακέτο ή πλαίσιο δεδομένων, *header* = κεφαλίδα πρωτοκόλλου, *payload* = δεδομένα που μεταφέρει, *stream* = ροή επικοινωνίας, *source/destination* = προέλευση και προορισμός, *timestamp* = χρονική σήμανση. Το **dissector** είναι το τμήμα που ερμηνεύει ένα πρωτόκολλο. Το **tshark** προσφέρει σχετική ανάλυση στη γραμμή εντολών.

Ξεκινήστε με ένα μικρό εργαστηριακό αρχείο: επιλέξτε ένα πακέτο, εξετάστε τις κεφαλίδες και εφαρμόστε φίλτρα εμφάνισης. Τα αγγλικά ονόματα μενού και πεδίων διατηρούνται για να τα αναγνωρίζετε στο πρόγραμμα, με ελληνικές οδηγίες. Τα φίλτρα και οι εντολές παραμένουν όπως στο πρωτότυπο· τα σημεία που χρειάζονται διευκρίνιση επισημαίνονται παρακάτω.

## 🎯 Εισαγωγή

**Το Wireshark** είναι δωρεάν εργαλείο ανοιχτού κώδικα για ανάλυση πακέτων. Χρησιμοποιείται στη διερεύνηση προβλημάτων δικτύου, στην ανάπτυξη λογισμικού και σε ελέγχους ασφάλειας.

### Βασικά χαρακτηριστικά

| Χαρακτηριστικό | Περιγραφή |
| --------- | ------------- |
| **Λεπτομερής ανάλυση πρωτοκόλλων** | Υποστήριξη πολλών πρωτοκόλλων |
| **Ζωντανή καταγραφή** | Καταγραφή πακέτων σε πραγματικό χρόνο |
| **Ανάλυση αποθηκευμένης καταγραφής** | Ανάγνωση αρχείων καταγραφής pcap και pcapng |
| **Φίλτρα επιλογής πακέτων** | Φίλτρα εμφάνισης και καταγραφής |
| **Πολλαπλές πλατφόρμες** | Windows, Linux και macOS |
| **Γραφικό περιβάλλον και γραμμή εντολών** | Wireshark με γραφικό περιβάλλον και tshark στη γραμμή εντολών |

### Παραδείγματα χρήσης

| Χρήση | Περιγραφή |
| ---------- | ------------- |
| **Διερεύνηση προβλημάτων δικτύου** | Διερεύνηση προβλημάτων συνδεσιμότητας |
| **Ανάλυση ασφάλειας** | Αναζήτηση ενδείξεων κακόβουλης κίνησης |
| **Ανάπτυξη πρωτοκόλλων** | Δοκιμές νέων πρωτοκόλλων |
| **Ψηφιακή διερεύνηση (Forensics)** | Ανάλυση καταγεγραμμένης κίνησης |
| **Εκπαίδευση** | Εκμάθηση λειτουργίας δικτύων |

## 📥 Εγκατάσταση

> **Δικαιώματα καταγραφής:** Η προσθήκη στην ομάδα wireshark δεν αρκεί σε κάθε εγκατάσταση. Χρειάζεται και κατάλληλη ρύθμιση του μηχανισμού καταγραφής, όπως dumpcap ή ο αντίστοιχος driver. Η ονομασία διεπαφής και τα απαιτούμενα δικαιώματα εξαρτώνται από το λειτουργικό. Δείτε τον [οδηγό Wireshark](https://www.wireshark.org/docs/wsug_html/).


### Windows
```bash
# Λήψη από τον επίσημο ιστότοπο
https://www.wireshark.org/download.html

# Εναλλακτικά μέσω Chocolatey
choco install wireshark
```

### Linux (Kali και Ubuntu)
```bash
# Kali, εφόσον είναι προεγκατεστημένο
wireshark

# Ubuntu/Debian
sudo apt install wireshark

# Προσθήκη χρήστη στην ομάδα καταγραφής· απαιτεί και κατάλληλη ρύθμιση δικαιωμάτων
sudo usermod -aG wireshark $USER
# Αποσύνδεση και νέα σύνδεση χρήστη για ενημέρωση ομάδων
```

### macOS
```bash
brew install --cask wireshark
```

### Επιβεβαίωση εγκατάστασης
```bash
wireshark --version
tshark --version
```

## 📡 Βασικά βήματα καταγραφής

> **Τι καταγράφεται:** Η επιλογή διεπαφής δεν δίνει αυτόματα πρόσβαση σε όλη την κίνηση του δικτύου. Τα captures μπορεί να είναι ελλιπή λόγω σημείου παρατήρησης, απωλειών ή μικρού snapshot length. Το αρχείο μπορεί να περιέχει δεδομένα και στοιχεία συνεδριών του εγκεκριμένου ελέγχου.


### Έναρξη καταγραφής

```
1. Επιλέξτε διεπαφή δικτύου από την αρχική οθόνη
2. Πατήστε "Start Capture", το μπλε πτερύγιο καρχαρία
3. Εναλλακτικό μενού: Capture → Start

Γρήγορη εκκίνηση: διπλό κλικ στο όνομα της διεπαφής δικτύου
```

### Διακοπή καταγραφής

```
Πατήστε το κόκκινο τετράγωνο στη γραμμή εργαλείων
Εναλλακτικό μενού: Capture → Stop
Εναλλακτικά: Ctrl+E
```

### Αποθήκευση καταγραφής

```
Μενού: File → Save As (αποθήκευση ως)
Μορφές: pcapng (προεπιλογή), pcap και άλλες
```

### Άνοιγμα αρχείου καταγραφής

```
Μενού: File → Open (άνοιγμα)
Εναλλακτικά: Ctrl+O
Εναλλακτική εντολή: wireshark file.pcap
```

## 🔍 Φίλτρα εμφάνισης (Display Filters)

> **Εμφάνιση και καταγραφή διαφέρουν:** Το display filter περιορίζει ποια από τα ήδη καταγεγραμμένα πακέτα εμφανίζονται· δεν αλλάζει από μόνο του την αρχική καταγραφή. Εισάγετε αυτά τα φίλτρα στη γραμμή φίλτρων του Wireshark, όχι ως εντολές τερματικού. Από το Wireshark 3.6 άλλαξε η σημασία του `!=` για πεδία με πολλαπλές τιμές, όπως το ip.addr. Οι κανονικές εκφράσεις χρειάζονται σωστή διαφυγή backslash: το παράδειγμα `matches` με ένα backslash πριν από την τελεία χρειάζεται έλεγχο της σύνταξης συμβολοσειρών. Δείτε τις [εκφράσεις φίλτρων](https://www.wireshark.org/docs/wsug_html_chunked/ChWorkBuildDisplayFilterSection.html).


### Σύνταξη φίλτρων

> **Σειρά έκφρασης:** Στο γενικό πρότυπο, field σημαίνει πεδίο, operator τελεστή σύγκρισης και value την τιμή σύγκρισης. Τα πραγματικά ονόματα πεδίων, όπως ip.addr ή tcp.port, παραμένουν όπως τα ορίζει το Wireshark.


Τα φίλτρα εμφάνισης χρησιμοποιούν **σύνταξη σύγκρισης πεδίων**:

```
field operator value
```

### Τελεστές σύγκρισης

| Τελεστής | Περιγραφή | Παράδειγμα |
| ---------- | ------------- | --------- |
| `==` ή `eq` | Ίσο | `ip.addr == 192.168.1.1` |
| `!=` ή `ne` | Όχι ίσο | `ip.addr != 10.0.0.1` |
| `>` ή `gt` | Μεγαλύτερο από | `frame.len > 100` |
| `<` ή `lt` | Μικρότερο από | `tcp.port < 1024` |
| `>=` ή `ge` | Μεγαλύτερο ή ίσο | `frame.len >= 64` |
| `<=` ή `le` | Μικρότερο ή ίσο | `tcp.port <= 1024` |
| `contains` | Περιέχει συμβολοσειρά | `http contains "password"` |
| `matches` | Αντιστοίχιση κανονικής έκφρασης | `http.host matches ".*\.com"` |

### Λογικοί τελεστές

| Τελεστής | Περιγραφή | Παράδειγμα |
| ---------- | ------------- | --------- |
| `and` ή `&&` | Λογικό ΚΑΙ | `ip.src == 192.168.1.1 and tcp.port == 80` |
| `or` ή `\|\|` | Λογικό Ή | `tcp.port == 80 or tcp.port == 443` |
| `not` ή `!` | Λογική άρνηση (ΟΧΙ) | `not arp` |
| `()` | Ομαδοποίηση | `(ip.src == 10.0.0.1) and (tcp or udp)` |

### Φίλτρα διευθύνσεων IP

```bash
# Συγκεκριμένη IP προέλευσης ή προορισμού
ip.addr == 192.168.1.1

# Μόνο IP προέλευσης
ip.src == 192.168.1.1

# Μόνο IP προορισμού
ip.dst == 192.168.1.1

# Εύρος IP, υποδίκτυο
ip.addr == 192.168.1.0/24

# Εξαίρεση IP· η συμπεριφορά του != διαφέρει σε παλιές εκδόσεις
ip.addr != 192.168.1.1

# Επικοινωνία μεταξύ δύο συστημάτων
ip.addr == 192.168.1.1 and ip.addr == 192.168.1.2
```

### Φίλτρα θυρών

```bash
# Συγκεκριμένη θύρα προέλευσης ή προορισμού
tcp.port == 80
udp.port == 53

# Μόνο θύρα προέλευσης
tcp.srcport == 443

# Μόνο θύρα προορισμού
tcp.dstport == 22

# Εύρος θυρών
tcp.port >= 1 and tcp.port <= 1024

# Πολλαπλές θύρες
tcp.port == 80 or tcp.port == 443 or tcp.port == 8080
tcp.port in {80 443 8080}
```

### Φίλτρα πρωτοκόλλων

```bash
# Με βάση το όνομα πρωτοκόλλου
http
dns
tcp
udp
arp
icmp
tls
ssh
ftp
smtp
dhcp

# Πεδία ειδικά για HTTP
http.request
http.response
http.request.method == "GET"
http.request.method == "POST"
http.response.code == 200
http.response.code >= 400

# Πεδία ειδικά για DNS
dns.qry.name == "google.com"
dns.qry.type == 1          # Εγγραφή A για διεύθυνση IPv4
dns.flags.response == 1    # Απαντήσεις DNS

# Πεδία ειδικά για TCP
tcp.flags.syn == 1         # Πακέτα με ενεργή σημαία SYN
tcp.flags.fin == 1         # Πακέτα με ενεργή σημαία FIN
tcp.flags.reset == 1       # Πακέτα με ενεργή σημαία RST
tcp.analysis.retransmission  # Ενδείξεις επαναμετάδοσης
tcp.stream == 5            # Συγκεκριμένη ροή επικοινωνίας
```

### Φίλτρα περιεχομένου

```bash
# Περιέχει συμβολοσειρά
http contains "password"
tcp contains "login"
frame contains "secret"

# Περιεχόμενο HTTP
http.request.uri contains "admin"
http.host == "example.com"
http.user_agent contains "Mozilla"
http.cookie contains "session"

# Αντιστοίχιση χωρίς διάκριση πεζών και κεφαλαίων
http.host matches "(?i)example"
```

### Συνήθη παραδείγματα φίλτρων

> **Οι περιγραφές είναι ενδεικτικές:** Το `tls` δεν σημαίνει αποκλειστικά HTTPS. Το φίλτρο SYN ή ACK περιλαμβάνει πολύ περισσότερα πακέτα από την αρχική τριμερή σύνδεση TCP. Η εξαίρεση του 192.168.0.0/16 δεν αποκλείει όλα τα ιδιωτικά ή τοπικά δίκτυα. Μια σημαία RST δεν αποδεικνύει από μόνη της επίθεση.


```bash
# Μόνο αναγνωρισμένη κίνηση HTTP
http

# Αναγνωρισμένη κίνηση TLS, όχι αποκλειστικά HTTPS
tls

# Ερωτήματα DNS
dns.flags.response == 0

# Πακέτα RST· δεν δηλώνουν πάντα αποτυχημένη αρχική σύνδεση
tcp.flags.reset == 1

# Μεγάλα πακέτα
frame.len > 1000

# Συγκεκριμένη διεύθυνση MAC
eth.addr == aa:bb:cc:dd:ee:ff

# Κίνηση Ethernet broadcast
eth.dst == ff:ff:ff:ff:ff:ff

# Εκτός του συγκεκριμένου εύρους 192.168.0.0/16, όχι κάθε τοπικού δικτύου
!(ip.addr == 192.168.0.0/16)

# Ευρύ φίλτρο SYN ή ACK· δεν απομονώνει μόνο την τριμερή αρχική σύνδεση TCP
tcp.flags.syn == 1 or tcp.flags.ack == 1

# Αιτήματα HTTP POST με διαθέσιμα δεδομένα
http.request.method == "POST" and http.file_data
```

## 🎣 Φίλτρα καταγραφής (Capture Filters)

> **Διαφορετική γλώσσα φίλτρων:** Τα capture filters χρησιμοποιούν σύνταξη libpcap/BPF. Όσα πακέτα αποκλείονται σε αυτό το στάδιο δεν μπορούν να ανακτηθούν αργότερα αλλάζοντας display filter. Οι θύρες 80, 443 ή 53 είναι συνήθεις αντιστοιχίσεις, όχι απόδειξη πρωτοκόλλου.


### Σύνταξη BPF (Berkeley Packet Filter)

Τα φίλτρα καταγραφής χρησιμοποιούν **σύνταξη BPF**, διαφορετική από τη σύνταξη των φίλτρων εμφάνισης.

### Βασική σύνταξη

```bash
# Σύστημα
host 192.168.1.1
src host 192.168.1.1
dst host 192.168.1.1

# Δίκτυο
net 192.168.1.0/24
src net 10.0.0.0/8

# Θύρα
port 80
src port 443
dst port 22
portrange 1-1024

# Πρωτόκολλο
tcp
udp
icmp
arp
```

### Συνδυασμένα φίλτρα

```bash
# Σύστημα και θύρα
host 192.168.1.1 and port 80

# Συγκεκριμένη επικοινωνία
host 192.168.1.1 and host 192.168.1.2

# Εξαίρεση κίνησης
not port 22
not host 10.0.0.1

# Σύνθετο φίλτρο
tcp and (port 80 or port 443) and host 192.168.1.1
```

### Συνήθη φίλτρα καταγραφής

| Σκοπός | Φίλτρο |
| --------- | -------- |
| Συγκεκριμένο σύστημα | `host 192.168.1.1` |
| Κίνηση σε συνήθεις θύρες web | `port 80 or port 443` |
| Κίνηση στη συνήθη θύρα DNS | `port 53` |
| Κίνηση στη συνήθη θύρα SSH | `port 22` |
| Εξαίρεση broadcast | `not broadcast` |
| Συγκεκριμένο υποδίκτυο | `net 192.168.1.0/24` |

## 🔬 Ανάλυση πρωτοκόλλων

### Ανάλυση TCP

```bash
# Σημαίες TCP
tcp.flags.syn == 1 and tcp.flags.ack == 0    # SYN χωρίς ACK
tcp.flags.syn == 1 and tcp.flags.ack == 1    # SYN-ACK
tcp.flags.fin == 1                            # FIN
tcp.flags.reset == 1                          # RST

# Ενδείξεις προβλημάτων TCP
tcp.analysis.retransmission
tcp.analysis.duplicate_ack
tcp.analysis.zero_window
tcp.analysis.lost_segment

# Ροή TCP
tcp.stream == 0
```

### Ανάλυση HTTP

```bash
# Αιτήματα HTTP
http.request
http.request.method == "GET"
http.request.method == "POST"
http.request.uri contains "/login"

# Αποκρίσεις HTTP
http.response
http.response.code == 200
http.response.code == 404
http.response.code >= 400    # Ενδείξεις σφάλματος

# Περιεχόμενο HTTP
http.content_type contains "json"
http.content_type contains "html"
http.file_data contains "password"
```

### Ανάλυση DNS

```bash
# Ερωτήματα DNS
dns.flags.response == 0
dns.qry.name == "example.com"
dns.qry.type == 1      # Εγγραφή A για διεύθυνση IPv4
dns.qry.type == 28     # Εγγραφή AAAA για διεύθυνση IPv6
dns.qry.type == 5      # CNAME
dns.qry.type == 15     # MX

# Απαντήσεις DNS
dns.flags.response == 1
dns.flags.rcode != 0   # Ενδείξεις σφάλματος
```

### Ανάλυση TLS/SSL

> **Κρυπτογράφηση και εκδόσεις:** Η καταγραφή TLS δεν εμφανίζει αυτόματα το κρυπτογραφημένο περιεχόμενο HTTP. Η ανάλυσή του απαιτεί κατάλληλα διαθέσιμα μυστικά συνεδρίας ή άλλη υποστηριζόμενη διαδικασία. Το `tls.record.version == 0x0303` δεν ξεχωρίζει αξιόπιστα TLS 1.2 από TLS 1.3, που χρησιμοποιεί τιμές συμβατότητας. Δείτε την [τεκμηρίωση TLS του Wireshark](https://wiki.wireshark.org/TLS) και το [TLS 1.3 record format](https://www.rfc-editor.org/rfc/rfc8446.html#section-5.1).


```bash
# Κίνηση TLS
tls

# Αρχική διαπραγμάτευση TLS
tls.handshake
tls.handshake.type == 1     # Μήνυμα Client Hello της αρχικής διαπραγμάτευσης
tls.handshake.type == 2     # Μήνυμα Server Hello της αρχικής διαπραγμάτευσης

# Πεδία πιστοποιητικών, όταν είναι διαθέσιμα στην καταγραφή
tls.handshake.certificate

# Πεδία έκδοσης TLS
tls.record.version == 0x0303  # Τιμή έκδοσης record 0x0303· δεν αποδεικνύει από μόνη της TLS 1.2
```

### Ανάλυση ARP

> **Δεν είναι απόδειξη spoofing:** Το Gratuitous ARP μπορεί να χρησιμοποιείται νόμιμα, π.χ. σε αλλαγές διεύθυνσης ή μεταγωγή εφεδρικών συστημάτων. Αξιολογήστε τις διευθύνσεις, τον χρόνο και το περιβάλλον πριν εξαγάγετε συμπέρασμα.


```bash
# Όλη η κίνηση ARP
arp

# Αιτήματα ARP
arp.opcode == 1

# Απαντήσεις ARP
arp.opcode == 2

# Gratuitous ARP, που μπορεί να έχει νόμιμη χρήση και δεν αποδεικνύει spoofing
arp.isgratuitous == 1
```

## 💻 tshark στη γραμμή εντολών

> **Καταγραφή και μορφή αρχείου:** Το `-f` επιλέγει capture filter και το `-Y` display filter. Η κατάληξη .pcap δεν καθορίζει από μόνη της τη μορφή· το tshark γράφει από προεπιλογή pcapng. Τα πεδία και τα στατιστικά εξαρτώνται από έκδοση και dissectors. Δείτε το [εγχειρίδιο tshark](https://www.wireshark.org/docs/man-pages/tshark.html).


### Βασική χρήση

```bash
# Καταγραφή πακέτων
tshark -i eth0

# Ανάγνωση αρχείου καταγραφής
tshark -r capture.pcap

# Εγγραφή σε αρχείο
tshark -i eth0 -w output.pcap
```

### Εφαρμογή φίλτρων

```bash
# Φίλτρο καταγραφής
tshark -i eth0 -f "port 80"

# Φίλτρο εμφάνισης
tshark -r capture.pcap -Y "http"
```

### Επιλογές αποτελεσμάτων

```bash
# Εμφάνιση συγκεκριμένων πεδίων
tshark -r capture.pcap -T fields -e ip.src -e ip.dst -e tcp.port

# Εξαγωγή αποτελεσμάτων σε JSON
tshark -r capture.pcap -T json

# Εμφάνιση στατιστικών
tshark -r capture.pcap -q -z io,stat,1
```

### Συνήθη παραδείγματα tshark

```bash
# Ζωντανή καταγραφή και εμφάνιση αιτημάτων HTTP
tshark -i eth0 -Y "http.request" -T fields -e http.host -e http.request.uri

# Εξαγωγή ονομάτων από ερωτήματα DNS
tshark -r capture.pcap -Y "dns.flags.response == 0" -T fields -e dns.qry.name

# Στατιστικά πακέτων ανά διεύθυνση IP
tshark -r capture.pcap -q -z ip_hosts,tree

# Στατιστικά HTTP
tshark -r capture.pcap -q -z http,tree
```

## 🎬 Παραδείγματα σεναρίων ελέγχου

### Παράδειγμα 1: Καταγραφή κίνησης HTTP
```bash
# Φίλτρο καταγραφής: port 80
# Φίλτρο εμφάνισης: http
# Χρήση Follow HTTP Stream για εξέταση των διαθέσιμων αιτημάτων και αποκρίσεων
```

### Παράδειγμα 2: Αναζήτηση στοιχείων σύνδεσης σε καταγραφή
```bash
# Φίλτρο εμφάνισης
http.request.method == "POST" and http contains "password"

# Εναλλακτικά για FTP
ftp contains "PASS"
```

### Παράδειγμα 3: Διερεύνηση πιθανής σάρωσης θυρών

> **Χρειάζεται συσχέτιση:** Το φίλτρο δείχνει SYN χωρίς ACK, κάτι που συμβαίνει και σε κανονικές αρχικές συνδέσεις. Η διερεύνηση σάρωσης απαιτεί εξέταση πολλών θυρών ή προορισμών, συχνότητας και αποκρίσεων.

```bash
# Πακέτα SYN χωρίς ACK· χρειάζεται σύγκριση προορισμών και συχνότητας
tcp.flags.syn == 1 and tcp.flags.ack == 0

# Εξετάστε πολλές διαφορετικές θύρες ή προορισμούς από μία πηγή
Μενού: Statistics → Conversations → TCP
```

### Παράδειγμα 4: Διερεύνηση πιθανής εξαγωγής δεδομένων μέσω DNS

> **Το φίλτρο δεν ανιχνεύει εξαγωγή δεδομένων:** Το frame.len μετρά ολόκληρο το καταγεγραμμένο πλαίσιο. Πακέτα DNS άνω των 512 bytes και εγγραφές TXT μπορούν να είναι απολύτως νόμιμα. Αξιολογήστε περιεχόμενο, συχνότητα και συμφραζόμενα.

```bash
# Πακέτα με DNS και μέγεθος frame άνω των 512 bytes, όχι αποκλειστικά μεγάλα ερωτήματα
dns and frame.len > 512

# Εγγραφές TXT· η παρουσία τους δεν είναι από μόνη της ασυνήθιστη
dns.qry.type == 16
```

### Παράδειγμα 5: Εξαγωγή αρχείων
```
Μενού: File → Export Objects → HTTP (εξαγωγή διαθέσιμων αντικειμένων HTTP)

Επιλέξτε τα διαθέσιμα αρχεία προς εξαγωγή
```

### Παράδειγμα 6: Ανάλυση αρχικής διαπραγμάτευσης TLS
```bash
tls.handshake

# Εξέταση Client Hello για το SNI, όπου είναι ορατό
tls.handshake.type == 1
```

### Παράδειγμα 7: Αναζήτηση μη κρυπτογραφημένων κωδικών
```bash
http contains "password" or http contains "passwd" or ftp or telnet
```
