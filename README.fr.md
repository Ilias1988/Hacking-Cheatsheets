## Utiliser les guides

Choisissez une catégorie, puis ouvrez un guide. Adaptez les exemples à votre laboratoire : les versions, les prérequis et les autorisations peuvent varier. Les noms des outils, les options, les chemins et les termes techniques nécessaires conservent leur forme d’origine. Pour une consultation hors ligne, téléchargez ou clonez le dépôt.

```bash
git clone https://github.com/Ilias1988/Hacking-Cheatsheets.git
cd Hacking-Cheatsheets
```
