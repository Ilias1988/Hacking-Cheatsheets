> **CTF (Capture the Flag)** — учебные соревнования, в которых нужно найти и отправить строку-флаг. Pwn означает задания по эксплуатации бинарных программ, ROP — построение цепочек из фрагментов машинного кода. Названия инструментов, команды и форматы флагов сохранены как в английском оригинале.

## 🔥 Краткий справочник команд для CTF

### Веб
```bash
# SQLi
sqlmap -u "http://url?id=1" --dbs

# Перебор каталогов
gobuster dir -u http://url -w /usr/share/wordlists/dirb/common.txt
```

### Криптография
```bash
# Определение типа хеша
hashid 'hash_string'
hash-identifier

# Декодирование Base64
echo "string" | base64 -d
```

### Компьютерная криминалистика
```bash
# Тип файла
file unknown_file
binwalk unknown_file

# Строки
strings -n 6 file | grep -i flag
```

### Pwn
```bash
# Проверить механизмы защиты
checksec binary

# Запустить в GDB
gdb ./binary
```

## 📋 Методология решения CTF

```
1. РАЗВЕДКА
   - Внимательно прочитать условие задания
   - Скачать все предоставленные файлы
   - Определить категорию (веб, криптография, pwn и т. п.)

2. СБОР СВЕДЕНИЙ
   - Применить подходящие инструменты
   - Проверить очевидные уязвимости
   - Поискать подсказки в именах файлов и метаданных

3. ЭКСПЛУАТАЦИЯ
   - Применить известные техники
   - Найти сведения о сообщениях об ошибках в Google
   - Проверить типичные полезные нагрузки (payloads)

4. ПОЛУЧЕНИЕ ФЛАГА
   - Искать флаг соответствующего формата: CTF{...}
   - Проверить весь вывод инструментов
   - Отправить флаг и проверить результат
```
