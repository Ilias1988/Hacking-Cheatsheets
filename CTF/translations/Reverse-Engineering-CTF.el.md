## Πριν ξεκινήσετε

Η **αντίστροφη ανάλυση (Reverse Engineering)** αναζητά τη λειτουργία ενός προγράμματος από το εκτελέσιμο και τη συμπεριφορά του. Το **disassembly** προβάλλει εντολές μηχανής σε αναγνώσιμη assembly. Το **decompilation** παράγει προσέγγιση ψευδοκώδικα και δεν ανακτά απαραίτητα τον αρχικό πηγαίο κώδικα.

Η **στατική ανάλυση** εξετάζει το αρχείο χωρίς να το εκτελεί, ενώ η **δυναμική ανάλυση** παρακολουθεί πραγματική εκτέλεση. Ο **debugger** επιτρέπει διακοπή και βηματική εκτέλεση, το **breakpoint** είναι σημείο διακοπής και το **patching** τροποποίηση bytes ή εντολών. Τα **registers** είναι καταχωρητές του επεξεργαστή και η **stack** στοίβα δεδομένων της εκτέλεσης.

Οι διευθύνσεις, τα ονόματα συναρτήσεων και οι θέσεις αρχείου του πρωτοτύπου είναι ενδεικτικά. Οι εντολές r2/aaa/afl ανήκουν στο Radare2, ενώ οι εντολές b/r/n/x και τα πρόσθετα GEF ανήκουν στο GDB. Τα πλήκτρα και η διαθεσιμότητα decompiler εξαρτώνται από προϊόν, έκδοση και αρχιτεκτονική. Χρησιμοποιήστε αντίγραφο για patching και απομονωμένο εργαστήριο για την εκτέλεση άγνωστου προγράμματος.

## 🔍 Αρχική ανάλυση

```bash
# Αναγνώριση τύπου αρχείου
file binary

# Εξαγωγή αναγνώσιμων συμβολοσειρών
strings binary | grep -i flag
strings -n 8 binary

# Πληροφορίες μορφής εκτελέσιμου ELF
readelf -h binary

# Έλεγχος μηχανισμών προστασίας
checksec binary
```

## 🛠️ Εργαλεία ανάλυσης εντολών μηχανής

Η ονομασία του μενού αυτόματης ανάλυσης προσαρμόστηκε στην επίσημη ροή Ghidra. Το F5 του πρωτοτύπου δεν παρουσιάζεται ως καθολική συντόμευση για κάθε εργαλείο· οι οδηγίες Ghidra και IDA δεν είναι εναλλάξιμες. Το [εισαγωγικό υλικό Ghidra](https://ghidra.re/ghidra_docs/GhidraClass/Beginner/Introduction_to_Ghidra_Student_Guide.html) εξηγεί τα διαφορετικά παράθυρα και τη ροή ανάλυσης.


### Ghidra — Εργαλείο αντίστροφης ανάλυσης
```
1. File → Import File — Εισαγωγή αρχείου
2. Analysis → Auto-Analyze — Αυτόματη ανάλυση
3. Εντοπίστε τη συνάρτηση main() όπου υπάρχει
4. Εξετάστε συγκρίσεις strcmp/memcmp για ελέγχους κωδικού
5. Εξετάστε τη συνάρτηση στο παράθυρο Decompiler για ψευδοκώδικα (το πρωτότυπο αναφέρει F5)
```

### IDA Free
```
1. Ανοίξτε το εκτελέσιμο
2. F5 για ψευδοκώδικα, όπου διατίθεται ο κατάλληλος Hex-Rays decompiler
3. X για διασταυρούμενες αναφορές
4. N για μετονομασία μεταβλητών
```

### Radare2
```bash
r2 binary
aaa          # Ανάλυση
afl          # Κατάλογος συναρτήσεων
pdf @main    # Προβολή εντολών της main
VV           # Οπτικό περιβάλλον
```

## 🐛 Αποσφαλμάτωση με GDB

```bash
# Εκκίνηση
gdb ./binary

# Σημεία διακοπής εκτέλεσης (breakpoints)
b main
b *0x401234

# Εκτέλεση μέσα στον debugger
r
r arg1 arg2

# Βηματική εκτέλεση
n           # Επόμενη γραμμή
s           # Είσοδος στη συνάρτηση
c           # Συνέχιση εκτέλεσης

# Εξέταση μνήμης και καταχωρητών
x/s $rdi    # Προβολή ως συμβολοσειρά
x/10x $rsp  # Προβολή 10 τιμών σε δεκαεξαδική μορφή από τη στοίβα
info reg    # Καταχωρητές

# Παράδειγμα αναζήτησης της λέξης flag στη μνήμη
find 0x0, 0xffffffff, "flag"
```

### Επεκτάσεις GDB: GEF και PEDA

Το παράδειγμα εγκατάστασης κατεβάζει script και το εκτελεί άμεσα. Οι εντολές vmmap/heap/telescope απαιτούν κατάλληλη επέκταση και δεν είναι εγγυημένα διαθέσιμες σε καθαρή εγκατάσταση GDB.

```bash
# Παράδειγμα εγκατάστασης GEF — λήψη και άμεση εκτέλεση απομακρυσμένου script
bash -c "$(curl -fsSL https://gef.blah.cat/sh)"

# Εντολές μέσα σε GDB με κατάλληλη επέκταση
vmmap
heap
telescope $rsp
```

## 🐍 Τροποποίηση bytes εκτελέσιμου με Python

Το 0x1234 είναι θέση μέσα στο αρχείο και όχι κατ’ ανάγκη διεύθυνση φόρτωσης στη μνήμη. Πρέπει να υπάρχει μέσα στο μήκος του αρχείου. Η τιμή 0x90 αντιστοιχεί σε NOP στο σχετικό πλαίσιο x86 και δεν είναι γενικός κανόνας για κάθε αρχιτεκτονική.


```python
# Ανάγνωση του εκτελέσιμου ως bytes
with open("binary", "rb") as f:
    data = bytearray(f.read())

# Τροποποίηση συγκεκριμένων bytes
data[0x1234] = 0x90  # NOP

# Εγγραφή αποτελέσματος
with open("patched", "wb") as f:
    f.write(data)
```

## 📊 Συνηθισμένα μοτίβα ελέγχου

| Έλεγχος | Ενδεικτική προσέγγιση του πρωτοτύπου |
| ------- | -------- |
| `strcmp(input, "password")` | Εντοπισμός της συμβολοσειράς "password" |
| `if (x == 0x1337)` | Εντοπισμός της τιμής 0x1337 |
| Έλεγχοι αποτροπής αποσφαλμάτωσης | Εξέταση τροποποίησης του ελέγχου ptrace |
| Συμβολοσειρές με απόκρυψη ή μετασχηματισμό | Ανάλυση κατά την εκτέλεση |
