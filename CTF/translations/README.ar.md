<a id="-quick-ctf-commands"></a>
## 🔥 أوامر سريعة لتحديات CTF

<a id="web"></a>
### الويب
```bash
# SQLi
sqlmap -u "http://url?id=1" --dbs

# تخمين أسماء المجلدات
gobuster dir -u http://url -w /usr/share/wordlists/dirb/common.txt
```

<a id="crypto"></a>
### التشفير
```bash
# تحديد نوع البصمة
hashid 'hash_string'
hash-identifier

# فك ترميز Base64
echo "string" | base64 -d
```

<a id="forensics"></a>
### الأدلة الجنائية الرقمية
```bash
# نوع الملف
file unknown_file
binwalk unknown_file

# السلاسل النصية
strings -n 6 file | grep -i flag
```

<a id="pwn"></a>
### Pwn
```bash
# فحص وسائل الحماية
checksec binary

# تشغيل الملف داخل GDB
gdb ./binary
```

<a id="-ctf-methodology"></a>
## 📋 منهجية حل تحديات CTF

```
1. الاستطلاع
   - قراءة وصف التحدي بعناية
   - تنزيل جميع الملفات
   - تحديد الفئة (web/crypto/pwn وغيرها)

2. جمع التفاصيل
   - تشغيل الأدوات المناسبة
   - البحث عن الثغرات الواضحة
   - البحث عن تلميحات في أسماء الملفات والبيانات الوصفية

3. الاستغلال
   - تطبيق التقنيات المعروفة
   - البحث عن رسائل الخطأ في Google
   - تجربة الحمولات الشائعة

4. التقاط العلم
   - البحث عن صيغة العلم: CTF{...}
   - فحص جميع المخرجات
   - إرسال العلم والتحقق من صحته
```
