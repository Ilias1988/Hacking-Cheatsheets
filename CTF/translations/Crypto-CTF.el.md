## Πριν ξεκινήσετε

Η **κωδικοποίηση (encoding)** αλλάζει τον τρόπο αναπαράστασης δεδομένων, όπως Base64 ή hex, και δεν παρέχει από μόνη της μυστικότητα. Η **κρυπτογράφηση (encryption)** προστατεύει περιεχόμενο με κλειδί και συγκεκριμένο αλγόριθμο. Μια **συνάρτηση κατακερματισμού (hash)** παράγει αποτύπωμα δεδομένων· δεν αντιμετωπίζεται ως κρυπτογράφηση με αντίστροφη αποκρυπτογράφηση.

Στο **hash cracking** δοκιμάζουμε υποψήφιες τιμές και συγκρίνουμε τα αποτυπώματά τους. Η **παραγοντοποίηση** αναζητά παράγοντες ενός ακεραίου. Το **XOR** είναι δυαδική πράξη που χρησιμοποιείται στα παραδείγματα με bytes, ενώ ο **RSA** είναι ασύμμετρο κρυπτογραφικό σύστημα με μαθηματικές προϋποθέσεις.

Ξεκινήστε από τη μορφή και το μήκος των δεδομένων και τις πληροφορίες της εκφώνησης. Ένα εργαλείο αναγνώρισης hash ή η λειτουργία Magic του CyberChef δίνει υποθέσεις που χρειάζονται έλεγχο. Οι εντολές του πρωτοτύπου προϋποθέτουν εγκατεστημένα εργαλεία και τα αντίστοιχα αρχεία. Δεν υποστηρίζεται ότι κάθε hash ή κάθε παράμετρος RSA μπορεί να ανακτηθεί με αυτά τα παραδείγματα.

## 🔤 Κωδικοποίηση και αποκωδικοποίηση

### Base64
```bash
echo "string" | base64           # Κωδικοποίηση
echo "c3RyaW5n" | base64 -d      # Αποκωδικοποίηση
```

### Δεκαεξαδική αναπαράσταση (Hex)
```bash
echo "string" | xxd -p           # Κωδικοποίηση
echo "737472696e67" | xxd -r -p  # Αποκωδικοποίηση
```

### ROT13
```bash
echo "string" | tr 'A-Za-z' 'N-ZA-Mn-za-m'
```

### ASCII
```python
# Python
chr(65)      # → 'A'
ord('A')     # → 65
```

## 🔑 RSA

### Βασικές μαθηματικές σχέσεις RSA

Οι σχέσεις αναφέρονται στη βασική περίπτωση RSA με διαφορετικούς πρώτους p και q και κατάλληλο e ώστε να υπάρχει ο αρθρωτός αντίστροφος. Το d είναι ιδιωτικός εκθέτης και δεν περιγράφει μόνο του όλη τη δομή ιδιωτικού κλειδιού. Το ^ δηλώνει δύναμη στη μαθηματική σημειογραφία εδώ· στην Python είναι τελεστής XOR.

```
n = p * q           (δημόσιο μέτρο)
φ(n) = (p-1)(q-1)   (συνάρτηση Euler για διαφορετικούς πρώτους p, q)
d = e⁻¹ mod φ(n)    (ιδιωτικός εκθέτης)
c = m^e mod n       (κρυπτογράφηση)
m = c^d mod n       (αποκρυπτογράφηση)
```

### RsaCtfTool
```bash
# Παράδειγμα εγκατάστασης
pip3 install rsactftool

# Παραδείγματα ανάλυσης RSA
rsactftool --publickey pub.pem --private
rsactftool --publickey pub.pem --uncipherfile cipher.txt
```

### Παραγοντοποίηση
```

```

## 🔒 Αναζήτηση αρχικού δεδομένου από hash

### Εκτίμηση τύπου hash
```bash
hashid 'hash_value'
hash-identifier
```

### Δοκιμή υποψήφιων τιμών
```bash
# John
john --wordlist=rockyou.txt hash.txt

# Hashcat
hashcat -m 0 hash.txt rockyou.txt      # MD5
hashcat -m 100 hash.txt rockyou.txt    # SHA1
hashcat -m 1400 hash.txt rockyou.txt   # SHA256
```

### Διαδικτυακές υπηρεσίες

## 🧮 XOR

Η συνάρτηση απαιτεί μη κενό κλειδί σε μορφή ακολουθίας bytes. Το ciphertext του δεύτερου αποσπάσματος πρέπει να έχει ήδη οριστεί. Η παραγωγή αποτελεσμάτων για 256 τιμές δεν επιλέγει από μόνη της τη σωστή λύση.


```python
# Παράδειγμα XOR με Python
def xor(data, key):
    return bytes([b ^ key[i % len(key)] for i, b in enumerate(data)])

# Δοκιμή όλων των κλειδιών XOR ενός byte
for key in range(256):
    result = bytes([b ^ key for b in ciphertext])
```
