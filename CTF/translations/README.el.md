## Πριν ξεκινήσετε

Το **CTF (Capture The Flag)** είναι άσκηση ασφάλειας όπου λύνουμε μια πρόκληση για να βρούμε μια προκαθορισμένη απάντηση, το **flag**. Η απάντηση μπορεί να μοιάζει με flag{...}, αλλά η σωστή μορφή ορίζεται από τη συγκεκριμένη διοργάνωση.

Οι κατηγορίες εδώ είναι **Web** για εφαρμογές ιστού, **Crypto** για κρυπτογραφία και κωδικοποιήσεις, **Reverse Engineering** για κατανόηση προγραμμάτων, **Forensics** για διερεύνηση αρχείων και δεδομένων και **Pwn/Binary** για αδυναμίες εκτελέσιμων. Δεν χρειάζεται κάθε άσκηση όλα τα εργαλεία του πίνακα.

Διαβάστε πρώτα την εκφώνηση, κρατήστε σημειώσεις για τις παρατηρήσεις σας και επιλέξτε τεχνική με βάση τα ευρήματα. Ένα **payload** είναι η είσοδος ή ακολουθία δεδομένων μιας δοκιμής. Ένα **binary** είναι εκτελέσιμο ή μεταγλωττισμένο αρχείο. Ένα **write-up** καταγράφει τα βήματα και το σκεπτικό της λύσης.

Οι εντολές, τα ονόματα αρχείων, τα δοκιμαστικά payloads και τα bytes διατηρούνται από το αγγλικό πρωτότυπο. Πρόκειται για παραδείγματα που απαιτούν αρχεία, εκδόσεις και περιβάλλον της αντίστοιχης άσκησης. Εργαστείτε στα συστήματα του CTF ή στο δικό σας εργαστήριο, σύμφωνα με τους κανόνες της διοργάνωσης.

## 🔥 Σύντομα παραδείγματα εντολών CTF

### Ασφάλεια ιστού (Web)
```bash
# SQLi
sqlmap -u "http://url?id=1" --dbs

# Αναζήτηση πιθανών καταλόγων από λίστα
gobuster dir -u http://url -w /usr/share/wordlists/dirb/common.txt
```

### Κρυπτογραφία (Crypto)
```bash
# Εκτίμηση τύπου hash
hashid 'hash_string'
hash-identifier

# Αποκωδικοποίηση Base64
echo "string" | base64 -d
```

### Ψηφιακή διερεύνηση (Forensics)
```bash
# Αναγνώριση τύπου αρχείου
file unknown_file
binwalk unknown_file

# Εξαγωγή αναγνώσιμων συμβολοσειρών
strings -n 6 file | grep -i flag
```

### Εκμετάλλευση εκτελέσιμων (Pwn)
```bash
# Έλεγχος μηχανισμών προστασίας
checksec binary

# Εκκίνηση με GDB
gdb ./binary
```

## 📋 Μεθοδολογία επίλυσης CTF

```
1. ΑΡΧΙΚΗ ΕΞΕΤΑΣΗ
   - Διαβάστε προσεκτικά την περιγραφή της άσκησης
   - Κατεβάστε τα αρχεία που παρέχονται
   - Αναγνωρίστε την κατηγορία (web/crypto/pwn/κ.λπ.)

2. ΔΙΕΡΕΥΝΗΣΗ
   - Χρησιμοποιήστε τα κατάλληλα εργαλεία
   - Εξετάστε προφανείς ενδείξεις αδυναμιών
   - Αναζητήστε στοιχεία σε ονόματα αρχείων και μεταδεδομένα

3. ΕΠΙΛΥΣΗ
   - Εφαρμόστε τεχνικές που ταιριάζουν στα ευρήματα
   - Αναζητήστε εξηγήσεις μηνυμάτων σφάλματος
   - Δοκιμάστε κατάλληλα payloads μέσα στην άσκηση

4. ΕΥΡΕΣΗ ΤΟΥ FLAG
   - Αναζητήστε την αναμενόμενη μορφή, όπως CTF{...}
   - Εξετάστε τα σχετικά αποτελέσματα
   - Υποβάλετε την απάντηση και επιβεβαιώστε ότι έγινε δεκτή
```
