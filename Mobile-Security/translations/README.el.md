## Πριν ξεκινήσετε

Ο έλεγχος ασφάλειας μιας εφαρμογής κινητού εξετάζει το ίδιο το πακέτο εφαρμογής, τα δεδομένα που αποθηκεύει και την επικοινωνία του με υπηρεσίες. Η ασφάλεια του διακομιστή δεν αποδεικνύεται από την ανάλυση της εφαρμογής και η προστασία της συσκευής δεν αντικαθιστά τους ελέγχους της εφαρμογής.

**Βασικοί όροι:** Το **APK** είναι πακέτο εφαρμογής Android και το **IPA** πακέτο εφαρμογής iOS. **Στατική ανάλυση** είναι εξέταση αρχείων χωρίς εκτέλεση της εφαρμογής. **Δυναμική ανάλυση** είναι παρατήρηση της συμπεριφοράς της ενώ εκτελείται. **Reverse engineering** είναι η διερεύνηση του τρόπου λειτουργίας από το διαθέσιμο πακέτο ή εκτελέσιμο. **Instrumentation / hooking** είναι παρακολούθηση ή παρέμβαση σε κλήσεις κώδικα κατά την εκτέλεση.

Το **root** στο Android και το **jailbreak** στο iOS αφορούν διαφορετικές παρεμβάσεις που μπορούν να επιτρέψουν πρόσβαση πέρα από τους συνηθισμένους περιορισμούς. Δεν υπάρχουν σε κάθε συσκευή και δεν αποτελούν υποχρεωτικό βήμα για κάθε είδος ελέγχου. Η συμβατότητα εξαρτάται από έκδοση λειτουργικού, συσκευή, εφαρμογή και εργαλεία.

**Δίκτυο:** Ο **proxy** μεσολαβεί στην επικοινωνία. Το **TLS** προστατεύει τη σύνδεση και τα πιστοποιητικά βοηθούν στην επαλήθευση της ταυτότητας του διακομιστή. Το **certificate pinning** προσθέτει περιορισμό σε συγκεκριμένα πιστοποιητικά ή κλειδιά. Ο όρος «SSL pinning» της πηγής διατηρείται όπου εμφανίζεται σε ονόματα εντολών.

**Ανάγνωση παραδειγμάτων:** Οι εντολές, οι κλάσεις, τα ονόματα μεθόδων και τα μοτίβα της πηγής διατηρούνται. Οι τίτλοι, τα σχόλια και οι οδηγίες εξηγούνται στα ελληνικά. Ονόματα όπως `com.target.app`, IP, `APP-UUID` και διαδρομές είναι ενδεικτικά. Τα παραδείγματα δεν έχουν εκτελεστεί στο πλαίσιο της μετάφρασης. Οι αλλαγές σε πιστοποιητικά, proxy ή εγκατεστημένες εφαρμογές αφορούν αποκλειστικά τη συσκευή του εξουσιοδοτημένου εργαστηρίου.

## 🎯 Έλεγχος ασφάλειας εφαρμογών κινητών

Ο έλεγχος ασφάλειας εφαρμογών κινητών εξετάζει αδυναμίες στις ακόλουθες περιοχές:
- 📦 **Πακέτο εφαρμογής:** ανάλυση αρχείων APK ή IPA
- 💾 **Αποθήκευση δεδομένων:** έλεγχος ασφάλειας τοπικών αρχείων και ρυθμίσεων
- 🔐 **Ταυτοποίηση:** έλεγχος μηχανισμών σύνδεσης και επαλήθευσης χρήστη
- 🌐 **Δίκτυο:** έλεγχος ασφάλειας επικοινωνιών
- 🔑 **Κρυπτογραφία:** έλεγχος αλγορίθμων, κλειδιών και χρήσης κρυπτογράφησης
- 🛡️ **Πλατφόρμα:** αδυναμίες που σχετίζονται με το λειτουργικό σύστημα

## 🛠️ Βασικά εργαλεία ελέγχου εφαρμογών κινητών

| Εργαλείο | Πλατφόρμα | Σκοπός |
| ------ | ---------- | --------- |
| **Frida** | Android και iOS | Παρατήρηση και παρέμβαση σε εφαρμογή κατά την εκτέλεσή της |
| **Διερεύνηση με Objection** | Android και iOS | Διερεύνηση εφαρμογής κινητού κατά την εκτέλεσή της |
| **MobSF** | Android και iOS | Αυτοματοποιημένη ανάλυση ασφάλειας |
| **jadx** | Android | Ανακατασκευή αναγνώσιμου κώδικα από APK |
| **apktool** | Android | Αντίστροφη ανάλυση περιεχομένου APK |
| **Burp Suite** | Android και iOS | Παρεμβολή στην επικοινωνία για έλεγχο της κίνησης |
| **Ghidra** | Android και iOS | Ανάλυση εκτελέσιμου κώδικα |
| **Έλεγχος επιφάνειας επίθεσης με drozer** | Android | Έλεγχος ασφάλειας |

### Παραδείγματα εγκατάστασης εργαλείων

Η εγκατάσταση εργαλείων στον υπολογιστή δεν αρκεί για να είναι έτοιμη η συσκευή. Η σύνδεση, ο agent ή server και οι εκδόσεις πρέπει να είναι συμβατά. Τα δοχεία Docker και οι διευθύνσεις εγκατάστασης της πηγής είναι παραδείγματα προς έλεγχο.

```bash
# Frida
pip install frida-tools

# Objection
pip install objection

# MobSF σε περιβάλλον Docker
docker pull opensecurity/mobile-security-framework-mobsf
docker run -p 8000:8000 opensecurity/mobile-security-framework-mobsf

# jadx
# Λήψη από https://github.com/skylot/jadx/releases

# apktool
# Λήψη από https://ibotpeaches.github.io/Apktool/install/

# drozer
pip install drozer
```

## 📊 Βασικές κατηγορίες κινδύνων OWASP Mobile Top 10 (2024)

Ο πίνακας αποδίδει τις κατηγορίες της έκδοσης 2024. Είναι χάρτης κινδύνων και όχι πλήρης λίστα δοκιμών. Δείτε την [επίσημη σελίδα OWASP Mobile Top 10](https://owasp.org/projects/mobile-top-10).


| # | Κατηγορία αδυναμίας | Περιγραφή |
| --- | --------------- | ------------- |
| M1 | Μη ορθή χρήση στοιχείων σύνδεσης | Στοιχεία ενσωματωμένα στον κώδικα και μη ασφαλής αποθήκευση |
| M2 | Ανεπαρκής ασφάλεια αλυσίδας εφοδιασμού λογισμικού | Κακόβουλα πακέτα ανάπτυξης ή παραβιασμένες βιβλιοθήκες |
| M3 | Μη ασφαλής ταυτοποίηση ή έλεγχος δικαιωμάτων | Αδύναμη ταυτοποίηση και προβληματικός έλεγχος πρόσβασης |
| M4 | Ανεπαρκής επαλήθευση εισόδου και εξόδου | Εγχύσεις δεδομένων και εκτέλεση κώδικα ιστού σε WebViews |
| M5 | Μη ασφαλής επικοινωνία | Απουσία TLS ή προβλήματα επαλήθευσης πιστοποιητικών |
| M6 | Ανεπαρκείς μηχανισμοί προστασίας ιδιωτικότητας | Διαρροή προσωπικών δεδομένων και υπερβολικά δικαιώματα |
| M7 | Ανεπαρκής προστασία του εκτελέσιμου | Έλλειψη προστασίας από ανάλυση ή μη εξουσιοδοτημένη μεταβολή |
| M8 | Μη ασφαλείς ρυθμίσεις | Ενεργή αποσφαλμάτωση και μη ασφαλείς προεπιλογές |
| M9 | Μη ασφαλής αποθήκευση δεδομένων | Αποθήκευση ή καταγραφή ευαίσθητων δεδομένων χωρίς κρυπτογράφηση |
| M10 | Ανεπαρκής κρυπτογραφική προστασία | Αδύναμοι αλγόριθμοι και κλειδιά ενσωματωμένα στον κώδικα |

## 🔗 Γρήγορη αναφορά εντολών Frida

Η επιλογή `-f` εκκινεί την εφαρμογή υπό παρακολούθηση, ενώ η σύνδεση σε ήδη εκτελούμενη διεργασία είναι διαφορετική ενέργεια. Επιλογές όπως `--no-pause` και η σύνταξη Objection της πηγής απαιτούν έλεγχο στην εγκατεστημένη έκδοση. Δείτε την [τεκμηρίωση Frida CLI](https://frida.re/docs/frida-cli/).


```bash
# Εμφάνιση διεργασιών που εκτελούνται
frida-ps -U

# Το -f του παραδείγματος εκκινεί την εφαρμογή υπό παρακολούθηση
frida -U -f com.app.package

# Εκκίνηση εφαρμογής με φόρτωση σεναρίου JavaScript
frida -U -f com.app.package -l script.js --no-pause

# Διερεύνηση εφαρμογής με Objection
objection -g com.app.package explore
```
