## 🎯 اختبار أمن تطبيقات الأجهزة المحمولة

يشمل اختبار أمن تطبيقات الأجهزة المحمولة تحديد الثغرات في الجوانب التالية:
- 📦 **حزمة التطبيق** - تحليل APK/IPA
- 💾 **تخزين البيانات** - التخزين المحلي غير الآمن
- 🔐 **المصادقة** - آليات مصادقة ضعيفة
- 🌐 **الشبكة** - اتصالات غير آمنة
- 🔑 **التشفير** - تشفير ضعيف
- 🛡️ **المنصة** - ثغرات خاصة بنظام التشغيل

## 🛠️ أدوات أساسية لأمن الأجهزة المحمولة

| الأداة | المنصة | الغرض |
|------|----------|---------|
| **Frida** | كلاهما | فحص السلوك وتعديله أثناء التشغيل (Dynamic Instrumentation) |
| **Objection** | كلاهما | استكشاف تطبيقات الأجهزة المحمولة أثناء التشغيل |
| **MobSF** | كلاهما | التحليل الأمني الآلي |
| **jadx** | Android | فك تجميع APK |
| **apktool** | Android | الهندسة العكسية لحزم APK |
| **Burp Suite** | كلاهما | اعتراض حركة المرور |
| **Ghidra** | كلاهما | تحليل الملفات التنفيذية |
| **drozer** | Android | التقييم الأمني |

<a id="-quick-reference-frida-commands"></a>
## 🔗 مرجع سريع: أوامر Frida

> **ملاحظة إصدار:** يحتفظ الدليل بأوامر الأصل. في Frida، يستخدم `-f` لتشغيل عملية جديدة؛ و`--no-pause` خيار من أمثلة أقدم، بينما يعرّف [المصدر الرسمي الحالي](https://github.com/frida/frida-tools/blob/main/frida_tools/repl.py) خيار `--pause`. راجع خيارات الإصدار المثبّت قبل تطبيق مثال.


```bash
# عرض العمليات قيد التشغيل
frida-ps -U

# الاتصال بعملية
frida -U -f com.app.package

# تشغيل التطبيق مع سكربت
frida -U -f com.app.package -l script.js --no-pause

# الاستكشاف باستخدام Objection
objection -g com.app.package explore
```
