## 🎯 Тестирование безопасности мобильных приложений

Тестирование безопасности мобильных приложений помогает находить уязвимости в следующих областях:
- 📦 **Пакет приложения** — анализ APK/IPA
- 💾 **Хранение данных** — небезопасное локальное хранение
- 🔐 **Аутентификация** — слабые механизмы проверки подлинности
- 🌐 **Сеть** — незащищённый обмен данными
- 🔑 **Криптография** — ненадёжное шифрование
- 🛡️ **Платформа** — уязвимости, специфичные для ОС

## 🛠️ Основные инструменты для проверки мобильных приложений

| Инструмент | Платформа | Назначение |
|------|----------|---------|
| **Frida** | Обе | Динамическая инструментация (исследование и изменение работы процесса) |
| **Objection** | Обе | Исследование мобильного приложения во время выполнения |
| **MobSF** | Обе | Автоматизированный анализ безопасности |
| **jadx** | Android | Декомпиляция APK |
| **apktool** | Android | Обратная разработка APK |
| **Burp Suite** | Обе | Перехват трафика |
| **Ghidra** | Обе | Анализ исполняемых файлов |
| **drozer** | Android | Оценка безопасности |

### Быстрая установка инструментов
```bash
# Frida
pip install frida-tools

# Objection
pip install objection

# MobSF (Docker)
docker pull opensecurity/mobile-security-framework-mobsf
docker run -p 8000:8000 opensecurity/mobile-security-framework-mobsf

# jadx
# Скачать с https://github.com/skylot/jadx/releases

# apktool
# Скачать с https://ibotpeaches.github.io/Apktool/install/

# drozer
pip install drozer
```

## 📊 OWASP Mobile Top 10 (2024)

| # | Уязвимость | Описание |
|---|---------------|-------------|
| M1 | Ненадлежащее использование учётных данных | Учётные данные в коде, небезопасное хранение |
| M2 | Недостаточная безопасность цепочки поставок | Вредоносные SDK, скомпрометированные библиотеки |
| M3 | Небезопасная аутентификация и авторизация | Слабая проверка подлинности, ошибки контроля доступа |
| M4 | Недостаточная проверка входных и выходных данных | Инъекции, XSS в WebView |
| M5 | Небезопасный обмен данными | Отсутствие TLS, проблемы с сертификатами |

## 🔗 Краткий справочник: команды Frida

```bash
# Перечислить запущенные процессы
frida-ps -U

# Подключиться к процессу
frida -U -f com.app.package

# Запустить процесс со скриптом
frida -U -f com.app.package -l script.js --no-pause

# Исследование через Objection
objection -g com.app.package explore
```

---

> **Уточнение к оригиналу:** параметр `-f` запускает новый процесс приложения (spawn), хотя комментарий выше говорит о подключении. `--no-pause` — параметр старых примеров: в текущем [исходном коде frida-tools](https://github.com/frida/frida-tools/blob/main/frida_tools/repl.py) предусмотрен `--pause`, а продолжение после запуска включено по умолчанию. Команды оригинала сохранены без изменений.
