## Πριν ξεκινήσετε

Το **Hashcat** δοκιμάζει υποψήφιους κωδικούς σε τοπικά hashes ή κατάλληλα εξαγόμενα δεδομένα. Μπορεί να αξιοποιήσει **GPU** (κάρτα γραφικών), **CPU** (επεξεργαστή) ή άλλα υποστηριζόμενα backends. Η ταχύτητα εξαρτάται έντονα από αλγόριθμο, υλικό, οδηγούς και είδος δοκιμών.

Οι δύο βασικές επιλογές έχουν διαφορετικό ρόλο: **-m** επιλέγει τύπο hash, ενώ **-a** επιλέγει τρόπο παραγωγής υποψήφιων κωδικών. Η **wordlist** είναι λίστα λέξεων, η **mask** είναι μοτίβο θέσεων χαρακτήρων και τα **rules** μετασχηματίζουν λέξεις. Ένα **kernel** είναι η υπολογιστική υλοποίηση ενός ελέγχου. Το **keyspace** είναι το σύνολο υποψήφιων τιμών που θα δοκιμαστούν.

Πρώτα επιβεβαιώστε τη μορφή εισόδου και μετά επιλέξτε τον κατάλληλο τρόπο δοκιμών. Οι εντολές, τα hashes, οι μάσκες και οι κανόνες του πρωτοτύπου παραμένουν αμετάβλητα. Οι σημειώσεις εξηγούν ελλιπή παραδείγματα, διαφορές εκδόσεων και περιορισμούς.

## 🎯 Εισαγωγή

**Το Hashcat** είναι εργαλείο ανάκτησης κωδικών και ελέγχου αντοχής τους. Υποστηρίζει πολλούς τύπους hashes και μπορεί να αξιοποιήσει GPU και άλλα υποστηριζόμενα υπολογιστικά backends.

### Βασικά χαρακτηριστικά

| Χαρακτηριστικό | Περιγραφή |
| --------- | ------------- |
| **350+ Τύποι hashes** | MD5, SHA, NTLM, bcrypt, WPA και άλλοι τύποι |
| **Επιτάχυνση με GPU** | Υποστήριξη κατάλληλων backends NVIDIA, AMD και Intel |
| **Πολλαπλές GPU** | Χρήση πολλών συσκευών· η κατανομή σε υπολογιστές απαιτεί πρόσθετη οργάνωση |
| **Πολλαπλοί τρόποι δοκιμών** | Λίστες λέξεων, δοκιμές συνδυασμών, υβριδικοί τρόποι και άλλοι |
| **Εκτεταμένοι κανόνες μετασχηματισμού** | Προχωρημένη παραγωγή παραλλαγών λέξεων |
| **Πολλαπλές πλατφόρμες** | Linux, Windows και macOS, ανάλογα με την έκδοση |

### Σύγκριση Hashcat και John the Ripper

> **Ενδεικτική σύγκριση:** Η ταχύτητα και το πλήθος formats αλλάζουν ανά έκδοση, αλγόριθμο και υλικό. Η ένδειξη «No» για αναγνώριση hash στο Hashcat είναι παρωχημένη: υπάρχει η επιλογή `--identify`. Η αναγνώριση προτείνει συμβατούς αλγορίθμους και χρειάζεται επιβεβαίωση. Δείτε την [επίσημη βοήθεια Hashcat](https://hashcat.net/wiki/doku.php?id=hashcat).

## 📥 Εγκατάσταση

> **Οδηγοί και πακέτα:** Τα ονόματα `hashcat-nvidia` και `hashcat-amd` είναι παραδείγματα του πρωτοτύπου, όχι καθολικά διαθέσιμα πακέτα. Χρειάζεται υποστηριζόμενο runtime για το υλικό και την έκδοση. Η εντολή `-I` εμφανίζει τις υπολογιστικές συσκευές που αναγνωρίζει η εγκατάσταση.


### Kali Linux
```bash
sudo apt update && sudo apt install hashcat

# Παράδειγμα εγκατάστασης υποστήριξης OpenCL· ελέγξτε τη διανομή
sudo apt install hashcat-nvidia  # NVIDIA
sudo apt install hashcat-amd     # AMD
```

### Ubuntu/Debian
```bash
sudo apt install hashcat
```

### Windows
```bash
# Λήψη από τον επίσημο ιστότοπο
https://hashcat.net/hashcat/

# Αποσυμπίεση και εκτέλεση από τον φάκελο
hashcat.exe -h
```

### Εγκατάσταση από πηγαίο κώδικα
```bash
git clone https://github.com/hashcat/hashcat.git
cd hashcat
make
./hashcat -h
```

### Επιβεβαίωση εγκατάστασης
```bash
hashcat --version
hashcat -I                    # Προβολή διαθέσιμων υπολογιστικών συσκευών
hashcat -b                    # Εκτέλεση δοκιμής επιδόσεων
```

## ⌨️ Βασική σύνταξη

### Γενική σύνταξη
```bash
hashcat [options] hash|hashfile [dictionary|mask]
```

### Βασικές επιλογές

| Επιλογή | Περιγραφή |
| -------- | ------------- |
| `-m` | Τύπος hash, αριθμητικό mode |
| `-a` | Τρόπος παραγωγής υποψήφιων κωδικών |
| `-o` | Αρχείο εξόδου |
| `-r` | Αρχείο κανόνων |
| `--show` | Εμφάνιση κωδικών που έχουν ανακτηθεί |
| `--status` | Ενεργοποίηση εμφάνισης κατάστασης |
| `-w` | Προφίλ φόρτου εργασίας (1-4) |
| `--force` | Παράκαμψη ορισμένων ελέγχων και προειδοποιήσεων |
| `-O` | Βελτιστοποιημένοι υπολογιστικοί kernels, με περιορισμούς |

### Πρώτη γνωριμία
```bash
# Βασικές δοκιμές από λίστα λέξεων
hashcat -m 0 -a 0 hash.txt wordlist.txt

# Εμφάνιση ανακτημένων αποτελεσμάτων
hashcat -m 0 hash.txt --show

# Προβολή παραδειγμάτων hashes
hashcat -m 0 --example-hashes
```

## 🎮 Τρόποι παραγωγής υποψήφιων κωδικών

### Επισκόπηση

| Λειτουργία | Όνομα | Περιγραφή |
| ------ | ------ | ------------- |
| `-a 0` | Λίστα λέξεων (Dictionary) | Δοκιμές από λίστα λέξεων |
| `-a 1` | Συνδυασμός λιστών (Combination) | Συνένωση λέξεων από δύο λίστες |
| `-a 3` | Δοκιμές συνδυασμών | Δοκιμές βάσει μοτίβου |
| `-a 6` | Υβριδικό: λίστα λέξεων και μοτίβο | Λίστα λέξεων και έπειτα μοτίβο |
| `-a 7` | Υβριδικό: μοτίβο και λίστα λέξεων | Μοτίβο και έπειτα λίστα λέξεων |
| `-a 9` | Αντιστοίχιση (Association) | Υποψήφιες λέξεις αντιστοιχισμένες ανά hash |

### Δοκιμές από λίστα λέξεων (-a 0)

```bash
# Βασικές δοκιμές από λίστα λέξεων
hashcat -m 0 -a 0 hash.txt wordlist.txt

# Με κανόνες μετασχηματισμού
hashcat -m 0 -a 0 hash.txt wordlist.txt -r rules/best64.rule

# Πολλαπλές λίστες λέξεων
hashcat -m 0 -a 0 hash.txt wordlist1.txt wordlist2.txt
```

### Συνδυασμός δύο λιστών (-a 1)

Συνενώνει λέξεις από δύο λίστες.

```bash
# Συνένωση λέξεων από δύο λίστες
hashcat -m 0 -a 1 hash.txt wordlist1.txt wordlist2.txt

# Συνδυασμοί word1word2
```

### Δοκιμές συνδυασμών βάσει μοτίβου (-a 3)

> **Ελλιπής μάσκα:** Το παράδειγμα που περιγράφεται ως «4-8 ψηφία» έχει μόνο τέσσερις θέσεις `?d`. Το `--increment-max=8` δεν προσθέτει μόνο του θέσεις στη μάσκα. Η μέγιστη μάσκα πρέπει να περιγράφει το επιδιωκόμενο μήκος. Δείτε την [τεκμηρίωση masks](https://hashcat.net/wiki/doku.php?id=mask_attack).


```bash
# 6 πεζά γράμματα
hashcat -m 0 -a 3 hash.txt ?l?l?l?l?l?l

# Στόχος του παραδείγματος: 4-8 ψηφία· η μάσκα έχει μόνο 4 θέσεις
hashcat -m 0 -a 3 hash.txt ?d?d?d?d --increment --increment-min=4 --increment-max=8

# Προσαρμοσμένο σύνολο χαρακτήρων
hashcat -m 0 -a 3 hash.txt -1 ?l?d ?1?1?1?1?1?1
```

### Υβριδικοί τρόποι (-a 6 και -a 7)

```bash
# Λίστα λέξεων και προσθήκη μοτίβου στο τέλος
hashcat -m 0 -a 6 hash.txt wordlist.txt ?d?d?d?d

# Μοτίβο στην αρχή και έπειτα λέξη λίστας
hashcat -m 0 -a 7 hash.txt ?d?d?d?d wordlist.txt
```

## 🎭 Δοκιμές βάσει μοτίβου (Mask)

### Σύμβολα συνόλων χαρακτήρων

> **Κυριολεκτικά σύμβολα:** Ο πίνακας διατηρεί τους χαρακτήρες που παραθέτει το πρωτότυπο, με διορθωμένη μορφοποίηση. Το πραγματικό `?s` περιλαμβάνει επίσης κενό και backslash, που λείπουν από την αρχική παράθεση. Εισαγωγικά και ειδικοί χαρακτήρες χρειάζονται σωστή διαφυγή ανά shell. Τα `?a` και `?b` δεν έχουν την ίδια σημασία.


| Σύμβολο αντικατάστασης | Χαρακτήρες |
| ------------- | ------------ |
| `?l` | abcdefghijklmnopqrstuvwxyz |
| `?u` | ABCDEFGHIJKLMNOPQRSTUVWXYZ |
| `?d` | 0123456789 |
| `?h` | 0123456789abcdef |
| `?H` | 0123456789ABCDEF |
| `?s` | <code>!&quot;#$%&amp;&#x27;()*+,-./:;&lt;=&gt;?@[]^_&#96;{&#124;}~</code> |
| `?a` | ?l?u?d?s |
| `?b` | 0x00 - 0xff |

### Προσαρμοσμένα σύνολα χαρακτήρων

```bash
# Ορισμός προσαρμοσμένου συνόλου χαρακτήρων
hashcat -a 3 -1 ?l?d hash.txt ?1?1?1?1?1?1

# Πολλαπλά προσαρμοσμένα σύνολα χαρακτήρων
hashcat -a 3 -1 abc -2 123 hash.txt ?1?2?1?2

# Ειδικοί χαρακτήρες
hashcat -a 3 -1 '!@#$%' hash.txt pass?1?1?1?1
```

### Δοκιμές αυξανόμενου μήκους (Increment)

```bash
# Δοκιμές μήκους 1-8
hashcat -a 3 hash.txt ?a?a?a?a?a?a?a?a --increment

# Ορισμός ελάχιστου και μέγιστου μήκους
hashcat -a 3 hash.txt ?a?a?a?a?a?a?a?a --increment --increment-min=4 --increment-max=8
```

### Συνήθη παραδείγματα μοτίβων

```bash
# 8 πεζά γράμματα
?l?l?l?l?l?l?l?l

# Η λέξη password και 4 ψηφία
password?d?d?d?d

# Κεφαλαίο, πεζά γράμματα και ψηφία
?u?l?l?l?l?l?d?d

# Μοτίβο τύπου Winter2024
?u?l?l?l?l?l?d?d?d?d

# Μοτίβο δέκα ψηφίων, ενδεικτικό αριθμού τηλεφώνου
?d?d?d?d?d?d?d?d?d?d
```

## 📜 Κανόνες μετασχηματισμού

### Έτοιμα αρχεία κανόνων

```bash
# Τοποθεσία
ls /usr/share/hashcat/rules/

# Συνήθη σύνολα κανόνων
best64.rule           # Σύνολο κανόνων Best64
rockyou-30000.rule    # Σύνολο 30000 κανόνων
d3ad0ne.rule          # Σύνολο κανόνων D3ad0ne
dive.rule             # Σύνολο κανόνων Dive
generated.rule        # Παραγόμενοι κανόνες
```

### Χρήση κανόνων

```bash
# Ένα αρχείο κανόνων
hashcat -m 0 -a 0 hash.txt wordlist.txt -r best64.rule

# Πολλαπλά αρχεία κανόνων
hashcat -m 0 -a 0 hash.txt wordlist.txt -r rule1.rule -r rule2.rule

# Παραγωγή τυχαίων κανόνων
hashcat -m 0 -a 0 hash.txt wordlist.txt -g 1000
```

### Συνήθεις πράξεις κανόνων

> **Παράδειγμα αντικατάστασης:** Στο `sXY`, τα X και Y είναι θέσεις για συγκεκριμένους χαρακτήρες. Η μετατροπή password → pa$$word του πίνακα είναι ενδεικτική, όχι το αποτέλεσμα του κυριολεκτικού sXY. Πολλαπλά αρχεία με `-r` μπορεί να συνδυάζουν μετασχηματισμούς και να αυξάνουν σημαντικά το πλήθος δοκιμών.


| Κανόνας | Περιγραφή | Παράδειγμα |
| ------ | ------------- | --------- |
| `:` | Διατήρηση της τιμής χωρίς αλλαγή | password |
| `l` | Μετατροπή όλων των γραμμάτων σε πεζά | PASSWORD → password |
| `u` | Μετατροπή όλων των γραμμάτων σε κεφαλαία | password → PASSWORD |
| `c` | Πρώτο γράμμα κεφαλαίο, τα υπόλοιπα πεζά | password → Password |
| `C` | Πρώτο γράμμα πεζό, τα υπόλοιπα κεφαλαία | password → pASSWORD |
| `t` | Εναλλαγή πεζών και κεφαλαίων | password → PASSWORD |
| `r` | Αντιστροφή σειράς χαρακτήρων | password → drowssap |
| `d` | Επανάληψη ολόκληρης της λέξης | pass → passpass |
| `$X` | Προσθήκη X στο τέλος | pass → passX |
| `^X` | Προσθήκη X στην αρχή | pass → Xpass |
| `sXY` | Αντικατάσταση χαρακτήρα X με Y | password → pa$$word |

## 💾 Διαχείριση συνεδριών

### Δημιουργία συνεδρίας
```bash
# Συνεδρία με συγκεκριμένο όνομα
hashcat -m 0 -a 0 hash.txt wordlist.txt --session=mysession

# Ενδεικτική θέση συνεδριών του πρωτοτύπου: ~/.hashcat/sessions/· ελέγξτε την έκδοσή σας
```

### Παύση και συνέχιση
```bash
# Παύση: πατήστε 'p' κατά τις δοκιμές
# Συνέχιση: πατήστε 'r' κατά τις δοκιμές

# Εναλλακτικά επαναφορά από γραμμή εντολών
hashcat --session=mysession --restore
```

### Πλήκτρα ελέγχου κατάστασης

Κατά τη διάρκεια των δοκιμών:
- `s` — εμφάνιση κατάστασης
- `p` — παύση
- `r` — συνέχιση
- `b` — παράλειψη του τρέχοντος σκέλους δοκιμών
- `c` — τερματισμός στο επόμενο σημείο επαναφοράς
- `q` — έξοδος

### Επιλογές αποτελεσμάτων

> **Διόρθωση μορφής εξόδου:** Το `--outfile-format=2` επιλέγει τον ανακτημένο κωδικό (plain), όχι hash:plain. Ο συνδυασμός hash και plain αντιστοιχεί σε `1,2`. Η γραμμή του παραδείγματος διατηρείται με διορθωμένο σχόλιο.

```bash
# Αποθήκευση σε αρχείο
hashcat -m 0 -a 0 hash.txt wordlist.txt -o cracked.txt

# Μορφή αποτελεσμάτων
hashcat -m 0 hash.txt --outfile-format=2    # Το --outfile-format=2 εμφανίζει τον ανακτημένο κωδικό· hash:plain αντιστοιχεί σε 1,2

# Εμφάνιση ανακτημένων αποτελεσμάτων
hashcat -m 0 hash.txt --show

# Εμφάνιση hashes που δεν έχουν ανακτηθεί
hashcat -m 0 hash.txt --left
```

## 🚀 Ρύθμιση απόδοσης GPU

> **Απόδοση και περιορισμοί:** Το `-O` μπορεί να περιορίζει το υποστηριζόμενο μήκος κωδικών. Το `--force` παρακάμπτει ελέγχους και δεν είναι γενική ρύθμιση επιδόσεων. Η προεπιλογή workload δεν πρέπει να συναχθεί από την ένδειξη default του πρωτοτύπου· ελέγξτε την τοπική βοήθεια. Τα -d και -D επιλέγουν διαφορετικά πράγματα: συσκευές και τύπους συσκευών αντίστοιχα.


### Προφίλ φόρτου εργασίας

| Προφίλ | Περιγραφή |
| --------- | ------------- |
| `-w 1` | Χαμηλός φόρτος για διαδραστική χρήση· η ένδειξη default του πρωτοτύπου χρειάζεται έλεγχο |
| `-w 2` | Μέτριος φόρτος |
| `-w 3` | Υψηλός φόρτος, πιθανή μειωμένη απόκριση της επιφάνειας εργασίας |
| `-w 4` | Μέγιστος φόρτος για σύστημα αφιερωμένο στις δοκιμές |

### Παραδείγματα ρυθμίσεων απόδοσης
```bash
# Παράδειγμα αυξημένου φόρτου εργασίας
hashcat -m 0 -a 0 hash.txt wordlist.txt -w 3 -O

# Βελτιστοποιημένοι kernels, με περιορισμούς μήκους κωδικού
hashcat -m 0 -a 0 hash.txt wordlist.txt -O

# Επιλογή συγκεκριμένης συσκευής
hashcat -m 0 -a 0 hash.txt wordlist.txt -d 1

# Επιλογή συσκευών τύπου GPU, όπου υποστηρίζεται
hashcat -m 0 -a 0 hash.txt wordlist.txt -D 2
```

### Επιλογές συσκευών

> **Περιορισμός πίνακα συσκευών:** Η δήλωση `-D 3 = FPGA` του πρωτοτύπου δεν αποτελεί γενική τρέχουσα οδηγία επιλογής FPGA. Τα υποστηριζόμενα backends και οι επιταχυντές εξαρτώνται από έκδοση και υλικό. Ελέγξτε τη βοήθεια της εγκατάστασης.

```bash
# Προβολή συσκευών
hashcat -I

# Επιλογή συγκεκριμένης συσκευής
hashcat -d 1 ...

# Τύποι υπολογιστικών συσκευών
# -D 1 = επεξεργαστής CPU
# -D 2 = κάρτα γραφικών GPU
# -D 3 = τύπος επιταχυντή κατά OpenCL· δεν εγγυάται υποστήριξη κάθε FPGA
```

### Δοκιμή επιδόσεων (Benchmark)
```bash
# Γενική δοκιμή επιδόσεων
hashcat -b

# Συγκεκριμένος τύπος hash
hashcat -b -m 0

# Δοκιμή επιδόσεων με --benchmark-all· δεν απενεργοποιεί το OpenCL
hashcat -b --benchmark-all
```

## 📊 Γρήγορη αναφορά

### Βασικές εντολές

| Εργασία | Εντολή |
| ------ | --------- |
| Δοκιμές MD5 από λίστα λέξεων | `hashcat -m 0 -a 0 hash.txt wordlist.txt` |
| Δοκιμές συνδυασμών για NT hashes | `hashcat -m 1000 -a 3 hash.txt ?a?a?a?a?a?a` |
| Δοκιμές SHA256 με κανόνες | `hashcat -m 1400 -a 0 hash.txt wordlist.txt -r rules.rule` |
| Εμφάνιση ανακτημένων αποτελεσμάτων | `hashcat -m 0 hash.txt --show` |
| Δοκιμή επιδόσεων (Benchmark) | `hashcat -b` |
| Προβολή συσκευών | `hashcat -I` |
| Επαναφορά συνεδρίας | `hashcat --session=name --restore` |

### Συνήθη modes τύπων hash

| Λειτουργία | Τύπος |
| ------ | ------ |
| 0 | MD5 |
| 100 | SHA1 |
| 1000 | NTLM |
| 1400 | SHA256 |
| 1800 | sha512crypt |
| 3200 | bcrypt |
| 22000 | WPA2 |

### Τρόποι παραγωγής υποψήφιων κωδικών

| Λειτουργία | Τύπος |
| ------ | ------ |
| -a 0 | Λίστα λέξεων (Dictionary) |
| -a 1 | Συνδυασμός λιστών (Combination) |
| -a 3 | Δοκιμές συνδυασμών |
| -a 6 | Υβριδικό: λίστα και μοτίβο |
| -a 7 | Υβριδικό: μοτίβο και λίστα |

## 💡 Συμβουλές και καλές πρακτικές

### Συμβουλές αποδοτικής χρήσης

1. **Ξεκινήστε με λίστα λέξεων και κανόνες**
   ```bash
   hashcat -m 0 -a 0 hash.txt rockyou.txt -r best64.rule
   ```

2. **Εξετάστε τους βελτιστοποιημένους kernels και τους περιορισμούς τους**
   ```bash
   hashcat -O ...
   ```

3. **Εξετάστε σχετικά μοτίβα**
   ```bash
   # Μοτίβο εποχής και έτους: Winter2024
   hashcat -a 3 -1 WSFJ -2 winterumeall hash.txt ?1?2?2?2?2?2?d?d?d?d
   ```

### Συμβουλές απόδοσης

```bash
# Παράδειγμα μέγιστου φόρτου· το --force δεν είναι γενική σύσταση
hashcat -m 0 -a 0 hash.txt wordlist.txt -w 4 -O --force

# Πολλαπλές GPU
hashcat -d 1,2 ...
```

### Ροή εργασίας

```
1. Αναγνώριση τύπου hash
2. Δοκιμές από λίστα λέξεων με κανόνες
3. Δοκιμές στοχευμένων μοτίβων (masks)
4. Δοκιμές πλήρων συνδυασμών, εφόσον είναι εφικτές
5. Δοκιμές υβριδικών τρόπων
```
