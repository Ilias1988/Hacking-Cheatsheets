## Πριν ξεκινήσετε

Η **κοινωνική μηχανική (Social Engineering)** εξετάζει πώς ένα παραπλανητικό αίτημα μπορεί να οδηγήσει σε αποκάλυψη πληροφοριών ή σε μη ασφαλή ενέργεια. **Phishing** λέγεται η παραπλάνηση με μηνύματα ή πλαστές σελίδες. **Pretexting** είναι το ψευδές πρόσχημα και η προσποιητή ταυτότητα που χρησιμοποιούνται για να γίνει πιστευτό το αίτημα. **OSINT** είναι η έρευνα πληροφοριών από δημόσιες πηγές.

Ξεκινήστε με τα είδη επιθέσεων και τις ύποπτες ενδείξεις. Ο οδηγός Phishing περιλαμβάνει εργαλεία και παραδείγματα μηνυμάτων, ενώ ο οδηγός Pretexting εξηγεί ρόλους, σενάρια και συμπεριφορές. Οι ψυχολογικοί μηχανισμοί περιγράφουν τάσεις, όχι κανόνες που ισχύουν για όλους τους ανθρώπους.

Το υλικό προορίζεται για εκπαίδευση και εξουσιοδοτημένες προσομοιώσεις με σαφή όρια. Οι εντολές, τα τεχνικά αναγνωριστικά και τα γραφικά των τίτλων διατηρούνται από το πρωτότυπο. Τα παραδείγματα μηνυμάτων είναι υποθετικά· δεν αποτελούν πραγματικές ειδοποιήσεις των εταιρειών που αναφέρονται.

## 🎯 Τι είναι η κοινωνική μηχανική;

Η κοινωνική μηχανική είναι η χειραγώγηση ανθρώπων ώστε να αποκαλύψουν εμπιστευτικές πληροφορίες ή να κάνουν ενέργειες που υπονομεύουν την ασφάλεια. Αξιοποιεί την εμπιστοσύνη, τις συνήθειες και την ανθρώπινη συμπεριφορά.

**Βασικοί μηχανισμοί:**
- 🎭 **Εξουσία ή κύρος:** τάση εμπιστοσύνης σε πρόσωπα που εμφανίζονται ως υπεύθυνοι ή ειδικοί.
- ⏰ **Αίσθηση επείγοντος:** η πίεση χρόνου μπορεί να περιορίσει τον έλεγχο ενός αιτήματος.
- 🤝 **Ανταπόδοση:** μια μικρή εξυπηρέτηση μπορεί να δημιουργήσει αίσθηση υποχρέωσης.
- 👥 **Συμπεριφορά των άλλων:** ο ισχυρισμός ότι «το έκαναν όλοι» μπορεί να επηρεάσει μια απόφαση.
- 😊 **Συμπάθεια:** η οικειότητα μπορεί να διευκολύνει την αποδοχή ενός αιτήματος.
- 📉 **Σπανιότητα:** μια υποτιθέμενη περιορισμένη ευκαιρία μπορεί να προκαλέσει βιαστική αντίδραση.

## 🛠️ Βασικά εργαλεία κοινωνικής μηχανικής

Η αναφορά σε «bypass 2FA» στο αγγλικό πρωτότυπο είναι υπεραπλούστευση. Υπάρχουν μέθοδοι ταυτοποίησης ανθεκτικές στο phishing· δείτε τις [κατηγορίες ταυτοποίησης της Microsoft](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-authentication-strengths). Οι διαθέσιμες δυνατότητες των εργαλείων εξαρτώνται από έκδοση και ρυθμίσεις.


| Εργαλείο | Χρήση | Τύπος |
| ------ | --------- | ------ |
| **GoPhish** | Πλαίσιο διαχείρισης προσομοιώσεων phishing | Ηλεκτρονικό ψάρεμα (Phishing) |
| **SET — Εργαλειοθήκη κοινωνικής μηχανικής** | Πλαίσιο εργαλείων κοινωνικής μηχανικής | Πολλαπλών χρήσεων |
| **Evilginx2** | Phishing μέσω ενδιάμεσου διακομιστή — περιορισμοί ως προς το 2FA | Ηλεκτρονικό ψάρεμα (Phishing) |
| **King Phisher** | Πλατφόρμα διαχείρισης προσομοιώσεων phishing | Ηλεκτρονικό ψάρεμα (Phishing) |
| **Modlishka** | Phishing με ενδιάμεσο reverse proxy | Ηλεκτρονικό ψάρεμα (Phishing) |
| **theHarvester** | Συλλογή διευθύνσεων email και ονομάτων domain | Συλλογή πληροφοριών |
| **Εργαλεία έρευνας LinkedIn** | Συλλογή δημόσιων πληροφοριών για εργαζομένους | OSINT |
| **Maltego** | Έρευνα δημόσιων πηγών και χαρτογράφηση συσχετίσεων | Συλλογή πληροφοριών |

### Παραδείγματα εγκατάστασης εργαλείων

Τα παραδείγματα χρησιμοποιούν διαφορετικά εργαλεία και προϋποθέτουν Linux ή κατάλληλο περιβάλλον με τα αντίστοιχα προγράμματα εγκατεστημένα. Το ZIP του GoPhish αφορά συγκεκριμένη έκδοση και αρχιτεκτονική, όχι εγγύηση ότι είναι η νεότερη. Δείτε την [επίσημη εγκατάσταση GoPhish](https://docs.getgophish.com/user-guide/installation).

```bash
# GoPhish
wget https://github.com/gophish/gophish/releases/download/v0.12.1/gophish-v0.12.1-linux-64bit.zip
unzip gophish-v0.12.1-linux-64bit.zip
./gophish

# SET — εργαλειοθήκη κοινωνικής μηχανικής
git clone https://github.com/trustedsec/social-engineer-toolkit
cd social-engineer-toolkit
pip install -r requirements.txt
python setoolkit

# Evilginx2
go install github.com/kgretzky/evilginx2@latest

# theHarvester
pip install theHarvester
theHarvester -d target.com -b all
```

## 📊 Είδη επιθέσεων κοινωνικής μηχανικής

| Είδος επίθεσης | Περιγραφή | Κανάλι προσέγγισης |
| ------------- | ------------- | -------- |
| **Ηλεκτρονικό ψάρεμα (Phishing)** | Παραπλανητικά email για κλοπή στοιχείων σύνδεσης | Email |
| **Στοχευμένο ηλεκτρονικό ψάρεμα (Spear Phishing)** | Στοχευμένο phishing σε συγκεκριμένα άτομα | Email |
| **Phishing με στόχο ανώτερα στελέχη (Whaling)** | Phishing με στόχο ανώτερα στελέχη | Email |
| **Τηλεφωνικό ψάρεμα (Vishing)** | Κοινωνική μηχανική μέσω τηλεφωνικής συνομιλίας | Τηλέφωνο |
| **Ψάρεμα μέσω SMS (Smishing)** | Phishing μέσω SMS | SMS |
| **Κατασκευή παραπλανητικού σεναρίου (Pretexting)** | Κατασκευή ψευδών σεναρίων για απόσπαση πληροφοριών | Διάφορα κανάλια |
| **Παραπλάνηση με δόλωμα (Baiting)** | Τοποθέτηση μολυσμένων μέσων, όπως USB, ως δολώματος | Φυσική παρουσία |
| **Απόσπαση πληροφοριών με αντάλλαγμα (Quid Pro Quo)** | Προσφορά ανταλλάγματος για πληροφορίες | Διάφορα κανάλια |
| **Είσοδος ακολουθώντας εξουσιοδοτημένο άτομο (Tailgating)** | Είσοδος σε ελεγχόμενο χώρο ακολουθώντας εξουσιοδοτημένο άτομο | Φυσική παρουσία |
| **Παραβίαση ιστοτόπων που επισκέπτεται ο στόχος (Watering Hole)** | Παραβίαση ιστοτόπων που επισκέπτονται τα στοχευμένα άτομα | Ιστός |

## 🔗 Γρήγορη αναφορά ενδείξεων phishing

### Ύποπτες ενδείξεις σε email

Μια ένδειξη δεν αποδεικνύει από μόνη της απάτη. Αντίστοιχα, ένα καλογραμμένο μήνυμα χωρίς ορθογραφικά λάθη μπορεί να είναι phishing. Επαληθεύστε ένα ύποπτο αίτημα από γνωστό, ανεξάρτητο κανάλι επικοινωνίας.

```
□ Η διεύθυνση αποστολέα δεν αντιστοιχεί στο domain της εταιρείας
□ Γενικός χαιρετισμός, όπως «Αγαπητέ πελάτη»
□ Πίεση χρόνου ή απειλές
□ Ορθογραφικά ή γραμματικά λάθη
□ Ύποπτοι σύνδεσμοι — εξετάστε τον πραγματικό προορισμό
□ Απρόσμενα συνημμένα
□ Αίτημα για ευαίσθητες πληροφορίες
□ Προσφορές που φαίνονται υπερβολικά καλές για να είναι αληθινές
```

### Ανάλυση διευθύνσεων URL

Η ηλικία ενός domain ή η απουσία κακής φήμης δεν αποδεικνύει ασφάλεια. Οι διευθύνσεις των υπηρεσιών παρακάτω ανοίγουν σε browser και δεν είναι εντολές shell. Πριν υποβάλετε URL σε εξωτερική υπηρεσία, εξετάστε αν περιέχει προσωπικά στοιχεία ή μυστικά tokens.

```bash
# Έλεγχος διαθέσιμων στοιχείων καταχώρισης του domain
whois suspicious-domain.com

# Υπηρεσίες ελέγχου φήμης διευθύνσεων
https://www.virustotal.com
https://urlscan.io

# Υπηρεσία ανάλυσης συντομευμένων διευθύνσεων
https://checkshorturl.com
```
