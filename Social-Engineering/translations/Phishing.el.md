## Πριν ξεκινήσετε

Το **phishing** είναι προσπάθεια να παραπλανηθεί κάποιος με μήνυμα ή σελίδα που εμφανίζεται ως αξιόπιστη. Τα **credentials** είναι στοιχεία σύνδεσης, όπως όνομα χρήστη και κωδικός. Μια **landing page** είναι η σελίδα στην οποία οδηγεί ο σύνδεσμος του μηνύματος. Ένα **template** είναι επαναχρησιμοποιήσιμο πρότυπο μηνύματος ή σελίδας. Η **campaign** είναι μια οργανωμένη προσομοίωση με συγκεκριμένους αποδέκτες και χρονικό διάστημα.

Το **SMTP** χρησιμοποιείται για αποστολή email. Το **domain** είναι το όνομα ενός διαδικτυακού τομέα, ενώ το **DNS** δημοσιεύει πληροφορίες για αυτόν. Το **SPF** δηλώνει ποιες υποδομές επιτρέπεται να στέλνουν email για συγκεκριμένη ταυτότητα αποστολής, το **DKIM** επιτρέπει επαλήθευση ψηφιακής υπογραφής email και το **DMARC** συνδέει τους ελέγχους με το domain του ορατού αποστολέα και την πολιτική διαχείρισης μηνυμάτων. Δεν είναι καθολική προστασία από κάθε παραπλανητικό μήνυμα.

Το **2FA** είναι ταυτοποίηση με δύο παράγοντες και το **MFA** με πολλαπλούς παράγοντες. Ένας **reverse proxy** είναι ενδιάμεσος διακομιστής που προωθεί αιτήματα και απαντήσεις. Η σχετική ενότητα εξηγεί τα όρια των παραδειγμάτων και δεν υποστηρίζει ότι παρακάμπτεται κάθε μορφή MFA.

Οι οδηγίες εργαλείων και τα ονόματα επιλογών μένουν στα αγγλικά, με ελληνικές επεξηγήσεις. Οι εντολές και τα HTML διατηρούνται για αντιστοίχιση με το πρωτότυπο. Τα κείμενα διαλόγων και μηνυμάτων μεταφράζονται. Τιμές όπως target.com, YOUR_SERVER_IP και YOUR_KEY χρειάζονται τις δικές σας τιμές στο εξουσιοδοτημένο εργαστήριο. Τα παραδείγματα URL δεν πρέπει να θεωρούνται ασφαλή ή να ανοίγονται επειδή εμφανίζονται εδώ. Σε εκπαιδευτικές δοκιμές χρησιμοποιήστε δοκιμαστικούς λογαριασμούς και δεδομένα σύμφωνα με τους συμφωνημένους κανόνες.

## 📊 Είδη phishing

| Τύπος | Αποδέκτης | Περιγραφή |
| ------ | -------- | ------------- |
| **Ηλεκτρονικό ψάρεμα (Phishing)** | Πολλοί αποδέκτες | Γενικά μηνύματα προς πολλούς χρήστες |
| **Στοχευμένο ηλεκτρονικό ψάρεμα (Spear Phishing)** | Συγκεκριμένα άτομα | Προσαρμοσμένα μηνύματα προς συγκεκριμένα άτομα |
| **Phishing με στόχο ανώτερα στελέχη (Whaling)** | Ανώτερα στελέχη | Στόχευση διευθυντικών στελεχών |
| **Αντιγραφή νόμιμου μηνύματος (Clone Phishing)** | Διάφοροι αποδέκτες | Αντίγραφο πραγματικού email με προσθήκη κακόβουλου περιεχομένου |
| **Τηλεφωνικό ψάρεμα (Vishing)** | Διάφοροι αποδέκτες | Παραπλάνηση μέσω φωνητικής ή τηλεφωνικής επικοινωνίας |
| **Ψάρεμα μέσω SMS (Smishing)** | Διάφοροι αποδέκτες | Παραπλάνηση μέσω SMS |
| **Ανακατεύθυνση σε πλαστή σελίδα (Pharming)** | Διάφοροι αποδέκτες | Παραποίηση της επίλυσης DNS για μετάβαση σε πλαστό ιστότοπο |

## 🛠️ Εγκατάσταση και χρήση του GoPhish

### Εγκατάσταση

Η αποσυμπίεση και η εκκίνηση πρέπει να αντιστοιχούν στον πραγματικό φάκελο εξαγωγής. Το cd gophish του πρωτοτύπου προϋποθέτει ότι υπάρχει αυτός ο φάκελος. Η διεύθυνση του πίνακα και το HTTP ή HTTPS εξαρτώνται από τη ρύθμιση config.json. Ο αρχικός κωδικός εμφανίζεται στην κονσόλα, σύμφωνα με την [τεκμηρίωση GoPhish](https://docs.getgophish.com/user-guide/installation).

```bash
# Λήψη GoPhish
wget https://github.com/gophish/gophish/releases/download/v0.12.1/gophish-v0.12.1-linux-64bit.zip
unzip gophish-v0.12.1-linux-64bit.zip
cd gophish

# Εκκίνηση GoPhish
./gophish

# Διεύθυνση του πίνακα διαχείρισης — ανοίγει σε browser
https://localhost:3333
# Αρχικός χρήστης: admin — ο κωδικός εμφανίζεται στην κονσόλα
```

### Σειρά ρυθμίσεων μιας προσομοίωσης

Οι αγγλικές ονομασίες διατηρούνται για να αντιστοιχούν στις επιλογές του GoPhish. Τα ανοίγματα και τα πατήματα συνδέσμων είναι ενδείξεις, καθώς η συμπεριφορά εφαρμογών email και αυτοματοποιημένων ελέγχων μπορεί να επηρεάσει την καταγραφή.

```
1. Sending Profile — Προφίλ αποστολής: ρύθμιση διακομιστή SMTP
2. Landing Page — Σελίδα προορισμού: δημιουργία δοκιμαστικής πλαστής φόρμας σύνδεσης
3. Email Template — Πρότυπο email: σχεδιασμός μηνύματος προσομοίωσης
4. Users & Groups — Χρήστες και ομάδες: εισαγωγή λίστας αποδεκτών
5. Launch Campaign — Εκκίνηση προσομοίωσης: αποστολή μηνυμάτων
6. Monitor Results — Παρακολούθηση: ανοίγματα, σύνδεσμοι και υποβολές στοιχείων
```

### Παράδειγμα προτύπου email

Το HTML εμφανίζει χαιρετισμό προς τον παραλήπτη, αίτημα επαλήθευσης λογαριασμού από υποτιθέμενο τμήμα IT και προθεσμία 24 ωρών. Το {{.FirstName}} συμπληρώνει το μικρό όνομα και το {{.URL}} τον σύνδεσμο της προσομοίωσης. Οι μεταβλητές και ο κώδικας του προτύπου διατηρούνται ακριβώς.

```html
<!DOCTYPE html>
<html>
<body>
<p>Dear {{.FirstName}},</p>
<p>Your IT department requires you to verify your account credentials.</p>
<p>Please click the link below to complete verification:</p>
<p><a href="{{.URL}}">Verify Account</a></p>
<p>This action is required within 24 hours.</p>
<br>
<p>IT Support Team</p>
</body>
</html>
```

### Παράδειγμα σελίδας προορισμού

Το HTML παρουσιάζει φόρμα με τίτλο Microsoft Login, πεδία email και κωδικού και κουμπί Sign in, δηλαδή «Σύνδεση». Είναι απλό παράδειγμα διεπαφής· από μόνο του δεν αποδεικνύει λειτουργική σύνδεση ούτε καθορίζει ασφαλή αποθήκευση δεδομένων.

```html
<!DOCTYPE html>
<html>
<head>
    <title>Microsoft Login</title>
</head>
<body>
    <form method="post" action="">
        <h2>Sign in</h2>
        <input type="email" name="email" placeholder="Email" required>
        <input type="password" name="password" placeholder="Password" required>
        <button type="submit">Sign in</button>
    </form>
</body>
</html>
```

## 🔥 Evilginx2 — ενδιάμεσος διακομιστής και περιορισμοί του 2FA

Τα παραδείγματα αφορούν παραπλάνηση μέσω ενδιάμεσου διακομιστή και δεν αποδεικνύουν παράκαμψη κάθε MFA. Μέθοδοι όπως FIDO2 ανήκουν στις [ανθεκτικές στο phishing μεθόδους ταυτοποίησης](https://learn.microsoft.com/en-us/entra/identity/authentication/concept-authentication-strengths). Το URL λήψης με αποσιωπητικά είναι ελλιπές και οι επιλογές εξαρτώνται από την έκδοση και τα διαθέσιμα αρχεία ρυθμίσεων.


### Εγκατάσταση
```bash
# Παράδειγμα εγκατάστασης Evilginx2
go install github.com/kgretzky/evilginx2@latest

# Εναλλακτικά: λήψη εκτελέσιμου αρχείου — το URL εδώ είναι ελλιπές
wget https://github.com/kgretzky/evilginx2/releases/...

# Εκτέλεση
sudo evilginx2
```

### Βασικό παράδειγμα ρυθμίσεων

Οι γραμμές αυτές ανήκουν στην κονσόλα του εργαλείου. Ονόματα όπως o365 προϋποθέτουν αντίστοιχο διαθέσιμο phishlet, δηλαδή αρχείο ρυθμίσεων για συγκεκριμένη ροή. Η λίστα υπηρεσιών δεν εγγυάται λειτουργία με τις τρέχουσες σελίδες τους.

```bash
# Εντολές στην κονσόλα του Evilginx2, όχι στο shell
config domain yourdomain.com
config ip YOUR_SERVER_IP

# Προβολή διαθέσιμων phishlets
phishlets

# Παράδειγμα ενεργοποίησης phishlet Microsoft 365
phishlets hostname o365 login.yourdomain.com
phishlets enable o365

# Δημιουργία συνδέσμου προσομοίωσης (lure)
lures create o365
lures get-url 0
```

### Ενδεικτικές ονομασίες phishlets και υπηρεσιών
```

google      - Λογαριασμοί Google
linkedin    - LinkedIn
twitter     - Twitter/X
github      - GitHub
instagram   - Instagram
```

### theHarvester
```bash
# Συλλογή διευθύνσεων email
theHarvester -d target.com -b all

# Παράδειγμα επιλογής συγκεκριμένων πηγών
theHarvester -d target.com -b google,linkedin,bing

# Αποθήκευση αποτελεσμάτων σε αρχείο
theHarvester -d target.com -b all -f output.html
```

### Hunter.io
```bash
# Μέσω API
curl "https://api.hunter.io/v2/domain-search?domain=target.com&api_key=YOUR_KEY"

# Αναζήτηση διεύθυνσης email με όνομα και domain
curl "https://api.hunter.io/v2/email-finder?domain=target.com&first_name=John&last_name=Doe&api_key=YOUR_KEY"
```

Οι διευθύνσεις κάτω από το σχόλιο «μορφή διευθύνσεων» είναι υποθέσεις και όχι επιβεβαιωμένοι λογαριασμοί ή εντολές εκτέλεσης.

```bash
python linkedin2username.py -u USERNAME -c COMPANY_NAME
```

## 📮 Υποδομή αποστολής μηνυμάτων

### Υπηρεσίες SMTP για εξουσιοδοτημένες δοκιμές

Οι υπηρεσίες αναφέρονται ως παραδείγματα του πρωτοτύπου. Η αποστολή προσομοιώσεων προϋποθέτει ότι επιτρέπεται από τον πάροχο και από το συμφωνημένο πεδίο ελέγχου.

```
- Amazon SES
- SendGrid
- Mailgun
- SMTP2GO
- Ιδιόκτητος διακομιστής αποστολής (αυξημένος κίνδυνος χαρακτηρισμού ως spam)
```

### Έλεγχος SPF, DKIM και DMARC — τι δείχνουν τα παραδείγματα

Οι παρακάτω εντολές διαβάζουν DNS εγγραφές SPF και DMARC· δεν ελέγχουν υπογραφή DKIM και δεν υλοποιούν από μόνες τους παράκαμψη. Το SPF softfail (~all) δεν αποδεικνύει ότι ένα μήνυμα θα γίνει αποδεκτό. Απαιτείται αξιολόγηση των ελέγχων και της πολιτικής του παραλήπτη. Το [SPF περιγράφει εξουσιοδότηση υποδομών αποστολής](https://www.rfc-editor.org/rfc/rfc7208).

```bash
# Ανάγνωση εγγραφής SPF
dig txt target.com | grep spf

# Ενδείξεις ρυθμίσεων SPF που χρειάζονται διερεύνηση:
# - "include:" που εξουσιοδοτεί τρίτους παρόχους — απαιτεί έλεγχο της πραγματικής πολιτικής
# - "~all" (softfail) αντί για "-all" — δεν αποδεικνύει επιτυχή παράκαμψη
# - Απουσία εγγραφής SPF

# Ανάγνωση εγγραφής DMARC
dig txt _dmarc.target.com
```

### Παραδείγματα ονομάτων domain για προσομοίωση phishing

Τα ζεύγη με το σύμβολο → είναι παραδείγματα ονομάτων και όχι εντολές. Μοιάζον domain δεν σημαίνει ίδιος ιδιοκτήτης ή νόμιμη σχέση με τον οργανισμό. Η έξοδος whois δεν εγγυάται ότι ένα όνομα είναι διαθέσιμο για καταχώριση.

```bash
# Παραδείγματα παρόμοιων ονομάτων domain (typosquatting)
target.com → tarqet.com
target.com → target-secure.com
target.com → target.co
target.com → target-login.com

# Έλεγχος στοιχείων καταχώρισης — όχι εγγύηση διαθεσιμότητας
whois potential-phish-domain.com
```

## 📱 Παραπλάνηση μέσω SMS (Smishing)

### Συνηθισμένα παραπλανητικά προσχήματα
```
- Ειδοποίηση παράδοσης δέματος
- Ειδοποίηση ασφάλειας από τράπεζα
- Ισχυρισμός για βραβείο ή κέρδος σε κλήρωση
- Επαλήθευση λογαριασμού
- Κωδικός ταυτοποίησης δύο παραγόντων
```

### Υπηρεσίες αποστολής SMS
```
- Twilio
- Nexmo/Vonage
- Plivo
- AWS SNS
```

### Παραδείγματα μηνυμάτων

Υποθετικά παραπλανητικά μηνύματα του πρωτοτύπου, μεταφρασμένα για αναγνώριση των προσχημάτων. Τα ονόματα εταιρειών και τα URL διατηρούνται για αντιστοίχιση και δεν αποτελούν σύσταση επίσκεψης.

```
[FedEx] Το δέμα σας περιμένει. Επιβεβαιώστε την παράδοση: http://short.url/abc

[BankName] Εντοπίστηκε ασυνήθιστη δραστηριότητα. Επαληθεύστε τώρα: http://secure-link.com

[Netflix] Η πληρωμή σας απέτυχε. Ενημερώστε τα στοιχεία: http://netflix-billing.com
```

## 📞 Τηλεφωνική παραπλάνηση (Vishing)

### Συνηθισμένα σενάρια
```
□ Τεχνική υποστήριξη που ζητά επαναφορά κωδικού
□ Υποτιθέμενο τμήμα αντιμετώπισης απάτης τράπεζας
□ Υποτιθέμενη κρατική υπηρεσία, όπως η φορολογική αρχή
□ Απάτη με πρόσχημα τεχνική υποστήριξη
□ Επείγον αίτημα από υποτιθέμενο CEO/CFO
□ Επαλήθευση στοιχείων προμηθευτή
```

### Παράδειγμα τηλεφωνικού διαλόγου παραπλάνησης
```
«Γεια σας, είμαι ο/η [Name] από την τεχνική υποστήριξη IT.
Εντοπίσαμε ασυνήθιστη δραστηριότητα στον λογαριασμό σας και
χρειάζεται να επαληθεύσουμε τα στοιχεία σύνδεσης για να αποτρέψουμε
ένα περιστατικό ασφάλειας. Μπορείτε να μου πείτε το όνομα χρήστη
και τον τρέχοντα κωδικό σας για να επαληθεύσω τον λογαριασμό;»
```

### Εργαλεία

Οι παρακάτω γραμμές απαριθμούν ονόματα εργαλείων και δεν αποτελούν ενιαίο εκτελέσιμο script.

```bash
# Εργαλεία αλλαγής εμφανιζόμενου αριθμού καλούντος
- SpoofCard
- SpoofTel

# Εργαλεία αλλοίωσης φωνής
- Voicemod
- Clownfish
```

## 🎯 SET — Εργαλειοθήκη κοινωνικής μηχανικής

### Εγκατάσταση
```bash
git clone https://github.com/trustedsec/social-engineer-toolkit
cd social-engineer-toolkit
pip install -r requirements.txt
sudo python setoolkit
```

### Επιλογές μενού

Οι αριθμοί και οι αγγλικές επιλογές διατηρούνται ως ενδεικτική αντιστοίχιση μενού του πρωτοτύπου. Η πραγματική σειρά μπορεί να διαφέρει ανά έκδοση. Payload ονομάζεται ο κώδικας που εκτελεί την επιδιωκόμενη ενέργεια και listener το πρόγραμμα που περιμένει εισερχόμενες συνδέσεις.

```
1) Spear-Phishing Attack Vectors — Σενάρια στοχευμένου phishing
2) Website Attack Vectors — Σενάρια μέσω ιστοτόπων
3) Infectious Media Generator — Δημιουργία μολυσμένων μέσων
4) Create a Payload and Listener — Δημιουργία payload και listener
5) Mass Mailer Attack — Μαζική αποστολή email
```

### Μηχανισμός συλλογής στοιχείων σύνδεσης

Το παρακάτω μπλοκ περιγράφει επιλογές μενού και όχι εντολές shell. Η συλλογή στοιχείων στην προσομοίωση πρέπει να ακολουθεί τους συμφωνημένους κανόνες χειρισμού δεδομένων.

```bash
# Επιλογές στο μενού του SET:
1) Social-Engineering Attacks — επιθέσεις κοινωνικής μηχανικής
2) Website Attack Vectors — σενάρια μέσω ιστοτόπων
3) Credential Harvester Attack Method — συλλογή στοιχείων σύνδεσης
2) Site Cloner — αντιγραφή σελίδας
# Εισαγωγή URL προς αντιγραφή, όπως το παράδειγμα https://login.microsoft.com
# Το παράδειγμα αφορά φιλοξενία πλαστής σελίδας και συλλογή στοιχείων σύνδεσης
```

## 📝 Πρότυπα παραπλανητικών email για προσομοιώσεις

### Επαναφορά κωδικού πρόσβασης
```
Θέμα: [ΑΠΑΙΤΕΙΤΑΙ ΕΝΕΡΓΕΙΑ] Αίτημα επαναφοράς κωδικού

Αγαπητέ/ή {Name},

Λάβαμε αίτημα επαναφοράς του κωδικού σας. Αν δεν κάνατε
εσείς το αίτημα, πατήστε παρακάτω για να προστατέψετε
άμεσα τον λογαριασμό σας.

[Προστασία του λογαριασμού μου]

Ο σύνδεσμος λήγει σε 24 ώρες.

Με εκτίμηση,
Ομάδα ασφάλειας
```
