## 🎯 Что такое социальная инженерия?

Социальная инженерия — это манипулирование людьми с целью получить конфиденциальные сведения или побудить их к действиям, нарушающим безопасность. Она использует особенности человеческой психологии, а не технические уязвимости.

**Основные принципы:**
- 🎭 **Авторитет** — люди доверяют представителям власти и руководителям
- ⏰ **Срочность** — нехватка времени снижает критичность мышления
- 🤝 **Взаимность** — люди чувствуют обязанность ответить услугой на услугу
- 👥 **Социальное доказательство** — люди ориентируются на поведение окружающих
- 😊 **Симпатия** — людям проще согласиться с теми, кто им нравится
- 📉 **Дефицит** — ограниченная доступность повышает привлекательность

## 🛠️ Основные инструменты социальной инженерии

| Инструмент | Назначение | Тип |
|------|---------|------|
| **GoPhish** | Платформа для фишинговых кампаний | Фишинг |
| **SET (Social Engineering Toolkit)** | Комплексная платформа социальной инженерии | Универсальный |
| **Evilginx2** | Фишинг с посредником (MITM), обход отдельных механизмов 2FA | Фишинг |
| **King Phisher** | Платформа для фишинговых кампаний | Фишинг |
| **Modlishka** | Фишинг с обратным прокси | Фишинг |
| **theHarvester** | Сбор адресов почты и доменов | Разведка |
| **Инструменты LinkedIn** | Сбор сведений о сотрудниках | OSINT |
| **Maltego** | OSINT и построение связей | Разведка |

> **Уточнение:** выражение «обход 2FA» не универсально: [CISA](https://www.cisa.gov/sites/default/files/2023-01/fact-sheet-implementing-phishing-resistant-mfa-508c.pdf) выделяет FIDO/WebAuthn как устойчивую к фишингу аутентификацию. Примеры установки ниже сохранены из оригинала, включая закреплённую версию GoPhish.

### Быстрая установка инструментов
```bash
# GoPhish
wget https://github.com/gophish/gophish/releases/download/v0.12.1/gophish-v0.12.1-linux-64bit.zip
unzip gophish-v0.12.1-linux-64bit.zip
./gophish

# SET (Social Engineering Toolkit)
git clone https://github.com/trustedsec/social-engineer-toolkit
cd social-engineer-toolkit
pip install -r requirements.txt
python setoolkit

# Evilginx2
go install github.com/kgretzky/evilginx2@latest

# theHarvester
pip install theHarvester
theHarvester -d target.com -b all
```

## 📊 Виды атак с применением социальной инженерии

| Вид атаки | Описание | Канал |
|-------------|-------------|--------|
| **Фишинг (Phishing)** | Обманные письма для кражи учётных данных | Электронная почта |
| **Целевой фишинг (Spear Phishing)** | Фишинг, направленный на конкретных людей | Электронная почта |
| **Whaling** | Фишинг против высшего руководства | Электронная почта |
| **Вишинг (Vishing)** | Голосовая социальная инженерия по телефону | Телефон |
| **Смишинг (Smishing)** | Фишинг через SMS | SMS |
| **Претекстинг (Pretexting)** | Вымышленные сценарии для получения сведений | Любой |
| **Приманка (Baiting)** | Подбрасывание заражённых носителей, например USB | Физический доступ |
| **Услуга за услугу (Quid Pro Quo)** | Предложение вознаграждения в обмен на сведения | Любой |
| **Tailgating** | Проход в защищённую зону вслед за человеком с доступом | Физический доступ |
| **Watering Hole** | Компрометация сайтов, которые посещают цели | Веб |

## 🔗 Краткий справочник: признаки фишинга

### Подозрительные признаки в письмах
```
□ Адрес отправителя не соответствует домену компании
□ Обезличенное обращение («Уважаемый клиент»)
□ Срочность или угрозы
□ Орфографические и грамматические ошибки
□ Подозрительные ссылки (наведите курсор для проверки)
□ Неожиданные вложения
□ Запрос конфиденциальных сведений
□ Неправдоподобно выгодные предложения
```

### Анализ URL
```bash
# Проверить возраст домена
whois suspicious-domain.com

# Проверить репутацию
https://www.virustotal.com
https://urlscan.io

# Проанализировать сокращённые URL
https://checkshorturl.com
```
