## 🎯 什么是借口伪装？

借口伪装（Pretexting）是指编造情境或理由，与目标接触，从而套取信息或诱导对方执行某项操作。它是大多数社会工程学攻击的基础。

**关键要素：**
- 🎭 **伪装身份** - 你所扮演的虚假身份
- 📖 **故事情境** - 可信的情境或理由
- 🎯 **目标** - 希望达成的结果
- 🔧 **道具** - 辅助材料（工牌、邮件等）

## 👥 常见伪装身份

### IT 支持
```
角色：IT 服务台技术人员
目标：重置密码、获得远程访问权限、安装软件

“您好，我是 IT 部门的 Mike。我们发现您的账户出现了一些异常活动，需要核实您的凭据，避免账户被锁定。”
```

### 供应商或承包商
```
角色：第三方供应商（暖通空调、安保、保洁等）
目标：进入现场、访问网络

“我是 [Vendor Company] 派来做计划维护的。能让我进入服务器机房吗？”
```

### 新员工
```
角色：需要帮助的新员工
目标：收集信息、进入办公楼

“您好，我刚入职市场部，目前无法访问共享驱动器。您能帮我看看吗？”
```

### 高管或权威人士
```
角色：CEO、CFO 或高级经理
目标：提出紧急要求、促成电汇、取得访问权限

“事情很紧急。CEO 马上就需要这份报告，我需要你跳过正常流程处理。”
```

### 快递员
```
角色：FedEx、UPS 或其他快递员
目标：进入现场、投递包裹

“这里有一个需要签收的包裹。能让我到前台吗？”
```

## 📋 借口情境

### 电话场景中的借口

#### IT 密码重置
```
“您好，我是 IT 服务台的 [Name]。我们检测到您的账户在近期安全事件中遭到入侵。我需要核实您的身份，并帮您重置密码。您能确认一下当前密码吗？这样我才能验证确实是您本人。”
```

#### 供应商信息核实
```
“您好，我是 [Vendor] 应付账款部门的工作人员。我们正在更新记录，需要为下一次付款核实贵公司的银行信息。您能确认一下记录中我方的账户号码吗？”
```

#### 人力资源问卷
```
“您好，我正在为人力资源部门进行员工满意度调查。问卷是匿名的，但我需要先确认您是本公司员工。您能告诉我所在部门和经理姓名吗？”
```

### 面对面场景中的借口

#### 消防检查员
```
“您好，我是市消防检查部门的。我们正在进行突击检查，需要进入服务器机房检查消防灭火系统。”
```

#### 求职面试
```
“我来参加下午 2 点与人力资源部门的面试。等待期间，能告诉我洗手间在哪里吗？”
（借此机会观察楼内环境）
```

#### 维修人员
```
“我们接到电话，说这片区域有漏水。能带我看看服务器机房在哪里吗？我需要检查吊顶上方的管道。”
```

## 🧠 心理学原理

### 权威
```
✓ 使用头衔，例如“IT 总监”“安全经理”
✓ 衣着与身份相符：西装、制服、工牌
✓ 讲话自信
✓ 提及相关政策和流程
```

### 紧迫感
```
✓ “这件事必须在 CEO 3 点开会前完成。”
✓ “系统将在 10 分钟后锁定您的账户。”
✓ “我们正在接受审计，必须立即处理。”
✓ 制造时间压力，阻碍对方核实
```

### 互惠
```
✓ 先帮一个小忙
✓ “我刚帮忙解决了那个打印机问题……”
✓ “我给大家带了咖啡……”
✓ 让对方觉得应该回报帮助
```

### 社会认同
```
✓ “其他人都已经完成了。”
✓ “您的经理 John 已经批准了。”
✓ “整个市场团队都填完这张表了。”
✓ 提及已经配合的其他人
```

### 好感
```
✓ 寻找共同点
✓ 呼应对方的肢体语言
✓ 真诚地称赞对方
✓ 提出请求前先建立融洽关系
```

## 🔧 道具与辅助材料

### 实体道具
```
□ 伪造工牌
□ 名片
□ 夹有看似正式表格的写字板
□ 高可视反光背心或制服
□ 工具箱或笔记本电脑包
□ 打印的邮件或授权书
□ 供应商文件
```

### 数字道具
```
□ 伪造的来电显示
□ 伪造邮箱地址（使用相似域名）
□ 虚假 LinkedIn 个人资料
□ 克隆的公司网站
□ 伪造的授权邮件
□ 虚假会议邀请
```

### 文件材料
```
□ 服务工单编号
□ 工作单
□ 授权表
□ 参考编号
□ 经理姓名（来自 OSINT）
```

## 🔍 用于借口伪装的 OSINT

### 目标调研
```bash
# 通过 LinkedIn 收集员工信息
- 姓名、职位、部门
- 汇报关系
- 近期帖子或动态

# 公司网站
- 高管团队
- 组织结构图
- 办公地点
- 供应商或合作伙伴信息

# 新闻稿
- 近期新闻、收购事项
- 高管变动
```

### 有用的信息
```
□ 员工姓名与职位
□ 部门结构
□ 经理姓名
□ 邮箱格式（first.last@company.com）
□ 电话号码
□ 办公地点
□ 供应商关系
□ 公司近期活动
```

## 📱 现场社会工程学

### 尾随进入（Tailgating）
```
方法：跟随获授权人员穿过受控门禁

“谢谢，我今天忘带工牌了！”
“能帮我扶一下门吗？我两只手都拿着东西。”
“我是跟 [Department] 的 [Name] 一起来的。”
```

### 借助他人许可进入（Piggybacking）
```
方法：让获授权人员主动放行

“您好，我来自 [Vendor]。他们知道我要来，但前台刚好不在。您能让我进去吗？”
```

### 垃圾搜寻（Dumpster Diving）
```
目标：被丢弃的文件和硬件

□ 组织结构图
□ 员工名单
□ 财务文件
□ 记录密码的便条
□ 含有数据的旧硬件
```

### 投放 USB 设备（诱饵攻击）
```
方法：放置感染恶意程序的 USB 设备

地点：
□ 停车场
□ 前台区域
□ 休息室
□ 吸烟区附近

标签示例：
□ “机密——人力资源部”
□ “薪酬信息 2024”
□ “裁员名单”
□ “私人照片”
```

## 📝 话术模板

### 电话话术：IT 支持
```
[电话铃响]
目标：“喂？”
你：“您好，请问是 [Target Name] 吗？”
目标：“是的。”
你：“您好，我是 IT 安全团队的 [Your Name]。我们一直在监测您账户上的异常登录尝试，来源是一个境外 IP 地址。我们想确认是不是您本人操作的。您今天有从 [Random Country] 登录吗？”
目标：“没有，不是我！”
你：“我想也是。出于安全考虑，我需要核实您的账户。您能确认一下用户名吗？我们会重置您的密码，阻止攻击者继续访问。”
```

### 邮件话术：高管请求
```
主题：紧急——需要电汇

您好，[Name]：

我正在开会，没法打电话。现在有一项时间紧迫的收购，需要你处理一笔紧急电汇。

请向以下账户转账 $45,000：
[Details]

开完会我会再解释。完成后请回复确认。

[Executive Name]
发自我的 iPhone
```

## ⚠️ 法律与伦理注意事项

### 交战规则（测试约定）
```
□ 始终取得书面授权
□ 明确测试范围和边界
□ 不访问个人账户
□ 不实施敲诈或胁迫
□ 记录全过程
□ 准备紧急联系人
□ 随身携带测试授权证明信
```

### 应避免的行为
```
✗ 冒充执法人员
✗ 作出真实威胁
✗ 访问超出范围的系统
✗ 窃取真实资金或资产
✗ 引发法律责任
✗ 造成心理伤害
```

## 📋 借口伪装检查清单

```markdown
准备阶段：
□ 调研目标组织（OSINT）
□ 确定关键人员
□ 设计伪装身份与背景故事
□ 准备辅助材料或道具
□ 练习话术与应答
□ 准备备用说辞

实施阶段：
□ 保持冷静、自信
□ 掌握对话节奏
□ 遭到质疑时准备调整说辞
□ 避免过度表现或提供过多细节
□ 判断何时应终止测试

测试后：
□ 记录哪些方法有效或无效
□ 妥善保护收集的数据
□ 报告发现
□ 提供改进建议
```
