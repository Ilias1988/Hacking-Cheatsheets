<a id="-what-is-pretexting"></a>
## 🎯 ما هو اختلاق الذرائع؟

اختلاق الذرائع هو إنشاء سيناريو مفتعل للتواصل مع الهدف واستخراج المعلومات منه أو دفعه إلى تنفيذ إجراء. وهو أساس معظم هجمات الهندسة الاجتماعية.

**المكونات الأساسية:**
- 🎭 **الشخصية (Persona)** — الهوية المزيفة التي تتقمصها
- 📖 **الرواية (Story)** — السيناريو أو المبرر القابل للتصديق
- 🎯 **الهدف (Goal)** — ما تريد تحقيقه
- 🔧 **الوسائل المساعدة (Props)** — مواد داعمة مثل البطاقات ورسائل البريد

<a id="-common-personas"></a>
## 👥 شخصيات شائعة لانتحالها

<a id="it-support"></a>
### الدعم التقني
```
الدور: فني مكتب الدعم التقني
الهدف: إعادة تعيين كلمة المرور، الوصول عن بُعد، تثبيت برنامج

"مرحبًا، معك Mike من قسم تقنية المعلومات. نلاحظ نشاطًا
غير معتاد على حسابك ونحتاج إلى التحقق من
بيانات اعتمادك لمنع قفل الحساب."
```

<a id="vendorcontractor"></a>
### مورد أو متعهد
```
الدور: مورد خارجي، مثل خدمات التكييف أو الأمن أو التنظيف
الهدف: الوصول المادي أو الوصول إلى الشبكة

"أنا من [Vendor Company] وجئت لإجراء الصيانة
المجدولة. هل تسمح لي بالدخول إلى غرفة الخوادم؟"
```

<a id="new-employee"></a>
### موظف جديد
```
الدور: موظف جديد يحتاج إلى المساعدة
الهدف: جمع المعلومات أو دخول المبنى

"مرحبًا، بدأت العمل للتو في التسويق وأواجه
صعوبة في الوصول إلى المجلد المشترك. هل يمكنك مساعدتي؟"
```

<a id="executiveauthority"></a>
### مسؤول تنفيذي أو صاحب سلطة
```
الدور: مدير تنفيذي أو مالي أو مدير رفيع
الهدف: طلبات عاجلة أو تحويلات مالية أو صلاحيات وصول

"الأمر عاجل. يحتاج المدير التنفيذي إلى هذا التقرير فورًا
وأحتاج منك تجاوز الإجراءات المعتادة."
```

<a id="delivery-person"></a>
### مندوب توصيل
```
الدور: مندوب FedEx أو UPS أو شركة توصيل
الهدف: الدخول المادي أو تسليم طرد

"لدي طرد يتطلب توقيعًا.
هل يمكنك السماح لي بالدخول إلى الاستقبال؟"
```

<a id="-pretext-scenarios"></a>
## 📋 سيناريوهات اختلاق الذرائع

<a id="phone-pretexts"></a>
### ذرائع عبر الهاتف

<a id="it-password-reset"></a>
#### إعادة تعيين كلمة المرور بذريعة الدعم التقني
```
"مرحبًا، معك [Name] من مكتب الدعم التقني. اكتشفنا
أن حسابك تعرض للاختراق خلال حادث
أمني حديث. أحتاج إلى التحقق من هويتك
ومساعدتك في إعادة تعيين كلمة المرور. هل يمكنك تأكيد
كلمة مرورك الحالية للتأكد من أنك صاحب الحساب؟"
```

<a id="vendor-verification"></a>
#### التحقق من المورد
```
"مرحبًا، أتصل من قسم الحسابات الدائنة لدى [Vendor]. نحدّث
سجلاتنا ونحتاج إلى التحقق من البيانات المصرفية لشركتكم
من أجل الدفعة التالية. هل يمكنك تأكيد
رقم الحساب المسجل لدينا لكم؟"
```

<a id="hr-survey"></a>
#### استبيان الموارد البشرية
```
"مرحبًا، أجري استبيانًا لرضا الموظفين
لصالح الموارد البشرية. الاستبيان مجهول الهوية، لكنني أحتاج إلى التحقق
من أنك موظف. هل يمكنك إخباري باسم قسمك
واسم مديرك؟"
```

<a id="in-person-pretexts"></a>
### ذرائع للتواصل وجهًا لوجه

<a id="fire-inspector"></a>
#### مفتش السلامة من الحرائق
```
"مرحبًا، أنا من مكتب مسؤول الوقاية من الحرائق بالمدينة. نجري
عمليات تفتيش مفاجئة. سأحتاج إلى الدخول إلى
غرفة الخوادم لفحص نظام إخماد الحرائق."
```

<a id="job-interview"></a>
#### مقابلة عمل
```
"أنا هنا لمقابلة الساعة 2 مساءً مع الموارد البشرية. في أثناء انتظاري،
هل يمكنك إرشادي إلى دورة المياه؟"
(استغلال الفرصة لاستطلاع المبنى)
```

<a id="maintenance-worker"></a>
#### عامل صيانة
```
"تلقينا بلاغًا عن تسرب مياه في هذه المنطقة.
هل يمكنك إرشادي إلى غرفة الخوادم؟ أحتاج إلى
فحص الأنابيب المارة فوق السقف."
```

<a id="-psychological-principles"></a>
## 🧠 المبادئ النفسية

<a id="authority"></a>
### السلطة
```
✓ استخدام مسميات مثل "مدير تقنية المعلومات" أو "مدير الأمن"
✓ ارتداء ملابس تلائم الدور: بدلات أو زي موحد أو بطاقات
✓ التحدث بثقة
✓ الإشارة إلى السياسات والإجراءات
```

<a id="urgency"></a>
### الإلحاح
```
✓ "يجب إنهاء هذا قبل اجتماع المدير التنفيذي في الساعة 3"
✓ "سيُقفل وصولك إلى النظام خلال 10 دقائق"
✓ "نحن تحت التدقيق ونحتاج إلى هذا فورًا"
✓ خلق ضغط زمني لمنع التحقق
```

<a id="reciprocity"></a>
### رد الجميل
```
✓ تقديم خدمة بسيطة أولًا
✓ "ساعدت للتو في حل مشكلة الطابعة تلك..."
✓ "أحضرت قهوة للجميع..."
✓ خلق شعور بوجوب رد الجميل
```

<a id="social-proof"></a>
### التأثر بسلوك الآخرين (Social Proof)
```
✓ "أكمل الجميع هذا بالفعل"
✓ "مديرك John وافق بالفعل على هذا"
✓ "أكمل فريق التسويق كله النموذج"
✓ الإشارة إلى أشخاص آخرين استجابوا
```

<a id="liking"></a>
### الألفة والإعجاب
```
✓ إيجاد اهتمامات مشتركة
✓ محاكاة لغة الجسد
✓ تقديم مجاملة صادقة
✓ بناء علاقة مريحة قبل الطلب
```

<a id="-props--supporting-materials"></a>
## 🔧 الوسائل المساعدة والمواد الداعمة

<a id="physical-props"></a>
### وسائل مادية
```
□ بطاقات هوية مزيفة
□ بطاقات عمل
□ لوح كتابة يحمل نماذج تبدو رسمية
□ سترة عالية الوضوح أو زي عمل
□ صندوق أدوات أو حقيبة حاسوب محمول
□ رسائل بريد مطبوعة أو خطابات تفويض
□ مستندات المورد
```

<a id="digital-props"></a>
### وسائل رقمية
```
□ هوية متصل منتحلة
□ عنوان بريد مزيف بنطاق مشابه
□ ملف شخصي مزيف على LinkedIn
□ نسخة من موقع الشركة
□ رسائل تفويض مزورة
□ دعوات اجتماعات مزيفة
```

<a id="documentation"></a>
### المستندات
```
□ رقم تذكرة الدعم
□ أمر عمل
□ نموذج تفويض
□ رقم مرجعي
□ اسم المدير من استخبارات المصادر المفتوحة (OSINT)
```

<a id="-osint-for-pretexting"></a>
## 🔍 استخبارات المصادر المفتوحة (OSINT) لاختلاق الذرائع

<a id="target-research"></a>
### البحث عن الهدف
```bash
# استخدام LinkedIn لمعلومات الموظفين
- الأسماء والمسميات الوظيفية والأقسام
- التسلسل الإداري
- المنشورات والأنشطة الحديثة

# موقع الشركة
- الفريق التنفيذي
- الهيكل التنظيمي
- مواقع المكاتب
- معلومات الموردين والشركاء

# البيانات الصحفية
- الأخبار وعمليات الاستحواذ الحديثة
- التغييرات في الإدارة التنفيذية
```

<a id="useful-information"></a>
### معلومات مفيدة
```
□ أسماء الموظفين ومسمياتهم الوظيفية
□ هيكل الأقسام
□ أسماء المديرين
□ صيغة البريد الإلكتروني (first.last@company.com)
□ أرقام الهواتف
□ مواقع المكاتب
□ العلاقات مع الموردين
□ أحداث الشركة الأخيرة
```

<a id="-physical-social-engineering"></a>
## 📱 الهندسة الاجتماعية الميدانية

<a id="tailgating"></a>
### التسلل خلف شخص مخول بالدخول (Tailgating)
```
الأسلوب: اتباع شخص مخول عبر باب مؤمن

"شكرًا، نسيت بطاقتي اليوم!"
"هل يمكنك إبقاء الباب مفتوحًا؟ يداي مشغولتان."
"أنا هنا مع [Name] من [Department]."
```

<a id="piggybacking"></a>
### الدخول بمساعدة شخص مخول (Piggybacking)
```
الأسلوب: جعل شخص مخول يسمح لك بالدخول

"مرحبًا، أنا من [Vendor]. إنهم ينتظرونني، لكن
موظف الاستقبال ابتعد قليلًا. هل تسمح لي بالدخول؟"
```

<a id="dumpster-diving"></a>
### البحث في النفايات (Dumpster Diving)
```
الهدف: مستندات وأجهزة جرى التخلص منها

□ المخططات التنظيمية
□ قوائم الموظفين
□ المستندات المالية
□ ملاحظات كلمات المرور
□ أجهزة قديمة تحتوي على بيانات
```

<a id="usb-drops-baiting"></a>
### ترك وحدات USB للطعم (Baiting)
```
الأسلوب: ترك وحدات USB مصابة

المواقع:
□ موقف السيارات
□ منطقة الاستقبال
□ غرف الاستراحة
□ بالقرب من أماكن التدخين

أفكار للملصقات:
□ "سري - الموارد البشرية"
□ "معلومات الرواتب 2024"
□ "قائمة تسريح الموظفين"
□ "صور خاصة"
```

<a id="-legal--ethical-considerations"></a>
## ⚠️ اعتبارات قانونية وأخلاقية

<a id="rules-of-engagement"></a>
### قواعد تنفيذ الاختبار (Rules of Engagement)
```
□ الحصول دائمًا على تفويض مكتوب
□ تحديد نطاق وحدود واضحة
□ عدم الوصول إلى الحسابات الشخصية
□ عدم اللجوء إلى الابتزاز أو الإكراه
□ توثيق كل شيء
□ توفير جهات اتصال للطوارئ
□ حمل خطاب التفويض وإثبات نطاق الاختبار
```

<a id="what-to-avoid"></a>
### ما ينبغي تجنبه
```
✗ انتحال صفة جهات إنفاذ القانون
✗ توجيه تهديدات حقيقية
✗ الوصول إلى أنظمة خارج النطاق
✗ سرقة أموال أو أصول فعلية
✗ التسبب في مسؤولية قانونية
✗ التسبب في أذى نفسي
```

<a id="-pretexting-checklist"></a>
## 📋 قائمة تحقق لاختلاق الذرائع

```markdown
التحضير:
□ البحث عن المؤسسة المستهدفة باستخدام OSINT
□ تحديد الموظفين الرئيسيين
□ بناء الشخصية وخلفيتها
□ إعداد المواد والوسائل الداعمة
□ التدرب على النص والردود
□ إعداد روايات بديلة

التنفيذ:
□ الحفاظ على الهدوء والثقة
□ توجيه المحادثة
□ الاستعداد لتغيير الأسلوب عند التشكيك
□ عدم المبالغة في الإقناع أو تقديم تفاصيل زائدة
□ معرفة متى يجب إيقاف المحاولة

بعد الاختبار:
□ توثيق ما نجح وما لم ينجح
□ تأمين أي بيانات جُمعت
□ الإبلاغ عن النتائج
□ تقديم التوصيات
```
