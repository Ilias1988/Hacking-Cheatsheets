## 🎯 Hva er pretexting?

Pretexting innebærer å konstruere en oppdiktet situasjon eller et påskudd for å komme i kontakt med en målperson, hente ut informasjon eller påvirke personen til å utføre en handling. Dette er grunnlaget for de fleste angrep som bygger på sosial manipulering.

**Viktige bestanddeler:**
- 🎭 **Rolle** – den falske identiteten du utgir deg for å ha
- 📖 **Historie** – den troverdige situasjonen eller begrunnelsen
- 🎯 **Mål** – det du vil oppnå
- 🔧 **Rekvisitter** – støttemateriell som adgangskort og e-poster

---

## 👥 Vanlige roller

### IT-brukerstøtte
```
Rolle: Tekniker ved IT-brukerstøtte
Mål: Tilbakestilling av passord, fjerntilgang, programvareinstallasjon

«Hei, dette er Mike fra IT. Vi ser uvanlig aktivitet
på kontoen din og må kontrollere påloggingsopplysningene
dine for å forhindre at kontoen blir sperret.»
```

### Leverandør eller oppdragstaker
```
Rolle: Ekstern leverandør (ventilasjon, sikkerhet, renhold)
Mål: Fysisk tilgang og nettverkstilgang

«Jeg kommer fra [Vendor Company] for det planlagte
vedlikeholdet. Kan du slippe meg inn på serverrommet?»
```

### Nyansatt
```
Rolle: Nyansatt som trenger hjelp
Mål: Informasjonsinnhenting og adgang til bygningen

«Hei, jeg har akkurat begynt i markedsavdelingen og
har problemer med å få tilgang til fellesdisken. Kan du hjelpe?»
```

### Leder eller autoritetsperson
```
Rolle: Administrerende direktør, økonomidirektør eller overordnet leder
Mål: Hasteforespørsler, bankoverføringer og tilgang

«Dette haster. Administrerende direktør trenger rapporten
umiddelbart, og jeg trenger at du omgår de vanlige rutinene.»
```

### Bud
```
Rolle: FedEx, UPS eller annet bud
Mål: Fysisk adgang og levering av en pakke

«Jeg har en pakke som krever signatur.
Kan du slippe meg inn i resepsjonen?»
```

## 📋 Situasjoner med oppdiktede påskudd

### Påskudd over telefon

#### Tilbakestilling av IT-passord
```
«Hei, dette er [Name] fra IT-brukerstøtte. Vi har
oppdaget at kontoen din ble kompromittert i en nylig
sikkerhetshendelse. Jeg må kontrollere identiteten din og
hjelpe deg med å tilbakestille passordet. Kan du bekrefte
det nåværende passordet ditt, så jeg kan kontrollere at det er deg?»
```

#### Bekreftelse av leverandøropplysninger
```
«Hei, jeg ringer fra leverandørreskontroen hos [Vendor]. Vi
oppdaterer registrene våre og må kontrollere bedriftens
bankopplysninger før neste betaling. Kan du bekrefte
kontonummeret dere har registrert for oss?»
```

#### HR-undersøkelse
```
«Hei, jeg gjennomfører en medarbeiderundersøkelse
for HR. Undersøkelsen er anonym, men jeg må kontrollere
at du er ansatt. Kan du fortelle hvilken avdeling du jobber
i, og hva lederen din heter?»
```

### Påskudd ved fysisk oppmøte

#### Branninspektør
```
«Hei, jeg kommer fra kommunens brannvesen. Vi
gjennomfører uanmeldte tilsyn. Jeg trenger tilgang til
serverrommet for å kontrollere brannslokkingsanlegget.»
```

#### Jobbintervju
```
«Jeg er her til intervjuet med HR klokken 2 PM. Mens jeg
venter, kan du vise meg hvor toalettet er?»
(Benytt anledningen til å orientere deg i bygningen)
```

#### Vedlikeholdsarbeider
```
«Vi har fått melding om en vannlekkasje i dette området.
Kan du vise meg hvor serverrommet er? Jeg må
kontrollere rørene over himlingen.»
```

## 🧠 Psykologiske prinsipper

### Autoritet
```
✓ Bruk titler: «IT-direktør», «sikkerhetssjef»
✓ Kle deg etter rollen: dress, uniform eller adgangskort
✓ Snakk med selvtillit
✓ Vis til retningslinjer og rutiner
```

### Tidspress
```
✓ «Dette må skje før møtet til administrerende direktør klokken 3»
✓ «Systemet sperrer deg ute om 10 minutter»
✓ «Vi er under revisjon og trenger dette umiddelbart»
✓ Skap tidspress for å hindre kontroll av opplysningene
```

### Gjensidighet
```
✓ Gjør en liten tjeneste først
✓ «Jeg hjalp akkurat med å løse skriverproblemet …»
✓ «Jeg tok med kaffe til alle …»
✓ Skap en følelse av plikt til å gjengjelde tjenesten
```

### Sosial bekreftelse
```
✓ «Alle de andre har allerede gjort dette»
✓ «Lederen din John har allerede godkjent dette»
✓ «Hele markedsavdelingen har fylt ut skjemaet»
✓ Vis til andre som har etterkommet forespørselen
```

### Sympati
```
✓ Finn felles interesser
✓ Speil kroppsspråket
✓ Gi oppriktige komplimenter
✓ Bygg en god relasjon før du ber om noe
```

## 🔧 Rekvisitter og støttemateriell

### Fysiske rekvisitter
```
□ Falske ID- eller adgangskort
□ Visittkort
□ Skriveplate med skjemaer som ser offisielle ut
□ Refleksvest eller uniform
□ Verktøykasse eller laptopveske
□ Utskrifter av e-poster eller fullmakter
□ Leverandørdokumenter
```

### Digitale rekvisitter
```
□ Forfalsket visning av telefonnummer
□ Falsk e-postadresse (domene som ligner)
□ Falsk LinkedIn-profil
□ Klonet virksomhetsnettsted
□ Forfalskede e-poster med godkjenning
□ Falske møteinnkallinger
```

### Dokumentasjon
```
□ Nummer på supportsak
□ Arbeidsordre
□ Fullmaktsskjema
□ Referansenummer
□ Navnet på lederen (fra OSINT)
```

## 🔍 OSINT for pretexting

### Undersøk målorganisasjonen
```bash
# LinkedIn for opplysninger om ansatte
- Navn, stillingstitler og avdelinger
- Rapporteringslinjer
- Nye innlegg og annen aktivitet

# Virksomhetens nettsted
- Ledergruppen
- Organisasjonskart
- Kontoradresser
- Opplysninger om leverandører og partnere

# Pressemeldinger
- Nye hendelser og oppkjøp
- Endringer i ledelsen
```

### Nyttig informasjon
```
□ Navn og stillingstitler på ansatte
□ Avdelingsstruktur
□ Navn på ledere
□ E-postformat (first.last@company.com)
□ Telefonnumre
□ Kontoradresser
□ Leverandørforbindelser
□ Nylige hendelser i virksomheten
```

## 📱 Sosial manipulering ved fysisk oppmøte

### Tailgating (følge etter noen gjennom en adgangskontroll)
```
Teknikk: Følg en person med adgang gjennom en sikret dør

«Takk, jeg glemte adgangskortet mitt i dag!»
«Kan du holde døren? Jeg har hendene fulle.»
«Jeg er her sammen med [Name] fra [Department].»
```

### Piggybacking (bli sluppet inn av noen med adgang)
```
Teknikk: Få en person med adgang til å slippe deg inn

«Hei, jeg kommer fra [Vendor]. De venter meg, men
resepsjonisten er borte et øyeblikk. Kan du slippe meg inn?»
```

### Dumpster diving (leting i avfall)
```
Mål: Kasserte dokumenter og maskinvare

□ Organisasjonskart
□ Ansattlister
□ Økonomiske dokumenter
□ Notater med passord
□ Gammel maskinvare med data
```

### Utplasserte USB-enheter (baiting)
```
Teknikk: Legg igjen infiserte USB-enheter

Plasseringer:
□ Parkeringsplass
□ Resepsjon
□ Pauserom
□ Ved røykeområder

Forslag til merking:
□ «Konfidensielt – HR»
□ «Lønnsinformasjon 2024»
□ «Liste over oppsigelser»
□ «Private bilder»
```

## 📝 Manusmaler

### Telefonmanus – IT-brukerstøtte
```
[Ring ring]
Målperson: «Hallo?»
Du: «Hei, snakker jeg med [Target Name]?»
Målperson: «Ja.»
Du: «Flott, dette er [Your Name] fra IT-sikkerhetsteamet.
Vi har fulgt med på noen uvanlige påloggingsforsøk på
kontoen din fra en utenlandsk IP-adresse. Vi vil forsikre
oss om at det ikke var deg. Prøvde du å logge inn fra
[Random Country] i dag?»
Målperson: «Nei, det var ikke meg!»
Du: «Det var det jeg trodde. Av sikkerhetshensyn må jeg
kontrollere kontoen din. Kan du bekrefte brukernavnet ditt,
så tilbakestiller vi passordet og stenger angriperen ute?»
```

### E-postmanus – forespørsel fra en leder
```
Emne: Haster – bankoverføring nødvendig

Hei [Name],

Jeg sitter i et møte og kan ikke ringe. Jeg trenger at du
gjennomfører en bankoverføring som haster, i forbindelse
med et oppkjøp med kort tidsfrist.

Overfør $45,000 til følgende konto:
[Details]

Jeg forklarer når jeg er ferdig i møtet. Bekreft
så snart det er gjennomført.

[Executive Name]
Sendt fra min iPhone
```

## ⚠️ Juridiske og etiske hensyn

### Rammer for oppdraget (Rules of Engagement)
```
□ Ha alltid skriftlig tillatelse
□ Definer tydelig omfang og grenser
□ Ikke gå inn på private kontoer
□ Ingen utpressing eller tvang
□ Dokumenter alt
□ Ha beredskapskontakter
□ Ha en skriftlig bekreftelse på testoppdraget tilgjengelig («get-out-of-jail letter»)
```

> **Presisering:** En «get-out-of-jail letter» er dokumentasjon på et avtalt testoppdrag, ikke juridisk immunitet eller tillatelse til handlinger utenfor avtalt omfang.

### Dette bør unngås
```
✗ Å utgi seg for å være politi
✗ Å fremsette reelle trusler
✗ Å få tilgang til systemer utenfor avtalt omfang
✗ Å stjele faktiske penger eller eiendeler
✗ Å pådra seg juridisk ansvar
✗ Å påføre psykisk skade
```

## 📋 Sjekkliste for pretexting

```markdown
Forberedelser:
□ Undersøk målorganisasjonen (OSINT)
□ Identifiser nøkkelpersoner
□ Utarbeid en rolle og bakgrunnshistorie
□ Klargjør støttemateriell og rekvisitter
□ Øv på manus og svar
□ Ha alternative historier klare

Gjennomføring:
□ Vær rolig og sikker
□ Styr samtalen
□ Vær klar til å endre retning hvis du blir utfordret
□ Ikke overdriv eller gi for mange detaljer
□ Vit når forsøket skal avbrytes

Etter oppdraget:
□ Dokumenter hva som fungerte og ikke fungerte
□ Sikre eventuelle innsamlede data
□ Rapporter funn
□ Gi anbefalinger
```
