## 🎯 Что такое претекстинг?

Претекстинг — создание вымышленного сценария, или предлога (pretext), чтобы вступить в контакт с человеком, получить сведения либо побудить его к нужному действию. Он лежит в основе большинства атак с применением социальной инженерии.

**Основные составляющие:**
- 🎭 **Роль (Persona)** — вымышленная личность, от имени которой вы действуете
- 📖 **История** — правдоподобный сценарий или причина обращения
- 🎯 **Цель** — желаемый результат
- 🔧 **Реквизит** — подтверждающие материалы: пропуска, письма и т. п.

## 👥 Типичные роли

### ИТ-поддержка
```
Роль: специалист службы ИТ-поддержки
Цель: сброс пароля, удалённый доступ, установка ПО

«Здравствуйте, это Майк из ИТ-отдела. Мы заметили необычную
активность в вашей учётной записи и должны проверить
учётные данные, чтобы предотвратить блокировку».
```

### Поставщик или подрядчик
```
Роль: сторонний подрядчик (вентиляция, охрана, уборка)
Цель: физический доступ, доступ к сети

«Я из [Vendor Company], приехал для планового обслуживания.
Можете пропустить меня в серверную?»
```

### Новый сотрудник
```
Роль: новый сотрудник, которому нужна помощь
Цель: сбор сведений, доступ в здание

«Здравствуйте, я только начал работать в маркетинге,
и у меня не получается открыть общий диск. Поможете?»
```

### Руководитель или представитель власти
```
Роль: генеральный директор, финансовый директор, старший руководитель
Цель: срочные поручения, банковские переводы, доступ

«Это срочно. Генеральному директору немедленно нужен этот отчёт,
поэтому придётся обойти обычные процедуры».
```

### Курьер
```
Роль: FedEx, UPS, курьер
Цель: физический доступ, передача посылки

«У меня посылка, за которую нужно расписаться.
Можете пропустить меня на ресепшен?»
```

## 📋 Сценарии претекстинга

### Телефонные предлоги

#### Сброс пароля от имени ИТ-поддержки
```
«Здравствуйте, это [Name] из службы ИТ-поддержки.
Мы обнаружили, что ваша учётная запись была скомпрометирована
в ходе недавнего инцидента. Мне нужно подтвердить вашу личность
и помочь сбросить пароль. Можете назвать текущий пароль,
чтобы я убедился, что это действительно вы?»
```

#### Проверка данных поставщика
```
«Здравствуйте, звоню из бухгалтерии [Vendor]. Мы обновляем
наши записи и должны проверить банковские реквизиты вашей
компании перед следующим платежом. Можете подтвердить
номер нашего счёта, который указан у вас?»
```

#### Опрос от отдела кадров
```
«Здравствуйте, я провожу для отдела кадров опрос
об удовлетворённости сотрудников. Опрос анонимный, но нужно
убедиться, что вы сотрудник. Назовите, пожалуйста,
ваш отдел и имя руководителя».
```

### Предлоги при личном контакте

#### Пожарный инспектор
```
«Здравствуйте, я из городской пожарной инспекции.
Мы проводим внеплановые проверки. Мне нужен доступ
в серверную для проверки системы пожаротушения».
```

#### Собеседование
```
«Я пришёл на собеседование с отделом кадров в 14:00.
Пока я жду, не подскажете, где туалет?»
(Использовать возможность осмотреть здание)
```

#### Сотрудник технического обслуживания
```
«Нам сообщили об утечке воды в этой части здания.
Покажите, пожалуйста, где серверная. Нужно проверить трубы,
которые проходят над потолком».
```

## 🧠 Психологические принципы

### Авторитет
```
✓ Использовать должности: «ИТ-директор», «руководитель службы безопасности»
✓ Одеваться соответственно роли: костюм, форма, пропуск
✓ Говорить уверенно
✓ Ссылаться на политики и процедуры
```

### Срочность
```
✓ «Это нужно сделать до совещания генерального директора в 15:00»
✓ «Через 10 минут система заблокирует вашу учётную запись»
✓ «У нас аудит, и это нужно немедленно»
✓ Создавать нехватку времени, чтобы помешать проверке
```

### Взаимность
```
✓ Сначала оказать небольшую услугу
✓ «Я только что помог решить проблему с принтером…»
✓ «Я принёс кофе для всех…»
✓ Создать ощущение обязанности ответить услугой
```

### Социальное доказательство
```
✓ «Все остальные уже это сделали»
✓ «Ваш руководитель Джон уже это согласовал»
✓ «Весь отдел маркетинга уже заполнил форму»
✓ Ссылаться на других людей, которые согласились
```

### Симпатия
```
✓ Найти общие интересы
✓ Повторять язык тела собеседника
✓ Делать уместные, искренние комплименты
✓ Установить контакт до обращения с просьбой
```

## 🔧 Реквизит и подтверждающие материалы

### Физический реквизит
```
□ Поддельные служебные пропуска
□ Визитные карточки
□ Планшет с бланками официального вида
□ Светоотражающий жилет или форма
□ Ящик с инструментами или сумка для ноутбука
□ Распечатанные письма и разрешения
□ Документы подрядчика
```

### Цифровой реквизит
```
□ Подменённый номер звонящего (Caller ID)
□ Поддельный адрес почты на похожем домене
□ Поддельный профиль LinkedIn
□ Копия сайта компании
□ Поддельные письма с разрешением
□ Поддельные приглашения на встречи
```

### Документы
```
□ Номер заявки в службу поддержки
□ Наряд на работы
□ Форма разрешения
□ Регистрационный номер
□ Имя руководителя (из OSINT)
```

## 📱 Социальная инженерия с физическим доступом

### Проход следом за сотрудником (Tailgating)
```
Приём: пройти через защищённую дверь вслед за человеком с доступом

«Спасибо, я сегодня забыл пропуск!»
«Подержите дверь, пожалуйста, у меня руки заняты».
«Я с [Name] из [Department]».
```

### Проход с помощью сотрудника (Piggybacking)
```
Приём: убедить человека с доступом пропустить вас

«Здравствуйте, я из [Vendor]. Меня ждут, но сотрудник ресепшена
куда-то отошёл. Можете меня пропустить?»
```

### Поиск сведений в выброшенных материалах (Dumpster Diving)
```
Цель: выброшенные документы и оборудование

□ Организационные схемы
□ Списки сотрудников
□ Финансовые документы
□ Записки с паролями
□ Старое оборудование с данными
```

### Подбрасывание USB-носителей (Baiting)
```
Приём: оставить заражённые USB-накопители

Места:
□ Парковка
□ Зона ресепшена
□ Комнаты отдыха
□ Рядом с местами для курения

Идеи надписей:
□ «Конфиденциально — отдел кадров»
□ «Сведения о зарплате за 2024 год»
□ «Список на увольнение»
□ «Личные фотографии»
```

## 📝 Шаблоны сценариев

### Телефонный сценарий — ИТ-поддержка
```
[Звонок]
Собеседник: «Алло?»
Вы: «Здравствуйте, это [Target Name]?»
Собеседник: «Да».
Вы: «Отлично, это [Your Name] из команды ИТ-безопасности.
Мы отслеживаем необычные попытки входа в вашу учётную запись
с зарубежного IP-адреса. Хотим убедиться, что это были не вы.
Вы сегодня пытались войти из [Random Country]?»
Собеседник: «Нет, это был не я!»
Вы: «Я так и думал. Для безопасности нужно проверить
вашу учётную запись. Назовите имя пользователя,
и мы сбросим пароль, чтобы закрыть доступ атакующему».
```

### Письмо — просьба руководителя
```
Тема: Срочно — необходим банковский перевод

Здравствуйте, [Name]!

Я на совещании и не могу позвонить. Нужно срочно провести
банковский перевод для сделки по приобретению,
сроки которой поджимают.

Переведите, пожалуйста, $45,000 на следующий счёт:
[Details]

Я всё объясню после совещания. Подтвердите выполнение.

[Executive Name]
Отправлено с моего iPhone
```

## ⚠️ Правовые и этические аспекты

### Правила проведения проверки (Rules of Engagement)
```
□ Всегда иметь письменное разрешение
□ Чётко определить границы и ограничения проверки
□ Не обращаться к личным учётным записям
□ Не применять шантаж или принуждение
□ Документировать все действия
□ Иметь контакты для экстренной связи
□ Иметь при себе письмо, подтверждающее разрешение на проверку
```

### Чего следует избегать
```
✗ Выдавать себя за сотрудника правоохранительных органов
✗ Высказывать реальные угрозы
✗ Получать доступ к системам за пределами согласованных границ
✗ Похищать реальные деньги или имущество
✗ Создавать основания для юридической ответственности
✗ Причинять психологический вред
```
