## 🎯 ¿Qué es el pretexting?

El pretexting consiste en inventar un escenario o pretexto para interactuar con una persona y obtener información o manipularla para que realice una acción. Es la base de muchos ataques de ingeniería social.

**Componentes clave:**
- 🎭 **Identidad** - La identidad falsa que se adopta
- 📖 **Historia** - El escenario o motivo creíble
- 🎯 **Objetivo** - Lo que se pretende conseguir
- 🔧 **Elementos de apoyo** - Materiales que respaldan la historia (acreditaciones, correos)

---

## 👥 Identidades habituales

### Soporte informático
```
Papel: técnico del servicio de soporte informático
Objetivo: restablecimiento de contraseña, acceso remoto e instalación de software

«Hola, soy Mike, del departamento de TI. Hemos detectado actividad
inusual en tu cuenta y necesitamos verificar tus credenciales
para evitar que se bloquee.»
```

### Proveedor o contratista
```
Papel: proveedor externo (climatización, seguridad, limpieza)
Objetivo: acceso físico y acceso a la red

«Vengo de [Vendor Company] para el mantenimiento programado.
¿Puedes dejarme entrar en la sala de servidores?»
```

### Nuevo empleado
```
Papel: nueva incorporación que necesita ayuda
Objetivo: recopilar información y acceder al edificio

«Hola, acabo de incorporarme al equipo de marketing y tengo problemas
para acceder a la unidad compartida. ¿Puedes ayudarme?»
```

### Directivo o figura de autoridad
```
Papel: CEO, CFO o alto directivo
Objetivo: peticiones urgentes, transferencias bancarias y acceso

«Es urgente. El CEO necesita este informe de inmediato
y necesito que omitas los procedimientos habituales.»
```

### Repartidor
```
Papel: repartidor de FedEx, UPS o mensajería
Objetivo: acceso físico y entrega de paquetes

«Tengo un paquete que requiere una firma.
¿Puedes dejarme pasar a recepción?»
```

## 📋 Escenarios de pretexting

### Pretextos telefónicos

#### Restablecimiento de contraseña por soporte informático
```
«Hola, soy [Name], del servicio de soporte informático. Hemos detectado
que tu cuenta se ha visto comprometida en un incidente de seguridad
reciente. Necesito verificar tu identidad y ayudarte a restablecer tu
contraseña. ¿Puedes confirmar tu contraseña actual para comprobar
que eres tú?»
```

#### Verificación de proveedores
```
«Hola, llamo del departamento de cuentas por pagar de [Vendor]. Estamos
actualizando nuestros registros y necesitamos verificar los datos
bancarios de vuestra empresa para el próximo pago. ¿Puedes confirmar
el número de cuenta que tenéis registrado para nosotros?»
```

#### Encuesta de Recursos Humanos
```
«Hola, estoy realizando una encuesta de satisfacción de empleados para
Recursos Humanos. Es anónima, pero necesito verificar que trabajas en
la empresa. ¿Puedes decirme tu departamento y el nombre de tu responsable?»
```

### Pretextos presenciales

#### Inspector de prevención de incendios
```
«Hola, vengo del servicio municipal de prevención de incendios. Estamos
realizando inspecciones sin previo aviso. Necesitaré acceder a vuestra
sala de servidores para revisar el sistema de extinción de incendios.»
```

#### Entrevista de trabajo
```
«Tengo una entrevista con Recursos Humanos a las 2 de la tarde.
Mientras espero, ¿puedes indicarme dónde están los aseos?»
(Aprovechar la ocasión para reconocer el edificio)
```

#### Personal de mantenimiento
```
«Hemos recibido un aviso de una fuga de agua en esta zona.
¿Puedes mostrarme dónde está la sala de servidores? Necesito
revisar las tuberías que pasan por encima del techo.»
```

## 🧠 Principios psicológicos

### Autoridad
```
✓ Utilizar cargos: «Director de TI», «Responsable de seguridad»
✓ Vestir de acuerdo con el papel: traje, uniforme, acreditación
✓ Hablar con seguridad
✓ Hacer referencia a políticas y procedimientos
```

### Urgencia
```
✓ «Esto debe hacerse antes de la reunión del CEO a las 3»
✓ «El sistema bloqueará tu acceso dentro de 10 minutos»
✓ «Nos están auditando y necesitamos esto de inmediato»
✓ Crear presión de tiempo para impedir la verificación
```

### Reciprocidad
```
✓ Hacer primero un pequeño favor
✓ «Acabo de ayudar a resolver el problema de la impresora...»
✓ «He traído café para todos...»
✓ Crear una sensación de obligación de devolver el favor
```

### Prueba social
```
✓ «Todos los demás ya lo han hecho»
✓ «Tu responsable John ya lo ha aprobado»
✓ «Todo el equipo de marketing ha rellenado el formulario»
✓ Mencionar a otras personas que accedieron
```

### Simpatía
```
✓ Buscar puntos en común
✓ Reflejar el lenguaje corporal
✓ Hacer cumplidos sinceros
✓ Generar confianza antes de pedir algo
```

## 🔧 Elementos y materiales de apoyo

### Elementos físicos de apoyo
```
□ Acreditaciones falsas
□ Tarjetas de visita
□ Portapapeles con formularios de apariencia oficial
□ Chaleco reflectante o uniforme
□ Caja de herramientas o bolsa de portátil
□ Correos o cartas de autorización impresos
□ Documentación de proveedores
```

### Elementos digitales de apoyo
```
□ Identificador de llamada suplantado
□ Dirección de correo falsa (dominio parecido)
□ Perfil falso de LinkedIn
□ Sitio web de la empresa clonado
□ Correos de autorización falsificados
□ Invitaciones falsas a reuniones
```

### Documentación
```
□ Número de ticket de servicio
□ Orden de trabajo
□ Formulario de autorización
□ Número de referencia
□ Nombre del responsable (obtenido mediante OSINT)
```

## 🔍 OSINT para pretexting

### Investigación del objetivo
```bash
# LinkedIn para obtener información de empleados
- Nombres, cargos y departamentos
- Estructura jerárquica
- Publicaciones o actividad recientes

# Sitio web de la empresa
- Equipo directivo
- Organigrama
- Ubicaciones de las oficinas
- Información de proveedores y socios

# Comunicados de prensa
- Noticias y adquisiciones recientes
- Cambios en la dirección
```

> **Formato del original:** el bloque anterior está etiquetado como `bash`, pero contiene una lista de fuentes e información que investigar, no comandos ejecutables.

### Información útil
```
□ Nombres y cargos de los empleados
□ Estructura de los departamentos
□ Nombres de los responsables
□ Formato de correo (first.last@company.com)
□ Números de teléfono
□ Ubicaciones de las oficinas
□ Relaciones con proveedores
□ Acontecimientos recientes en la empresa
```

## 📱 Ingeniería social presencial

### Tailgating
```
Técnica: seguir a una persona autorizada a través de una puerta de acceso restringido

«¡Gracias, hoy me he olvidado la acreditación!»
«¿Puedes sujetarme la puerta? Tengo las manos ocupadas.»
«Estoy aquí con [Name], de [Department].»
```

### Piggybacking
```
Técnica: conseguir que una persona autorizada permita la entrada

«Hola, vengo de [Vendor]. Me están esperando, pero la persona de
recepción se ha ausentado. ¿Puedes dejarme entrar?»
```

### Dumpster Diving
```
Objetivo: documentos y equipos desechados

□ Organigramas
□ Listas de empleados
□ Documentos financieros
□ Notas con contraseñas
□ Equipos antiguos con datos
```

### Abandono de USB (baiting o señuelo)
```
Técnica: dejar unidades USB infectadas

Ubicaciones:
□ Aparcamiento
□ Recepción
□ Salas de descanso
□ Cerca de zonas de fumadores

Ideas para las etiquetas:
□ «Confidencial - RR. HH.»
□ «Información salarial 2024»
□ «Lista de despidos»
□ «Fotos privadas»
```

## 📝 Plantillas de guiones

### Guion telefónico: soporte informático
```
[Suena el teléfono]
Objetivo: «¿Diga?»
Tú: «Hola, ¿hablo con [Target Name]?»
Objetivo: «Sí.»
Tú: «Perfecto, soy [Your Name], del equipo de seguridad de TI.
Hemos observado intentos de inicio de sesión inusuales en tu cuenta
desde una dirección IP extranjera. Queremos asegurarnos de que no
has sido tú. ¿Has intentado iniciar sesión desde [Random Country] hoy?»
Objetivo: «¡No, no he sido yo!»
Tú: «Eso pensaba. Por seguridad, necesito verificar tu cuenta.
¿Puedes confirmar tu nombre de usuario? Restableceremos tu contraseña
para bloquear el acceso del atacante.»
```

### Guion de correo: petición de un directivo
```
Asunto: Urgente - Se necesita una transferencia bancaria

Hola, [Name]:

Estoy en una reunión y no puedo llamar. Necesito que tramites una
transferencia urgente para una adquisición con un plazo muy ajustado.

Transfiere $45,000 a la siguiente cuenta:
[Details]

Te lo explicaré cuando salga de la reunión.
Confírmame cuando esté hecho.

[Executive Name]
Enviado desde mi iPhone
```

## ⚠️ Consideraciones legales y éticas

### Reglas de la prueba (Rules of Engagement)
```
□ Contar siempre con autorización escrita
□ Definir con claridad el alcance y los límites
□ No acceder a cuentas personales
□ No recurrir al chantaje ni a la coacción
□ Documentar todo
□ Disponer de contactos de emergencia
□ Llevar una carta que acredite la autorización de la prueba
```

### Qué se debe evitar
```
✗ Suplantar a las fuerzas de seguridad
✗ Formular amenazas reales
✗ Acceder a sistemas fuera del alcance autorizado
✗ Robar dinero o bienes reales
✗ Generar responsabilidades legales
✗ Causar daño psicológico
```

## 📋 Lista de comprobación de pretexting

```markdown
Preparación:
□ Investigar la organización objetivo (OSINT)
□ Identificar al personal clave
□ Desarrollar la identidad y su historia
□ Preparar los materiales y elementos de apoyo
□ Practicar el guion y las respuestas
□ Preparar historias alternativas

Ejecución:
□ Mantener la calma y la seguridad
□ Controlar la conversación
□ Estar preparado para cambiar de enfoque si surgen dudas
□ No exagerar ni aportar demasiados detalles
□ Saber cuándo abandonar la prueba

Después de la prueba:
□ Documentar qué funcionó y qué no
□ Proteger todos los datos capturados
□ Informar de los hallazgos
□ Proporcionar recomendaciones
```
