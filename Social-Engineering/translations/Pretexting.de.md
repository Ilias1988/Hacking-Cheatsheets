## 🎯 Was ist Pretexting?

Beim Pretexting wird ein erfundenes, glaubwürdiges Szenario als Vorwand genutzt, um mit einer Zielperson ins Gespräch zu kommen, Informationen zu erhalten oder sie zu einer Handlung zu bewegen. Es bildet die Grundlage vieler Social-Engineering-Angriffe.

**Wichtige Bestandteile:**
- 🎭 **Rolle (Persona)** – Die vorgetäuschte Identität
- 📖 **Geschichte** – Das glaubwürdige Szenario beziehungsweise die Begründung
- 🎯 **Ziel** – Das gewünschte Ergebnis
- 🔧 **Hilfsmittel** – Unterstützende Materialien wie Ausweise oder E-Mails

## 👥 Häufige Rollen

### IT-Support
```
Rolle: Techniker im IT-Helpdesk
Ziel: Passwortzurücksetzung, Fernzugriff, Softwareinstallation

„Hallo, hier ist Mike von der IT. Wir sehen ungewöhnliche
Aktivitäten in Ihrem Konto und müssen Ihre Zugangsdaten
überprüfen, um eine Sperrung zu verhindern.“
```

### Dienstleister oder Auftragnehmer
```
Rolle: Externer Dienstleister (Heizung/Klima, Sicherheit, Reinigung)
Ziel: Physischer Zutritt, Netzwerkzugang

„Ich bin von [Vendor Company] und für die vereinbarte Wartung
hier. Können Sie mich in den Serverraum lassen?“
```

### Neuer Mitarbeiter
```
Rolle: Neuer Mitarbeiter, der Hilfe benötigt
Ziel: Informationen sammeln, Zutritt zum Gebäude

„Hallo, ich habe gerade im Marketing angefangen und habe
Probleme mit dem Zugriff auf das gemeinsame Laufwerk.
Könnten Sie mir helfen?“
```

### Führungskraft oder Autoritätsperson
```
Rolle: Geschäftsführer, Finanzvorstand oder leitender Manager
Ziel: Dringende Anfragen, Überweisungen oder Zugang

„Das ist dringend. Der Geschäftsführer benötigt diesen Bericht
sofort. Ich brauche Ihre Unterstützung, um die üblichen
Verfahren zu umgehen.“
```

### Zustellperson
```
Rolle: FedEx-, UPS- oder Kurierzusteller
Ziel: Physischer Zutritt, Paketabgabe

„Ich habe ein Paket, für das eine Unterschrift erforderlich ist.
Können Sie mich zum Empfang hineinlassen?“
```

## 📋 Szenarien für Vorwände

### Vorwände am Telefon

#### Passwortzurücksetzung durch die IT
```
„Guten Tag, hier ist [Name] vom IT-Helpdesk. Wir haben festgestellt,
dass Ihr Konto bei einem kürzlichen Sicherheitsvorfall kompromittiert
wurde. Ich muss Ihre Identität überprüfen und Ihnen bei der
Passwortzurücksetzung helfen. Können Sie mir Ihr aktuelles Passwort
nennen, damit ich bestätigen kann, dass Sie es wirklich sind?“
```

#### Überprüfung eines Dienstleisters
```
„Hallo, ich rufe aus der Kreditorenbuchhaltung von [Vendor] an.
Wir aktualisieren unsere Unterlagen und müssen die Bankdaten
Ihres Unternehmens für die nächste Zahlung überprüfen.
Können Sie die Kontonummer bestätigen, die Sie für uns hinterlegt haben?“
```

#### Befragung durch die Personalabteilung
```
„Guten Tag, ich führe für die Personalabteilung eine Befragung zur
Mitarbeiterzufriedenheit durch. Die Befragung ist anonym, aber ich
muss prüfen, ob Sie hier beschäftigt sind. Können Sie mir Ihre
Abteilung und den Namen Ihres Vorgesetzten nennen?“
```

### Vorwände bei persönlichem Kontakt

#### Brandschutzinspektor
```
„Hallo, ich bin von der städtischen Brandschutzbehörde. Wir führen
unangekündigte Kontrollen durch. Ich benötige Zugang zu Ihrem
Serverraum, um die Feuerlöschanlage zu überprüfen.“
```

#### Vorstellungsgespräch
```
„Ich bin wegen des Vorstellungsgesprächs mit der Personalabteilung
um 14 Uhr hier. Könnten Sie mir zeigen, wo die Toilette ist,
während ich warte?“
(Die Gelegenheit nutzen, um das Gebäude zu erkunden)
```

#### Wartungstechniker
```
„Wir haben einen Anruf wegen eines Wasserlecks in diesem Bereich
erhalten. Können Sie mir zeigen, wo der Serverraum ist?
Ich muss die Leitungen oberhalb der Decke überprüfen.“
```

## 🧠 Psychologische Prinzipien

### Autorität
```
✓ Funktionsbezeichnungen verwenden: „IT-Leiter“, „Sicherheitsmanager“
✓ Passende Kleidung tragen: Anzug, Uniform oder Ausweis
✓ Selbstsicher sprechen
✓ Auf Richtlinien und Verfahren verweisen
```

### Dringlichkeit
```
✓ „Das muss vor der Besprechung des Geschäftsführers um 3 erledigt sein“
✓ „Das System wird Sie in 10 Minuten aussperren“
✓ „Wir werden gerade geprüft und benötigen das sofort“
✓ Zeitdruck erzeugen, um eine Überprüfung zu verhindern
```

### Gegenseitigkeit
```
✓ Zuerst einen kleinen Gefallen tun
✓ „Ich habe gerade bei dem Druckerproblem geholfen …“
✓ „Ich habe Kaffee für alle mitgebracht …“
✓ Das Gefühl erzeugen, den Gefallen erwidern zu müssen
```

### Soziale Bewährtheit (Social Proof)
```
✓ „Alle anderen haben das bereits erledigt“
✓ „Ihr Vorgesetzter John hat das bereits genehmigt“
✓ „Das gesamte Marketingteam hat das Formular ausgefüllt“
✓ Auf andere verweisen, die der Aufforderung nachgekommen sind
```

### Sympathie
```
✓ Gemeinsamkeiten finden
✓ Körpersprache spiegeln
✓ Glaubwürdig Komplimente machen
✓ Vor der Bitte eine persönliche Verbindung aufbauen
```

## 🔧 Hilfsmittel und unterstützende Materialien

### Physische Hilfsmittel
```
□ Gefälschte Dienstausweise
□ Visitenkarten
□ Klemmbrett mit offiziell wirkenden Formularen
□ Warnweste oder Uniform
□ Werkzeugkasten oder Laptoptasche
□ Ausgedruckte E-Mails oder Genehmigungsschreiben
□ Unterlagen eines Dienstleisters
```

### Digitale Hilfsmittel
```
□ Gefälschte Absenderrufnummer
□ Gefälschte E-Mail-Adresse (ähnliche Domain)
□ Gefälschtes LinkedIn-Profil
□ Kopie der Unternehmenswebsite
□ Gefälschte Genehmigungs-E-Mails
□ Gefälschte Besprechungseinladungen
```

### Dokumentation
```
□ Nummer eines Supporttickets
□ Arbeitsauftrag
□ Genehmigungsformular
□ Referenznummer
□ Name des Vorgesetzten (aus OSINT)
```

## 📱 Physisches Social Engineering

### Tailgating
```
Technik: Einer berechtigten Person durch eine gesicherte Tür folgen

„Oh, danke! Ich habe heute meinen Ausweis vergessen!“
„Können Sie die Tür aufhalten? Ich habe die Hände voll.“
„Ich bin mit [Name] aus [Department] hier.“
```

### Piggybacking
```
Technik: Eine berechtigte Person dazu bringen, den Zutritt zu ermöglichen

„Hallo, ich komme von [Vendor]. Man erwartet mich, aber die
Empfangskraft ist gerade nicht da. Könnten Sie mich hineinlassen?“
```

### Dumpster Diving
```
Ziel: Weggeworfene Unterlagen und Hardware

□ Organigramme
□ Beschäftigtenlisten
□ Finanzunterlagen
□ Passwortnotizen
□ Alte Hardware mit gespeicherten Daten
```

### USB Drops (Baiting)
```
Technik: Infizierte USB-Sticks auslegen

Orte:
□ Parkplatz
□ Empfangsbereich
□ Pausenräume
□ In der Nähe von Raucherbereichen

Ideen für Beschriftungen:
□ „Vertraulich – Personalabteilung“
□ „Gehaltsinformationen 2024“
□ „Entlassungsliste“
□ „Private Fotos“
```

## 📝 Gesprächs- und Nachrichtenvorlagen

### Telefonleitfaden – IT-Support
```
[Telefon klingelt]
Zielperson: „Hallo?“
Sie: „Guten Tag, spreche ich mit [Target Name]?“
Zielperson: „Ja.“
Sie: „Sehr gut, hier ist [Your Name] vom IT-Sicherheitsteam.
Wir beobachten ungewöhnliche Anmeldeversuche an Ihrem Konto
von einer ausländischen IP-Adresse. Wir möchten sicherstellen,
dass Sie das nicht waren. Haben Sie heute versucht, sich aus
[Random Country] anzumelden?“
Zielperson: „Nein, das war ich nicht!“
Sie: „Das dachte ich mir. Zur Sicherheit muss ich Ihr Konto
überprüfen. Können Sie Ihren Benutzernamen bestätigen?
Dann setzen wir Ihr Passwort zurück, um den Angreifer auszusperren.“
```

### E-Mail-Vorlage – Anfrage einer Führungskraft
```
Betreff: Dringend – Überweisung erforderlich

Hallo [Name],

ich bin in einer Besprechung und kann nicht telefonieren.
Ich brauche Ihre Unterstützung bei einer dringenden Überweisung
für eine zeitkritische Übernahme.

Bitte überweisen Sie $45,000 auf das folgende Konto:
[Details]

Ich erkläre alles nach der Besprechung. Bitte bestätigen Sie,
sobald die Überweisung ausgeführt wurde.

[Executive Name]
Von meinem iPhone gesendet
```

## ⚠️ Rechtliche und ethische Aspekte

### Vereinbarte Einsatzregeln (Rules of Engagement)
```
□ Immer eine schriftliche Genehmigung haben
□ Umfang und Grenzen eindeutig festlegen
□ Kein Zugriff auf private Konten
□ Keine Erpressung oder Nötigung
□ Alles dokumentieren
□ Notfallkontakte bereithalten
□ Genehmigungsschreiben zur Klärung bei Kontrollen mitführen
```

### Was zu vermeiden ist
```
✗ Sich als Strafverfolgungsbehörde ausgeben
✗ Echte Drohungen aussprechen
✗ Auf Systeme außerhalb des vereinbarten Umfangs zugreifen
✗ Tatsächlich Geld oder Vermögenswerte stehlen
✗ Rechtliche Haftungsrisiken verursachen
✗ Psychische Schäden verursachen
```

## 📋 Checkliste für Pretexting

```markdown
Vorbereitung:
□ Zielorganisation recherchieren (OSINT)
□ Wichtige Personen identifizieren
□ Rolle und Hintergrundgeschichte entwickeln
□ Unterstützende Materialien und Hilfsmittel vorbereiten
□ Gesprächsleitfaden und Antworten üben
□ Alternative Erklärungen bereithalten

Durchführung:
□ Ruhig und selbstsicher bleiben
□ Das Gespräch führen
□ Bei Rückfragen auf eine andere Erklärung umstellen können
□ Nicht übertreiben oder zu viele Einzelheiten nennen
□ Den richtigen Zeitpunkt zum Abbruch erkennen

Nach dem Einsatz:
□ Dokumentieren, was funktioniert hat und was nicht
□ Erfasste Daten sichern
□ Ergebnisse berichten
□ Empfehlungen geben
```

## Hinweise zur deutschen Ausgabe

> **Begriffe:** *OSINT* ist die Auswertung öffentlich zugänglicher Informationen. *Tailgating* und *Piggybacking* bezeichnen hier unterschiedliche Varianten des Mitgehens in einen geschützten Bereich; die Abgrenzung ist in der Praxis nicht einheitlich. *Dumpster Diving* meint das Durchsuchen weggeworfener Materialien, *Baiting* das Anlocken mit einem Köder, hier USB-Sticks. Das „Get-out-of-jail letter“ genannte Dokument ist ein mitgeführtes Genehmigungsschreiben.

> **Einordnung der Vorlagen:** Die Dialoge sind Beispiele für Täuschungsversuche, keine legitimen Identitätsprüfungen. Die behauptete anonyme HR-Befragung fragt zugleich identifizierende Angaben ab. Die Beschriftung mit 2024 ist ein historischer Beispieltext. Beträge, technische Adressen und Platzhalter der Nachrichtenvorlagen wurden unverändert übernommen. Die unter `bash` stehende OSINT-Liste enthält Recherchepunkte und keine ausführbaren Shell-Befehle.
