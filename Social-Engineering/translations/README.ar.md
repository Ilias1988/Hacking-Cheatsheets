<a id="-what-is-social-engineering"></a>
## 🎯 ما هي الهندسة الاجتماعية؟

الهندسة الاجتماعية هي التلاعب بالأشخاص لدفعهم إلى كشف معلومات سرية أو تنفيذ إجراءات تضر بالأمن. وهي تستغل الجوانب النفسية والسلوكية لدى الإنسان بدلًا من الثغرات التقنية.

**المبادئ الأساسية:**
- 🎭 **السلطة (Authority)** — يميل الناس إلى الثقة بأصحاب السلطة
- ⏰ **الإلحاح (Urgency)** — يقلل ضغط الوقت من التفكير النقدي
- 🤝 **رد الجميل (Reciprocity)** — يشعر الناس بالالتزام بمقابلة المعروف
- 👥 **التأثر بسلوك الآخرين (Social Proof)** — يميل الناس إلى اتباع الجماعة
- 😊 **الألفة والإعجاب (Liking)** — يستجيب الناس لمن يرتاحون إليهم
- 📉 **الندرة (Scarcity)** — يزيد التوفر المحدود من الرغبة

<a id="quick-tool-install"></a>
### تثبيت سريع للأدوات
```bash
# GoPhish
wget https://github.com/gophish/gophish/releases/download/v0.12.1/gophish-v0.12.1-linux-64bit.zip
unzip gophish-v0.12.1-linux-64bit.zip
./gophish

# حزمة أدوات الهندسة الاجتماعية SET
git clone https://github.com/trustedsec/social-engineer-toolkit
cd social-engineer-toolkit
pip install -r requirements.txt
python setoolkit

# Evilginx2
go install github.com/kgretzky/evilginx2@latest

# theHarvester
pip install theHarvester
theHarvester -d target.com -b all
```

<a id="-social-engineering-attack-types"></a>
## 📊 أنواع هجمات الهندسة الاجتماعية

| نوع الهجوم | الوصف | القناة |
|-------------|-------------|--------|
| **التصيد (Phishing)** | رسائل مضللة لسرقة بيانات الاعتماد | البريد الإلكتروني |
| **التصيد الموجه (Spear Phishing)** | تصيد يستهدف أفرادًا محددين | البريد الإلكتروني |
| **تصيد كبار المسؤولين (Whaling)** | تصيد يستهدف الإدارة التنفيذية العليا | البريد الإلكتروني |
| **التصيد الصوتي (Vishing)** | هندسة اجتماعية عبر الصوت أو الهاتف | الهاتف |
| **التصيد النصي (Smishing)** | تصيد عبر الرسائل النصية | SMS |
| **اختلاق الذرائع (Pretexting)** | إنشاء سيناريوهات مزيفة لاستخراج المعلومات | أي قناة |
| **الطعم (Baiting)** | ترك وسائط مصابة مثل USB | ميدانية |
| **المقايضة (Quid Pro Quo)** | تقديم شيء مقابل المعلومات | أي قناة |
| **التسلل خلف شخص مخول (Tailgating)** | اتباع شخص مخول للدخول إلى منطقة مؤمنة | ميدانية |
| **هجوم موقع التجمع (Watering Hole)** | اختراق مواقع يزورها المستهدفون | الويب |

<a id="-quick-reference-phishing-indicators"></a>
## 🔗 مرجع سريع: مؤشرات التصيد

<a id="red-flags-in-emails"></a>
### علامات تحذير في رسائل البريد
```
□ عنوان المرسل لا يطابق نطاق الشركة
□ تحيات عامة مثل "عزيزي العميل"
□ إلحاح أو تهديدات
□ أخطاء إملائية أو نحوية
□ روابط مشبوهة؛ مرر المؤشر فوقها لفحص الوجهة
□ مرفقات غير متوقعة
□ طلب معلومات حساسة
□ عروض مغرية إلى حد يصعب تصديقه
```

<a id="url-analysis"></a>
### تحليل عناوين URL
```bash
# فحص عمر النطاق
whois suspicious-domain.com

# فحص السمعة
https://www.virustotal.com
https://urlscan.io

# تحليل الروابط المختصرة
https://checkshorturl.com
```
