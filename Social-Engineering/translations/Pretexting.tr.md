## 🎯 Pretexting (Senaryo Kurma) Nedir?

Pretexting; hedefin güvenini kazanmak, gizli bilgileri elde etmek veya hedefi belirli bir eylemi gerçekleştirmeye ikna etmek amacıyla kurgusal bir hikaye veya senaryo (pretext) yaratma sanatıdır. Sosyal mühendislik saldırılarının çoğunun temelini oluşturur.

**Temel Bileşenler:**
- 🎭 **Kişilik/Profil (Persona)** - Büründüğünüz sahte kimlik
- 📖 **Hikaye (Story)** - İnandırıcı senaryo ve mantıksal gerekçe
- 🎯 **Hedef (Goal)** - Elde etmek istediğiniz bilgi veya eylem
- 🔧 **Aksesuarlar (Props)** - Destekleyici materyaller (yaka kartları, sahte e-postalar, belgeler)

## 👥 Yaygın Profiller (Personas)

### BT Desteği
```
Rol: BT Yardım Masası Teknisyeni
Hedef: Parola sıfırlama, uzaktan erişim, yazılım yükletme

"Merhaba, ben BT'den Mehmet. Hesabınızda şüpheli 
hareketler görüyoruz; sistemin sizi kilitlemesini 
önlemek için kimlik bilgilerinizi doğrulamamız gerekiyor."
```

### Tedarikçi / Yüklenici
```
Rol: Üçüncü taraf servis sağlayıcı (iklimlendirme, güvenlik, temizlik)
Hedef: Fiziksel erişim, ağ erişimi

"Merhaba, [Tedarikçi Firma]'dan planlı bakım için geldim. 
Beni sunucu odasına alabilir misiniz?"
```

### Yeni İşe Alınan Çalışan
```
Rol: Yardıma ihtiyacı olan yeni çalışan
Hedef: Bilgi toplama, bina veya ağ erişimi

"Merhaba, pazarlama departmanında yeni başladım da, 
ortak ağ sürücüsüne bağlanmakta sorun yaşıyorum. 
Yardımcı olabilir misiniz?"
```

### Üst Düzey Yönetici / Otorite
```
Rol: CEO, CFO veya Genel Müdür
Hedef: Acil talepler, para transferleri, prosedür atlatma

"Bu konu son derece acil. Genel Müdürümüzün bu rapora 
derhal ihtiyacı var, rutin prosedürleri atlayarak 
dosyayı hemen bana iletmenizi bekliyorum."
```

### Kargo / Kurye Görevlisi
```
Rol: Kargo dağıtım personeli
Hedef: Fiziksel erişim, güvenlik geçişi

"İmzalı teslim edilmesi gereken önemli bir paketim var. 
Danışmaya kadar geçmeme izin verebilir misiniz?"
```

## 📋 Senaryo Örnekleri

### Telefon Senaryoları

#### BT Parola Sıfırlama
```
"Merhaba, ben BT yardım masasından [İsim]. Güvenlik 
taramalarımızda hesabınızın yakın zamanda bir güvenlik 
ihlalinden etkilendiğini belirledik. Parolanızı güvenli 
şekilde sıfırlayabilmem için mevcut şifrenizi teyit 
ederek kimliğinizi doğrulayabilir misiniz?"
```

#### Tedarikçi Bilgi Güncelleme
```
"Merhaba, [Tedarikçi Firma] muhasebe departmanından 
arıyorum. Gelecek ay yapılacak ödemeler öncesinde 
sistemimizdeki kayıtları güncelliyoruz. Dosyamızda 
bulunan şirket banka hesap numaranızı teyit edebilir misiniz?"
```

#### İK Memnuniyet Anketi
```
"Merhaba, İnsan Kaynakları adına çalışan memnuniyeti 
anketi yürütüyorum. Anketimiz tamamen anonimdir; ancak 
şirket personeli olduğunuzu doğrulamak adına departmanınızı 
ve yöneticinizin adını öğrenebilir miyim?"
```

### Yüz Yüze (Fiziksel) Senaryolar

#### Yangın / İş Güvenliği Denetçisi
```
"Merhaba, belediye itfaiye denetim biriminden geliyorum. 
Haberli olmayan rutin kontroller yapıyoruz. Yangın 
söndürme sistemlerini denetlemek üzere sistem odasına 
girmem gerekiyor."
```

#### İş Görüşmesi Adayı
```
"Merhaba, saat 14:00'te İK ile iş görüşmem vardı. Sıramı 
beklerken lavaboyu kullanabilir miyim?" 
(Bina içinde gözetimsiz dolaşarak keşif yapma fırsatı)
```

#### Tesisat / Teknik Servis Çalışanı
```
"Bu katta su sızıntısı olduğuna dair bildirim aldık. 
Tavandan geçen boruları kontrol etmek için sunucu odasını 
gösterebilir misiniz?"
```

## 🧠 Psikolojik İlkeler

### Otorite (Authority)
```
✓ Unvan kullanın: "Bilgi Güvenliği Müdürü", "Denetim Direktörü"
✓ Görünüme dikkat edin: Takım elbise, resmi yaka kartı, üniforma
✓ Kendinizden emin ve kararlı konuşun
✓ Şirket politikalarına ve kurallara atıfta bulunun
```

### Aciliyet (Urgency)
```
✓ "Bunun Genel Müdürün saat 15'teki toplantısından önce çözülmesi şart"
✓ "Hesabınız 10 dakika içinde kilitlenecek"
✓ "Şu anda acil bir denetim altındayız"
✓ Kurbanın doğrulama yapmasına fırsat bırakmayacak zaman baskısı kurun
```

### Karşılıklılık (Reciprocity)
```
✓ Önce karşı tarafa küçük bir iyilik yapın
✓ "Az önce yazıcı probleminizi çözmüştüm..."
✓ "Ofise gelirken herkese kahve aldım..."
✓ Karşı tarafta bir borçluluk ve yardım etme hissi oluşturun
```

### Sosyal Kanıt (Social Proof)
```
✓ "Diğer herkes bu formu çoktan doldurdu"
✓ "Yöneticiniz Ahmet Bey az önce onay verdi"
✓ "Tüm finans ekibi bu doğrulamayı tamamladı"
✓ Başkalarının da aynı şeyi yaptığını öne sürün
```

### Sempatiklik (Liking)
```
✓ Ortak ilgi alanları bulun
✓ Beden dilini taklit edin (mirroring)
✓ Samimi ve içten iltifatlar edin
✓ Bir şey talep etmeden önce güven ve bağ oluşturun
```

## 🔧 Aksesuarlar ve Destekleyici Materyaller

### Fiziksel Aksesuarlar
```
□ Sahte şirket yaka kartı / ziyaretçi kartı
□ Kartvizitler
□ Resmi görünümlü formların takılı olduğu dosya panosu (clipboard)
□ Reflektörlü yelek veya iş üniforması
□ Alet çantası veya dizüstü bilgisayar çantası
□ Yazdırılmış e-postalar veya sahte yetki yazıları
□ Tedarikçi servis formları
```

### Dijital Aksesuarlar
```
□ Sahte arayan numara (caller ID spoofing)
□ Benzer alan adından açılmış e-posta adresi
□ Sahte LinkedIn profili
□ Klonlanmış şirket web sitesi
□ Taklit edilmiş şirket içi toplantı davetleri
```

### Destekleyici Dokümantasyon
```
□ Arıza kayıt / bilet numarası
□ İş emri belgesi
□ Yetkilendirme formu
□ OSINT ile elde edilmiş gerçek yönetici ismi
```

## 🔍 Pretexting İçin OSINT (Açık Kaynak İstihbaratı)

### Hedef Araştırması
```bash
# Çalışan bilgileri için LinkedIn
- İsimler, unvanlar, departmanlar
- Şirket organizasyon yapısı ve hiyerarşi
- Son paylaşımlar ve duyurular

# Şirket web sitesi
- Yönetim ekibi
- Ofis konumları ve adresler
- İş ortakları ve kullanılan teknolojiler

# Basın bültenleri
- Son satın almalar, etkinlikler ve organizasyonel değişiklikler
```

## 📱 Fiziksel Sosyal Mühendislik

### Kuyruk Takibi (Tailgating)
```
Teknik: Kartlı kapıdan geçen yetkili bir personelin arkasından içeri süzülme

"Çok teşekkürler, kartımı masamda unutmuşum da!"
"Kapıyı tutabilir misiniz, ellerim tamamen dolu!"
"Finans departmanından [İsim] Bey'in yanına gelmiştim."
```

### İkna Ederek Geçme (Piggybacking)
```
Teknik: Yetkili bir kişinin kapıyı sizin için açmasını sağlama

"Merhaba, [Tedarikçi]'den geldim. Beni bekliyorlardı ama danışma 
yerinde yoktu, kapıyı açabilir misiniz?"
```

### Çöp Karıştırma (Dumpster Diving)
```
Hedef: Atılmış fiziksel belgeler ve donanımlar

□ Organizasyon şemaları
□ Çalışan ve müşteri listeleri
□ Finansal belgeler ve faturalar
□ Masa üstü şifre notları
□ Verisi silinmemiş eski donanımlar
```

### Yemleme (USB Drops / Baiting)
```
Teknik: Güvenlik açığı barındıran USB bellekleri stratejik noktalara bırakma

Konumlar:
□ Şirket otoparkı
□ Danışma ve lobi alanı
□ Mola ve dinlenme odaları
□ Sigara içme alanları

Etiket Örnekleri:
□ "Gizli - İK Raporu"
□ "Maaş Skalası 2024"
□ "İşten Çıkarma Listesi"
□ "Özel Fotoğraflar"
```

## ⚠️ Hukuki ve Etik Hususlar

### Angajman Kuralları (Rules of Engagement)
```
□ Daima imzalı ve yazılı izin belgesi bulundurun
□ Kapsamı ve kırmızı çizgileri net şekilde tanımlayın
□ Kişisel hesaplara ve özel verilere kesinlikle erişmeyin
□ Şantaj veya tehdit içeren yöntemlere asla başvurmayın
□ Yapılan her adımı anlık olarak belgeleyin
□ Acil durum irtibat kişilerini hazır bulundurun
□ Yanınızda mutlaka yetkilendirme mektubu ("get-out-of-jail letter") taşıyın
```

### Kesinlikle Kaçınılması Gerekenler
```
✗ Kolluk kuvveti veya polis memuru taklidi yapmak
✗ Gerçek hayati tehditler savurmak
✗ Kapsam dışındaki sistemlere sızmak
✗ Şirkete ait gerçek para veya varlık çalmak
✗ Şirketi yasal yükümlülük altına sokacak eylemler
✗ Hedef kişilerde psikolojik travma yaratmak
```

## 📋 Pretexting Kontrol Listesi

```markdown
Hazırlık:
□ Hedef kurum hakkında OSINT araştırması yapın
□ Kilit personeli ve organizasyon şemasını belirleyin
□ İnandırıcı bir kimlik (persona) ve arka plan hikayesi oluşturun
□ Destekleyici aksesuarları ve belgeleri hazırlayın
□ Konuşma metnini ve olası itiraz senaryolarını prova edin
□ Alternatif yedek senaryolarınızı hazır bulundurun

Uygulama:
□ Soğukkanlı ve özgüvenli kalın
□ Konuşmanın akışını kontrol edin
□ Zor sorularla karşılaşırsanız konuyu ustalıkla yönlendirin
□ Fazla ayrıntı vererek şüphe uyandırmaktan kaçının
□ Ne zaman geri çekilip testi durduracağınızı bilin

Uygulama Sonrası:
□ Nelerin çalıştığını ve nelerin başarısız olduğunu belgeleyin
□ Toplanan tüm verileri güvenli şekilde muhafaza edin
□ Güvenlik açığı ve risk raporunu oluşturun
□ Personel eğitimi ve güvenlik önerilerini sunun
```
