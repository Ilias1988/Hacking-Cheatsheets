## Πριν ξεκινήσετε

Το **pretexting** είναι η κατασκευή ενός ψευδούς λόγου επικοινωνίας. Η **persona** είναι η προσποιητή ταυτότητα και το **backstory** η ιστορία που την υποστηρίζει. Τα **props** είναι αντικείμενα ή έγγραφα που χρησιμοποιούνται για να ενισχυθεί ο ισχυρισμός. Το **OSINT** αφορά πληροφορίες από δημόσιες πηγές, όπως ο εταιρικός ιστότοπος ή επαγγελματικές αναρτήσεις.

Τα **IT** και **HR** σημαίνουν αντίστοιχα τμήμα πληροφορικής και ανθρώπινου δυναμικού. Οι τίτλοι **CEO** και **CFO** αντιστοιχούν σε διευθύνοντα σύμβουλο και οικονομικό διευθυντή. Ο όρος **Rules of Engagement** περιγράφει τους συμφωνημένους κανόνες, τα όρια και τις συνθήκες διακοπής του ελέγχου.

Τα υποδείγματα δείχνουν πώς μπορεί να φαίνεται μια απόπειρα παραπλάνησης. Αιτήματα για κωδικούς, χρήματα ή παράκαμψη διαδικασιών πρέπει να αναγνωρίζονται ως σημεία που χρειάζονται ανεξάρτητη επαλήθευση. Σε εξουσιοδοτημένη άσκηση ορίστε εκ των προτέρων συμμετέχοντες, χώρους, επιτρεπόμενες ενέργειες και υπεύθυνο επικοινωνίας. Η αναφορά μιας τεχνικής στον οδηγό δεν την καθιστά αυτομάτως επιτρεπτή σε κάθε έλεγχο.

## 🎯 Τι είναι το pretexting;

Το pretexting είναι η κατασκευή ενός ψευδούς σεναρίου, δηλαδή ενός προσχήματος, ώστε κάποιος να πειστεί να δώσει πληροφορίες ή να κάνει μια ενέργεια. Είναι συνηθισμένο στοιχείο επιθέσεων κοινωνικής μηχανικής.

**Βασικά στοιχεία ενός προσχήματος:**
- 🎭 **Προσποιητή ταυτότητα (persona):** ποιος ισχυρίζεται ότι είναι το άτομο που προσεγγίζει τον αποδέκτη.
- 📖 **Ιστορία:** το σενάριο και η υποτιθέμενη αιτία της επικοινωνίας.
- 🎯 **Στόχος:** η πληροφορία ή η ενέργεια που επιδιώκεται.
- 🔧 **Υποστηρικτικό υλικό (props):** αντικείμενα ή έγγραφα, όπως κάρτες εισόδου και email, που κάνουν τον ισχυρισμό να φαίνεται αληθινός.

## 👥 Συνηθισμένες προσποιητές ταυτότητες

### Τεχνική υποστήριξη πληροφορικής
```
Ρόλος: Τεχνικός υποστήριξης πληροφορικής
Στόχος: Επαναφορά κωδικού, απομακρυσμένη πρόσβαση, εγκατάσταση λογισμικού

«Γεια σας, είμαι ο Mike από το IT. Βλέπουμε ασυνήθιστη
δραστηριότητα στον λογαριασμό σας και χρειάζεται να επαληθεύσουμε
τα στοιχεία σύνδεσης για να αποφύγουμε το κλείδωμά του.»
```

### Προμηθευτής ή εξωτερικός συνεργάτης
```
Ρόλος: Εξωτερικός συνεργάτης για κλιματισμό, ασφάλεια ή καθαρισμό
Στόχος: Φυσική πρόσβαση ή πρόσβαση στο δίκτυο

«Ήρθα από τη [Vendor Company] για την προγραμματισμένη
συντήρηση. Μπορείτε να με αφήσετε να μπω στον χώρο των διακομιστών;»
```

### Νέος εργαζόμενος
```
Ρόλος: Νέος εργαζόμενος που χρειάζεται βοήθεια
Στόχος: Συλλογή πληροφοριών ή είσοδος στο κτίριο

«Γεια σας, μόλις ξεκίνησα στο μάρκετινγκ και δυσκολεύομαι
να συνδεθώ στον κοινόχρηστο δίσκο. Μπορείτε να με βοηθήσετε;»
```

### Διευθυντικό στέλεχος ή πρόσωπο κύρους
```
Ρόλος: CEO, CFO ή ανώτερο διευθυντικό στέλεχος
Στόχος: Επείγοντα αιτήματα, τραπεζικές μεταφορές ή πρόσβαση

«Είναι επείγον. Ο διευθύνων σύμβουλος χρειάζεται αυτή την αναφορά
αμέσως και πρέπει να παρακάμψεις τις συνήθεις διαδικασίες.»
```

### Διανομέας ή υπάλληλος ταχυμεταφορών
```
Ρόλος: Υπάλληλος FedEx, UPS ή άλλης εταιρείας ταχυμεταφορών
Στόχος: Φυσική πρόσβαση ή παράδοση δέματος

«Έχω ένα δέμα που χρειάζεται υπογραφή.
Μπορείτε να με αφήσετε να μπω στην υποδοχή;»
```

## 📋 Σενάρια με παραπλανητικά προσχήματα

### Τηλεφωνικά προσχήματα

#### Προσποιητή επαναφορά κωδικού από το IT
```
«Γεια σας, είμαι ο/η [Name] από την τεχνική υποστήριξη IT.
Εντοπίσαμε ότι ο λογαριασμός σας παραβιάστηκε σε πρόσφατο
περιστατικό ασφάλειας. Χρειάζεται να επαληθεύσω την ταυτότητά σας
και να βοηθήσω στην επαναφορά του κωδικού. Μπορείτε να μου πείτε
τον τρέχοντα κωδικό σας για να επιβεβαιώσω ότι είστε εσείς;»
```

#### Προσποιητή επαλήθευση στοιχείων προμηθευτή
```
«Γεια σας, καλώ από το λογιστήριο της [Vendor]. Ενημερώνουμε
τα αρχεία μας και χρειάζεται να επαληθεύσουμε τα τραπεζικά στοιχεία
της εταιρείας σας για την επόμενη πληρωμή. Μπορείτε να επιβεβαιώσετε
τον αριθμό λογαριασμού που έχετε καταχωρίσει για εμάς;»
```

#### Προσποιητή έρευνα ανθρώπινου δυναμικού
```
«Γεια σας, πραγματοποιώ έρευνα ικανοποίησης εργαζομένων για το HR.
Η έρευνα είναι ανώνυμη, αλλά πρέπει να επαληθεύσω ότι εργάζεστε
στην εταιρεία. Μπορείτε να μου πείτε το τμήμα σας
και το όνομα του προϊσταμένου σας;»
```

### Προσχήματα με φυσική παρουσία

#### Προσποιητός επιθεωρητής πυρασφάλειας
```
«Γεια σας, είμαι από το γραφείο πυρασφάλειας του δήμου.
Κάνουμε αιφνιδιαστικούς ελέγχους. Χρειάζομαι πρόσβαση στον χώρο
των διακομιστών για να εξετάσω το σύστημα πυρόσβεσης.»
```

#### Προσποιητή συνέντευξη εργασίας
```
«Ήρθα για τη συνέντευξη με το HR στις 14:00.
Όσο περιμένω, μπορείτε να μου δείξετε πού είναι η τουαλέτα;»
(Στο σενάριο, η αναμονή χρησιμοποιείται ως ευκαιρία παρατήρησης του κτιρίου.)
```

#### Προσποιητός τεχνικός συντήρησης
```
«Μας κάλεσαν για διαρροή νερού σε αυτό το σημείο.
Μπορείτε να μου δείξετε πού είναι ο χώρος των διακομιστών;
Πρέπει να ελέγξω τους σωλήνες πάνω από την οροφή.»
```

## 🧠 Ψυχολογικοί μηχανισμοί παραπλάνησης

### Επίκληση εξουσίας ή κύρους
```
✓ Χρήση τίτλων όπως «Διευθυντής IT» ή «Υπεύθυνος ασφάλειας»
✓ Εμφάνιση που ταιριάζει στον ρόλο: κοστούμι, στολή ή κάρτα εισόδου
✓ Ομιλία με αυτοπεποίθηση
✓ Επίκληση πολιτικών και διαδικασιών
```

### Τεχνητή αίσθηση επείγοντος
```
✓ «Αυτό πρέπει να γίνει πριν από τη συνάντηση του CEO στις 3»
✓ «Το σύστημα θα κλειδώσει τον λογαριασμό σου σε 10 λεπτά»
✓ «Βρισκόμαστε σε έλεγχο και το χρειαζόμαστε αμέσως»
✓ Δημιουργία πίεσης χρόνου ώστε να μη γίνει επαλήθευση
```

### Αίσθηση υποχρέωσης ανταπόδοσης
```
✓ Προηγείται μια μικρή εξυπηρέτηση
✓ «Μόλις βοήθησα να λυθεί εκείνο το πρόβλημα του εκτυπωτή…»
✓ «Έφερα καφέ για όλους…»
✓ Δημιουργία αίσθησης υποχρέωσης για ανταπόδοση
```

### Επίκληση της συμπεριφοράς των άλλων
```
✓ «Όλοι οι άλλοι το έχουν ήδη κάνει»
✓ «Ο προϊστάμενός σου, ο John, το έχει ήδη εγκρίνει»
✓ «Όλη η ομάδα μάρκετινγκ συμπλήρωσε τη φόρμα»
✓ Επίκληση άλλων ατόμων που υποτίθεται ότι συμμορφώθηκαν
```

### Εκμετάλλευση συμπάθειας και οικειότητας
```
✓ Αναζήτηση κοινών ενδιαφερόντων
✓ Μίμηση της γλώσσας του σώματος
✓ Φιλοφρονήσεις που φαίνονται ειλικρινείς
✓ Δημιουργία οικειότητας πριν από το αίτημα
```

## 🔍 Έρευνα δημόσιων πηγών για την κατανόηση ενός σεναρίου

### Έρευνα για τον οργανισμό που εξετάζεται

Το μπλοκ είναι λίστα κατηγοριών δημόσιων πληροφοριών, παρότι στο πρωτότυπο επισημαίνεται ως bash. Οι γραμμές με παύλα δεν είναι εντολές.

```bash
# Δημόσιες πληροφορίες εργαζομένων από LinkedIn
- Ονόματα, θέσεις και τμήματα
- Ιεραρχία και σχέσεις αναφοράς
- Πρόσφατες αναρτήσεις ή δραστηριότητα

# Εταιρικός ιστότοπος
- Διοικητική ομάδα
- Οργανόγραμμα
- Τοποθεσίες γραφείων
- Πληροφορίες προμηθευτών ή συνεργατών

# Δελτία Τύπου
- Πρόσφατα νέα και εξαγορές
- Αλλαγές διευθυντικών στελεχών
```

### Πληροφορίες που μπορεί να αξιοποιηθούν σε ένα πρόσχημα
```
□ Ονόματα εργαζομένων και θέσεις εργασίας
□ Δομή τμημάτων
□ Ονόματα προϊσταμένων
□ Μορφή διευθύνσεων email (first.last@company.com)
□ Τηλεφωνικοί αριθμοί
□ Τοποθεσίες γραφείων
□ Σχέσεις με προμηθευτές
□ Πρόσφατα εταιρικά γεγονότα
```

## 📱 Κοινωνική μηχανική με φυσική παρουσία

### Είσοδος ακολουθώντας εξουσιοδοτημένο άτομο (Tailgating)

Ο οδηγός χρησιμοποιεί τον όρο για είσοδο ακολουθώντας κάποιον σε ελεγχόμενο χώρο και τον όρο piggybacking για είσοδο με τη βοήθειά του. Η χρήση των δύο όρων μπορεί να διαφέρει μεταξύ πηγών.

```
Τεχνική: Είσοδος από ελεγχόμενη πόρτα ακολουθώντας εξουσιοδοτημένο άτομο

«Ευχαριστώ, ξέχασα την κάρτα μου σήμερα!»
«Μπορείτε να κρατήσετε την πόρτα; Έχω γεμάτα τα χέρια μου.»
«Ήρθα με τον/την [Name] από το [Department].»
```

### Είσοδος με βοήθεια εξουσιοδοτημένου ατόμου (Piggybacking)
```
Τεχνική: Είσοδος με τη βοήθεια εξουσιοδοτημένου ατόμου

«Γεια σας, είμαι από τη [Vendor]. Με περιμένουν, αλλά ο υπάλληλος
της υποδοχής έχει απομακρυνθεί. Μπορείτε να με αφήσετε να μπω;»
```

### Αναζήτηση πληροφοριών σε απορρίμματα (Dumpster Diving)
```
Στόχος: Απορριφθέντα έγγραφα και εξοπλισμός

□ Οργανογράμματα
□ Κατάλογοι εργαζομένων
□ Οικονομικά έγγραφα
□ Σημειώσεις με κωδικούς πρόσβασης
□ Παλιός εξοπλισμός που περιέχει δεδομένα
```

### Τοποθέτηση USB ως δολώματος (USB Drops)

Το πρωτότυπο περιγράφει κακόβουλο δόλωμα USB. Για εκπαιδευτική προσομοίωση απαιτείται προκαθορισμένο, ελεγχόμενο υλικό και συμφωνημένα όρια· η ενότητα δεν περιέχει οδηγίες δημιουργίας κακόβουλου αρχείου.

```
Τεχνική: Εγκατάλειψη μολυσμένων USB ως δολώματος

Τοποθεσίες:
□ Χώρος στάθμευσης
□ Χώρος υποδοχής
□ Χώροι διαλείμματος
□ Κοντά σε χώρους καπνίσματος

Ενδεικτικές ετικέτες του σεναρίου:
□ «Εμπιστευτικό — HR»
□ «Στοιχεία μισθοδοσίας 2024»
□ «Λίστα απολύσεων»
□ «Προσωπικές φωτογραφίες»
```

## 📝 Υποδείγματα διαλόγων και μηνυμάτων

### Υπόδειγμα τηλεφωνικού διαλόγου — τεχνική υποστήριξη
```
[Χτυπά το τηλέφωνο]
Αποδέκτης: «Παρακαλώ;»
Ελεγκτής: «Γεια σας, μιλάω με τον/την [Target Name];»
Αποδέκτης: «Ναι.»
Ελεγκτής: «Ωραία, είμαι ο/η [Your Name] από την ομάδα ασφάλειας IT.
Παρακολουθούμε ασυνήθιστες απόπειρες σύνδεσης στον λογαριασμό σας
από διεύθυνση IP του εξωτερικού. Θέλουμε να βεβαιωθούμε ότι
δεν ήσασταν εσείς. Προσπαθήσατε να συνδεθείτε σήμερα
από τη [Random Country];»
Αποδέκτης: «Όχι, δεν ήμουν εγώ!»
Ελεγκτής: «Αυτό υποθέσαμε. Για λόγους ασφάλειας πρέπει να επαληθεύσω
τον λογαριασμό σας. Μπορείτε να επιβεβαιώσετε το όνομα χρήστη;
Θα επαναφέρουμε τον κωδικό σας για να αποκλείσουμε τον εισβολέα.»
```

### Υπόδειγμα email — αίτημα διευθυντικού στελέχους
```
Θέμα: Επείγον — Απαιτείται τραπεζική μεταφορά

Είμαι σε συνάντηση και δεν μπορώ να τηλεφωνήσω. Χρειάζομαι
να προχωρήσεις σε επείγουσα τραπεζική μεταφορά για μια εξαγορά
με στενό χρονικό περιθώριο.

Μετάφερε $45,000 στον ακόλουθο λογαριασμό:
[Details]

Θα εξηγήσω μόλις τελειώσει η συνάντηση.
Επιβεβαίωσε όταν ολοκληρωθεί.

[Executive Name]
Στάλθηκε από το iPhone μου
```

## ⚠️ Νομικές και δεοντολογικές παράμετροι

### Συμφωνημένοι κανόνες του ελέγχου (Rules of Engagement)
```
□ Έχετε πάντα γραπτή εξουσιοδότηση
□ Ορίστε σαφές πεδίο ελέγχου και όρια
□ Μην αποκτάτε πρόσβαση σε προσωπικούς λογαριασμούς
□ Μην χρησιμοποιείτε εκβιασμό ή εξαναγκασμό
□ Τεκμηριώνετε τις ενέργειες και τα ευρήματα
□ Έχετε διαθέσιμα στοιχεία επικοινωνίας για έκτακτη ανάγκη
□ Έχετε διαθέσιμη την επιστολή εξουσιοδότησης για επίδειξη
```

### Ενέργειες προς αποφυγή
```
✗ Προσποίηση ιδιότητας οργάνου επιβολής του νόμου
✗ Πραγματικές απειλές
✗ Πρόσβαση σε συστήματα εκτός του συμφωνημένου πεδίου
✗ Κλοπή πραγματικών χρημάτων ή περιουσιακών στοιχείων
```

## 📋 Λίστα ελέγχου προσομοίωσης pretexting

```markdown
Προετοιμασία:
□ Ερευνήστε τον οργανισμό από δημόσιες πηγές (OSINT)
□ Εντοπίστε τις σχετικές θέσεις και υπευθυνότητες
□ Προετοιμάστε την προσποιητή ταυτότητα και το σενάριό της
□ Προετοιμάστε το συμφωνημένο υποστηρικτικό υλικό
□ Εξασκηθείτε στο σενάριο και στις απαντήσεις
□ Προετοιμάστε εναλλακτικές εκδοχές μέσα στα συμφωνημένα όρια

Εκτέλεση της προσομοίωσης:
□ Παραμείνετε ήρεμοι και συγκροτημένοι
□ Διατηρήστε τη συνομιλία μέσα στο σενάριο του ελέγχου
□ Προετοιμαστείτε για αλλαγή πορείας αν αμφισβητηθεί το σενάριο
□ Αποφύγετε υπερβολικούς ισχυρισμούς και περιττές λεπτομέρειες
□ Γνωρίζετε πότε πρέπει να διακοπεί ο έλεγχος

Μετά τον έλεγχο:
□ Καταγράψτε τι λειτούργησε και τι όχι
□ Προστατέψτε τα δεδομένα που συλλέχθηκαν
□ Αναφέρετε τα ευρήματα
□ Προτείνετε βελτιώσεις
```
