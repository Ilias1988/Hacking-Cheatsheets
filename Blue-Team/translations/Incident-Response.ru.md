
### Быстрая первичная оценка Windows
```cmd
# Текущие пользовательские сеансы
query user
qwinsta

# Активные соединения
netstat -ano | findstr ESTABLISHED

# Запущенные процессы
tasklist /v
wmic process get processid,parentprocessid,commandline

# Недавние изменения файлов
forfiles /P C:\ /S /D +01/01/2024

# Задания планировщика
schtasks /query /fo LIST /v

# Службы
sc query state=all
wmic service get name,startmode,state

# Ключи Run в реестре
reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run"
reg query "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run"

# Недавняя история PowerShell
type %APPDATA%\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt
```

### Быстрая первичная оценка Linux
```bash
# Кто вошёл в систему
w
who
last -a

# Активные соединения
ss -tulnp
netstat -tulnp
lsof -i

# Запущенные процессы
ps auxwww
pstree -p

# Недавние изменения файлов
find / -mtime -1 -type f 2>/dev/null

# Задания cron
cat /etc/crontab
ls -la /etc/cron.*
for user in $(cut -f1 -d: /etc/passwd); do crontab -u $user -l 2>/dev/null; done

# Сценарии запуска
ls -la /etc/init.d/
systemctl list-unit-files --type=service

# История команд
cat ~/.bash_history
cat /root/.bash_history
```

## Сдерживание инцидента

### Краткосрочное сдерживание
```bash
# Изолировать сеть (Windows)
netsh advfirewall set allprofiles state on
netsh advfirewall firewall add rule name="Block All" dir=in action=block
netsh advfirewall firewall add rule name="Block All Out" dir=out action=block

# Изолировать сеть (Linux)
iptables -P INPUT DROP
iptables -P OUTPUT DROP
iptables -P FORWARD DROP

# Отключить скомпрометированную учётную запись
net user compromised_user /active:no   # Windows
passwd -l compromised_user             # Linux

# Завершить вредоносный процесс
taskkill /PID <pid> /F               # Windows
kill -9 <pid>                        # Linux
```

### Долгосрочное сдерживание
```bash
# Сегментировать сеть
# Применить правила межсетевого экрана для изоляции затронутой VLAN
# Обновить ACL на коммутаторах и маршрутизаторах

# Заблокировать вредоносные IP-адреса и домены на межсетевом экране
# Добавить в список блокировки прокси
# Обновить DNS sinkhole — перенаправление вредоносных доменов

# Временно отключить затронутые службы
sc config <service> start= disabled   # Windows
systemctl disable <service>           # Linux
```

### Сохранение цифровых доказательств
```bash
# Дамп памяти (Windows — использовать WinPMEM или DumpIt)
winpmem_mini_x64.exe memory.raw

# Дамп памяти (Linux)
dd if=/dev/mem of=/evidence/memory.dump bs=1M

# Образ диска
dd if=/dev/sda of=/evidence/disk.img bs=4M status=progress

# Хеш для проверки целостности
sha256sum /evidence/disk.img > disk.img.sha256

# Сначала собрать наиболее изменчивые данные (порядок изменчивости):
# 1. Память
# 2. Состояние сети
# 3. Запущенные процессы
# 4. Диск
```

## Устранение последствий и причин

### Удаление вредоносного ПО
```bash
# Найти и удалить механизмы закрепления

# Windows — реестр
reg delete "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" /v "MalwareName" /f

# Windows — задания планировщика
schtasks /delete /tn "MalwareTask" /f

# Windows — службы
sc delete "MalwareService"

# Linux — Cron
crontab -r
rm /etc/cron.d/malware

# Linux — Systemd
systemctl disable malware
rm /etc/systemd/system/malware.service
```

## Восстановление

### Восстановление систем
```bash
# Восстановить из чистой резервной копии
# Пересоздать скомпрометированные системы
# Проверить целостность перед подключением к сети

# Поэтапное восстановление:
1. Сначала восстановить критически важные системы
2. Отслеживать признаки повторного заражения
3. Восстановить остальные системы
4. Вернуться к штатной работе
```

### Мониторинг после восстановления
```bash
# Повысить детализацию журналирования
# Развернуть дополнительные средства мониторинга
# Отслеживать возвращение атакующего

# Ключевые индикаторы для наблюдения:
- Те же IOC (IP-адреса, домены, хеши)
- Сходные тактики, техники и процедуры (TTP)
- Попытки доступа к тем же учётным записям
- Связь с инфраструктурой командования и управления (C2)
```

## Краткий справочник

### Классификация по критичности

| Уровень | Описание | Время реагирования |
|-------|-------------|---------------|
| **Критический** | Активное вторжение, утечка данных | Немедленно |
| **Высокий** | Подтверждённая компрометация | < 1 часа |
| **Средний** | Возможная компрометация | < 4 часов |
| **Низкий** | Подозрительная активность | < 24 часов |

### Типичные индикаторы компрометации (IOC) для сбора

| Тип IOC | Примеры |
|----------|----------|
| **Хеш** | MD5, SHA1, SHA256 |
| **IP** | IP-адреса источника и назначения |
| **Домен** | Домены командования и управления (C2) |
| **URL** | Вредоносные URL |
| **Электронная почта** | Отправитель фишингового письма |
| **Файл** | Имя вредоносного файла |
| **Реестр** | Ключи закрепления |
