## Πριν ξεκινήσετε

Η **Blue Team** είναι η ομάδα που προστατεύει συστήματα, παρακολουθεί συμβάντα και αντιμετωπίζει περιστατικά ασφαλείας. Οι οδηγοί συνδέουν την παρατήρηση μιας ένδειξης με τη διερεύνηση και την αποκατάσταση. Προτεινόμενη σειρά: αντιμετώπιση περιστατικών → καταγραφές → SIEM → αναζήτηση απειλών → ενίσχυση ασφάλειας → Sigma → YARA.

**Βασικοί όροι:** Το **SOC (Security Operations Center)** είναι η λειτουργία ή ομάδα παρακολούθησης ασφάλειας. Το **SIEM** συγκεντρώνει και συσχετίζει συμβάντα από πολλές πηγές. Το **EDR** παρακολουθεί συσκευές για ανίχνευση και απόκριση. Τα **IDS/IPS** εντοπίζουν ή εμποδίζουν ύποπτη κίνηση. Ένα **IOC (Indicator of Compromise)** είναι ένδειξη πιθανής παραβίασης, όπως διεύθυνση IP, τομέας ή σύνοψη αρχείου· δεν είναι αυτοτελής απόδειξη επίθεσης.

**Πώς διαβάζουμε τους οδηγούς:** Οι εντολές, τα ερωτήματα και τα μοτίβα κανόνων διατηρούν τη σύνταξη του αγγλικού πρωτοτύπου. Οι τίτλοι, οι επεξηγήσεις και τα σχόλια αποδίδονται στα ελληνικά. Στα πλαίσια `cmd`, `spl` και `kql`, οι γραμμές που αρχίζουν με `#` είναι επεξηγήσεις του οδηγού και δεν αποτελούν κατ’ ανάγκη αποδεκτή σύνταξη της αντίστοιχης κονσόλας.

Οι διευθύνσεις IP, οι ημερομηνίες, τα ονόματα αρχείων και τιμές όπως `<pid>` ή `<service>` είναι ενδεικτικά. Η μετάφραση δεν αποτελεί δοκιμή λειτουργίας των παραδειγμάτων. Οι αλλαγές σε λογαριασμούς, υπηρεσίες ή τείχη προστασίας προϋποθέτουν σχέδιο εφαρμογής και επαναφοράς.

## 🎯 Τι είναι η αμυντική ομάδα ασφαλείας (Blue Team);

Η **αμυντική ομάδα ασφαλείας (Blue Team)** έχει την ευθύνη για:
- 🔍 **Ανίχνευση** απειλών και επιθέσεων
- 🛡️ **Προστασία** συστημάτων και δικτύων
- 🚨 **Αντιμετώπιση** περιστατικών ασφαλείας
- 📊 **Παρακολούθηση** ύποπτης δραστηριότητας
- 🔒 **Ενίσχυση ασφάλειας** της υποδομής

## 📊 Κύκλος αμυντικών ενεργειών

Η ροή του διαγράμματος είναι: προετοιμασία → ανίχνευση → ανάλυση → απόκριση → αποκατάσταση → συμπεράσματα → βελτίωση. Ο κύκλος επαναλαμβάνεται καθώς αλλάζουν οι απειλές και τα συστήματα.

│   │ 1. PREPARE   │───▶│ 2. DETECT    │───▶│ 3. ANALYZE           │        │
│   │  (Hardening) │    │  (Monitor)   │    │  (Investigate)       │        │
