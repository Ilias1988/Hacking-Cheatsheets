## Πριν ξεκινήσετε

Η **αντιμετώπιση περιστατικών (Incident Response / IR)** είναι οργανωμένη διαδικασία εντοπισμού, αξιολόγησης, περιορισμού και αποκατάστασης ενός συμβάντος ασφαλείας. Το **triage** είναι η αρχική αξιολόγηση σοβαρότητας και προτεραιοτήτων. Το **containment** περιορίζει την εξάπλωση, το **eradication** αφαιρεί αιτίες και υπολείμματα και το **recovery** επαναφέρει την ασφαλή λειτουργία.

**Πλαίσιο αναφοράς:** Η εξάδα σταδίων του πρωτοτύπου είναι εκπαιδευτική διάσπαση μιας παραδοσιακής προσέγγισης. Δεν παρουσιάζεται εδώ ως αυτούσιο τρέχον πρότυπο NIST. Η [NIST SP 800-61 Rev. 3](https://csrc.nist.gov/pubs/sp/800/61/r3/final), που δημοσιεύτηκε το 2025 και αντικατέστησε τη Rev. 2, συνδέει την αντιμετώπιση περιστατικών με τη διαχείριση κινδύνου και το CSF 2.0.

**Πριν από επεμβάσεις:** Η απομόνωση δικτύου μπορεί να διακόψει την απομακρυσμένη πρόσβαση και η διαγραφή εργασιών ή ο τερματισμός διεργασιών μπορεί να καταστρέψει στοιχεία. Οι ενέργειες επιλέγονται σύμφωνα με το σχέδιο αντιμετώπισης και τη σοβαρότητα του περιστατικού. Τα πρότυπα επαφών και αναφοράς παρακάτω συμπληρώνονται με τα πραγματικά στοιχεία του οργανισμού.

## 2️⃣ Ανίχνευση και ανάλυση

### Αρχικές ερωτήσεις αξιολόγησης (Triage)
```markdown
1. Τι είδους περιστατικό είναι;
   - [ ] Μόλυνση από κακόβουλο λογισμικό
   - [ ] Μη εξουσιοδοτημένη πρόσβαση
   - [ ] Παραβίαση δεδομένων
   - [ ] Άρνηση υπηρεσίας
   - [ ] Απειλή από άτομο με εσωτερική πρόσβαση
   - [ ] Ηλεκτρονικό ψάρεμα

2. Πότε εντοπίστηκε;
3. Πώς εντοπίστηκε;
4. Ποια συστήματα επηρεάζονται;
5. Ποια δεδομένα ενδέχεται να έχουν επηρεαστεί;
6. Παραμένει σε εξέλιξη;
```

### Αρχικός έλεγχος Windows
```cmd
# Τρέχουσες συνεδρίες χρηστών
query user
qwinsta

# Ενεργές συνδέσεις
netstat -ano | findstr ESTABLISHED

# Διεργασίες που εκτελούνται
tasklist /v
wmic process get processid,parentprocessid,commandline

# Πρόσφατες τροποποιήσεις αρχείων
forfiles /P C:\ /S /D +01/01/2024

# Προγραμματισμένες εργασίες
schtasks /query /fo LIST /v

# Υπηρεσίες
sc query state=all
wmic service get name,startmode,state

# Κλειδιά αυτόματης εκτέλεσης Run στο μητρώο
reg query "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run"
reg query "HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Run"

# Πρόσφατο ιστορικό PowerShell
type %APPDATA%\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt
```

### Αρχικός έλεγχος Linux
```bash
# Συνδεδεμένοι χρήστες
w
who
last -a

# Ενεργές συνδέσεις
ss -tulnp

lsof -i

# Διεργασίες που εκτελούνται
ps auxwww

# Πρόσφατες τροποποιήσεις αρχείων

```

### Ανάλυση δικτύου
```bash
# Καταγραφή κίνησης δικτύου

# Κίνηση στις θύρες 80 και 443 — η 443 δεν σημαίνει ορατό μη κρυπτογραφημένο HTTP
```

## 3️⃣ Περιορισμός περιστατικού (Containment)

### Άμεσος περιορισμός
```bash
# Παράδειγμα απομόνωσης δικτύου στα Windows
netsh advfirewall set allprofiles state on
netsh advfirewall firewall add rule name="Block All" dir=in action=block
netsh advfirewall firewall add rule name="Block All Out" dir=out action=block

# Παράδειγμα απομόνωσης δικτύου στο Linux
iptables -P INPUT DROP
iptables -P OUTPUT DROP
iptables -P FORWARD DROP

# Απενεργοποίηση ή κλείδωμα παραβιασμένου λογαριασμού
net user compromised_user /active:no   # Windows
passwd -l compromised_user             # Linux

# Τερματισμός διεργασίας που έχει επιβεβαιωθεί ως κακόβουλη
taskkill /PID <pid> /F               # Windows
kill -9 <pid>                        # Linux
```

### Περιορισμός μεγαλύτερης διάρκειας

Η απενεργοποίηση αυτόματης εκκίνησης μιας υπηρεσίας δεν σημαίνει απαραίτητα ότι η υπηρεσία που ήδη εκτελείται σταματά αμέσως.

```bash
# Τμηματοποίηση δικτύου
# Κανόνες τείχους προστασίας για απομόνωση του επηρεασμένου VLAN
# Ενημέρωση λιστών ελέγχου πρόσβασης σε μεταγωγείς και δρομολογητές

# Αποκλεισμός κακόβουλων IP ή τομέων στο τείχος προστασίας
# Προσθήκη στον κατάλογο αποκλεισμού του διαμεσολαβητή
# Ενημέρωση μηχανισμού ελεγχόμενης ανακατεύθυνσης DNS (Sinkhole)

# Προσωρινός περιορισμός επηρεασμένων υπηρεσιών
sc config <service> start= disabled   # Windows
systemctl disable <service>           # Linux
```

### Διαφύλαξη αποδεικτικών στοιχείων

**Περιορισμός του παραδείγματος:** η ανάγνωση του `/dev/mem` δεν αποτελεί γενικά πλήρη και διαθέσιμη μέθοδο απόκτησης μνήμης σε σύγχρονα Linux. Τα ζωντανά δεδομένα μεταβάλλονται κατά τη συλλογή. Η ακεραιότητα αρχείων και η αλυσίδα φύλαξης στοιχείων απαιτούν καταγραφή της διαδικασίας και κατάλληλα εργαλεία.

```bash
# Αντίγραφο μνήμης Windows με κατάλληλο εργαλείο όπως WinPMEM ή DumpIt
winpmem_mini_x64.exe memory.raw

# Παράδειγμα πρόσβασης στη μνήμη Linux — απαιτεί έλεγχο περιορισμών
dd if=/dev/mem of=/evidence/memory.dump bs=1M

# Αντίγραφο περιεχομένου δίσκου
dd if=/dev/sda of=/evidence/disk.img bs=4M status=progress

# Υπολογισμός ψηφιακής σύνοψης για έλεγχο ακεραιότητας
sha256sum /evidence/disk.img > disk.img.sha256

# Προτεραιότητα στα δεδομένα που χάνονται ευκολότερα:
# 1. Μνήμη
# 2. Κατάσταση δικτύου
# 3. Διεργασίες που εκτελούνται
# 4. Δίσκος
```

## 4️⃣ Εξάλειψη αιτίας και υπολειμμάτων (Eradication)

### Αφαίρεση κακόβουλου λογισμικού

Η εντολή `crontab -r` αφαιρεί ολόκληρο το crontab του συγκεκριμένου χρήστη, όχι μόνο την κακόβουλη καταχώριση. Η αφαίρεση αρχείων ή υπηρεσιών πρέπει να βασίζεται σε τεκμηριωμένη διάγνωση.

```bash
# Εντοπισμός και αφαίρεση μηχανισμών διατήρησης πρόσβασης

# Windows — μητρώο
reg delete "HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run" /v "MalwareName" /f

# Windows — προγραμματισμένες εργασίες
schtasks /delete /tn "MalwareTask" /f

# Windows — υπηρεσίες
sc delete "MalwareService"

# Linux — εργασίες cron
crontab -r
rm /etc/cron.d/malware

# Linux — υπηρεσίες systemd
systemctl disable malware
rm /etc/systemd/system/malware.service
```

### Επαναφορά κωδικών και ανάκληση στοιχείων πρόσβασης

Η αποκατάσταση Active Directory και ειδικά η αλλαγή του `krbtgt` απαιτούν σχεδιασμό, έλεγχο αναπαραγωγής και χρονισμού. Η σύντομη υπενθύμιση του πρωτοτύπου δεν είναι πλήρες σχέδιο αποκατάστασης.

```bash
# Απαίτηση επαναφοράς κωδικών για όλους τους παραβιασμένους λογαριασμούς
# Επαναφορά κωδικών λογαριασμών υπηρεσιών
# Αντικατάσταση κλειδιών API και διακριτικών πρόσβασης (Tokens)
# Ανάκληση ενεργών συνεδριών

# Windows — απαίτηση αλλαγής κωδικού
net user username /logonpasswordchg:yes

# Σχεδιασμός ανάκλησης εισιτηρίων Kerberos σε παραβίαση Active Directory
# - Η αναφορά σε δύο αλλαγές krbtgt απαιτεί ξεχωριστό σχέδιο και κατάλληλο χρονισμό
# - Επαναφορά κωδικών όλων των λογαριασμών διαχειριστή
```

### Διορθώσεις και ενημερώσεις
```bash
# Εφαρμογή διορθώσεων ασφαλείας που λείπουν
# Ενημέρωση υπογραφών προστασίας από κακόβουλο λογισμικό
# Διόρθωση ρυθμίσεων που επέτρεψαν την επίθεση
```

```bash
1. Επαναφορά των κρίσιμων συστημάτων πρώτα
2. Παρακολούθηση ενδείξεων νέας μόλυνσης
3. Επαναφορά των υπόλοιπων συστημάτων
4. Επιστροφή στην κανονική λειτουργία
```

### Παρακολούθηση μετά την αποκατάσταση
```bash
# Αύξηση λεπτομέρειας καταγραφών

# Έλεγχος πιθανής επανεμφάνισης του επιτιθέμενου

# Βασικές ενδείξεις προς παρακολούθηση:
- Ίδιες ενδείξεις παραβίασης: IP, τομείς και συνόψεις αρχείων
```

## 📊 Γρήγορη αναφορά

### Κατάταξη σοβαρότητας

Οι χρόνοι είναι ενδεικτικοί στόχοι του πρωτοτύπου. Κάθε οργανισμός ορίζει τις δικές του προτεραιότητες και δεσμεύσεις ανάλογα με την επίπτωση και τους διαθέσιμους πόρους.


| Επίπεδο | Περιγραφή | Χρόνος απόκρισης |
| ------- | ------------- | --------------- |
| **Κρίσιμο** | Παραβίαση σε εξέλιξη ή εξαγωγή δεδομένων | Άμεση |
| **Υψηλό** | Επιβεβαιωμένη παραβίαση | Λιγότερο από 1 ώρα |
| **Μέτριο** | Πιθανή παραβίαση | Λιγότερο από 4 ώρες |
| **Χαμηλό** | Ύποπτη δραστηριότητα | Λιγότερο από 24 ώρες |

### Συνηθισμένες ενδείξεις παραβίασης προς συλλογή

| Είδος ένδειξης παραβίασης | Παραδείγματα |
| ---------- | ---------- |
| **Ψηφιακή σύνοψη αρχείου (Hash)** | MD5, SHA1, SHA256 |
| **Διεύθυνση IP** | Διευθύνσεις προέλευσης και προορισμού |
| **Όνομα τομέα (Domain)** | Τομείς υποδομής απομακρυσμένου ελέγχου (C2) |
| **Διεύθυνση ιστού (URL)** | Κακόβουλες διευθύνσεις ιστού |
| **Ηλεκτρονικό ταχυδρομείο** | Αποστολέας μηνύματος ηλεκτρονικού ψαρέματος |
| **Αρχείο** | Όνομα αρχείου κακόβουλου λογισμικού |
| **Μητρώο Windows (Registry)** | Κλειδιά διατήρησης πρόσβασης |
