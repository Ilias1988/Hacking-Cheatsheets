## 🎯 什么是蓝队？

**蓝队（Blue Team）**是负责以下工作的防御安全团队：
- 🔍 **检测**威胁和攻击
- 🛡️ **保护**系统与网络
- 🚨 **响应**安全事件
- 📊 **监控**可疑活动
- 🔒 **加固**基础设施

## 🔗 红队与蓝队对比

| 方面 | 红队（进攻） | 蓝队（防御） |
|--------|---------------------|----------------------|
| **目标** | 发现漏洞 | 保护系统 |
| **方式** | 攻击模拟 | 防御与检测 |
| **工具** | Metasploit, Cobalt Strike | SIEM, EDR, IDS/IPS |
| **输出** | 发现的漏洞 | 检测到的事件 |
| **重点** | 突破防线 | 阻止入侵 |
