## Что такое Blue Team?

**Blue Team** — команда защитной безопасности, которая отвечает за:
- 🔍 **Обнаружение** угроз и атак
- 🛡️ **Защиту** систем и сетей
- 🚨 **Реагирование** на инциденты безопасности
- 📊 **Мониторинг** подозрительной активности
- 🔒 **Укрепление защиты** инфраструктуры

---

**Подписи к схеме:** подготовка (укрепление защиты) → обнаружение (мониторинг) → анализ (расследование) → реагирование (сдерживание) → восстановление → извлечение уроков (отчёт) → улучшение.

## Red Team и Blue Team

| Аспект | Red Team (атака) | Blue Team (защита) |
|--------|---------------------|----------------------|
| **Цель** | Найти уязвимости | Защитить системы |
| **Подход** | Имитация атак | Защита и обнаружение |
| **Инструменты** | Metasploit, Cobalt Strike | SIEM, EDR, IDS/IPS |
| **Результат** | Найденные уязвимости | Выявленные инциденты |
| **Фокус** | Проникновение | Предотвращение проникновения |

## Краткий справочник

### Основные ID событий Windows

| ID события | Описание |
|----------|-------------|
| 4624 | Успешный вход |
| 4625 | Неудачный вход |
| 4648 | Вход с явно указанными учётными данными |
| 4672 | Вход администратора (специальные привилегии) |
| 4688 | Создание процесса |
| 4698 | Создано задание планировщика |
| 4720 | Создана учётная запись пользователя |
| 7045 | Установка службы |

### Основные журналы Linux

| Журнал | Расположение |
|-----|----------|
| Аутентификация | `/var/log/auth.log` |
| Syslog | `/var/log/syslog` |
| Сообщения | `/var/log/messages` |
| Безопасность | `/var/log/secure` |
| Аудит | `/var/log/audit/audit.log` |
