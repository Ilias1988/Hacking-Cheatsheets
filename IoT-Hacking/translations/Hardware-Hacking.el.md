## Πριν ξεκινήσετε

Η **διερεύνηση υλικού** αναγνωρίζει εξαρτήματα, ακροδέκτες και διαθέσιμες διεπαφές μιας πλακέτας. Το **pin** είναι ακροδέκτης και το **pinout** η αντιστοίχισή του σε σήμα. Το **UART** είναι ασύγχρονη σειριακή επικοινωνία, το **JTAG** διεπαφή ελέγχου και αποσφαλμάτωσης και τα **SPI/I2C** δίαυλοι επικοινωνίας με περιφερειακά. Το **EEPROM** είναι τύπος επανεγγράψιμης μη πτητικής μνήμης· δεν είναι κάθε συσκευή I2C EEPROM.

Το **TX/RX** δηλώνει μετάδοση/λήψη, το **GND** τη γείωση αναφοράς και το **VCC** τροφοδοσία. Ο **baud rate** είναι ρυθμός συμβόλων επικοινωνίας. Ο **ελεγκτής (controller)** συντονίζει την αντίστοιχη επικοινωνία με το **περιφερειακό (peripheral)**. Τα ονόματα MOSI/MISO διατηρούνται όπως στο πρωτότυπο για αναγνώριση των σημάτων SPI.

Το **πολύμετρο** μετρά τάση ή συνέχεια σε κατάλληλη λειτουργία, ο **αναλυτής λογικών σημάτων** καταγράφει ψηφιακά σήματα και ο **προγραμματιστής μνήμης** επικοινωνεί με συγκεκριμένους υποστηριζόμενους τύπους μνήμης. Το μοντέλο ενός ολοκληρωμένου USB-UART δεν αρκεί για να γνωρίζουμε τα ηλεκτρικά χαρακτηριστικά ολόκληρου του προσαρμογέα.

Πριν από σύνδεση επιβεβαιώστε pinout, τάσεις τροφοδοσίας, λογικά επίπεδα και τρόπο τροφοδότησης από την τεκμηρίωση της συσκευής και του εργαλείου. Η αναφορά 3.3V/5V στον πίνακα δεν σημαίνει ότι όλα τα pins ανέχονται και τις δύο τάσεις. Μην συνδέετε VCC ή παράλληλες τροφοδοσίες χωρίς τεκμηριωμένη ανάγκη και συμβατότητα. Οι εντολές του οδηγού είναι παραδείγματα, όχι καθολική διαδικασία καλωδίωσης.

## 🔌 UART — Σειριακή επικοινωνία και πιθανή κονσόλα

Μια UART μπορεί να εμφανίζει μόνο μηνύματα εκκίνησης ή να απαιτεί ταυτοποίηση. Ο εντοπισμός TX/RX δεν εγγυάται διαθέσιμο shell. Οι πίνακες περιγράφουν ρόλους σημάτων, όχι φυσική σειρά ακροδεκτών σε κάθε συσκευή.


### Αναγνώριση ακροδεκτών UART
```
TX (Transmit) - Έξοδος δεδομένων από τη συσκευή
RX (Receive) - Είσοδος δεδομένων προς τη συσκευή
GND - Γείωση αναφοράς του κυκλώματος
VCC - Τροφοδοσία (3.3V/5V στο παράδειγμα, όχι καθολική προδιαγραφή)
```

### Εργαλεία
- **Πολύμετρο (Multimeter):** Μετρήσεις για διερεύνηση GND και τροφοδοσίας VCC.
- **Αναλυτής λογικών σημάτων (Logic Analyzer):** Παρατήρηση σημάτων για διερεύνηση TX/RX και baud rate.
- **Προσαρμογέας USB-UART:** Ενδεικτικές οικογένειες FT232, CP2102 και CH340· χρειάζεται έλεγχος των χαρακτηριστικών της συγκεκριμένης πλακέτας.

### Παράδειγμα σειριακής σύνδεσης
```bash
# Σειριακή σύνδεση με screen σε Linux
screen /dev/ttyUSB0 115200

# Σειριακή σύνδεση με minicom σε Linux
minicom -D /dev/ttyUSB0 -b 115200

# picocom
picocom -b 115200 /dev/ttyUSB0
```

### Συνηθισμένοι ρυθμοί συμβόλων (baud rates)
```
9600, 19200, 38400, 57600, 115200
```

## 🔧 JTAG — Διεπαφή ελέγχου και αποσφαλμάτωσης

Το παράδειγμα OpenOCD επιλέγει συγκεκριμένα αρχεία ρυθμίσεων jlink και stm32f1x. Δεν αναγνωρίζει καθολικά κάθε προσαρμογέα ή επεξεργαστή. Η παρουσία pins δεν συνεπάγεται ενεργοποιημένο ή ξεκλείδωτο debug.


### Ακροδέκτες (pins)
```
TDI - Είσοδος δεδομένων ελέγχου (Test Data In)
TDO - Έξοδος δεδομένων ελέγχου (Test Data Out)
TCK - Ρολόι ελέγχου (Test Clock)
TMS - Επιλογή λειτουργίας ελέγχου (Test Mode Select)
TRST - Επαναφορά ελέγχου, προαιρετικός ακροδέκτης (Test Reset)
```

### Εργαλεία
```bash
# Παράδειγμα ρυθμίσεων OpenOCD
openocd -f interface/jlink.cfg -f target/stm32f1x.cfg

# JTAGulator
# Αναζήτηση πιθανής αντιστοίχισης ακροδεκτών JTAG
```

## 📟 SPI — Παράδειγμα επικοινωνίας με μνήμη flash

### Ακροδέκτες (pins)
```
MOSI - Δεδομένα από ελεγκτή προς περιφερειακό
MISO - Δεδομένα από περιφερειακό προς ελεγκτή
CLK  - Σήμα ρολογιού (Clock)
CS   - Επιλογή ολοκληρωμένου κυκλώματος (Chip Select)
```

### Ανάγνωση περιεχομένου μνήμης flash

Τα παραδείγματα flashrom χρησιμοποιούν -r για ανάγνωση σε αρχείο. Χρειάζονται υποστήριξη του πραγματικού chip, συμβατές τάσεις και σωστή σύνδεση. Ανάγνωση ενώ η μνήμη παραμένει πάνω στην πλακέτα μπορεί να επηρεάζεται από άλλα κυκλώματα ή τροφοδοσίες· οι εντολές δεν περιγράφουν αυτές τις προϋποθέσεις.

```bash
# Ανάγνωση με flashrom
flashrom -p ch341a_spi -r dump.bin

# Bus Pirate
flashrom -p buspirate_spi:dev=/dev/ttyUSB0 -r dump.bin
```

## 📡 I2C — Παράδειγμα επικοινωνίας με EEPROM

### Ακροδέκτες (pins)
```
SDA - Γραμμή σειριακών δεδομένων (Serial Data)
SCL - Γραμμή σειριακού ρολογιού (Serial Clock)
```

### Παράδειγμα διερεύνησης και ανάγνωσης EEPROM

Τα bus 1 και address 0x50 είναι ενδεικτικά, όχι καθολικές τιμές EEPROM. Η σάρωση I2C δεν είναι κατ’ ανάγκη παθητική: το [εγχειρίδιο i2cdetect](https://manpages.debian.org/trixie/i2c-tools/i2cdetect.8.en.html) εξηγεί ότι χρησιμοποιεί δοκιμαστικές εντολές που μπορούν να επηρεάσουν συσκευές. Η -y παραλείπει την ερώτηση επιβεβαίωσης. Απαιτείται κατανόηση του συγκεκριμένου διαύλου πριν από χρήση.

```bash
# i2c-tools
i2cdetect -y 1
i2cdump -y 1 0x50
```
