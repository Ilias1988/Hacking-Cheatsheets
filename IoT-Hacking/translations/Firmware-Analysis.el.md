## Πριν ξεκινήσετε

Η **ανάλυση firmware** εξετάζει ένα αντίγραφο του λογισμικού της συσκευής. Το αρχείο μπορεί να περιέχει εκτελέσιμα, ρυθμίσεις, συμπιεσμένα δεδομένα και ένα ή περισσότερα συστήματα αρχείων. Η **εξαγωγή (extraction)** ανακτά περιεχόμενο σε αρχεία και καταλόγους· η **προσάρτηση (mount)** το παρουσιάζει μέσω του λειτουργικού. Δεν είναι η ίδια διαδικασία.

Τα **SquashFS**, **JFFS2** και **UBIFS** είναι συστήματα αρχείων που συναντώνται σε ενσωματωμένα συστήματα. Το **ELF** είναι μορφή μεταγλωττισμένων αρχείων, το **OTA (Over-The-Air)** ενημέρωση μέσω επικοινωνίας και το **dump** αντίγραφο δεδομένων από μνήμη ή συσκευή. Η **εντροπία** περιγράφει χαρακτηριστικά κατανομής των δεδομένων· υψηλή τιμή μπορεί να σχετίζεται με συμπίεση ή κρυπτογράφηση, αλλά δεν αποδεικνύει ποια από τις δύο υπάρχει.

Διατηρήστε το αρχικό αρχείο και αναλύστε αντίγραφο σε κατάλληλο εργαστήριο. Οι διαδρομές firmware.bin, filesystem/, image.ubi και τα offsets ή μεγέθη του πρωτοτύπου είναι ενδεικτικά. Τα εργαλεία και οι επιλογές τους εξαρτώνται από την εγκατεστημένη έκδοση. Η εξαγωγή ορισμένων αρχείων δεν αποδεικνύει πλήρη ανάκτηση ολόκληρου του firmware.

## 📥 Απόκτηση αντιγράφου firmware

Το μπλοκ είναι λίστα πιθανών πηγών firmware σε σχόλια και όχι εκτελέσιμη διαδικασία. Η δυνατότητα απόκτησης δεδομένων μέσω μιας διεπαφής ή ενημέρωσης εξαρτάται από τη συσκευή και τους μηχανισμούς προστασίας της.


```bash
# Λήψη από τον επίσημο ιστότοπο του κατασκευαστή
# Διερεύνηση πακέτου ασύρματης ενημέρωσης OTA στο εξουσιοδοτημένο εργαστήριο
# Απόκτηση αντιγράφου από τη συσκευή, ανάλογα με τη διαθέσιμη διεπαφή UART/SPI/JTAG
# Διερεύνηση περιεχομένου της συνοδευτικής εφαρμογής κινητού
```

## 🔍 Αρχική ανάλυση

```bash
# Αναγνώριση τύπου αρχείου
file firmware.bin

# Αναζήτηση αναγνώσιμων συμβολοσειρών
strings firmware.bin | grep -i password
strings firmware.bin | grep -i admin
strings firmware.bin | grep -i http

# Εκτίμηση εντροπίας — πιθανή ένδειξη συμπίεσης ή κρυπτογράφησης
binwalk -E firmware.bin
```

## 📦 Εξαγωγή περιεχομένου με Binwalk

Οι επιλογές -eM, -D και η συμπεριφορά εξαγωγής πρέπει να ελεγχθούν στην εγκατεστημένη έκδοση. Το πρωτότυπο περιλαμβάνει σύνταξη που δεν είναι κατ’ ανάγκη κοινή σε όλες τις εκδόσεις· δείτε το [επίσημο έργο Binwalk](https://github.com/ReFirmLabs/binwalk). Αναγνώριση υπογραφής δεν εγγυάται επιτυχή ή πλήρη εξαγωγή.


```bash
# Σάρωση του αρχείου firmware
binwalk firmware.bin

# Απόπειρα εξαγωγής περιεχομένου που υποστηρίζει η συγκεκριμένη εγκατάσταση
binwalk -e firmware.bin

# Εξαγωγή σε κατάλογο
binwalk -e -C output firmware.bin

# Παράδειγμα αναδρομικής εξαγωγής
binwalk -eM firmware.bin

# Παράδειγμα κανόνα εξαγωγής για ELF — εξαρτάται από την έκδοση
binwalk -D 'elf:elf' firmware.bin
```

## 🗂️ Συστήματα αρχείων

### SquashFS

Το unsquashfs αναμένει αρχείο εικόνας ως είσοδο. Αν το squashfs-root είναι ήδη κατάλογος, η πρώτη εντολή δεν είναι σωστή χρήση αυτού του καταλόγου ως εικόνας. Η mksquashfs δημιουργεί νέο αρχείο συστήματος αρχείων· αυτό δεν αρκεί για να παραχθεί έγκυρο πλήρες firmware με τους σωστούς headers, ελέγχους ακεραιότητας ή υπογραφές. Δείτε το [έργο squashfs-tools](https://github.com/plougher/squashfs-tools).

```bash
# Εξαγωγή περιεχομένου
unsquashfs squashfs-root
unsquashfs -d output filesystem.squashfs

# Δημιουργία νέας εικόνας συστήματος αρχείων
mksquashfs output modified.squashfs -comp xz
```

### JFFS2

Η dd γράφει απευθείας στη συσκευή που ορίζεται από το of=. Μην θεωρήσετε ότι το /dev/mtdblock0 είναι πάντα η μνήμη RAM που δημιουργεί το mtdram: μπορεί να αντιστοιχεί σε άλλη MTD συσκευή. Το παράδειγμα προϋποθέτει έλεγχο του πραγματικού προορισμού και απομονωμένο περιβάλλον. Τα ονόματα, τα μεγέθη και οι διαδρομές του πρωτοτύπου δεν είναι ασφαλείς καθολικές προεπιλογές.

```bash
# Παράδειγμα προετοιμασίας και προσάρτησης JFFS2 — ελέγξτε πρώτα τον προορισμό εγγραφής
modprobe jffs2
modprobe mtdram total_size=32768 erase_size=256
dd if=jffs2.img of=/dev/mtdblock0
mount -t jffs2 /dev/mtdblock0 /mnt
```

### UBIFS
```bash
# Εξαγωγή με ubi_reader
ubireader_extract_files image.ubi
```

## 🔐 Ευαίσθητα στοιχεία και στοιχεία σύνδεσης

Οι αναζητήσεις επιστρέφουν υποψήφια ευρήματα, όχι επιβεβαιωμένους ενεργούς κωδικούς. Οι σχετικές διαδρομές etc/shadow και etc/passwd πρέπει να αναφέρονται στο εξαγόμενο αντίγραφο που εξετάζετε. Αρχεία, hashes και κλειδιά χρειάζονται καταγραφή προέλευσης και κατάλληλο χειρισμό πριν ενσωματωθούν σε αναφορά.


```bash
# Αναζήτηση πιθανών στοιχείων σύνδεσης
grep -rni "password" filesystem/
grep -rni "admin" filesystem/
grep -rni "api_key" filesystem/
grep -rni "secret" filesystem/

# Αναζήτηση αρχείων που ενδέχεται να περιέχουν κλειδιά SSH
find . -name "id_rsa*"
find . -name "*.pem"

# Αναζήτηση αρχείων ρυθμίσεων
find . -name "*.conf"
find . -name "*.cfg"
cat etc/shadow
cat etc/passwd
```

## 🔄 Ανάλυση μεταγλωττισμένων προγραμμάτων

Η εκκίνηση ghidraRun εξαρτάται από τη διανομή και την εγκατάσταση. Οι συμβολοσειρές που μοιάζουν με διευθύνσεις ή πρωτόκολλα δεν αποδεικνύουν από μόνες τους ενεργή υπηρεσία ή backdoor.


```bash
# Εντοπισμός μεταγλωττισμένων αρχείων μορφής ELF
find . -type f -exec file {} \; | grep ELF

# Εκκίνηση Ghidra για ανάλυση
ghidraRun

# Αναζήτηση ενσωματωμένων συμβολοσειρών
strings binary | grep -E "http|ftp|telnet|ssh"
```
