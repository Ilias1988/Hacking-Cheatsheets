## 🔌 UART (последовательная консоль)

### Определение выводов UART
```
TX (Transmit) — передача данных из устройства
RX (Receive) — приём данных устройством
GND — общий провод (земля)
VCC — питание (3.3V/5V)
```

### Инструменты
- **Мультиметр** — определить GND и VCC
- **Логический анализатор** — определить TX/RX и скорость передачи
- **USB-UART** — FT232, CP2102, CH340

### Подключение
```bash
# Linux screen
screen /dev/ttyUSB0 115200

# Linux minicom
minicom -D /dev/ttyUSB0 -b 115200

# picocom
picocom -b 115200 /dev/ttyUSB0
```

### Типичные скорости передачи (бод)
```
9600, 19200, 38400, 57600, 115200
```

## 🔧 JTAG (отладочный интерфейс)

### Выводы
```
TDI — вход тестовых данных (Test Data In)
TDO — выход тестовых данных (Test Data Out)
TCK — тактовый сигнал тестирования (Test Clock)
TMS — выбор режима тестирования (Test Mode Select)
TRST — сброс тестового интерфейса (Test Reset, необязательный)
```

### Инструменты
```bash
# OpenOCD
openocd -f interface/jlink.cfg -f target/stm32f1x.cfg

# JTAGulator
# Автоматически определить назначение выводов JTAG
```

## 📟 SPI (флеш-память)

### Выводы
```
MOSI — выход ведущего, вход ведомого (Master Out Slave In)
MISO — вход ведущего, выход ведомого (Master In Slave Out)
CLK — тактовый сигнал (Clock)
CS — выбор микросхемы (Chip Select)
```

### Чтение дампа флеш-памяти
```bash
# flashrom
flashrom -p ch341a_spi -r dump.bin

# Bus Pirate
flashrom -p buspirate_spi:dev=/dev/ttyUSB0 -r dump.bin
```

## 📡 I2C (EEPROM)

### Выводы
```
SDA — линия последовательных данных (Serial Data)
SCL — линия тактового сигнала (Serial Clock)
```

### Чтение дампа EEPROM
```bash
# i2ctools
i2cdetect -y 1
i2cdump -y 1 0x50
```
