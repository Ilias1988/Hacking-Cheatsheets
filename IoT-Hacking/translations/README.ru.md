> **Пояснение к схеме:** поверхность атаки охватывает беспроводные интерфейсы (Wireless), аппаратную часть (Hardware), прошивку (Firmware), сеть (Network), мобильное приложение (Mobile App) и облако (Cloud).

> **Уточнение:** unsquashfs извлекает содержимое без монтирования. Его аргументом служит образ файловой системы или блочное устройство, а squashfs-root обычно является именем выходного каталога; исходная строка предполагает, что так назван именно входной образ. См. [официальное руководство Unsquashfs](https://github.com/plougher/squashfs-tools/blob/master/Documentation/4.7.4/USAGE-UNSQUASHFS.md).

## 🔥 Краткий справочник

### Прошивка
```bash
# Извлечь прошивку
binwalk -e firmware.bin

# Найти файловые системы
binwalk firmware.bin | grep -i filesystem

# Распаковать squashfs (подпись оригинала говорит о монтировании; см. уточнение)
unsquashfs squashfs-root
```

### Аппаратные интерфейсы
```bash
# Подключение UART
screen /dev/ttyUSB0 115200

# Bus Pirate
sudo picocom -b 115200 /dev/ttyUSB0
```
