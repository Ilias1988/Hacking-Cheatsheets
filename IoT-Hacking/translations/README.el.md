## Πριν ξεκινήσετε

Το **IoT (Internet of Things)** περιλαμβάνει δικτυωμένες συσκευές που συνδυάζουν ηλεκτρονικό υλικό, λογισμικό και υπηρεσίες. Το **firmware** είναι το ενσωματωμένο λογισμικό της συσκευής, ενώ το **hardware** είναι η πλακέτα, οι μνήμες, τα ολοκληρωμένα κυκλώματα και οι φυσικές διεπαφές της.

Η ασφάλεια μιας συσκευής μπορεί να εξαρτάται από την ίδια την πλακέτα, το firmware, την εφαρμογή κινητού, το δίκτυο και το cloud που τη συνοδεύει. Τα **API** είναι διεπαφές επικοινωνίας λογισμικού, το **BLE** Bluetooth Low Energy και το **RE (Reverse Engineering)** αντίστροφη ανάλυση. Οι ονομασίες UART, JTAG, SPI και I2C εξηγούνται στον οδηγό υλικού.

Ξεκινήστε από την αναγνώριση του μοντέλου και της έκδοσης και, αν υπάρχει νόμιμα διαθέσιμο αντίγραφο firmware, από την ανάλυσή του χωρίς αλλαγή στη συσκευή. Κρατήστε σημειώσεις και αντίγραφα των αρχικών δεδομένων. Η παρουσία μιας διεπαφής ή μιας συμβολοσειράς δεν αποδεικνύει δυνατότητα πρόσβασης ή ευπάθεια.

Οι εντολές και τα τεχνικά αναγνωριστικά παραμένουν όπως στο αγγλικό πρωτότυπο, με ελληνικές εξηγήσεις. Είναι παραδείγματα για δική σας συσκευή ή εξουσιοδοτημένο εργαστήριο. Οι θύρες συσκευών, τα αρχεία, οι τάσεις και οι ρυθμίσεις προσαρμογέων χρειάζονται έλεγχο για το συγκεκριμένο περιβάλλον.

## 🔥 Γρήγορη αναφορά

Το unsquashfs εξάγει εικόνα SquashFS και δεν εκτελεί προσάρτηση. Το squashfs-root είναι συνηθισμένο όνομα καταλόγου εξαγωγής, όχι εγγύηση ότι το όρισμα του παραδείγματος είναι έγκυρη εικόνα. Η διαδρομή /dev/ttyUSB0 και ο ρυθμός 115200 πρέπει να αντιστοιχούν στη δική σας συσκευή.


### Ενσωματωμένο λογισμικό (Firmware)
```bash
# Εξαγωγή περιεχομένου firmware
binwalk -e firmware.bin

# Αναζήτηση ενδείξεων συστημάτων αρχείων
binwalk firmware.bin | grep -i filesystem

# Παράδειγμα εξαγωγής SquashFS — δείτε τον περιορισμό της διαδρομής
unsquashfs squashfs-root
```

### Υλικό συσκευής (Hardware)
```bash
# Σύνδεση σειριακής κονσόλας UART
screen /dev/ttyUSB0 115200

# Bus Pirate
sudo picocom -b 115200 /dev/ttyUSB0
```

## 🔍 Παραδείγματα αναζητήσεων IoT στο Shodan

Οι γραμμές είναι ερωτήματα αναζήτησης Shodan, παρότι το μπλοκ χαρακτηρίζεται bash στο πρωτότυπο. Δεν είναι εντολές shell. Μια θύρα ή οι λέξεις default password δεν επιβεβαιώνουν συγκεκριμένο προϊόν, διαθέσιμη πρόσβαση ή έγκυρα στοιχεία σύνδεσης.


```bash
# Αναζήτηση όρων σχετικών με κάμερες
webcam country:US

# Αναζήτηση ενδείξεων βιομηχανικών πρωτοκόλλων
port:502 modbus

# Αναζήτηση πιθανών MQTT brokers
port:1883

# Αναζήτηση των όρων του παραδείγματος — δεν αποδεικνύει πρόσβαση
default password
```
