## Πριν ξεκινήσετε

Το **reconnaissance** είναι η συλλογή πληροφοριών πριν από έναν έλεγχο ασφάλειας. Το Nmap στέλνει δοκιμαστικά πακέτα για να εντοπίσει **hosts** (συσκευές ή συστήματα), **ports** (θύρες επικοινωνίας) και υπηρεσίες. Το **enumeration** είναι η πιο λεπτομερής καταγραφή τους. Μια ανοιχτή θύρα δεν σημαίνει από μόνη της ευπάθεια.

Διαβάστε τα παραδείγματα με τη σειρά: επιλογή στόχου → έλεγχος διαθεσιμότητας → σάρωση θυρών → αναγνώριση υπηρεσιών → επιλεγμένα scripts NSE → αποθήκευση αποτελεσμάτων. Οι διευθύνσεις, τα domains και τα ονόματα αρχείων είναι παραδείγματα προς προσαρμογή στο εγκεκριμένο εργαστήριό σας. Οι εντολές παραμένουν όπως στο αγγλικό πρωτότυπο· οι σημειώσεις εξηγούν περιορισμούς τους.

**Όροι:** *probe* = δοκιμαστικό πακέτο ή αίτημα, *root* = λογαριασμός διαχειριστή Linux, *timeout* = χρονικό όριο αναμονής, *IDS* = σύστημα ανίχνευσης εισβολών. Τα **NSE scripts** είναι πρόσθετοι έλεγχοι του Nmap· διαφέρουν ως προς τη λειτουργία και τις επιπτώσεις τους.

## 🎯 Εισαγωγή

**Το Nmap** (Network Mapper) είναι δωρεάν εργαλείο ανοιχτού κώδικα για ανακάλυψη συστημάτων σε δίκτυα και ελέγχους ασφάλειας. Χρησιμοποιείται ευρέως για τη σάρωση δικτύων.

### Βασικά χαρακτηριστικά

| Χαρακτηριστικό | Περιγραφή |
| --------- | ------------- |
| **Εντοπισμός ενεργών συστημάτων (Host Discovery)** | Εντοπισμός ενεργών συστημάτων στο δίκτυο |
| **Σάρωση θυρών** | Αναγνώριση ανοιχτών θυρών και υπηρεσιών |
| **Αναγνώριση εκδόσεων** | Αναγνώριση εκδόσεων υπηρεσιών |
| **Αναγνώριση λειτουργικού συστήματος** | Αναγνώριση λειτουργικών συστημάτων |
| **Scripts του Nmap Scripting Engine (NSE)** | Έλεγχοι ευπαθειών και scripts αξιοποίησής τους |
| **Μορφές αποτελεσμάτων** | Αποτελέσματα XML, κατάλληλα για grep ή σε κανονικό κείμενο |

### Καταστάσεις θυρών

> **Πώς διαβάζονται οι καταστάσεις:** Περιγράφουν τι μπόρεσε να παρατηρήσει το Nmap από τη συγκεκριμένη θέση και με τη συγκεκριμένη τεχνική. Το `filtered` δεν αποδεικνύει ποιο σύστημα προκάλεσε το φιλτράρισμα, ενώ οι συνδυασμένες καταστάσεις δηλώνουν αβεβαιότητα. Δείτε τον [επίσημο οδηγό σάρωσης](https://nmap.org/book/man-port-scanning-techniques.html).


| Κατάσταση | Περιγραφή |
| ------- | ------------- |
| `open` | Μια εφαρμογή δέχεται συνδέσεις στη θύρα |
| `closed` | Η θύρα είναι προσβάσιμη, αλλά καμία εφαρμογή δεν ακούει σε αυτή |
| `filtered` | Δεν διαπιστώνεται αν η θύρα είναι ανοιχτή, π.χ. λόγω φιλτραρίσματος |
| `unfiltered` | Η θύρα είναι προσβάσιμη, αλλά η συγκεκριμένη σάρωση δεν καθορίζει αν είναι ανοιχτή |
| `open\|filtered` | Δεν διακρίνεται αν είναι ανοιχτή ή φιλτραρισμένη |
| `closed\|filtered` | Δεν διακρίνεται αν είναι κλειστή ή φιλτραρισμένη |

## 🎯 Καθορισμός στόχων

### Μεμονωμένοι στόχοι
```bash
# Διεύθυνση IP
nmap 192.168.1.1

# Όνομα συστήματος
nmap scanme.nmap.org

# Πεδίο
nmap example.com
```

### Πολλαπλοί στόχοι
```bash
# Τιμές χωρισμένες με κενά
nmap 192.168.1.1 192.168.1.2 192.168.1.3

# Εύρος
nmap 192.168.1.1-100

# Γραφή υποδικτύου CIDR
nmap 192.168.1.0/24

# Απαντήσεις wildcard σε πολλά διαφορετικά ονόματα
nmap 192.168.1.*

# Εύρος τιμών οκτάδας IP
nmap 192.168.0-255.1-254

# Συνδυασμός τύπων στόχων
nmap 192.168.1.0/24 10.0.0.1
```

### Εισαγωγή από αρχείο
```bash
# Ανάγνωση από αρχείο
nmap -iL targets.txt

# targets.txt:
# 192.168.1.1
# 192.168.1.0/24
# scanme.nmap.org
```

### Εξαίρεση στόχων
```bash
# Εξαίρεση ενός συστήματος
nmap 192.168.1.0/24 --exclude 192.168.1.1

# Εξαιρέσεις από αρχείο
nmap 192.168.1.0/24 --excludefile exclude.txt
```

### Τυχαίοι στόχοι
```bash
# Παράδειγμα επιλογής τυχαίων στόχων· απαιτείται εξουσιοδοτημένο πεδίο ελέγχου
nmap -iR 100
```

## 🔎 Εντοπισμός ενεργών συστημάτων (Host Discovery)

> **Διαθεσιμότητα και σάρωση θυρών:** Το `-Pn` παραλείπει τον αρχικό έλεγχο διαθεσιμότητας· δεν παρακάμπτει firewall. Επιλογές όπως `-PS`, `-PA`, `-PU` ή `-PR` επιλέγουν δοκιμές εντοπισμού, αλλά χωρίς `-sn` συνήθως ακολουθεί και σάρωση θυρών. Το `-sL` μπορεί να κάνει αναζητήσεις DNS, παρότι δεν σαρώνει θύρες. Δείτε την [τεκμηρίωση Host Discovery](https://nmap.org/book/man-host-discovery.html).


### Επιλογές εντοπισμού συστημάτων

| Επιλογή | Περιγραφή |
| -------- | ------------- |
| `-sL` | Απαρίθμηση στόχων χωρίς σάρωση θυρών |
| `-sn` | Εντοπισμός ενεργών συστημάτων χωρίς σάρωση θυρών |
| `-Pn` | Παράλειψη εντοπισμού· όλοι οι στόχοι θεωρούνται ενεργοί |
| `-PS` | Έλεγχος διαθεσιμότητας με TCP SYN |
| `-PA` | Έλεγχος διαθεσιμότητας με TCP ACK |
| `-PU` | Έλεγχος διαθεσιμότητας με UDP |
| `-PE` | Έλεγχος με αίτημα ICMP echo |
| `-PP` | Έλεγχος με αίτημα ICMP timestamp |
| `-PM` | Έλεγχος με αίτημα ICMP netmask |
| `-PO` | Έλεγχος διαθεσιμότητας με πρωτόκολλα IP |
| `-PR` | Έλεγχος με ARP στο τοπικό δίκτυο |

### Εντοπισμός ενεργών συστημάτων χωρίς σάρωση θυρών
```bash
# Μόνο εντοπισμός ενεργών συστημάτων
nmap -sn 192.168.1.0/24

# Εντοπισμός ενεργών συστημάτων από λίστα
nmap -sn -iL hosts.txt
```

### Παράλειψη εντοπισμού ενεργών συστημάτων
```bash
# Σάρωση όλων των στόχων χωρίς προηγούμενο έλεγχο διαθεσιμότητας
nmap -Pn 192.168.1.1

# Χρήσιμο όταν:
# - Συστήματα που φιλτράρουν αιτήματα ICMP
# - Έλεγχος στόχων που μπορεί να βρίσκονται πίσω από firewall
```

### Έλεγχος διαθεσιμότητας με TCP SYN ή ACK
```bash
# Έλεγχος TCP SYN στη θύρα 80
nmap -PS80 192.168.1.1

# Έλεγχος TCP ACK στη θύρα 80
nmap -PA80 192.168.1.1

# Πολλαπλές θύρες
nmap -PS22,80,443 192.168.1.1
```

### Έλεγχος διαθεσιμότητας με UDP
```bash
# Έλεγχος διαθεσιμότητας με UDP
nmap -PU53 192.168.1.1

# Πολλαπλές θύρες
nmap -PU53,161 192.168.1.1
```

### Έλεγχος διαθεσιμότητας με ICMP
```bash
# Αίτημα ICMP echo
nmap -PE 192.168.1.1

# Αίτημα ICMP timestamp
nmap -PP 192.168.1.1

# Αίτημα ICMP netmask
nmap -PM 192.168.1.1
```

### Έλεγχος με ARP στο τοπικό δίκτυο
```bash
# Σάρωση ARP, συνήθως γρήγορη στο τοπικό δίκτυο
nmap -PR 192.168.1.0/24

# Παράδειγμα ελέγχου ARP· δείτε τη σημείωση για το -sn
nmap -sn -PR 192.168.1.0/24
```

### Απενεργοποίηση αναζήτησης ονομάτων DNS
```bash
# Χωρίς αναζήτηση ονομάτων DNS, συνήθως ταχύτερα
nmap -n 192.168.1.1

# Πάντα αναζήτηση ονομάτων DNS
nmap -R 192.168.1.1
```

## 🔌 Τεχνικές σάρωσης θυρών

### Επισκόπηση τύπων σάρωσης

| Επιλογή | Όνομα | Περιγραφή |
| -------- | ------ | ------------- |
| `-sS` | Σάρωση SYN | Σάρωση SYN χωρίς ολοκλήρωση σύνδεσης, προεπιλογή με κατάλληλα δικαιώματα |
| `-sT` | Σύνδεση TCP (Connect) | Πλήρης σύνδεση TCP χωρίς απαίτηση δικαιωμάτων root |
| `-sU` | Σάρωση UDP | Σάρωση θυρών UDP |
| `-sA` | Σάρωση ACK | Διερεύνηση συμπεριφοράς κανόνων firewall |
| `-sW` | Σάρωση TCP Window | Παρόμοια με ACK· εξετάζει το πεδίο παραθύρου TCP |
| `-sM` | Σάρωση Maimon | Δοκιμαστικό πακέτο με σημαίες FIN/ACK |
| `-sN` | Σάρωση NULL | Χωρίς ενεργές σημαίες TCP |
| `-sF` | Σάρωση FIN | Με ενεργή τη σημαία FIN |
| `-sX` | Σάρωση Xmas | Με ενεργές τις σημαίες FIN, PSH και URG |

### Σάρωση SYN, γνωστή και ως «stealth»
```bash
# Συνήθης σάρωση SYN με δικαιώματα root
sudo nmap -sS 192.168.1.1

# Δεν ολοκληρώνει την τριμερή διαδικασία σύνδεσης TCP
# Γρήγορη σάρωση με τις επιλογές αποφυγής ανίχνευσης του παραδείγματος
```

### Σάρωση με πλήρη σύνδεση TCP
```bash
# Πλήρης σύνδεση TCP
nmap -sT 192.168.1.1

# Χωρίς απαίτηση δικαιωμάτων root
# Πλήρης σύνδεση TCP· δεν είναι εγγυημένη η επιτυχία της
```

### Σάρωση UDP
```bash
# Σάρωση θυρών UDP
sudo nmap -sU 192.168.1.1

# Η σάρωση UDP μπορεί να είναι πολύ αργή
# Συνδυασμός με αναγνώριση εκδόσεων
sudo nmap -sU -sV 192.168.1.1

# Συνήθεις θύρες UDP
sudo nmap -sU -p 53,67,68,69,123,161,500 192.168.1.1
```

### Συνδυασμός TCP και UDP
```bash
# Σάρωση TCP και UDP
sudo nmap -sS -sU 192.168.1.1

# Συγκεκριμένες θύρες
sudo nmap -sS -sU -p T:80,443,U:53,161 192.168.1.1
```

### Σαρώσεις NULL, FIN και Xmas
```bash
# Σάρωση NULL χωρίς ενεργές σημαίες TCP
sudo nmap -sN 192.168.1.1

# Σάρωση FIN, μόνο με σημαία FIN
sudo nmap -sF 192.168.1.1

# Σάρωση Xmas με σημαίες FIN, PSH και URG
sudo nmap -sX 192.168.1.1

# Ενδεικτικές χρήσεις:
# - Διερεύνηση συμπεριφοράς firewall χωρίς παρακολούθηση συνδέσεων (stateless)
# - Το πρωτότυπο αναφέρει περιορισμό σε Windows· η συμπεριφορά εξαρτάται από τη στοίβα TCP
```

### Σάρωση ACK
```bash
# Διερεύνηση συμπεριφοράς κανόνων firewall
sudo nmap -sA 192.168.1.1

# Διερεύνηση:
# - Ποιες θύρες εμφανίζονται ως filtered
# - Κανόνες τείχους προστασίας
# Επιστρέφει κατάσταση unfiltered ή filtered
```

### Σάρωση TCP Window
```bash
# Παρόμοια με σάρωση ACK
sudo nmap -sW 192.168.1.1

# Εκτίμηση κατάστασης από το μέγεθος παραθύρου TCP, όπου εφαρμόζεται
```

### Έμμεση σάρωση Idle/Zombie
```bash
# Έμμεση σάρωση μέσω ενδιάμεσου συστήματος· δεν εγγυάται αφάνεια
sudo nmap -sI zombie_host 192.168.1.1

# Έμμεση τεχνική· μην θεωρείτε ότι αποκλείεται κάθε άμεση επικοινωνία
# Απαιτεί κατάλληλο ενδιάμεσο σύστημα («zombie»)
```

## 🎚️ Καθορισμός θυρών

### Επιλογές θυρών

| Επιλογή | Περιγραφή |
| -------- | ------------- |
| `-p <port>` | Σάρωση συγκεκριμένων θυρών |
| `-p-` | Σάρωση και των 65.535 θυρών από 1 έως 65535 |
| `-p 1-1000` | Σάρωση εύρους θυρών |
| `--top-ports <n>` | Σάρωση των N συχνότερων θυρών |
| `-F` | Σύντομη σάρωση των 100 συχνότερων θυρών |
| `-r` | Σάρωση θυρών με διαδοχική σειρά |

### Συγκεκριμένες θύρες
```bash
# Μία θύρα
nmap -p 80 192.168.1.1

# Πολλαπλές θύρες
nmap -p 80,443,22 192.168.1.1

# Εύρος θυρών
nmap -p 1-1000 192.168.1.1

# Όλες οι θύρες
nmap -p- 192.168.1.1

# Συνδυασμός τύπων στόχων
nmap -p 22,80,443,1000-2000 192.168.1.1
```

### Θύρες ανά πρωτόκολλο

> **Προσοχή στο UDP:** Το πρόθεμα `U:` επιλέγει θύρες UDP, αλλά δεν ενεργοποιεί μόνο του σάρωση UDP. Το αντίστοιχο παράδειγμα του πρωτοτύπου χρειάζεται τον κατάλληλο τύπο σάρωσης, όπως `-sU`. Οι θύρες του πίνακα είναι συνηθισμένες αντιστοιχίσεις, όχι απόδειξη για την υπηρεσία που λειτουργεί πραγματικά σε κάθε θύρα.

```bash
# Θύρες TCP
nmap -p T:80,443 192.168.1.1

# Θύρες UDP
nmap -p U:53,161 192.168.1.1

# Docker και Kubernetes
nmap -p T:80,443,U:53 192.168.1.1
```

### Συχνότερες θύρες
```bash
# Οι 100 συχνότερες θύρες, σύντομη σάρωση
nmap -F 192.168.1.1

# Οι 10 συχνότερες θύρες
nmap --top-ports 10 192.168.1.1

# Οι 1000 συχνότερες θύρες, προεπιλογή
nmap --top-ports 1000 192.168.1.1
```

## 🔬 Αναγνώριση υπηρεσιών και εκδόσεων

### Επιλογές αναγνώρισης εκδόσεων

| Επιλογή | Περιγραφή |
| -------- | ------------- |
| `-sV` | Αναγνώριση εκδόσεων |
| `--version-intensity <0-9>` | Ένταση δοκιμαστικών ελέγχων |
| `--version-light` | Ελαφρύς έλεγχος εκδόσεων (ένταση 2) |
| `--version-all` | Δοκιμή όλων των ελέγχων αναγνώρισης (ένταση 9) |
| `--version-trace` | Διαγνωστική έξοδος ελέγχου εκδόσεων |

### Βασική αναγνώριση εκδόσεων
```bash
# Αναγνώριση εκδόσεων υπηρεσιών
nmap -sV 192.168.1.1

# Παράδειγμα εξόδου:
# PORT    STATE SERVICE VERSION
# 22/tcp  open  ssh     OpenSSH 7.9
# 80/tcp  open  http    Apache httpd 2.4.38
```

### Ένταση αναγνώρισης εκδόσεων
```bash
# Ελαφρύς έλεγχος εκδόσεων, συνήθως ταχύτερος
nmap -sV --version-light 192.168.1.1

# Όλοι οι έλεγχοι αναγνώρισης εκδόσεων
nmap -sV --version-all 192.168.1.1

# Προσαρμοσμένη ένταση ελέγχου (0-9)
nmap -sV --version-intensity 5 192.168.1.1
```

## 💻 Αναγνώριση λειτουργικού συστήματος

### Επιλογές αναγνώρισης λειτουργικού συστήματος

| Επιλογή | Περιγραφή |
| -------- | ------------- |
| `-O` | Ενεργοποίηση αναγνώρισης λειτουργικού συστήματος |
| `--osscan-limit` | Έλεγχος μόνο συστημάτων με κατάλληλες συνθήκες αναγνώρισης |
| `--osscan-guess` | Πιο ελαστική εκτίμηση λειτουργικού συστήματος |
| `--max-os-tries` | Μέγιστος αριθμός προσπαθειών αναγνώρισης λειτουργικού συστήματος |

### Βασική αναγνώριση λειτουργικού συστήματος
```bash
# Αναγνώριση λειτουργικού συστήματος με δικαιώματα root
sudo nmap -O 192.168.1.1

# Παράδειγμα εξόδου:
# Running: Linux 3.X|4.X
# OS CPE: cpe:/o:linux:linux_kernel:3
# OS details: Linux 3.10 - 4.11
```

### Πιο ελαστική εκτίμηση λειτουργικού συστήματος
```bash
# Πιο ελαστική εκτίμηση λειτουργικού συστήματος
sudo nmap -O --osscan-guess 192.168.1.1
```

### Συνδυαστική σάρωση με -A

> **Τι σημαίνει το -A:** Ενεργοποιεί αναγνώριση λειτουργικού συστήματος, εκδόσεων, προεπιλεγμένα scripts και traceroute. Δεν ορίζει από μόνο του γρηγορότερο χρονισμό.

```bash
# Ενεργοποίηση αναγνώρισης λειτουργικού, εκδόσεων, scripts και traceroute
sudo nmap -A 192.168.1.1

# Ενεργοποιεί λειτουργίες αντίστοιχες με: -O -sV -sC --traceroute
```

## ⏱️ Χρονισμός και απόδοση

> **Ταχύτητα και ακρίβεια:** Υψηλές τιμές ρυθμού, λιγότερες επαναλήψεις και μικρά χρονικά όρια μπορεί να χάσουν αποκρίσεις ή να επιβαρύνουν το δίκτυο. Τα προφίλ είναι αφετηρίες ρύθμισης, όχι εγγυήσεις ταχύτητας ή αποφυγής εντοπισμού.


### Προφίλ χρονισμού

| Επιλογή | Όνομα | Περιγραφή |
| -------- | ------ | ------------- |
| `-T0` | Paranoid (εξαιρετικά αργό) | Πολύ αργός ρυθμός· δεν εξασφαλίζει αποφυγή IDS |
| `-T1` | Sneaky (πολύ αργό) | Αργός ρυθμός· δεν εξασφαλίζει αποφυγή IDS |
| `-T2` | Polite (περιορισμένος ρυθμός) | Μικρότερη χρήση εύρους ζώνης και πιο αργή σάρωση |
| `-T3` | Normal (κανονικό) | Προεπιλεγμένος χρονισμός |
| `-T4` | Aggressive (γρήγορο) | Γρήγορη σάρωση για αξιόπιστο δίκτυο |
| `-T5` | Insane (πολύ γρήγορο) | Πολύ γρήγορη σάρωση με πιθανότητα παράλειψης θυρών |

### Χρήση
```bash
# Αργός ρυθμός χωρίς εγγύηση αποφυγής εντοπισμού
nmap -T1 192.168.1.1

# Κανονικός χρονισμός, προεπιλογή
nmap -T3 192.168.1.1

# Γρήγορο
nmap -T4 192.168.1.1

# Πολύ γρήγορος ρυθμός για κατάλληλο τοπικό δίκτυο
nmap -T5 192.168.1.1
```

### Αναλυτικές ρυθμίσεις χρονισμού

| Επιλογή | Περιγραφή |
| -------- | ------------- |
| `--min-rate <n>` | Ελάχιστος αριθμός πακέτων ανά δευτερόλεπτο |
| `--max-rate <n>` | Μέγιστος αριθμός πακέτων ανά δευτερόλεπτο |
| `--min-parallelism <n>` | Ελάχιστος αριθμός παράλληλων δοκιμών |
| `--max-parallelism <n>` | Μέγιστος αριθμός παράλληλων δοκιμών |
| `--min-hostgroup <n>` | Ελάχιστος αριθμός συστημάτων ανά παράλληλη ομάδα |
| `--max-hostgroup <n>` | Μέγιστος αριθμός συστημάτων ανά παράλληλη ομάδα |
| `--host-timeout <time>` | Διακοπή ελέγχου ενός συστήματος μετά το χρονικό όριο |
| `--scan-delay <time>` | Καθυστέρηση μεταξύ δοκιμαστικών πακέτων |
| `--max-retries <n>` | Μέγιστος αριθμός επαναλήψεων δοκιμής |

```bash
# Αποστολή τουλάχιστον 1000 πακέτων ανά δευτερόλεπτο
nmap --min-rate 1000 192.168.1.0/24

# Μέχρι 100 πακέτα ανά δευτερόλεπτο
nmap --max-rate 100 192.168.1.1

# Διακοπή ελέγχου του συστήματος μετά από 30 λεπτά
nmap --host-timeout 30m 192.168.1.0/24

# Καθυστέρηση μεταξύ δοκιμαστικών πακέτων
nmap --scan-delay 1s 192.168.1.1
```

## 📜 Scripts του Nmap Scripting Engine (NSE)

> **Επιλογή scripts:** Η κατηγορία `auth` περιλαμβάνει ελέγχους ταυτοποίησης και πιθανής παράκαμψης, όχι μόνο παράκαμψη. Οι ετικέτες `safe` και `default` δεν αντικαθιστούν την ανάγνωση της περιγραφής κάθε script. Η έκφραση `not intrusive` δεν περιορίζει την επιλογή αποκλειστικά στην κατηγορία `safe`. Μοτίβα όπως `http-*` επιλέγουν πολλά scripts και η διαθεσιμότητα διαφέρει ανά έκδοση. Δείτε την [επίσημη τεκμηρίωση NSE](https://nmap.org/book/nse-usage.html).


### Κατηγορίες scripts

| Κατηγορία | Περιγραφή |
| ---------- | ------------- |
| `auth` | Έλεγχοι ταυτοποίησης και ενδεχόμενης παράκαμψής της |
| `broadcast` | Εντοπισμός συστημάτων με μηνύματα broadcast |
| `brute` | Δοκιμές πολλών πιθανών στοιχείων σύνδεσης (brute force) |
| `default` | Προεπιλεγμένα scripts (-sC) |
| `discovery` | Εντοπισμός υπηρεσιών |
| `dos` | Άρνηση υπηρεσίας (DoS) |
| `exploit` | Αξιοποίηση ευπαθειών |
| `external` | Ερωτήματα σε εξωτερικές υπηρεσίες |
| `fuzzer` | Δοκιμές με ποικίλες εισόδους (fuzzing) |
| `intrusive` | Ενδέχεται να προκαλέσουν διακοπή υπηρεσιών |
| `malware` | Εντοπισμός κακόβουλου λογισμικού |
| `safe` | Scripts κατηγορίας safe· απαιτείται έλεγχος της λειτουργίας τους |
| `version` | Αναγνώριση εκδόσεων |
| `vuln` | Αναζήτηση ενδείξεων ευπαθειών |

### Επιλογές scripts

| Επιλογή | Περιγραφή |
| -------- | ------------- |
| `-sC` | Προεπιλεγμένα scripts |
| `--script <scripts>` | Εκτέλεση συγκεκριμένων scripts |
| `--script-args <args>` | Παράμετροι scripts |
| `--script-updatedb` | Ενημέρωση ευρετηρίου scripts |
| `--script-help <script>` | Βοήθεια για συγκεκριμένο script |

### Προεπιλεγμένα scripts
```bash
# Εκτέλεση προεπιλεγμένων scripts
nmap -sC 192.168.1.1

# Με αναγνώριση εκδόσεων
nmap -sV -sC 192.168.1.1
```

### Εκτέλεση συγκεκριμένων scripts
```bash
# Ένα script
nmap --script http-title 192.168.1.1

# Πολλαπλά scripts
nmap --script http-title,http-headers 192.168.1.1

# Κατηγορία
nmap --script vuln 192.168.1.1

# Απαντήσεις wildcard σε πολλά διαφορετικά ονόματα
nmap --script "http-*" 192.168.1.1

# Συνδυασμός κατηγοριών
nmap --script "vuln and safe" 192.168.1.1

# Εξαίρεση scripts
nmap --script "not intrusive" 192.168.1.1
```

### Συνηθισμένα scripts

#### Έλεγχοι ενδείξεων ευπαθειών
```bash
# Scripts της κατηγορίας vuln
nmap --script vuln 192.168.1.1

# Έλεγχος συγκεκριμένου αναγνωριστικού ευπάθειας CVE
nmap --script smb-vuln-ms17-010 192.168.1.1

# Heartbleed
nmap --script ssl-heartbleed 192.168.1.1

# ShellShock
nmap --script http-shellshock 192.168.1.1
```

#### Scripts για HTTP
```bash
# Συλλογή πληροφοριών HTTP
nmap --script http-enum 192.168.1.1

# Κεφαλίδες HTTP
nmap --script http-headers 192.168.1.1

# Μέθοδοι HTTP
nmap --script http-methods 192.168.1.1

# Τίτλος σελίδας HTTP
nmap --script http-title 192.168.1.1

# Έλεγχος robots.txt
nmap --script http-robots.txt 192.168.1.1
```

#### Scripts για SMB
```bash
# Διερεύνηση SMB
nmap --script smb-enum-shares 192.168.1.1
nmap --script smb-enum-users 192.168.1.1
nmap --script smb-os-discovery 192.168.1.1

# Έλεγχοι ευπαθειών SMB
nmap --script smb-vuln* 192.168.1.1
```

#### Scripts για SSH
```bash
# Μέθοδοι ταυτοποίησης SSH
nmap --script ssh-auth-methods 192.168.1.1

# Κλειδί ταυτότητας διακομιστή SSH
nmap --script ssh-hostkey 192.168.1.1

# Δοκιμή στοιχείων σύνδεσης SSH από λίστα
nmap --script ssh-brute 192.168.1.1
```

#### Scripts για DNS
```bash
# Αναζήτηση ονομάτων DNS βάσει λίστας λέξεων
nmap --script dns-brute example.com

# Έλεγχος μεταφοράς ζώνης DNS
nmap --script dns-zone-transfer example.com
```

#### Scripts για MySQL και βάσεις δεδομένων
```bash
# Πληροφορίες MySQL
nmap --script mysql-info 192.168.1.1

# Συλλογή πληροφοριών MySQL
nmap --script mysql-enum 192.168.1.1

# Δοκιμές στοιχείων σύνδεσης MySQL
nmap --script mysql-brute 192.168.1.1
```

### Παράμετροι scripts
```bash
# Διαδοχικές δοκιμές βάσει λίστας λέξεων
nmap --script ssh-brute --script-args userdb=users.txt,passdb=passwords.txt 192.168.1.1

# Δοκιμές στοιχείων ταυτοποίησης HTTP βάσει λίστας
nmap --script http-brute --script-args http-brute.path=/admin 192.168.1.1
```

## 🛡️ Τεχνικές αποφυγής firewall και συστημάτων ανίχνευσης (IDS)

> **Όρια των τεχνικών:** Οι όροι «stealth» και «zombie» του πρωτοτύπου δεν σημαίνουν αόρατη σάρωση. SYN, κατακερματισμός, decoys ή παραποίηση διευθύνσεων δεν εξασφαλίζουν ανωνυμία ή παράκαμψη ελέγχων. Η παραποίηση IP μπορεί επίσης να εμποδίσει τη λήψη αποκρίσεων. Δείτε την [τεκμηρίωση firewall/IDS](https://nmap.org/book/man-bypass-firewalls-ids.html).


### Τεχνικές αποφυγής ανίχνευσης

| Επιλογή | Περιγραφή |
| -------- | ------------- |
| `-f` | Κατακερματισμός πακέτων |
| `--mtu <size>` | Προσαρμοσμένο μέγεθος MTU |
| `-D <decoys>` | Χρήση επιπλέον διευθύνσεων ως δολωμάτων (decoys) |
| `-S <IP>` | Παραποίηση IP προέλευσης |
| `--source-port <port>` | Ορισμός θύρας προέλευσης |
| `--data-length <n>` | Προσθήκη τυχαίων δεδομένων |
| `--randomize-hosts` | Τυχαία σειρά στόχων |
| `--spoof-mac <mac>` | Παραποίηση διεύθυνσης MAC |
| `--badsum` | Αποστολή πακέτων με λανθασμένο άθροισμα ελέγχου |

### Κατακερματισμός πακέτων
```bash
# Κατακερματισμός πακέτων
nmap -f 192.168.1.1

# Προσαρμοσμένο MTU
nmap --mtu 16 192.168.1.1
```

### Διευθύνσεις δολώματα (decoys)
```bash
# Χρήση επιπλέον διευθύνσεων ως δολωμάτων (decoys)
nmap -D decoy1,decoy2,ME 192.168.1.1

# Τυχαίες διευθύνσεις δολώματα
nmap -D RND:5 192.168.1.1
```

### Παραποίηση IP και ορισμός θύρας προέλευσης
```bash
# Παραποίηση IP προέλευσης
nmap -S 192.168.1.100 -e eth0 192.168.1.1

# Ορισμός θύρας προέλευσης που συχνά επιτρέπεται
nmap --source-port 53 192.168.1.1
nmap --source-port 80 192.168.1.1
```

### Παραποίηση διεύθυνσης MAC
```bash
# Τυχαία διεύθυνση MAC
nmap --spoof-mac 0 192.168.1.1

# Συγκεκριμένος κατασκευαστής MAC
nmap --spoof-mac Apple 192.168.1.1

# Συγκεκριμένη διεύθυνση MAC
nmap --spoof-mac 00:11:22:33:44:55 192.168.1.1
```

### Προσθήκη επιπλέον δεδομένων
```bash
# Προσθήκη τυχαίων δεδομένων στα πακέτα
nmap --data-length 25 192.168.1.1
```

## 💡 Συμβουλές και καλές πρακτικές

### Συμβουλές απόδοσης

1. **Χρήση σάρωσης SYN με τα κατάλληλα δικαιώματα**
   ```bash
   # Απαιτεί δικαιώματα root και συνήθως έχει μικρότερο κόστος σύνδεσης
   sudo nmap -sS 192.168.1.1
   ```

2. **Αρχικός περιορισμός του εύρους θυρών**
   ```bash
   # Ξεκινήστε από τις συχνότερες θύρες
   nmap --top-ports 100 192.168.1.1
   ```

3. **Προσαρμογή ταχύτητας σε τοπικά δίκτυα**
   ```bash
   nmap -T5 --min-rate 5000 192.168.1.0/24
   ```

### Συμβουλές ακρίβειας

1. **Συνδυασμός διαφορετικών τύπων σάρωσης**
   ```bash
   # TCP και UDP
   sudo nmap -sS -sU -sV 192.168.1.1
   ```

2. **Περισσότερες επαναλήψεις σε ασταθή δίκτυα**
   ```bash
   nmap --max-retries 3 192.168.1.1
   ```
