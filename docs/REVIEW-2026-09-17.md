## Recommended Review Order

1. High-use tooling: Burp Suite and Metasploit.
2. Fast-moving platforms: AWS, Azure/Entra, GCP, Kubernetes, and mobile testing.
3. Identity and lateral movement: Impacket, Rubeus, PowerView, Mimikatz, and Responder.
4. Payload libraries: SQLi, XSS, SSTI, deserialization, SSRF, and command injection.
5. Defensive content: incident response, logging, Sigma/YARA, SIEM, and hardening.
6. Remaining tools, CTF material, OSINT, and translations.

For each guide, remove incorrect or redundant examples, check every flag against
the current local help, add primary references, record a verification date, and
replace the review-pending label only after the complete document is reviewed.

## Known Limitation

External-link availability does not prove technical correctness. The repository
therefore treats link checking, source verification, and lab execution as three
separate evidence levels. Lab-tested claims should name the exact tool version,
operating system, and test environment.
