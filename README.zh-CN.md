先选择分类，再打开对应文档。请根据自己的实验环境调整示例：不同版本、前置条件和权限可能影响结果。工具名称、选项、路径及必要的技术术语保留原始形式。如需离线阅读，请下载或克隆仓库。

```bash
git clone https://github.com/Ilias1988/Hacking-Cheatsheets.git
cd Hacking-Cheatsheets
```
