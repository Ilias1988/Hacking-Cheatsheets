## Come usare le guide

Scegli una categoria e apri una guida. Gli esempi vanno adattati al tuo laboratorio: versioni, prerequisiti e permessi possono variare. I nomi degli strumenti, le opzioni, i percorsi e i termini tecnici necessari restano nella forma originale. Per consultare tutto offline, scarica il repository oppure clonalo.

```bash
git clone https://github.com/Ilias1988/Hacking-Cheatsheets.git
cd Hacking-Cheatsheets
```
