## 🎯 Что такое тестирование безопасности облачных сред?

Тестирование безопасности облачных сред включает поиск уязвимостей облачной инфраструктуры, в том числе:
- 🪣 **Хранилища** — ошибки настройки S3, Blob и GCS
- 🔑 **IAM** — ошибки управления идентификацией и доступом (Identity and Access Management)
- 🖥️ **Вычислительные ресурсы** — уязвимости EC2, виртуальных машин и бессерверных сервисов
- 🌐 **Сеть** — VPC, группы безопасности и межсетевые экраны
- 🔐 **Секреты** — раскрытые учётные данные и ключи

## 🛠️ Основные инструменты проверки безопасности облаков

| Инструмент | Назначение | Платформа |
|------|---------|----------|
| **ScoutSuite** | Аудит безопасности нескольких облачных платформ | Все |
| **Prowler** | Оценка безопасности AWS | AWS |
| **CloudSploit** | Сканер безопасности облаков | Все |
| **Pacu** | Фреймворк эксплуатации уязвимостей AWS | AWS |
| **CloudBrute** | Сбор сведений об облачных ресурсах | Все |
| **S3Scanner** | Поиск и перечисление бакетов S3 | AWS |
| **AzureHound** | Пути атак в Azure AD | Azure |
| **gcp_enum** | Сбор сведений о GCP | GCP |

### Быстрая установка инструментов
```bash
# ScoutSuite (несколько облачных платформ)
pip install scoutsuite
scout aws

# Prowler (AWS)
git clone https://github.com/prowler-cloud/prowler
cd prowler && ./prowler

# Pacu (эксплуатация уязвимостей AWS)
git clone https://github.com/RhinoSecurityLabs/pacu
cd pacu && python3 pacu.py

# CloudBrute (сбор сведений)
go install github.com/0xsha/CloudBrute@latest
```

## 📊 Распространённые уязвимости облачных сред

| Уязвимость | Описание | Последствия |
|---------------|-------------|--------|
| **Общедоступные S3/Blob** | Общедоступное хранилище | Утечка данных |
| **Избыточные права IAM** | Разрешения с шаблоном * | Полная компрометация учётной записи |
| **Доступные извне метаданные** | Доступ к 169.254.169.254 | Кража учётных данных |
| **Учётные данные в исходном коде** | Ключи в коде и конфигурациях | Захват учётной записи |
| **SSRF для доступа к метаданным** | Доступ к метаданным облака | Кража учётных данных |
| **Небезопасные функции** | Ошибки настройки Lambda/Functions | Выполнение кода |
