## Πριν ξεκινήσετε

Το **cloud**, ή **νέφος**, είναι υποδομή και υπηρεσίες που λειτουργούν σε περιβάλλον παρόχου, όπως AWS, Microsoft Azure ή Google Cloud. Ο έλεγχος ασφάλειας εξετάζει ποιος έχει πρόσβαση, σε ποιους πόρους και με ποιες δυνατότητες. Δεν περιορίζεται στην αναζήτηση τεχνικών ευπαθειών: συχνά το πρόβλημα είναι μια λανθασμένη άδεια ή η έκθεση στοιχείων σύνδεσης.

**Βασικό λεξιλόγιο:** **Πόρος (resource)** είναι μια υπηρεσία ή αντικείμενο, όπως δίσκος, βάση ή εικονική μηχανή. **IAM (Identity and Access Management)** είναι η διαχείριση ταυτοτήτων και πρόσβασης. Μια **πολιτική (policy)** περιγράφει άδειες και περιορισμούς, ενώ ένας **ρόλος (role)** συγκεντρώνει δυνατότητες που αποδίδονται σε ταυτότητες. Ένα **bucket** είναι χώρος αποθήκευσης αντικειμένων και ένα **secret** είναι ευαίσθητο στοιχείο, όπως κωδικός ή κλειδί API.

**Κοινές έννοιες στους τρεις παρόχους:** **VM/instance** σημαίνει εικονική μηχανή. **Serverless function** είναι κώδικας που εκτελείται σε διαχειριζόμενο περιβάλλον χωρίς ο χρήστης να διαχειρίζεται τον υποκείμενο διακομιστή. Το **metadata service / IMDS** παρέχει πληροφορίες σε μια εικονική μηχανή. Η πρόσβαση της ίδιας της μηχανής στα μεταδεδομένα είναι συνήθης λειτουργία, όχι από μόνη της ευπάθεια. **SSRF** είναι αδυναμία όπου μια εφαρμογή παρακινείται να στείλει αίτημα προς μη αναμενόμενο προορισμό.

**Ανάγνωση παραδειγμάτων:** Διατηρούνται οι εντολές και οι τιμές του αγγλικού πρωτοτύπου, με ελληνικά σχόλια και εξηγήσεις. IP, τομείς, ονόματα και τιμές όπως `BUCKET_NAME`, `PROJECT_ID`, `TENANT-ID`, `ARN` ή `xxxxxxxx` είναι ενδεικτικά. Τα παραδείγματα απαιτούν προσαρμογή και έλεγχο έκδοσης εργαλείων. Η μετάφραση δεν αποτελεί δοκιμή λειτουργίας. Οι εξωτερικοί οδηγοί εργαλείων παραπέμπουν προς το παρόν στις αγγλικές εκδόσεις τους.

Ο έλεγχος αφορά μόνο λογαριασμούς και πόρους για τους οποίους υπάρχει εξουσιοδότηση. Εντολές μεταφόρτωσης, αλλαγής κώδικα ή εκτέλεσης συνάρτησης αλλάζουν το περιβάλλον και μπορεί να επιφέρουν κόστος.

## 🎯 Τι είναι ο έλεγχος ασφάλειας στο νέφος;

Ο έλεγχος ασφάλειας νέφους εξετάζει αδυναμίες σε υποδομή και υπηρεσίες, όπως:
- 🪣 **Αποθήκευση (Storage):** λανθασμένες ρυθμίσεις S3, Blob και GCS
- 🔑 **Ταυτότητες και πρόσβαση (IAM):** αδυναμίες διαχείρισης ταυτοτήτων και δικαιωμάτων
- 🖥️ **Εκτέλεση υπολογιστικών εργασιών (Compute):** EC2, εικονικές μηχανές και διαχειριζόμενες συναρτήσεις
- 🌐 **Δίκτυο (Network):** εικονικά ιδιωτικά δίκτυα VPC, ομάδες κανόνων ασφαλείας και τείχη προστασίας
- 🔐 **Μυστικά στοιχεία (Secrets):** εκτεθειμένα στοιχεία σύνδεσης και κλειδιά

## 🛠️ Βασικά εργαλεία ελέγχου ασφάλειας νέφους

| Εργαλείο | Σκοπός | Πλατφόρμα |
| ------ | --------- | ---------- |
| **ScoutSuite** | Έλεγχος ασφάλειας σε περισσότερους παρόχους νέφους | Πολλές πλατφόρμες, όπου υποστηρίζονται |
| **Prowler** | Έλεγχοι ασφάλειας AWS στο παράδειγμα της πηγής | AWS |
| **CloudSploit** | Αυτοματοποιημένος έλεγχος ρυθμίσεων νέφους | Πολλές πλατφόρμες, όπου υποστηρίζονται |
| **Pacu** | Πλαίσιο ελέγχου τεχνικών εκμετάλλευσης AWS | AWS |
| **CloudBrute** | Εντοπισμός πόρων νέφους | Πολλές πλατφόρμες, όπου υποστηρίζονται |
| **S3Scanner** | Εντοπισμός χώρων αποθήκευσης S3 (Buckets) | AWS |
| **AzureHound** | Εντοπισμός διαδρομών πρόσβασης στο Microsoft Entra ID | Azure |
| **gcp_enum** | Συλλογή πληροφοριών Google Cloud | GCP |

### Παραδείγματα εγκατάστασης εργαλείων

Οι εντολές εγκατάστασης αποτελούν παραδείγματα της πηγής. Οι πλατφόρμες που υποστηρίζει ένα εργαλείο και η διαδικασία εγκατάστασής του μπορεί να έχουν αλλάξει· η ένδειξη «πολλές πλατφόρμες» δεν εγγυάται ίδια κάλυψη για όλους τους παρόχους.

```bash
# ScoutSuite — έλεγχος σε περισσότερους παρόχους
pip install scoutsuite
scout aws

# Prowler — παράδειγμα ελέγχου AWS
git clone https://github.com/prowler-cloud/prowler
cd prowler && ./prowler

# Pacu — σενάρια ελέγχου ασφάλειας AWS
git clone https://github.com/RhinoSecurityLabs/pacu
cd pacu && python3 pacu.py

# CloudBrute — εντοπισμός πόρων
go install github.com/0xsha/CloudBrute@latest
```

## 📊 Συνηθισμένες αδυναμίες υποδομών νέφους

| Αδυναμία | Περιγραφή | Επίπτωση |
| --------------- | ------------- | -------- |
| **Δημόσια αποθήκευση S3/Blob** | Χώρος αποθήκευσης προσβάσιμος ανώνυμα ή δημόσια | Διαρροή δεδομένων |
| **Υπερβολικά δικαιώματα IAM** | Πολιτικές με ευρείες άδειες ή χαρακτήρα μπαλαντέρ * | Πιθανή εκτεταμένη παραβίαση, ανάλογα με τα πραγματικά δικαιώματα |
| **Μη αναμενόμενη έκθεση μεταδεδομένων** | Πρόσβαση στο 169.254.169.254 από μη επιτρεπόμενο πλαίσιο | Πιθανή αποκάλυψη στοιχείων πρόσβασης |
| **Στοιχεία πρόσβασης ενσωματωμένα στον κώδικα** | Κλειδιά μέσα σε κώδικα ή αρχεία ρυθμίσεων | Κατάληψη λογαριασμού |
| **Πρόσβαση σε μεταδεδομένα μέσω SSRF** | Μη αναμενόμενη πρόσβαση σε μεταδεδομένα του νέφους | Πιθανή αποκάλυψη στοιχείων πρόσβασης |
| **Μη ασφαλείς ρυθμίσεις συναρτήσεων** | Λανθασμένες ρυθμίσεις Lambda ή Functions | Πιθανή εκτέλεση κώδικα |
