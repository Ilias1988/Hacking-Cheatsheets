## Πριν ξεκινήσετε

Το **Ghidra** βοηθά να κατανοήσετε ένα μεταγλωττισμένο πρόγραμμα χωρίς να έχετε τον αρχικό πηγαίο κώδικα. Το **disassembly** ερμηνεύει bytes ως εντολές επεξεργαστή, ενώ το **decompilation** παράγει μια πιθανή αναπαράσταση υψηλότερου επιπέδου. Ο ψευδοκώδικας δεν είναι ανακτήσιμο ακριβές αντίγραφο του αρχικού προγράμματος.

**Βασικοί όροι:** address = διεύθυνση, instruction = εντολή, function = συνάρτηση, symbol = όνομα ή ετικέτα, XREF = αναφορά από ή προς άλλη θέση, data type = τύπος δεδομένων, calling convention = κανόνες μεταφοράς ορισμάτων και αποτελέσματος. Τα αγγλικά ονόματα μενού διατηρούνται για να τα αναγνωρίζετε στην εφαρμογή.

Ξεκινήστε με ένα μικρό δικό σας εκτελέσιμο: εισαγωγή, ανάλυση, εύρεση συναρτήσεων και τεκμηρίωση. Η σωστή αρχιτεκτονική και οι τύποι δεδομένων επηρεάζουν άμεσα το αποτέλεσμα. Οι εντολές και τα δεδομένα του πρωτοτύπου διατηρούνται, με σημειώσεις για εκδόσεις και περιορισμούς.

## 🎯 Τι είναι το Ghidra

Το **Ghidra** είναι ελεύθερο εργαλείο ανοιχτού κώδικα για αντίστροφη μηχανική λογισμικού (SRE), που αναπτύχθηκε από την NSA. Παρέχει:

- 🔍 **Disassembler** — ερμηνεία δυαδικού κώδικα ως εντολές assembly.
- 🔄 **Decompiler** — παραγωγή ψευδοκώδικα που μοιάζει με C.
- 📊 **Ανάλυση** — αυτοματοποιημένη ανάλυση κώδικα.
- 🔧 **Patching** — τροποποίηση bytes και εντολών.
- 🐍 **Scripts** — αυτοματοποίηση με Python ή Java.
- 👥 **Συνεργασία** — υποστήριξη περισσότερων χρηστών.

### Υποστηριζόμενες αρχιτεκτονικές

| Αρχιτεκτονική | Παραλλαγές |
| -------------- | ---------- |
| **x86** | 16/32/64-bit |
| **ARM** | ARM32, ARM64, Thumb |
| **MIPS** | 32/64-bit |
| **PowerPC** | 32/64-bit |
| **SPARC** | 32/64-bit |
| **RISC-V** | 32/64-bit |
| **AVR** | 8-bit |
| **6502** | 8-bit |

### Υποστηριζόμενες μορφές

| Μορφή | Περιγραφή |
| -------- | ------------- |
| ELF | Εκτελέσιμα Linux |
| PE/COFF | Εκτελέσιμα Windows |
| Mach-O | Εκτελέσιμα macOS |
| Raw Binary | Firmware και εικόνες ROM |
| APK/DEX | Εφαρμογές Android |
| και πολλές ακόμη μορφές... |

```bash

## 🔧 Επεμβάσεις και τροποποιήσεις

> **Βάση ανάλυσης και αρχείο διαφέρουν:** Μια αλλαγή στο project δεν σημαίνει αυτόματα σωστό νέο εκτελέσιμο PE/ELF. Η εξαγωγή Binary δεν εγγυάται διατήρηση της αρχικής μορφής, headers και relocations. Η αντικατάσταση CALL με πέντε NOP προϋποθέτει συγκεκριμένο μήκος εντολής· δεν εφαρμόζεται σε κάθε κλήση.


### Τροποποίηση εντολής

```
# Μέθοδος 1: πληκτρολόγιο
Επιλογή εντολής → Ctrl+Shift+G, κατά το πρωτότυπο
Εισαγάγετε νέα εντολή και πατήστε Enter

# Μέθοδος 2: μενού
Δεξί κλικ → Patch Instruction — τροποποίηση εντολής
```

### Τροποποίηση δεδομένων

```
# Αλλαγή bytes
Δεξί κλικ → Patch Data — τροποποίηση δεδομένων
Εισαγάγετε bytes σε δεκαεξαδική μορφή

# Ή
Επιλογή bytes → Ctrl+Shift+G, κατά το πρωτότυπο
```

### Συνήθη παραδείγματα τροποποίησης

| Αρχικό | Τροποποιημένο | Σκοπός |
| ---------- | --------- | --------- |
| `JE` | `JMP` | Πάντα μετάβαση |
| `JNE` | `JMP` | Πάντα μετάβαση |
| `JE` | `NOP` | Χωρίς την αρχική μετάβαση |
| `CALL` | `NOP NOP NOP NOP NOP` | Παράλειψη κλήσης |
| `74` | `75` | JE → JNE |
| `75` | `74` | JNE → JE |
| `74` | `EB` | JE → JMP, σύντομο σχετικό άλμα |

### Εξαγωγή τροποποιημένου δυαδικού αρχείου

```
File → Export Program — εξαγωγή προγράμματος
Format: Binary — επιλογή μορφής δυαδικής εξαγωγής
Επιλέξτε προορισμό
```

### Ακολουθία εντολών NOP

```
# Συμπλήρωση με NOP

### Scripts Python στο Ghidra

> **Jython και Python 3 διαφέρουν:** Το κλασικό περιβάλλον scripts Jython βασίζεται σε Python 2.7 και δεν δέχεται f-strings όπως το πρώτο δείγμα. Το PyGhidra προσφέρει διαφορετική ενσωμάτωση Python 3. Επιλέξτε κατάλληλο περιβάλλον και API για την εγκατάστασή σας. Βλ. [PyGhidra](https://github.com/NationalSecurityAgency/ghidra/blob/master/Ghidra/Features/PyGhidra/README.md).


```python
# Παράδειγμα: καταγραφή όλων των συναρτήσεων
from ghidra.program.model.listing import Function

fm = currentProgram.getFunctionManager()
funcs = fm.getFunctions(True)  # True = αύξουσα σειρά διευθύνσεων

for func in funcs:
    print(f"Function: {func.getName()} at {func.getEntryPoint()}")
```

### Συνήθεις λειτουργίες scripts

```python
# Λήψη τρέχουσας διεύθυνσης
currentAddress

# Λήψη τρέχοντος προγράμματος
currentProgram

# Λήψη διαχειριστή συναρτήσεων
fm = currentProgram.getFunctionManager()

# Λήψη προβολής εντολών
listing = currentProgram.getListing()

# Λήψη εντολής στη διεύθυνση
instr = listing.getInstructionAt(addr)

# Λήψη bytes στη διεύθυνση
memory = currentProgram.getMemory()
bytes = getBytes(addr, length)

# Δημιουργία ετικέτας
createLabel(addr, "my_label", True)

# Προσθήκη σχολίου
setEOLComment(addr, "My comment")

# Λήψη αναφορών
refMgr = currentProgram.getReferenceManager()
refs = refMgr.getReferencesTo(addr)
```

### Ενσωματωμένα scripts του πρωτοτύπου

> **Διαθεσιμότητα scripts:** Η λίστα είναι ενδεικτική. Ονόματα, λειτουργίες και προέλευση μπορεί να διαφέρουν και ορισμένα scripts να χρειάζονται πρόσθετη εγκατάσταση. Εξετάστε τον κώδικα κάθε script πριν το εκτελέσετε.


| Script — πρόγραμμα εντολών | Σκοπός |
| -------- | --------- |
| FindCrypt | Αναζήτηση σταθερών κρυπτογραφίας |
| FunctionID | Αντιστοίχιση συναρτήσεων βιβλιοθηκών |
| ExportFunctionInfoScript | Εξαγωγή λίστας συναρτήσεων |
| FindStrings | Αναζήτηση αναφορών σε συμβολοσειρές |
| SearchMemory | Αναζήτηση μοτίβων |

## 📊 Γρήγορη αναφορά

### Ροή ανάλυσης

```
1. Εισαγωγή δυαδικού αρχείου → File → Import
2. Αυτόματη ανάλυση → Analysis → Auto Analyze, με έλεγχο των επιλογών
3. Αναζήτηση σημείου εισόδου → G → main ή entry
4. Εξέταση συναρτήσεων → Symbol Tree → Functions
5. Εξέταση συμβολοσειρών → Search → For Strings
6. Ακολουθήστε τις κλήσεις και τα άλματα για κατανόηση ροής
7. Μετονομάστε σύμβολα με L σε συναρτήσεις και μεταβλητές
8. Τεκμηριώστε την ανάλυση με σχόλια (;)
```

### Συνήθεις εργασίες

| Εργασία | Τρόπος |
| ------ | ----- |
| Αναζήτηση main() | `G` → `main` ή αναζήτηση στο Symbol Tree |
| Προβολή συμβολοσειρών | Search → For Strings — αναζήτηση συμβολοσειρών |
| Αναζήτηση ενδείξεων κρυπτογραφίας | Εκτέλεση του script FindCrypt εφόσον είναι διαθέσιμο |
| Έλεγχος εισαγόμενων συναρτήσεων | Symbol Tree → Imports — εισαγόμενες συναρτήσεις |
| Αναζήτηση XREFs | Επιλογή → Ctrl+Shift+F, κατά το πρωτότυπο |
| Δημιουργία συνάρτησης | Επιλογή διεύθυνσης → `F` |
| Παραγωγή ψευδοκώδικα | Window → Decompiler — ψευδοκώδικας |

### Λίστα ελέγχου αντίστροφης μηχανικής

```
☐ Αναγνωρίστε τον τύπο αρχείου, π.χ. PE ή ELF
☐ Εκτελέστε αυτόματη ανάλυση
☐ Εντοπίστε το σημείο εισόδου ή τη main
☐ Εξετάστε συμβολοσειρές για ενδείξεις
☐ Εντοπίστε συναρτήσεις που χρειάζονται διερεύνηση
☐ Χαρτογραφήστε τη ροή του προγράμματος
☐ Αναλύστε ύποπτες συναρτήσεις
☐ Τεκμηριώστε τα ευρήματα με σχόλια
☐ Μετονομάστε συναρτήσεις και μεταβλητές
☐ Δημιουργήστε δομές όπου χρειάζεται
```

### Συμβάσεις κλήσης συναρτήσεων

> **Συνοπτικός πίνακας:** Οι τιμές αφορούν συνήθεις περιπτώσεις ακέραιων ορισμάτων/αποτελεσμάτων. Κινητή υποδιαστολή, δομές, varargs και ειδικοί κανόνες ABI μπορεί να χρησιμοποιούν άλλους καταχωρητές ή στοίβα. Το x64 Linux του πίνακα υπονοεί τη συνήθη σύμβαση System V AMD64.


| Σύμβαση | Επιστροφή | Ορίσματα | Ποιος αποδεσμεύει τα ορίσματα της στοίβας |
| ------------ | -------- | ------ | ---------------- |
| **cdecl** | EAX | Στοίβα, από δεξιά προς τα αριστερά | Καλούσα συνάρτηση |
| **stdcall** | EAX | Στοίβα, από δεξιά προς τα αριστερά | Καλούμενη συνάρτηση |
| **fastcall** | EAX | ECX, EDX, Stack | Καλούμενη συνάρτηση |
| **x64 Win** | RAX | RCX, RDX, R8, R9 | Καλούσα συνάρτηση |
| **x64 Linux** | RAX | RDI, RSI, RDX, RCX, R8, R9 | Καλούσα συνάρτηση |
