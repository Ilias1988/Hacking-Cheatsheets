## Cómo utilizar las guías

Elige una categoría y abre una guía. Adapta los ejemplos a tu laboratorio: las versiones, los requisitos y los permisos pueden variar. Los nombres de herramientas, las opciones, las rutas y los términos técnicos necesarios conservan su forma original. Para consultar el contenido sin conexión, descarga o clona el repositorio.

```bash
git clone https://github.com/Ilias1988/Hacking-Cheatsheets.git
cd Hacking-Cheatsheets
```
