## 💡 面向管理层的写作建议

### 建议做法 ✅
```
✓ 优先说明业务影响，而非技术细节
✓ 使用通俗语言，避免术语
✓ 提供清晰的成本收益分析
✓ 提供可执行的建议
✓ 最多控制在 2-3 页
✓ 使用可视化元素（图表、示意图、表格）
✓ 突出安全投入的投资回报率（ROI）
✓ 与行业基准比较
```

### 应避免的做法 ❌
```
✗ 不要使用 CVE、CVSS 等技术术语
✗ 不要罗列所有发现，重点说明严重问题
✗ 不要提供过多技术细节
✗ 不要遗漏成本与时间安排
✗ 不要写得过于冗长
✗ 不要只渲染恐惧而不给出解决方案
```
