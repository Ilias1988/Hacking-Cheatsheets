# 📝 Πρότυπα αναφορών ασφάλειας — Reporting Templates

[🇬🇧 Κεντρικό README (English)](../../README.md)

Τα πρότυπα αυτά βοηθούν να μετατρέψετε έναν τεχνικό έλεγχο σε σαφή, τεκμηριωμένη αναφορά. Τα **ευρήματα (findings)** περιγράφουν επιβεβαιωμένες αδυναμίες, τα **αποδεικτικά στοιχεία (evidence)** στηρίζουν τους ισχυρισμούς και οι **διορθωτικές ενέργειες (remediation)** εξηγούν πώς αντιμετωπίζονται.

## Επιλέξτε πρότυπο

| Πρότυπο | Πότε χρησιμοποιείται | Οδηγός |
| --- | --- | --- |
| **Αναφορά ελέγχου διείσδυσης (Pentest Report)** | Πλήρης παράδοση ενός ελέγχου: πεδίο, μεθοδολογία, ευρήματα, αποδεικτικά στοιχεία και διορθώσεις | [📄 Προβολή](Pentest-Report-Template.el.md) |
| **Αναφορά ευπάθειας για Bug Bounty** | Αναπαραγωγή και τεκμηρίωση μιας ευπάθειας για αξιολόγηση από την ομάδα ασφάλειας | [📄 Προβολή](Bug-Bounty-Report-Template.el.md) |
| **Σύνοψη για τη διοίκηση (Executive Summary)** | Σύντομη παρουσίαση κινδύνων και αποφάσεων με επιχειρησιακούς όρους | [📄 Προβολή](Executive-Summary-Template.el.md) |

## Πώς να τα χρησιμοποιήσετε

1. Επιλέξτε το κατάλληλο πρότυπο και αντιγράψτε το σε ξεχωριστό έγγραφο εργασίας.
2. Συμπληρώστε τα πεδία σε αγκύλες με πραγματικά στοιχεία του έργου.
3. Αντικαταστήστε ενδεικτικά ευρήματα, αριθμούς, βαθμολογίες, κόστη και ημερομηνίες. Αφαιρέστε ενότητες που δεν εφαρμόζονται.
4. Διαχωρίστε όσα παρατηρήσατε από όσα αποτελούν πιθανές επιπτώσεις ή υποθέσεις.
5. Ελέγξτε αναπαραγωγή, πηγές, συνδέσμους, απόκρυψη ευαίσθητων δεδομένων και ονόματα συνημμένων πριν από την παράδοση.

Οι αγγλικοί τεχνικοί όροι διατηρούνται όπου χρειάζονται για αντιστοίχιση με εργαλεία και πλατφόρμες. Κάθε ελληνικός οδηγός περιέχει σύνδεσμο στο αγγλικό πρωτότυπο. Οι ελληνικές εκδόσεις είναι βοηθήματα μάθησης και σύνταξης· η γλώσσα πραγματικής παράδοσης ή υποβολής καθορίζεται από τον πελάτη ή το πρόγραμμα.
