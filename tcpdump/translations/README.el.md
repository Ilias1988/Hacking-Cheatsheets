## Πριν ξεκινήσετε

Το **tcpdump** καταγράφει και εμφανίζει πακέτα από τη γραμμή εντολών. Είναι χρήσιμο σε Linux/Unix, σε απομακρυσμένα συστήματα μέσω SSH και για αποθήκευση αρχείων που θα εξετάσετε αργότερα στο Wireshark. Τα παραδείγματα εντολών του οδηγού προϋποθέτουν κατάλληλο Unix shell και τα αναγκαία δικαιώματα καταγραφής.

**Βασικοί όροι:** *interface* = διεπαφή δικτύου, π.χ. eth0, *BPF filter* = έκφραση επιλογής πακέτων, *pcap* = μορφή αρχείου καταγραφής, *snaplen* = μέγιστος αριθμός bytes που κρατούνται από κάθε πακέτο, *rotation* = εναλλαγή αρχείων, *ring buffer* = κυκλική επαναχρησιμοποίηση περιορισμένου αριθμού αρχείων. Μια IP ή θύρα μπορεί να αφορά προέλευση ή προορισμό, ανάλογα με το φίλτρο.

Πρώτα επιλέξτε διεπαφή και φίλτρο, μετά διάρκεια ή αριθμό πακέτων και τέλος τρόπο εμφάνισης ή αποθήκευσης. Οι IP, οι διεπαφές και τα αρχεία είναι ενδεικτικά. Οι εντολές διατηρούνται από το αγγλικό πρωτότυπο, με σημειώσεις για περιορισμούς και λανθασμένες περιγραφές.

## 🎯 Εισαγωγή

**Το tcpdump** είναι εργαλείο ανάλυσης πακέτων στη γραμμή εντολών, διαθέσιμο σε πολλά λειτουργικά συστήματα τύπου Unix. Χρησιμοποιεί τη βιβλιοθήκη libpcap και τη σύνταξη φίλτρων BPF (Berkeley Packet Filter).

### Βασικά χαρακτηριστικά

| Χαρακτηριστικό | Περιγραφή |
| --------- | ------------- |
| **Μικρές απαιτήσεις πόρων** | Χωρίς γραφικό περιβάλλον, με μικρές απαιτήσεις πόρων |
| **Φίλτρα BPF** | Επιλογή πακέτων με εκφράσεις φίλτρων |
| **Συμβατότητα με pcap** | Ανάγνωση και εγγραφή αρχείων pcap |
| **Χρήση σε scripts** | Κατάλληλο για αυτοματοποίηση |
| **Ευρεία διαθεσιμότητα** | Διαθέσιμο σε πολλά συστήματα τύπου Unix |

### Σύγκριση tcpdump και Wireshark

> **Ενδεικτική σύγκριση:** Το Wireshark διαθέτει και το tshark για scripts και απομακρυσμένη ανάλυση. Η χρήση tcpdump μέσω SSH δεν αποκλείει ανάλυση του ίδιου αρχείου στο Wireshark. Οι χαρακτηρισμοί του πίνακα δεν είναι μετρήσεις απόδοσης.


| Χαρακτηριστικό | tcpdump | Wireshark |
| --------- | --------- | ----------- |
| **Περιβάλλον χρήσης** | CLI | GUI |
| **Απαιτήσεις πόρων** | Μικρές | Μεγαλύτερες |
| **Απομακρυσμένη χρήση** | Εύκολη χρήση μέσω SSH | Χρειάζεται κατάλληλη ρύθμιση |
| **Εκτέλεση σεναρίων** | Απλή κατά το πρωτότυπο | Πιο σύνθετη κατά το πρωτότυπο |
| **Ανάλυση** | Βασική κατά το πρωτότυπο | Εκτενέστερη κατά το πρωτότυπο |

## ⌨️ Βασική σύνταξη

### Γενική σύνταξη
```bash
tcpdump [options] [filter expression]
```

### Βασικές εντολές
```bash
# Καταγραφή στην προεπιλεγμένη διεπαφή δικτύου
sudo tcpdump

# Καταγραφή σε συγκεκριμένη διεπαφή δικτύου
sudo tcpdump -i eth0

# Καταγραφή μέχρι συγκεκριμένο αριθμό πακέτων
sudo tcpdump -c 100

# Καταγραφή με αναλυτική έξοδο
sudo tcpdump -v
sudo tcpdump -vv
sudo tcpdump -vvv
```

## ⚙️ Συνηθισμένες επιλογές

### Επιλογές εμφάνισης

| Επιλογή | Περιγραφή |
| -------- | ------------- |
| `-i` | Διεπαφή δικτύου για την καταγραφή |
| `-c` | Αριθμός πακέτων πριν από τη διακοπή |
| `-n` | Χωρίς μετατροπή διευθύνσεων σε ονόματα συστημάτων |
| `-nn` | Χωρίς μετατροπή διευθύνσεων και θυρών σε ονόματα |
| `-v` | Αναλυτική έξοδος |
| `-vv` | Ακόμη πιο αναλυτική έξοδος |
| `-vvv` | Πολύ αναλυτική έξοδος |
| `-q` | Περιορισμένη έξοδος |
| `-t` | Χωρίς εμφάνιση χρονικής σήμανσης |
| `-tt` | Εμφάνιση χρονικής σήμανσης Unix |
| `-ttt` | Εμφάνιση διαφοράς χρόνου μεταξύ διαδοχικών πακέτων |
| `-tttt` | Εμφάνιση ημερομηνίας και ώρας |

### Επιλογές καταγραφής

| Επιλογή | Περιγραφή |
| -------- | ------------- |
| `-w` | Εγγραφή σε αρχείο pcap |
| `-r` | Ανάγνωση από αρχείο pcap |
| `-s` | Μέγιστο μήκος δεδομένων ανά καταγεγραμμένο πακέτο, σε bytes |
| `-s0` | Χρήση προεπιλεγμένου μέγιστου μήκους καταγραφής |
| `-D` | Προβολή διαθέσιμων διεπαφών δικτύου |

### Επιλογές αποτελεσμάτων

| Επιλογή | Περιγραφή |
| -------- | ------------- |
| `-A` | Εμφάνιση δεδομένων ως ASCII |
| `-X` | Εμφάνιση δεκαεξαδικών δεδομένων και ASCII |
| `-XX` | Εμφάνιση δεκαεξαδικών δεδομένων και ASCII μαζί με την κεφαλίδα επιπέδου ζεύξης |
| `-e` | Εμφάνιση κεφαλίδας επιπέδου ζεύξης |
| `-l` | Έξοδος με προσωρινή αποθήκευση ανά γραμμή |

### Συνήθεις συνδυασμοί επιλογών
```bash
# Χωρίς επίλυση ονομάτων, με αναλυτική έξοδο και μεγάλο μήκος καταγραφής
sudo tcpdump -nnvvs0 -i eth0

# Αποθήκευση σε αρχείο
sudo tcpdump -i eth0 -w capture.pcap

# Ανάγνωση από αρχείο
tcpdump -r capture.pcap

# Έξοδος ASCII
sudo tcpdump -A -i eth0

# Δεκαεξαδικά δεδομένα και ASCII
sudo tcpdump -X -i eth0
```

## 🎣 Φίλτρα BPF

> **Φίλτρο και shell:** Σε σύνθετες εκφράσεις χρειάζονται κατάλληλα εισαγωγικά ώστε παρενθέσεις και λογικοί τελεστές να περάσουν ως ένα φίλτρο, αντί να ερμηνευθούν από το shell. Τα φίλτρα tcpdump δεν είναι display filters του Wireshark. Δείτε τη [σύνταξη pcap-filter](https://www.tcpdump.org/manpages/pcap-filter.7.html).


### Φίλτρα συστημάτων

```bash
# Κίνηση προς ή από συγκεκριμένο σύστημα
tcpdump host 192.168.1.1

# Μόνο σύστημα προέλευσης
tcpdump src host 192.168.1.1

# Μόνο σύστημα προορισμού
tcpdump dst host 192.168.1.1

# Πολλαπλά συστήματα
tcpdump host 192.168.1.1 or host 192.168.1.2

# Εξαίρεση συστήματος
tcpdump not host 192.168.1.1

# Δίκτυο ή υποδίκτυο
tcpdump net 192.168.1.0/24
tcpdump src net 10.0.0.0/8
```

### Φίλτρα θυρών

```bash
# Συγκεκριμένη θύρα
tcpdump port 80
tcpdump port 443

# Θύρα προέλευσης
tcpdump src port 443

# Θύρα προορισμού
tcpdump dst port 22

# Εύρος θυρών
tcpdump portrange 1-1024

# Πολλαπλές θύρες
tcpdump port 80 or port 443
tcpdump port 80 or port 443 or port 8080
```

### Φίλτρα πρωτοκόλλων

```bash
# Επιλογή πρωτοκόλλου
tcpdump tcp
tcpdump udp
tcpdump icmp
tcpdump arp

# Πρωτόκολλο και θύρα
tcpdump tcp port 80
tcpdump udp port 53
```

### Λογικοί τελεστές

| Τελεστής | Εναλλακτική αναζήτηση | Περιγραφή |
| ---------- | ------------- | ------------- |
| `and` | `&&` | Λογικό ΚΑΙ |
| `or` | `\|\|` | Λογικό Ή |
| `not` | `!` | Λογική άρνηση (ΟΧΙ) |
| `()` |  | Ομαδοποίηση |

### Συνδυασμένα φίλτρα

```bash
# Σύστημα ΚΑΙ θύρα
tcpdump host 192.168.1.1 and port 80

# Σύστημα ΚΑΙ πρωτόκολλο
tcpdump host 192.168.1.1 and tcp

# Σύνθετο φίλτρο
tcpdump 'host 192.168.1.1 and (port 80 or port 443)'

# Εξαίρεση συγκεκριμένης κίνησης
tcpdump not port 22 and not port 53

# Κίνηση μεταξύ δύο συστημάτων
tcpdump host 192.168.1.1 and host 192.168.1.2
```

## 📡 Φίλτρα πρωτοκόλλων

### Σημαίες TCP

```bash
# Πακέτα με ενεργή σημαία SYN
tcpdump 'tcp[tcpflags] & tcp-syn != 0'
tcpdump 'tcp[13] & 2 != 0'

# Πακέτα με ενεργές σημαίες SYN και ACK
tcpdump 'tcp[tcpflags] & (tcp-syn|tcp-ack) == (tcp-syn|tcp-ack)'

# Πακέτα με ενεργή σημαία FIN
tcpdump 'tcp[tcpflags] & tcp-fin != 0'

# Πακέτα με ενεργή σημαία RST
tcpdump 'tcp[tcpflags] & tcp-rst != 0'

# Πακέτα με ενεργή σημαία PSH
tcpdump 'tcp[tcpflags] & tcp-push != 0'

# Μόνο η σημαία ACK
tcpdump 'tcp[tcpflags] == tcp-ack'
```

### Πίνακας σημαιών TCP

| Σημαία | Δεκαεξαδική αναπαράσταση (Hex) | Δεκαδική τιμή | tcpdump |
| ------ | ----- | ----- | --------- |
| FIN | 0x01 | 1 | tcp-fin |
| SYN | 0x02 | 2 | tcp-syn |
| RST | 0x04 | 4 | tcp-rst |
| PSH | 0x08 | 8 | tcp-push |
| ACK | 0x10 | 16 | tcp-ack |
| URG | 0x20 | 32 | tcp-urg |

### Κίνηση HTTP

> **Περιορισμός των παραδειγμάτων:** Το πρώτο φίλτρο εντοπίζει δεδομένα TCP στη θύρα 80, όχι αποκλειστικά αιτήματα HTTP. Οι έλεγχοι συγκεκριμένων bytes βασίζονται σε θέσεις μέσα σε μεμονωμένα πακέτα και δεν αντικαθιστούν ανασύνθεση ροής. Οι εκφράσεις με ip[] αφορούν IPv4. Η κρυπτογράφηση HTTPS δεν αφαιρείται με ASCII έξοδο.


```bash
# Πακέτα TCP στη θύρα 80 με δεδομένα· όχι μόνο αιτήματα HTTP
tcpdump -A 'tcp port 80 and (((ip[2:2] - ((ip[0]&0xf)<<2)) - ((tcp[12]&0xf0)>>2)) != 0)'

# Αιτήματα GET
tcpdump -A 'tcp port 80 and tcp[((tcp[12:1] & 0xf0) >> 2):4] = 0x47455420'

# Αιτήματα POST
tcpdump -A 'tcp port 80 and tcp[((tcp[12:1] & 0xf0) >> 2):4] = 0x504f5354'

# Απλή καταγραφή TCP στη θύρα 80
tcpdump -A -s0 'tcp port 80'
```

### Κίνηση DNS

> **Θύρες και κατευθύνσεις:** Η θύρα 53 περιλαμβάνει παραδοσιακή κίνηση DNS, όχι κάθε κρυπτογραφημένη μεταφορά DNS. Το παράδειγμα «Capture DNS Queries» παρακάτω με σκέτο udp port 53 περιλαμβάνει και ερωτήματα και απαντήσεις.


```bash
# Κίνηση στη θύρα 53· δεν καλύπτει κάθε μορφή DNS
tcpdump port 53
tcpdump udp port 53

# Μόνο ερωτήματα DNS
tcpdump 'udp port 53 and udp[10] & 0x80 = 0'

# Μόνο απαντήσεις DNS
tcpdump 'udp port 53 and udp[10] & 0x80 = 0x80'
```

### Κίνηση ICMP

```bash
# Κίνηση ICMP για IPv4
tcpdump icmp

# Αίτημα ICMP echo, όπως στο ping
tcpdump 'icmp[icmptype] == icmp-echo'

# Απάντηση ICMP echo
tcpdump 'icmp[icmptype] == icmp-echoreply'

# Μήνυμα ICMP μη προσβάσιμου προορισμού
tcpdump 'icmp[icmptype] == icmp-unreach'
```

### Κίνηση ARP

```bash
# Όλη η κίνηση ARP
tcpdump arp

# Αιτήματα ARP
tcpdump 'arp[6:2] == 1'

# Απαντήσεις ARP
tcpdump 'arp[6:2] == 2'
```

## 💾 Επιλογές αποτελεσμάτων

### Εγγραφή σε αρχείο

> **Το tee δεν εμφανίζει τα πακέτα αυτού του παραδείγματος:** Με `-w capture.pcap`, τα δεδομένα γράφονται στο αρχείο και δεν διοχετεύονται ως αποκωδικοποιημένα πακέτα στην κανονική έξοδο. Το `| tee` επομένως δεν προσφέρει τον ταυτόχρονο τρόπο εμφάνισης που υπονοεί το πρωτότυπο. Η περιστροφή αρχείων μπορεί να επαναχρησιμοποιεί παλιά αρχεία. Δείτε το [εγχειρίδιο tcpdump](https://www.tcpdump.org/manpages/tcpdump.1.html).


```bash
# Εγγραφή σε αρχείο pcap
tcpdump -w capture.pcap

# Κυκλική αποθήκευση έως 100 αρχεία με όριο περίπου 1 εκατομμυρίου bytes ανά αρχείο
tcpdump -w capture.pcap -W 100 -C 1

# Εναλλαγή αρχείων με χρονική σήμανση στο όνομα
tcpdump -w capture_%Y%m%d_%H%M%S.pcap -G 3600

# Παράδειγμα του πρωτοτύπου· το -w με αρχείο δεν δίνει πακέτα στο tee
tcpdump -w capture.pcap | tee
```

### Ανάγνωση από αρχείο

> **Καταμέτρηση:** Το `wc -l` μετρά γραμμές κειμένου. Δεν αποτελεί γενικά ακριβή μέτρηση πακέτων αν αλλάξει η μορφή εξόδου ή εμφανιστούν δεδομένα σε πολλές γραμμές.


```bash
# Ανάγνωση αρχείου pcap
tcpdump -r capture.pcap

# Ανάγνωση με φίλτρα
tcpdump -r capture.pcap 'host 192.168.1.1'

# Πρόχειρη καταμέτρηση γραμμών εξόδου, όχι γενικά αξιόπιστη καταμέτρηση πακέτων
tcpdump -r capture.pcap | wc -l

# Ανάγνωση με αναλυτική έξοδο
tcpdump -nnvvXSs0 -r capture.pcap
```

### Μορφές εμφάνισης

```bash
# Περιεχόμενο σε ASCII
tcpdump -A -i eth0

# Δεκαεξαδικά δεδομένα και ASCII
tcpdump -X -i eth0

# Μόνο δεκαεξαδικά δεδομένα
tcpdump -x -i eth0

# Μαζί με την κεφαλίδα επιπέδου ζεύξης, π.χ. Ethernet
tcpdump -XX -i eth0

# Εμφάνιση απόλυτων αριθμών ακολουθίας TCP
tcpdump -S -i eth0
```

## 🎬 Παραδείγματα σεναρίων ελέγχου

### Παράδειγμα 1: Καταγραφή κίνησης σε θύρες web
```bash
sudo tcpdump -i eth0 -nnvvXSs0 'tcp port 80 or tcp port 443'
```

### Παράδειγμα 2: Καταγραφή κίνησης DNS
```bash
sudo tcpdump -i eth0 -nn 'udp port 53'
```

### Παράδειγμα 3: Καταγραφή κίνησης συγκεκριμένου συστήματος
```bash
sudo tcpdump -i eth0 -nn host 192.168.1.100
```

### Παράδειγμα 4: Αναζήτηση συνδέσεων SSH
```bash
sudo tcpdump -i eth0 'tcp port 22'
```

### Παράδειγμα 5: Καταγραφή ICMP (Ping)
```bash
sudo tcpdump -i eth0 icmp
```

### Παράδειγμα 6: Διερεύνηση πιθανής σάρωσης θυρών με SYN
```bash
sudo tcpdump -i eth0 'tcp[tcpflags] == tcp-syn'
```

### Παράδειγμα 7: Παράδειγμα εισερχόμενης κίνησης του πρωτοτύπου

> **Μη έγκυρη αντικατάσταση εντολής:** Τα μονά εισαγωγικά του παραδείγματος περνούν το `$(hostname -I | cut -d" " -f1)` ως κυριολεκτικό κείμενο στο φίλτρο· το shell δεν το εκτελεί εκεί. Η γραμμή χρειάζεται διόρθωση και επιλογή της κατάλληλης διεύθυνσης διεπαφής πριν από χρήση.

```bash
sudo tcpdump -i eth0 'dst host $(hostname -I | cut -d" " -f1)'
```

### Παράδειγμα 8: Παρακολούθηση συγκεκριμένης επικοινωνίας
```bash
sudo tcpdump -i eth0 'host 192.168.1.1 and host 192.168.1.2'
```

### Παράδειγμα 9: Καταγραφή στοιχείων σύνδεσης FTP
```bash
sudo tcpdump -A -i eth0 'tcp port 21'
```

### Παράδειγμα 10: Αποθήκευση για ανάλυση στο Wireshark
```bash
sudo tcpdump -i eth0 -s0 -w capture.pcap
# Στη συνέχεια ανοίξτε το capture.pcap στο Wireshark
```

### Παράδειγμα 11: Απομακρυσμένη καταγραφή μέσω SSH

> **Προϋποθέσεις απομακρυσμένης καταγραφής:** Η διεπαφή πρέπει να υπάρχει στο απομακρυσμένο σύστημα και η εντολή πρέπει να έχει δικαιώματα χωρίς διαδραστική είσοδο που παρεμβάλλεται στη ροή καταγραφής. Κρατήστε διαγνωστικά μηνύματα χωριστά από τα δυαδικά δεδομένα του capture.

```bash
ssh user@remote 'sudo tcpdump -w - -i eth0' | wireshark -k -i -
```

### Παράδειγμα 12: Καταγραφή με εξαίρεση της θύρας SSH
```bash
sudo tcpdump -i eth0 'not port 22'
```

## 📊 Γρήγορη αναφορά

### Βασικές εντολές

| Εργασία | Εντολή |
| ------ | --------- |
| Προβολή διεπαφών δικτύου | `tcpdump -D` |
| Βασική καταγραφή | `tcpdump -i eth0` |
| Χωρίς επίλυση διευθύνσεων και θυρών σε ονόματα | `tcpdump -nn` |
| Καταγραφή N πακέτων | `tcpdump -c 100` |
| Εγγραφή σε αρχείο | `tcpdump -w file.pcap` |
| Ανάγνωση από αρχείο | `tcpdump -r file.pcap` |
| Αναλυτική έξοδος | `tcpdump -v` |
| Έξοδος ASCII | `tcpdump -A` |
| Έξοδος δεκαεξαδικών δεδομένων και ASCII | `tcpdump -X` |
| Μεγάλο μήκος καταγραφής πακέτου | `tcpdump -s0` |

### Συνήθη φίλτρα

| Φίλτρο | Περιγραφή |
| -------- | ------------- |
| `host 1.2.3.4` | Κίνηση προς ή από το σύστημα |
| `port 80` | Κίνηση στη θύρα 80 |
| `tcp` | Μόνο κίνηση TCP |
| `udp` | Μόνο κίνηση UDP |
| `icmp` | Μόνο κίνηση ICMP |
| `net 192.168.1.0/24` | Κίνηση προς ή από το υποδίκτυο |
| `src host 1.2.3.4` | Το σύστημα είναι η προέλευση |
| `dst port 443` | Θύρα προορισμού 443 |

### Συνδυασμοί φίλτρων

| Παράδειγμα | Περιγραφή |
| --------- | ------------- |
| `host A and port 80` | Σύστημα A και θύρα 80 |
| `port 80 or port 443` | Θύρα 80 ή 443 |
| `not port 22` | Εξαίρεση της συνήθους θύρας SSH |
| `tcp and port 80` | Θύρα TCP 80 |

## 💡 Συμβουλές και καλές πρακτικές

### Συμβουλές απόδοσης

> **Snapshot length:** Το `-s 96` κρατά έως 96 bytes ανά πακέτο· δεν εγγυάται «μόνο κεφαλίδες». Μπορεί να περιλαμβάνει payload ή να κόβει μεγάλες κεφαλίδες. Το `-s0` επιλέγει το προεπιλεγμένο μέγιστο όριο της εγκατάστασης, όχι απεριόριστο μήκος.


```bash
# Χωρίς επίλυση διευθύνσεων και θυρών σε ονόματα, συνήθως ταχύτερα
tcpdump -nn

# Περιορισμός αποθηκευμένων bytes ανά πακέτο
tcpdump -s 96   # Τα 96 bytes του παραδείγματος δεν περιορίζονται απαραίτητα σε κεφαλίδες

# Χρήση φίλτρων BPF για μείωση φόρτου
tcpdump 'host 192.168.1.1'  # Φιλτράρισμα κατά την καταγραφή, συνήθως στο επίπεδο του πυρήνα
```

### Παρατηρήσεις δικαιωμάτων και καταγραφής

> **Χρονισμός αλλαγής δικαιωμάτων:** Το `-Z user`, όπου υποστηρίζεται, αποδεσμεύει αυξημένα δικαιώματα μετά το άνοιγμα της διεπαφής καταγραφής και πριν ανοίξει αρχεία εξόδου. Δεν περιμένει να ολοκληρωθεί όλη η καταγραφή, όπως αναφέρει το πρωτότυπο.


```bash
# Εκτέλεση χωρίς root, εφόσον έχουν ρυθμιστεί τα απαιτούμενα δικαιώματα
# Εναλλακτικά περιορίστε τη διάρκεια καταγραφής

# Αποδέσμευση αυξημένων δικαιωμάτων μετά το άνοιγμα της διεπαφής, όχι μετά το τέλος της καταγραφής
tcpdump -Z user
```

### Συντομεύσεις εντολών (Aliases)

```bash
# Προσθήκη στο ~/.bashrc για Bash
alias tcpdump='sudo tcpdump -nnvvXSs0'
alias tcpdump-web='sudo tcpdump -nnvvXSs0 port 80 or port 443'
alias tcpdump-dns='sudo tcpdump -nn port 53'
```
