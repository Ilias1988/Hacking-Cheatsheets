## Πριν ξεκινήσετε

Ο οδηγός οργανώνει εργαλεία ασφάλειας ανά χρήση, ώστε να καταλαβαίνετε τι κάνει κάθε κατηγορία. Τα ονόματα εργαλείων μένουν στα αγγλικά για να μπορείτε να τα αναζητήσετε. Οι περιγραφές είναι συνοπτικές και δεν σημαίνουν ότι κάθε εργαλείο είναι εγκατεστημένο ή κατάλληλο για κάθε έλεγχο.

**Βασικοί όροι:** enumeration = συστηματική καταγραφή στοιχείων, scanner = αυτοματοποιημένος έλεγχος στόχων, fuzzing = δοκιμή διαφορετικών εισόδων, proxy = διαμεσολαβητής επικοινωνίας, OSINT = συλλογή από ανοικτές πηγές, reverse engineering = αντίστροφη μηχανική, forensics = ψηφιακή διερεύνηση, payload = δοκιμαστική είσοδος ή κώδικας ανάλογα με το πλαίσιο, metapackage = πακέτο που συγκεντρώνει άλλα πακέτα.

Η αναφορά «600+ εργαλεία» και η λίστα «Top 50» διατηρούνται ως τίτλοι του πρωτοτύπου, όχι ως σημερινή απογραφή ή κατάταξη. Ορισμένες ονομασίες, διανομές, λειτουργίες ή διαθεσιμότητες έχουν αλλάξει. Η παρουσία εδώ δεν αποτελεί νέα σύσταση εγκατάστασης. Για διαθέσιμα πακέτα και επιλογές εγκατάστασης συμβουλευτείτε τον [επίσημο κατάλογο Kali](https://www.kali.org/tools/) και τα [metapackages](https://www.kali.org/docs/general-use/metapackages/). Δεν εκτελείται κανένα εργαλείο κατά τη μετάφραση.
