## Πριν ξεκινήσετε

Το **Burp Suite** τοποθετεί έναν **proxy**, δηλαδή ενδιάμεσο μηχανισμό επιθεώρησης, ανάμεσα στον browser και την εφαρμογή. Έτσι βλέπετε το **request** (αίτημα HTTP) και το **response** (απόκριση), αλλάζετε επιλεγμένα δεδομένα και εξετάζετε τη συμπεριφορά της εφαρμογής.

Ξεκινήστε με **Proxy → HTTP history** για καταγραφή και **Repeater** για χειροκίνητη επανάληψη ενός αιτήματος. Το **Intruder** επαναλαμβάνει δοκιμές με πολλές τιμές, ο **Scanner** κάνει αυτοματοποιημένους ελέγχους όπου περιλαμβάνεται στην έκδοσή σας, ενώ **Decoder**, **Comparer** και **Sequencer** βοηθούν στην ανάλυση δεδομένων. Το **scope** είναι το συμφωνημένο σύνολο στόχων και διαδρομών που επιτρέπεται να ελέγξετε.

**Όροι:** *payload* = δοκιμαστικά δεδομένα, *token* = τιμή που χρησιμοποιείται π.χ. ως αναγνωριστικό συνεδρίας ή στοιχείο ελέγχου ενός αιτήματος, *CA* = αρχή πιστοποίησης.

Τα ονόματα μενού και κουμπιών παραμένουν στα αγγλικά για να τα αναγνωρίζετε στο πρόγραμμα. Οι εξηγήσεις είναι ελληνικές. Το πρωτότυπο περιλαμβάνει παλιές διαδρομές μενού και δυνατότητες διαφορετικών εκδόσεων· οι σχετικές σημειώσεις εξηγούν αυτές τις διαφορές. Τα αιτήματα HTTP και τα payloads παραμένουν αμετάβλητα.

## 🎯 Εισαγωγή

**Το Burp Suite** είναι συλλογή εργαλείων της PortSwigger για ελέγχους ασφάλειας εφαρμογών web. Επιτρέπει την επιθεώρηση, τροποποίηση και επανάληψη αιτημάτων, καθώς και αυτοματοποιημένους ελέγχους ανάλογα με την έκδοση.

### Εκδόσεις

> **Διαφορές εκδόσεων:** Η Community προσφέρει βασικά εργαλεία χειροκίνητου ελέγχου, ενώ ο ενσωματωμένος αυτοματοποιημένος Scanner απαιτεί Professional ή το αντίστοιχο προϊόν DAST. Η παλιά ονομασία Enterprise και η παλιά τιμή του πρωτοτύπου χρειάζονται επικαιροποίηση· εδώ δεν δίνεται σταθερή τιμή συνδρομής. Δείτε τη [σύγκριση εκδόσεων PortSwigger](https://portswigger.net/burp).


| Έκδοση | Δυνατότητες | Κόστος |
| --------- | ---------- | ------- |
| **Community** | Βασικός proxy και εργαλεία χειροκίνητων ελέγχων | Δωρεάν |
| **Professional** | Scanner, Intruder χωρίς τον περιορισμό ταχύτητας της Community και Collaborator | Συνδρομή· ελέγξτε την επίσημη τρέχουσα τιμή |
| **Enterprise (παλαιότερη ονομασία)** | Ενσωμάτωση σε CI/CD και δυνατότητες για ομάδες | Επικοινωνία με το τμήμα πωλήσεων |

### Βασικά εργαλεία

| Εργαλείο | Περιγραφή |
| ------ | ------------- |
| **Proxy** | Παρεμβολή για επιθεώρηση και τροποποίηση κίνησης HTTP/HTTPS |
| **Spider** | Αυτόματη εξερεύνηση συνδέσμων εφαρμογής |
| **Scanner** | Αυτοματοποιημένη αναζήτηση ευπαθειών |
| **Intruder** | Αυτοματοποιημένοι προσαρμοσμένοι έλεγχοι |
| **Repeater** | Χειροκίνητη τροποποίηση και επανάληψη αιτημάτων |
| **Decoder** | Κωδικοποίηση και αποκωδικοποίηση δεδομένων |
| **Comparer** | Σύγκριση αποκρίσεων |
| **Sequencer** | Στατιστική ανάλυση τυχαιότητας tokens |

## 📥 Εγκατάσταση και αρχική ρύθμιση

### Λήψη

```bash
# Λήψη από τον επίσημο ιστότοπο
https://portswigger.net/burp/releases

# Διαθέσιμο για:
# - Windows, μέσω εγκαταστάτη ή αυτόνομης έκδοσης
# - macOS, μέσω αρχείου DMG
# - Linux, μέσω script ή αρχείου JAR
```

### Απαιτήσεις συστήματος

> **Παλιές απαιτήσεις:** Ο πίνακας μεταφέρει ενδεικτικές τιμές του πρωτοτύπου, όχι τις σημερινές απαιτήσεις. Ειδικά το JRE 8+ δεν είναι γενική οδηγία για σύγχρονες εκδόσεις. Οι εγγενείς εγκαταστάτες περιλαμβάνουν κατάλληλο περιβάλλον Java. Ελέγξτε τις [τρέχουσες απαιτήσεις Burp](https://portswigger.net/burp/documentation/desktop/getting-started/system-requirements).


| Προϋπόθεση | Ελάχιστο | Προτεινόμενο |
| ------------- | --------- | ------------- |
| RAM | 4 GB | 8+ GB |
| Χώρος δίσκου | 500 MB | 2+ GB |
| Java | JRE 8+ (παλιά απαίτηση του πρωτοτύπου) | Ενσωματωμένο περιβάλλον Java |
| Ανάλυση οθόνης | 1280x800 | 1920x1080 |

### Ρύθμιση κατά την πρώτη εκκίνηση

> **Έργα και εκκίνηση Java:** Τα μόνιμα αρχεία έργου εξαρτώνται από την έκδοση του Burp. Η εντολή μνήμης του πρωτοτύπου έχει λανθασμένη σειρά: οι επιλογές Java, όπως `-Xmx4g`, πρέπει να προηγούνται του `-jar`, το οποίο ακολουθείται από το αρχείο JAR. Δείτε τις [οδηγίες εκκίνησης](https://portswigger.net/burp/documentation/desktop/troubleshooting/launch-from-command-line).


1. **Επιλογή τύπου έργου**
   - Temporary project — προσωρινό έργο για δοκιμές
   - New project on disk — νέο έργο σε δίσκο, όπου υποστηρίζεται
   - Open existing project — άνοιγμα υπάρχοντος έργου

2. **Ρυθμίσεις**
   - Use Burp defaults — χρήση προεπιλογών, κατάλληλη αφετηρία για αρχάριους
   - Load from configuration file — φόρτωση αρχείου ρυθμίσεων

3. **Δέσμευση μνήμης**
   ```bash
   # Παράδειγμα αύξησης μνήμης· δείτε τη σημείωση για τη σειρά επιλογών Java
   java -jar -Xmx4g burpsuite_pro.jar
   ```

## 🔌 Ρύθμιση proxy

> **Μενού και HTTPS:** Διαδρομές όπως Proxy → Options ή Extender προέρχονται από παλαιότερες εκδόσεις. Ελέγξτε τις αντίστοιχες ρυθμίσεις της εγκατάστασής σας· ο ενσωματωμένος browser του Burp απλοποιεί την αρχική ρύθμιση. Το πιστοποιητικό CA δίνει στον proxy δυνατότητα επιθεώρησης HTTPS· χρησιμοποιήστε προφίλ browser για το εργαστήριο. Δείτε τα [πρώτα βήματα Burp](https://portswigger.net/burp/documentation/desktop/getting-started).


### Ρύθμιση προγράμματος περιήγησης

#### Χειροκίνητη ρύθμιση proxy

| Πρόγραμμα περιήγησης | Θέση ρυθμίσεων proxy |
| --------- | ------------------------ |
| Firefox | Settings → Network → Manual proxy (ρυθμίσεις δικτύου και χειροκίνητου proxy) |
| Chrome | Χρησιμοποιεί τον proxy του συστήματος ή πρόσθετο περιήγησης |
| Safari | System Preferences → Network → Proxies (ρυθμίσεις δικτύου και proxy συστήματος) |

**Προεπιλεγμένος proxy Burp:**
```
Host: 127.0.0.1 (διεύθυνση τοπικού proxy)
Port: 8080 (θύρα proxy)
```

#### Ρύθμιση Firefox
```
1. Ανοίξτε τις ρυθμίσεις Firefox (Preferences)
2. Αναζητήστε τη λέξη "proxy"
3. Πατήστε "Settings..."
4. Επιλέξτε "Manual proxy configuration" για χειροκίνητη ρύθμιση proxy
5. HTTP Proxy: 127.0.0.1  Port: 8080 (διεύθυνση και θύρα τοπικού proxy)
6. Ενεργοποιήστε το "Also use this proxy for HTTPS", όπου εμφανίζεται
7. Πατήστε OK
```

#### Πρόσθετο FoxyProxy
```
1. Εγκαταστήστε το πρόσθετο FoxyProxy
2. Προσθέστε νέο proxy:
   - Title: Burp Suite (όνομα καταχώρισης)
   - Proxy Type: HTTP (τύπος proxy)
   - Proxy IP: 127.0.0.1 (διεύθυνση)
   - Port: 8080 (θύρα proxy)
3. Ενεργοποιήστε το κατά τη διάρκεια των ελέγχων
```

### Εγκατάσταση πιστοποιητικού CA για HTTPS

```bash
# Βήμα 1: Με ενεργό τον proxy, επισκεφθείτε:
http://burp

# Βήμα 2: Πατήστε "CA Certificate" για λήψη του πιστοποιητικού

# Βήμα 3: Εισαγωγή πιστοποιητικού:
# Firefox: Settings → Certificates → Import → Trust for websites (εισαγωγή και εμπιστοσύνη για ιστοτόπους)
# Chrome: Settings → Security → Manage certificates → Import (εισαγωγή πιστοποιητικού)
# Σύστημα: εισαγωγή στις έμπιστες ριζικές αρχές πιστοποίησης
```

### Σημεία ακρόασης proxy (listeners)

> **Διεύθυνση ακρόασης:** Το `127.0.0.1` δέχεται συνδέσεις από το τοπικό σύστημα. Το `0.0.0.0` του παραδείγματος ακούει σε όλες τις διεπαφές IPv4 και μπορεί να εκθέσει τον proxy σε άλλες συσκευές. Περιορίστε την πρόσβαση στο απαιτούμενο εργαστηριακό δίκτυο.


```
Μενού: Proxy → Options → Proxy Listeners

Προεπιλογή: 127.0.0.1:8080

Προσθέστε προσαρμοσμένα σημεία ακρόασης (listeners):
- Διαφορετικές θύρες για διαφορετικούς ελέγχους
- Ακρόαση σε όλες τις διεπαφές (0.0.0.0) για εργαστηριακό έλεγχο κινητών, με περιορισμό πρόσβασης
- Προώθηση σε διαφορετικά συστήματα
```

### Invisible Proxy για εφαρμογές χωρίς ρύθμιση proxy

```
1. Μενού: Proxy → Options → Proxy Listeners
2. Επεξεργασία listener → Request handling
3. Ενεργοποιήστε το "Support invisible proxying"
4. Ρυθμίστε το αρχείο hosts ή το DNS
```

## 🎣 Παρεμβολή και επιθεώρηση κίνησης

### Κουμπιά παρεμβολής

| Κουμπί | Λειτουργία |
| -------- | ---------- |
| **Intercept is on/off** | Ενεργοποίηση ή απενεργοποίηση παρεμβολής |
| **Forward** | Αποστολή αιτήματος στον server |
| **Drop** | Απόρριψη αιτήματος |
| **Action (ενέργεια)** | Μενού πρόσθετων ενεργειών |

### Επιλογές παρεμβολής

```
Μενού: Proxy → Options → Intercept Client Requests

Παραδείγματα κανόνων:
- Παύση για επιθεώρηση μόνο αντικειμένων εντός scope
- Παύση μόνο συγκεκριμένων τύπων αρχείων
- Εξαίρεση εικόνων και στατικών αρχείων
```

### Τροποποίηση αιτήματος

```http
# Αρχικό αίτημα
GET /page.php?id=1 HTTP/1.1
Host: target.com

# Τροποποιημένο αίτημα κατά την παύση για επιθεώρηση
GET /page.php?id=1' OR '1'='1 HTTP/1.1
Host: target.com
```

### Κανόνες αντιστοίχισης και αντικατάστασης (Match and Replace)

```
Μενού: Proxy → Options → Match and Replace

Συνήθεις κανόνες:
- Αφαίρεση κεφαλίδων ασφάλειας από την τοπική απόκριση
- Τροποποίηση User-Agent
- Προσθήκη προσαρμοσμένων κεφαλίδων
- Αντικατάσταση παραμέτρων αιτήματος
```

| Τύπος | Μοτίβο αντιστοίχισης | Αντικατάσταση | Σκοπός |
| ------ | ------- | --------- | --------- |
| Κεφαλίδα αιτήματος | `User-Agent: .*` | `User-Agent: Custom` | Αλλαγή User-Agent |
| Σώμα αιτήματος | `password=test` | `password=admin` | Δοκιμή στοιχείων σύνδεσης |
| Κεφαλίδα απόκρισης | `X-Frame-Options.*` | ` ` | Αφαίρεση κεφαλίδας |
| Σώμα απόκρισης | `disabled` | `enabled` | Ενεργοποίηση κουμπιών στην τοπική απόκριση |

### Τροποποίηση απόκρισης

> **Τοπική τροποποίηση:** Αφαίρεση κεφαλίδων, αλλαγή JavaScript ή ενεργοποίηση κουμπιών στην απόκριση επηρεάζει όσα βλέπει ο browser. Δεν αποδεικνύει από μόνη της παράκαμψη δικαιωμάτων στον server.


```
Μενού: Proxy → Options → Intercept Server Responses

Ενεργοποίηση για:
- Αφαίρεση κεφαλίδων ασφάλειας από την τοπική απόκριση
- Τροποποίηση JavaScript
- Αλλαγή περιεχομένου απόκρισης
- Έλεγχος περιορισμών που εφαρμόζονται στον browser
```

## 🎯 Στόχος και όρια ελέγχου (Scope)

### Προσθήκη στα όρια ελέγχου

```
Τρόπος 1: Δεξί κλικ στο Site map → Add to scope
Τρόπος 2: Target → Scope → Add (χειροκίνητη προσθήκη)
Τρόπος 3: Από το Proxy history → Add to scope
```

### Καθορισμός ορίων ελέγχου

```
Μενού: Target → Scope

Συμπερίληψη στα όρια ελέγχου (scope):
- Protocol: Any/HTTP/HTTPS (πρωτόκολλο: οποιοδήποτε, HTTP ή HTTPS)
- Host/IP: target.com (όνομα ή IP στόχου)
- Port: Any/Specific (οποιαδήποτε ή συγκεκριμένη θύρα)
- File: Regex pattern (μοτίβο κανονικής έκφρασης για τη διαδρομή)

Παραδείγματα μοτίβων:
.*\.target\.com$          # Όλοι οι υποτομείς
^https://target\.com/app  # Συγκεκριμένη διαδρομή
```

### Προχωρημένες ρυθμίσεις ορίων

```
Μενού: Target → Scope → Advanced scope control

Συμπερίληψη:
  Protocol: HTTPS
  Host: target.com
  Port: 443
  File: ^/api/.*

Εξαίρεση:
  Host: .*\.google\.com
  File: .*\.(jpg|png|gif|css|js)$
```

### Χάρτης ιστοτόπου (Site map)

```
Μενού: Target → Site map

Δυνατότητες:
- Προβολή περιεχομένου που έχει ανακαλυφθεί
- Φιλτράρισμα βάσει scope
- Αναζήτηση και φιλτράρισμα περιεχομένου
- Επισήμανση αντικειμένων ενδιαφέροντος
- Σύγκριση χαρτών ιστοτόπου
```

## 🕷️ Αυτόματη εξερεύνηση ιστοτόπου (Spider/Crawler)

### Εκκίνηση εξερεύνησης

```
1. Κάντε δεξί κλικ στον στόχο μέσα στο Site map
2. Επιλέξτε "Spider this host" ή "Spider this branch" στις παλιές εκδόσεις
3. Εναλλακτικά: Target → Site map → δεξί κλικ → Scan → Crawl
```

### Ρυθμίσεις εξερεύνησης

```
Παλιό μενού: Spider → Options ή
Μενού: Dashboard → New scan → Crawl

Ρυθμίσεις αυτόματης εξερεύνησης:
- Μέγιστο βάθος ακολούθησης συνδέσμων
- Μέγιστη διάρκεια εξερεύνησης
- Υποβολή φορμών
- Διαχείριση σύνδεσης χρήστη
```

### Ρύθμιση αυτόματης εξερεύνησης

| Ρύθμιση | Περιγραφή | Προτεινόμενο |
| --------- | ------------- | ------------- |
| **Link depth — βάθος ακολούθησης συνδέσμων** | Πόσα επίπεδα συνδέσμων θα ακολουθούνται | 5-10 |
| **Max requests — μέγιστος αριθμός αιτημάτων** | Συνολικό όριο αιτημάτων | 1000-5000 |
| **Duplicate removal — αφαίρεση διπλοτύπων** | Παράλειψη παρόμοιων σελίδων | Ενεργό |
| **Παθητική ανάλυση** | Ανάλυση αποκρίσεων κατά την εξερεύνηση | Ενεργό |

### Υποβολή φορμών

```
Μενού: Spider → Options → Application Login

Ρύθμιση σύνδεσης για:
- Ένα σύνολο στοιχείων σύνδεσης
- Λίστα στοιχείων σύνδεσης
- Αναγνώριση κατάστασης συνεδρίας
```

## 🔍 Scanner

> **Κάλυψη και επιβεβαίωση:** Ο ενσωματωμένος Scanner δεν περιλαμβάνεται στην Community. Οι γενικές λίστες ευπαθειών του πρωτοτύπου δεν εγγυώνται ότι κάθε περίπτωση θα εντοπιστεί. Κωδικοί HTTP, μεταβολές μήκους ή απουσία ευρημάτων δεν αρκούν για συμπέρασμα χωρίς έλεγχο της πραγματικής απόκρισης και της ταυτοποίησης.


### Τύποι σάρωσης

| Τύπος | Περιγραφή | Χρήση |
| ------ | ------------- | ---------- |
| **Passive — παθητική ανάλυση** | Ανάλυση κίνησης που περνά από τον proxy | Κατά την επεξεργασία κίνησης, εφόσον είναι διαθέσιμη και ενεργή |
| **Active — ενεργός έλεγχος** | Αποστολή δοκιμαστικών δεδομένων για αναζήτηση ευπαθειών | Με εξουσιοδότηση |
| **Full — εκτενής έλεγχος** | Εκτενής σάρωση | Όταν υπάρχει επαρκής χρόνος |
| **Custom — προσαρμοσμένος έλεγχος** | Μόνο συγκεκριμένοι έλεγχοι | Στοχευμένοι έλεγχοι |

### Εκκίνηση σάρωσης

```
Τρόπος 1: Δεξί κλικ → Scan
Τρόπος 2: Dashboard → New scan
Τρόπος 3: Αποστολή στον Scanner από άλλα εργαλεία
```

### Ρύθμιση σάρωσης

```
Μενού: Dashboard → New scan → Scan configuration

Έτοιμες ρυθμίσεις ελέγχων:
- Audit checks - all except JavaScript analysis (όλα εκτός ανάλυσης JavaScript)
- Audit checks - critical issues only (μόνο κρίσιμα προβλήματα)
- Audit checks - light, active (ελαφριοί ενεργοί έλεγχοι)
- Audit checks - medium, active (ενεργοί έλεγχοι μέσης έντασης)
- Audit checks - full, active (εκτενείς ενεργοί έλεγχοι)
```

### Κατηγορίες ευπαθειών

```
Ο Scanner αναζητά ενδείξεις για:

- XSS στην πλευρά του browser (DOM-based XSS)

Ταυτοποίηση:
- Αδυναμίες μηχανισμών ταυτοποίησης
- Προβλήματα διαχείρισης συνεδρίας
- Αδύναμοι κωδικοί πρόσβασης

Άλλες κατηγορίες:
- Πλαστογράφηση αιτημάτων από άλλον ιστότοπο (CSRF)

## 🔫 Intruder

### Τρόποι συνδυασμού δοκιμαστικών δεδομένων

| Τύπος | Σημεία εισαγωγής | Κώδικας ενέργειας μετά την πρόσβαση (Payloads) | Χρήση |
| ------ | ----------- | ---------- | ---------- |
| **Sniper** | 1+ | Ένα σύνολο τιμών, ένα σημείο κάθε φορά | Έλεγχος μίας παραμέτρου |
| **Battering Ram** | 1+ | Ένα σύνολο τιμών, ίδια τιμή σε όλα τα σημεία | Ίδια τιμή σε όλα τα σημεία |
| **Pitchfork** | 1+ | Πολλά σύνολα τιμών, με παράλληλη αντιστοίχιση | Ζεύγη ονόματος χρήστη και κωδικού |
| **Cluster Bomb** | 1+ | Πολλά σύνολα τιμών, όλοι οι συνδυασμοί | Δοκιμή όλων των συνδυασμών στοιχείων σύνδεσης από τις λίστες |

### Αποστολή στο Intruder

```
1. Κάντε δεξί κλικ στο αίτημα
2. Επιλέξτε "Send to Intruder" για αποστολή στο Intruder
3. Συντόμευση: Ctrl+I
```

### Ορισμός σημείων εισαγωγής

```
Μενού: Intruder → Positions

Σημειώστε τα σημεία εισαγωγής με σύμβολα §:

GET /login.php?user=§admin§&pass=§test§ HTTP/1.1

Κουμπιά:
- Add § — σημείωση επιλεγμένου κειμένου
- Clear § — αφαίρεση σημείων εισαγωγής
- Auto § — αυτόματη επιλογή σημείων εισαγωγής
```

### Τύποι δοκιμαστικών δεδομένων (payloads)

| Τύπος | Περιγραφή |
| ------ | ------------- |
| **Simple list — απλή λίστα** | Προσαρμοσμένη λίστα λέξεων |
| **Runtime file — αρχείο κατά την εκτέλεση** | Φόρτωση από αρχείο |
| **Numbers — αριθμοί** | Διαδοχικοί ή τυχαίοι αριθμοί |
| **Dates — ημερομηνίες** | Ακολουθίες ημερομηνιών |
| **Brute forcer — συνδυασμοί χαρακτήρων** | Συνδυασμοί χαρακτήρων |
| **Null payloads — κενές τιμές** | Κενές τιμές, π.χ. για έλεγχο ρυθμού αιτημάτων |
| **Username generator — παραγωγή ονομάτων χρήστη** | Συνήθη μοτίβα ονομάτων χρήστη |

### Επεξεργασία payloads

```
Μενού: Intruder → Payloads → Payload Processing

Προσθέστε κανόνες:
- Προσθήκη προθέματος ή επιθέματος
- Κωδικοποίηση URL
- Κωδικοποίηση Base64
- Υπολογισμός hash (MD5, SHA)
- Αντιστοίχιση και αντικατάσταση
```

### Εντοπισμός συμβολοσειρών στις αποκρίσεις (Grep - Match)

```
Μενού: Intruder → Options → Grep - Match

Προσθέστε συμβολοσειρές για επισήμανση στις αποκρίσεις:
- "Login successful" (μήνυμα επιτυχούς σύνδεσης)
- "Invalid password" (μήνυμα μη αποδεκτού κωδικού)
- "error" (ένδειξη σφάλματος)
- Προσαρμοσμένη κανονική έκφραση

Βοηθά στον εντοπισμό διαφορετικών αποκρίσεων· η επιτυχία χρειάζεται επιβεβαίωση.
```

### Παραδείγματα αυτοματοποιημένων ελέγχων

#### Δοκιμές σύνδεσης με λίστες στοιχείων
```
POST /login HTTP/1.1
Content-Type: application/x-www-form-urlencoded

username=§admin§&password=§password§

Attack type: Cluster bomb (όλοι οι συνδυασμοί)
Payload 1: Username list (λίστα ονομάτων χρήστη)
Payload 2: Password list (λίστα κωδικών)
```

#### Δοκιμές διαφορετικών τιμών παραμέτρων
```
GET /api/user/§1§ HTTP/1.1

Attack type: Sniper (ένα σημείο κάθε φορά)
Payload: Numbers 1-1000 (αριθμοί από 1 έως 1000)
```

#### Αναζήτηση περιεχομένου
```
GET /§admin§ HTTP/1.1

Attack type: Sniper (ένα σημείο κάθε φορά)
Payload: Directory wordlist (λίστα ονομάτων καταλόγων)
Filter: Status code != 404 (εξαίρεση κωδικού 404)
```

### Ανάλυση αποτελεσμάτων

```
Μετά τον αυτοματοποιημένο έλεγχο:
- Ταξινόμηση βάσει μήκους για εντοπισμό διαφορετικών αποκρίσεων
- Ταξινόμηση βάσει κωδικού κατάστασης HTTP
- Φιλτράρισμα βάσει αντιστοίχισης Grep - Match
- Εξαγωγή αποτελεσμάτων
```

## 🔢 Sequencer

> **Στατιστική ένδειξη, όχι απόδειξη:** Ένα αποτέλεσμα Excellent ή μια τιμή εντροπίας δεν αποδεικνύει από μόνο του κρυπτογραφικά ασφαλή παραγωγή tokens. Εξαρτάται από το δείγμα, τον πραγματικό μηχανισμό παραγωγής και το πλαίσιο χρήσης. Δείτε την [τεκμηρίωση Sequencer](https://portswigger.net/burp/documentation/desktop/tools/sequencer).

### Μετρήσεις ανάλυσης

| Παράμετρος | Ενδεικτική τιμή του πρωτοτύπου | Περιγραφή |
| -------- | ------------ | ------------- |
| **Overall quality — συνολική ποιότητα** | >100 bits (ενδεικτικός ισχυρισμός του πρωτοτύπου) | Στατιστική εκτίμηση τυχαιότητας |
| **Character-level — επίπεδο χαρακτήρων** | Υψηλή εκτιμώμενη εντροπία | Εκτίμηση τυχαιότητας ανά χαρακτήρα |
| **Bit-level — επίπεδο bits** | Υψηλή εκτιμώμενη εντροπία | Εκτίμηση τυχαιότητας ανά bit |

### Ερμηνεία

```
Αποτελέσματα:
- Excellent: θετική στατιστική ένδειξη τυχαιότητας, όχι απόδειξη κρυπτογραφικής ασφάλειας
- Good: θετική στατιστική ένδειξη που χρειάζεται αξιολόγηση στο συγκεκριμένο πλαίσιο
- Poor: πιθανή προβλεψιμότητα

| Εργαλείο | Βασική χρήση | Βασική συντόμευση |
| ------ | ------------- | -------------- |
| Proxy | Παρεμβολή για επιθεώρηση κίνησης | Ctrl+T (εναλλαγή) |
| Repeater | Χειροκίνητος έλεγχος | Ctrl+R (αποστολή) |
| Intruder | Αυτοματοποιημένοι έλεγχοι | Ctrl+I (αποστολή) |
| Scanner | Αναζήτηση ευπαθειών | Δεξί κλικ → Scan |
| Spider | Αναζήτηση περιεχομένου | Δεξί κλικ → Spider |
| Decoder | Κωδικοποίηση και αποκωδικοποίηση | - |
| Comparer | Σύγκριση διαφορών μεταξύ αποκρίσεων | Αποστολή στο Comparer |
| Sequencer | Ανάλυση tokens | Αποστολή στο Sequencer |

### Συνοπτικός πίνακας τρόπων ελέγχου Intruder

| Τρόπος ελέγχου | Πότε χρησιμοποιείται |
| -------- | ---------- |
| **Sniper** | Έλεγχος μίας παραμέτρου κάθε φορά |
| **Battering Ram** | Ίδιο payload σε όλα τα σημεία |
| **Pitchfork** | Ζεύγη username:password |
| **Cluster Bomb** | Όλοι οι συνδυασμοί ονόματος χρήστη × κωδικού |

### Συνηθισμένοι κωδικοί κατάστασης HTTP

| Κωδικός | Σημασία | Ενδεικτική ερμηνεία στο Intruder |
| ------ | --------- | ---------------------- |
| 200 | OK | Κανονική απόκριση |
| 301/302 | Ανακατεύθυνση | Μπορεί να υποδεικνύει επιτυχία· απαιτεί επιβεβαίωση |
| 401 | Απαιτείται ταυτοποίηση | Μη αποδεκτά ή ελλιπή στοιχεία ταυτοποίησης |
| 403 | Απαγορευμένη πρόσβαση | Άρνηση πρόσβασης |
| 404 | Δεν βρέθηκε | Μη διαθέσιμη διαδρομή |
| 500 | Σφάλμα διακομιστή | Πιθανή ένδειξη προβλήματος, όχι απόδειξη ευπάθειας |

## 💡 Συμβουλές και καλές πρακτικές

### Συμβουλές απόδοσης

1. **Περιορίστε τα όρια ελέγχου**
   ```
   Συμπεριλάβετε στο scope μόνο τα εγκεκριμένα domains
   Μειώνει άσχετες καταχωρίσεις στο ιστορικό Proxy, με τα κατάλληλα φίλτρα
   ```

2. **Απενεργοποιήστε πρόσθετα που δεν χρειάζεστε**
   ```
   Απενεργοποιήστε περιττά πρόσθετα για καλύτερη απόδοση
   ```

3. **Χρησιμοποιήστε αρχεία έργου, όπου υποστηρίζονται**
   ```
   Αποθηκεύετε συχνά την εργασία σας, όπου υποστηρίζεται
   Χρησιμοποιήστε αρχεία έργου για μεγάλους ελέγχους, όπου υποστηρίζονται
   ```

### Συμβουλές ελέγχου

1. **Ξεκινήστε με παθητική ανάλυση**
   ```
   Εξετάστε τα αρχικά ευρήματα παθητικής ανάλυσης
   Αξιολογήστε τα πριν από ενεργούς ελέγχους
   ```

2. **Χρησιμοποιήστε αρχικά το Repeater**
   ```
   Ο χειροκίνητος έλεγχος μπορεί να αποκαλύψει προβλήματα που χάνει η αυτοματοποίηση
   Κατανοήστε την εφαρμογή πριν από την αυτοματοποίηση
   ```

3. **Οργανώστε τους ελέγχους σε καρτέλες**
   ```
   Δώστε περιγραφικά ονόματα στις καρτέλες Repeater
   Δώστε περιγραφικά ονόματα στους ελέγχους Intruder
   ```

### Ρυθμίσεις ρυθμού και αιτημάτων

```
Ρυθμίσεις ρυθμού αιτημάτων, χωρίς εγγύηση αποφυγής εντοπισμού:

Παλιό μενού: Project options → Connections:
- Περιορισμός ρυθμού αιτημάτων
- Τυχαίες καθυστερήσεις
- Όριο παράλληλων συνδέσεων

Μενού: Intruder → Options:
- Καθυστέρηση αιτημάτων
- Χρόνος εκκίνησης
```

### Διερεύνηση προβλημάτων

| Πρόβλημα | Ενδεικτική προσέγγιση |
| ------- | ---------- |
| Δεν επιθεωρείται η κίνηση HTTPS | Ελέγξτε την εγκατάσταση και την εμπιστοσύνη του πιστοποιητικού CA |
| Αργή λειτουργία | Περιορίστε τα όρια ελέγχου και απενεργοποιήστε περιττά πρόσθετα |
| Αιτήματα που δεν εμφανίζονται | Ελέγξτε την επιλογή "Intercept Server Responses" για αποκρίσεις και τις ρυθμίσεις αιτημάτων για αιτήματα |
| Ο Scanner δεν βρίσκει ευπάθειες | Ελέγξτε πρώτα κάλυψη και ταυτοποίηση και έπειτα την ένταση σάρωσης |
