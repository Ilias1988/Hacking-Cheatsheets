## 🎯 Методология OSINT

Этапы на схеме: 1 — определить информационные потребности; 2 — собрать исходные данные; 3 — обработать их; 4 — проанализировать и сопоставить результаты; 5 — подготовить и представить выводы.

```
┌─────────────────────────────────────────────────────────────┐
│                    OSINT LIFECYCLE                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. REQUIREMENTS    →  Define intelligence needs            │
│         ↓                                                   │
│  2. COLLECTION      →  Gather raw data from sources         │
│         ↓                                                   │
│  3. PROCESSING      →  Convert data to usable format        │
│         ↓                                                   │
│  4. ANALYSIS        →  Evaluate and correlate findings      │
│         ↓                                                   │
│  5. DISSEMINATION   →  Report and present intelligence      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 🔥 Краткий справочник команд

### theHarvester
```bash
# Сбор адресов почты и поддоменов
theHarvester -d target.com -l 500 -b all

# Конкретные источники
theHarvester -d target.com -b google,linkedin,twitter

# Сохранить в файл
theHarvester -d target.com -b all -f results.html
```

### Sherlock (поиск по имени пользователя)

> **Версии:** примеры запуска Sherlock в оригинале относятся к прежней структуре проекта. Сверяйте способ установки и запуска с [официальной документацией Sherlock](https://sherlockproject.xyz/installation); исходные команды ниже сохранены без изменений.

```bash
# Поиск на всех платформах
python3 sherlock.py username

# Конкретные сайты
python3 sherlock.py username --site twitter instagram facebook

# Сохранить результат в файл
python3 sherlock.py username --output results.txt
```

### Maltego
```
# Типы преобразований:
- Человек → адрес почты
- Адрес почты → домен
- Домен → IP-адрес
- IP-адрес → местоположение
- Профили социальных сетей
```

### Recon-ng
```bash
# Запустить recon-ng
recon-ng

# Создать рабочее пространство
workspaces create target_name

# Загрузить модули
modules load recon/domains-hosts/hackertarget
modules load recon/contacts-credentials/hibp_breach

# Указать цель
options set SOURCE target.com

# Выполнить модуль
run
```

## 📊 Категории OSINT

### Пассивная OSINT
```
Без прямого взаимодействия с целью:
- Поисковые системы
- Социальные сети
- Открытые реестры
- Archive.org
- Данные WHOIS
```

### Активная OSINT
```
С определённым взаимодействием с целью:
- Сканирование портов
- DNS-запросы
- Обход веб-сайтов
- Проверка адресов почты
```

## 🔒 Операционная безопасность (OPSEC)

### Рекомендуемые практики
```
✓ Использовать VPN/Tor
✓ Создавать вспомогательные учётные записи
✓ Использовать виртуальные машины
✓ Не использовать личные учётные записи
✓ Регулярно очищать cookies и кеш
✓ Использовать отдельные профили браузера
✓ Документировать все действия
```

### Вспомогательные учётные записи (sock puppets)
```
- Использовать вымышленные личности
- Поддерживать согласованную роль на разных платформах
- Использовать аккаунты с историей (они могут вызывать больше доверия)
- Указывать правдоподобные сведения профиля
- Не связывать аккаунты с реальной личностью
```
