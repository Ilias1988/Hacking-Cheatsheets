## Πριν ξεκινήσετε

Η **αντίστροφη αναζήτηση εικόνας** ξεκινά από μια εικόνα για να εντοπίσει ίδιες ή παρόμοιες δημοσιεύσεις. Τα **μεταδεδομένα** είναι πληροφορίες που συνοδεύουν το αρχείο. Το **EXIF** μπορεί να περιλαμβάνει στοιχεία κάμερας, χρόνου ή GPS· τα **IPTC** και **XMP** είναι επιπλέον μορφές μεταδεδομένων. Το **OCR** αναγνωρίζει κείμενο μέσα σε εικόνες.

Κρατήστε το αρχικό αρχείο και εργαστείτε σε αντίγραφο. Η απουσία EXIF δεν αποδεικνύει παραποίηση και η παρουσία ημερομηνίας ή GPS δεν αποδεικνύει ότι οι τιμές είναι αυθεντικές. Πλατφόρμες, επεξεργασία και εξαγωγή αρχείων μπορεί να μεταβάλουν τα διαθέσιμα δεδομένα.

Τα αποτελέσματα ομοιότητας, αναζήτησης προσώπου ή ανάλυσης συμπίεσης είναι ενδείξεις που χρειάζονται διασταύρωση. Η ένδειξη «καλύτερο» του αγγλικού πίνακα είναι αξιολογικός χαρακτηρισμός του πρωτοτύπου και δεν αποτελεί τεκμηριωμένη σύγκριση υπηρεσιών. Εξετάστε τι δεδομένα θα κοινοποιήσετε πριν ανεβάσετε εικόνα σε εξωτερικό εργαλείο.

## 📷 Εξαγωγή μεταδεδομένων EXIF

Η εντολή αφαίρεσης μεταδεδομένων αλλάζει το αρχείο εργασίας· εκτελέστε την μόνο στο αντίγραφο που έχετε επιλέξει για επεξεργασία. Τα υπόλοιπα παραδείγματα ζητούν προβολή πεδίων και δεν εγγυώνται ότι τα πεδία υπάρχουν.


### ExifTool
```bash
# Προβολή διαθέσιμων μεταδεδομένων
exiftool image.jpg

# Συντεταγμένες GPS
exiftool -gps* image.jpg

# Πληροφορίες κάμερας και χρόνου λήψης
exiftool -make -model -datetime image.jpg

# Αφαίρεση μεταδεδομένων από το αρχείο εργασίας
exiftool -all= image.jpg
```

### Διαδικτυακά εργαλεία
- [Pic2Map](https://www.pic2map.com/)
- [FotoForensics](https://fotoforensics.com/)
- [Metadata Remover Viewer](https://metadataremover.ai/metadata-viewer) — Εργαλείο τρίτου παρόχου για εξέταση μεταδεδομένων EXIF/IPTC/XMP μέσω browser. Δοκιμάστε το με μη ευαίσθητα αρχεία.

> Τα μεταδεδομένα μπορούν να τροποποιηθούν ή να αφαιρεθούν· διασταυρώστε τα με άλλα αποδεικτικά στοιχεία.

## 🔎 Ανάλυση εικόνας

### Εξέταση ψηφιακών χαρακτηριστικών εικόνας

Η ELA εξετάζει χαρακτηριστικά συμπίεσης. Ένα διαφορετικό οπτικό μοτίβο δεν αρκεί για να αποδείξει παραποίηση ή να αποδώσει τον δημιουργό μιας εικόνας. Η λίστα περιγράφει δυνατότητες που αναφέρει το πρωτότυπο και όχι αποτελέσματα ανάλυσης συγκεκριμένου αρχείου.

```
Ενδεικτικές λειτουργίες που αναφέρει το πρωτότυπο για το FotoForensics.com:
- ELA (Error Level Analysis) — Εξέταση διαφορών επιπέδου συμπίεσης
- Εξαγωγή μεταδεδομένων
- Εξέταση ενδείξεων κρυμμένων δεδομένων
- Ανάλυση συμπίεσης
```

### Εκτίμηση τοποθεσίας από εικόνες
```
1. Εξαγωγή διαθέσιμων δεδομένων GPS από EXIF
2. Αναζήτηση αναγνωρίσιμων σημείων της εικόνας
3. Σύγκριση με εικόνες δρόμων, όπως street view
4. Εξέταση κειμένου σε κτίρια ή πινακίδες
```
