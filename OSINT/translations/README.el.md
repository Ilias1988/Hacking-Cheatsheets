## Πριν ξεκινήσετε

Το **OSINT (Open Source Intelligence)** είναι η οργανωμένη συλλογή, αξιολόγηση και συσχέτιση πληροφοριών από δημόσια διαθέσιμες πηγές. Δεν είναι απλώς λίστα αποτελεσμάτων αναζήτησης: χρειάζεται συγκεκριμένο ερώτημα, καταγραφή της πηγής και διάκριση ανάμεσα σε παρατήρηση και υπόθεση.

Ξεκινήστε από τη μεθοδολογία και επιλέξτε τον θεματικό οδηγό που σας χρειάζεται. Το **username** είναι όνομα χρήστη, το **domain** όνομα διαδικτυακού τομέα και η **IP** διεύθυνση δικτυακής σύνδεσης. Το **API** είναι τρόπος επικοινωνίας με μια υπηρεσία μέσω αιτημάτων. Τα ονόματα εργαλείων, οι πραγματικές εντολές και τα παραδείγματα αναζητήσεων παραμένουν όπως στο πρωτότυπο, με ελληνικά σχόλια και εξηγήσεις.

Οι πίνακες υπηρεσιών αποτυπώνουν το πρωτότυπο και δεν αποτελούν επιβεβαιωμένο τρέχοντα κατάλογο τιμών, γεωγραφικής κάλυψης ή λειτουργιών. Κάποιες λειτουργίες απαιτούν λογαριασμό, συνδρομή ή API key. Ελέγξτε την επίσημη τεκμηρίωση της έκδοσης που χρησιμοποιείτε. Τα παραδείγματα ονομάτων, email, τηλεφώνων και domain είναι υποδείγματα, όχι συμπεράσματα έρευνας.

Για κάθε χρήσιμο εύρημα κρατήστε URL πηγής, χρόνο πρόσβασης, σύντομη περιγραφή και βαθμό βεβαιότητας. Ίδιο όνομα ή username δεν αποδεικνύει ίδιο πρόσωπο. Περιορίστε τη συλλογή στα στοιχεία που σχετίζονται με τον σκοπό και το συμφωνημένο πεδίο της έρευνας.

## 🔥 Γρήγορη αναφορά εντολών

### theHarvester
```bash
# Συλλογή email και υποτομέων
theHarvester -d target.com -l 500 -b all

# Επιλογή συγκεκριμένων πηγών
theHarvester -d target.com -b google,linkedin,twitter

# Αποθήκευση σε αρχείο
theHarvester -d target.com -b all -f results.html
```

### Sherlock — Αναζήτηση ονομάτων χρήστη

Τα παραδείγματα του πρωτοτύπου χρησιμοποιούν διαφορετικές μορφές εκκίνησης και επιλογών Sherlock. Δεν είναι εγγυημένα ισοδύναμες για κάθε έκδοση. Επιβεβαιώστε τη σύνταξη από το [επίσημο έργο Sherlock](https://github.com/sherlock-project/sherlock)· οι εντολές εδώ διατηρούνται για αντιστοίχιση με την αγγλική έκδοση.

```bash
# Αναζήτηση στις πλατφόρμες που υποστηρίζει το εργαλείο
python3 sherlock.py username

# Επιλογή συγκεκριμένων ιστοτόπων
python3 sherlock.py username --site twitter instagram facebook

# Αποθήκευση σε αρχείο
python3 sherlock.py username --output results.txt
```

### Maltego
```
# Ενδεικτικοί τύποι μετασχηματισμών (Transforms):
- Person to Email — Από πρόσωπο σε email
- Email to Domain — Από email σε domain
- Domain to IP — Από domain σε IP
- IP to Location — Από IP σε εκτίμηση τοποθεσίας
- Social Media profiles — Προφίλ κοινωνικών δικτύων
```

### Recon-ng

Οι γραμμές workspaces, modules, options και run είναι εντολές μέσα στην κονσόλα recon-ng. Τα συγκεκριμένα modules πρέπει να υπάρχουν και μπορεί να χρειάζονται δικές τους εξαρτήσεις ή κλειδιά πρόσβασης.

```bash
# Εκκίνηση recon-ng
recon-ng

# Δημιουργία χώρου εργασίας
workspaces create target_name

# Φόρτωση πρόσθετων ελέγχου (modules)
modules load recon/domains-hosts/hackertarget
modules load recon/contacts-credentials/hibp_breach

# Ορισμός αντικειμένου έρευνας
options set SOURCE target.com

# Εκτέλεση του επιλεγμένου module
run
```

## 📊 Κατηγορίες OSINT

Η διάκριση παθητικού και ενεργού εξαρτάται από το πού κατευθύνεται το αίτημα. Για παράδειγμα, αναζήτηση αποθηκευμένων δεδομένων DNS σε τρίτο πάροχο διαφέρει από απευθείας ερώτημα στον εξυπηρετητή του εξεταζόμενου domain.


### Παθητική συλλογή πληροφοριών (Passive OSINT)
```
Χωρίς άμεση αλληλεπίδραση με την εξεταζόμενη υποδομή:
- Μηχανές αναζήτησης
- Δημόσια διαθέσιμα κοινωνικά δίκτυα
- Δημόσια αρχεία
- Archive.org
- Στοιχεία WHOIS
```

### Ενεργή συλλογή πληροφοριών (Active OSINT)
```
Με κάποια αλληλεπίδραση με την εξεταζόμενη υποδομή:
- Σάρωση θυρών
- Ερωτήματα DNS
- Αυτοματοποιημένη περιήγηση ιστοτόπου (web crawling)
- Έλεγχος ενδείξεων εγκυρότητας email
```

## 🔒 Ασφάλεια της ερευνητικής διαδικασίας (OPSEC)

VPN, Tor ή εικονική μηχανή δεν εγγυώνται ανωνυμία. Η διαχείριση ερευνητικής ταυτότητας δεν αντικαθιστά τους όρους πρόσβασης ούτε επιτρέπει πλαστοπροσωπία ή πρόσβαση σε ιδιωτικό υλικό.


### Καλές πρακτικές
```
✓ Χρήση VPN ή Tor όπου είναι κατάλληλο
✓ Ξεχωριστοί ερευνητικοί λογαριασμοί
✓ Χρήση εικονικών μηχανών
✓ Αποφυγή χρήσης προσωπικών λογαριασμών
✓ Τακτική διαχείριση cookies και προσωρινής μνήμης
✓ Ξεχωριστά προφίλ browser
✓ Καταγραφή πηγών, ενεργειών και ευρημάτων
```

### Ξεχωριστοί ερευνητικοί λογαριασμοί (Sock Puppet Accounts)
```
- Χρήση κατασκευασμένης ερευνητικής ταυτότητας
- Συνεπής ερευνητική ταυτότητα στις επιλεγμένες πλατφόρμες
- Παλαιότεροι λογαριασμοί μπορεί να αντιμετωπίζονται ως πιο αξιόπιστοι
- Στοιχεία προφίλ που ταιριάζουν στην ερευνητική ταυτότητα
- Διαχωρισμός από την προσωπική ταυτότητα του ερευνητή
```

## 📋 Λίστα ελέγχου OSINT

```markdown
## Αντικείμενο έρευνας: [Όνομα/Εταιρεία/Domain]

### Πρόσωπα
□ Παραλλαγές ονοματεπωνύμου
□ Τηλεφωνικοί αριθμοί
□ Διευθύνσεις email
□ Ταχυδρομικές διευθύνσεις
```
