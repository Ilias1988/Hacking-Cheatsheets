## 🔍 Обратный поиск изображений

> **Примечание:** оценки «лучше всего» в таблице передают мнение оригинала, а не измеренную точность распознавания. Визуальное совпадение требует независимого подтверждения.

## 📷 Извлечение метаданных (EXIF)

### ExifTool
```bash
# Просмотреть все метаданные
exiftool image.jpg

# Координаты GPS
exiftool -gps* image.jpg

# Сведения о камере
exiftool -make -model -datetime image.jpg

# Удалить метаданные
exiftool -all= image.jpg
```

### Онлайн-инструменты
- [Pic2Map](https://www.pic2map.com/)
- [FotoForensics](https://fotoforensics.com/)
- [Metadata Remover Viewer](https://metadataremover.ai/metadata-viewer) — сторонний инструмент просмотра EXIF/IPTC/XMP в браузере. Для проверки используйте файлы без конфиденциальных сведений.

> Метаданные можно изменить или удалить; сопоставляйте их с другими доказательствами.
