## Πριν ξεκινήσετε

Η έρευνα προσώπων ξεκινά από δημόσιες πληροφορίες και εξετάζει αν διαφορετικές αναφορές μπορούν να συσχετιστούν αξιόπιστα. Το **reverse lookup** είναι αντίστροφη αναζήτηση: ξεκινάτε από ένα στοιχείο, όπως email ή τηλέφωνο, για να αναζητήσετε σχετικές δημόσιες αναφορές. Το **Google dork** είναι εξειδικευμένο ερώτημα με τελεστές όπως site: ή filetype:.

Οι υπηρεσίες του οδηγού έχουν διαφορετική πρόσβαση και κάλυψη. Πολλά παραδείγματα δημόσιων αρχείων αφορούν τις ΗΠΑ και δεν περιγράφουν αντίστοιχη διαθεσιμότητα στην Ελλάδα. Οι χαρακτηρισμοί «δωρεάν» και «επί πληρωμή» είναι η κατηγοριοποίηση του πρωτοτύπου, όχι επικαιροποιημένος τιμοκατάλογος.

Διατηρήθηκαν τα αγγλικά ονόματα και οι τελεστές στα παραδείγματα αναζήτησης ώστε να φαίνεται η αρχική σύνταξη. Αντικαταστήστε τις ενδεικτικές τιμές με στοιχεία που εμπίπτουν στη δική σας επιτρεπόμενη έρευνα. Ένα κοινό όνομα, ένα αποτέλεσμα εργαλείου ή μια ομοιότητα προσώπου είναι αφετηρία διασταύρωσης, όχι ασφαλής ταυτοποίηση. Τα διαθέσιμα δημόσια στοιχεία δεν δικαιολογούν απεριόριστη συλλογή ή δημοσιοποίηση.

## 🔎 Εξειδικευμένες αναζητήσεις Google για πρόσωπα

### Βασικές αναζητήσεις
```
# Αναζήτηση ονόματος
"John Smith" site:linkedin.com
"John Smith" site:facebook.com
"John Smith" site:twitter.com

# Όνομα και τοποθεσία
"John Smith" "New York"
"John Smith" "NYC" OR "New York City"

# Όνομα και εταιρεία
"John Smith" "Microsoft"
"John Smith" site:microsoft.com

# Όνομα και email
"John Smith" "@gmail.com"
"John Smith" email
```

### Επαγγελματικές πληροφορίες
```
# Αναζήτηση βιογραφικού
"John Smith" filetype:pdf resume
"John Smith" filetype:doc CV
intitle:"curriculum vitae" "John Smith"

# Αναζήτηση ειδικά στο LinkedIn
site:linkedin.com/in "John Smith"
site:linkedin.com "John Smith" "Software Engineer"

# Επαγγελματικά προφίλ
site:about.me "John Smith"
site:crunchbase.com "John Smith"
```

### Εντοπισμός προφίλ κοινωνικών δικτύων
```
# Αναζήτηση πιθανών προφίλ
"John Smith" (site:facebook.com OR site:twitter.com OR site:instagram.com)

# Αναζήτηση ονόματος χρήστη
"johnsmith123" site:twitter.com
"johnsmith123" site:reddit.com
"johnsmith123" site:github.com
```

## 🛠️ Εργαλεία γραμμής εντολών

### Sherlock — Αναζήτηση ονομάτων χρήστη

Τα παραδείγματα του πρωτοτύπου χρησιμοποιούν διαφορετικές μορφές εκκίνησης και επιλογών Sherlock. Δεν είναι εγγυημένα ισοδύναμες για κάθε έκδοση. Επιβεβαιώστε τη σύνταξη από το [επίσημο έργο Sherlock](https://github.com/sherlock-project/sherlock)· οι εντολές εδώ διατηρούνται για αντιστοίχιση με την αγγλική έκδοση.

```bash
# Παράδειγμα εγκατάστασης
git clone https://github.com/sherlock-project/sherlock.git
cd sherlock
pip3 install -r requirements.txt

# Αναζήτηση ονόματος χρήστη σε διαφορετικές πλατφόρμες
python3 sherlock username

# Αναζήτηση πολλών ονομάτων χρήστη
python3 sherlock user1 user2 user3

# Αναζήτηση μόνο σε συγκεκριμένους ιστοτόπους
python3 sherlock username --site twitter instagram facebook

# Εξαγωγή αποτελεσμάτων
python3 sherlock username --output results.txt
python3 sherlock username --csv
python3 sherlock username --xlsx
```

### Maigret — Εκτενέστερη αναζήτηση ονομάτων χρήστη
```bash
# Παράδειγμα εγκατάστασης
pip3 install maigret

# Αναζήτηση
maigret username

# Χρήση Tor όπου υποστηρίζεται
maigret username --tor

# Εξαγωγή αποτελεσμάτων σε JSON
maigret username --json results.json
```

### holehe — Ενδείξεις εγγραφής email σε υπηρεσίες
```bash
# Παράδειγμα εγκατάστασης
pip3 install holehe

# Έλεγχος ενδείξεων εγγραφής email σε διαφορετικές υπηρεσίες
holehe email@example.com

# Εμφάνιση αποτελεσμάτων που το εργαλείο αναγνωρίζει ως εγγεγραμμένα
holehe email@example.com --only-used
```

## 📧 Συσχέτιση email με πρόσωπο

Ένα email μπορεί να έχει αλλάξει κάτοχο ή να χρησιμοποιείται από ομάδα. Η αντιστοίχιση με πρόσωπο χρειάζεται περισσότερα από μία αναφορά σε υπηρεσία αναζήτησης.


### Έρευνα με αφετηρία μια διεύθυνση email
```
1. Αναζήτηση email στο Google: "email@example.com"
2. Έλεγχος HIBP: haveibeenpwned.com
3. Έρευνα σε επιτρεπόμενες πηγές καταγεγραμμένων διαρροών
4. Έλεγχος δημόσιων ενδείξεων εγγραφής σε κοινωνικά δίκτυα
5. Υπηρεσίες αντίστροφης αναζήτησης email
```

### Αναζήτηση μορφής εταιρικών email
```bash
# Συνηθισμένα μοτίβα διευθύνσεων email
first.last@company.com
flast@company.com
firstl@company.com
first_last@company.com
first@company.com

# Σελίδα αναζήτησης email του Hunter.io
https://hunter.io/email-finder
```

### Εργαλεία έρευνας αριθμών τηλεφώνου

Οι εντολές εγκατάστασης και τα API είναι παραδείγματα του πρωτοτύπου και χρειάζονται έλεγχο έκδοσης και λογαριασμού. Οι ενδείξεις ονόματος καλούντος, παρόχου ή παλαιότερου κατόχου μπορεί να μην αντιστοιχούν στον σημερινό χρήστη του αριθμού.

```bash
# phoneinfoga
pip3 install phoneinfoga
phoneinfoga scan -n "+1234567890"
phoneinfoga serve -p 8080  # Διαδικτυακή διεπαφή

# Χρήση API
curl "https://api.numlookupapi.com/v1/validate/14155551234?apikey=YOUR_KEY"
```

## 👥 Ανάλυση δικτύου δημόσιων συσχετίσεων

### Έρευνα LinkedIn
```
# Αναζήτηση προφίλ
site:linkedin.com/in "John Smith"
site:linkedin.com/in "John Smith" "Company Name"

# Αναζήτηση δημόσιων συσχετίσεων
Εξετάστε την ένδειξη "People Also Viewed" — άλλα προφίλ που προβλήθηκαν
Εξετάστε τις δημόσια ορατές κοινές συνδέσεις
Εξετάστε τον δημόσιο κατάλογο εργαζομένων της εταιρείας
```

### Έρευνα Facebook

Οι αγγλικές φράσεις Graph Search διατηρούνται ως παραδείγματα αναζήτησης του πρωτοτύπου: αφορούν όνομα, εργοδότη, πόλη και προτιμήσεις. Δεν αποτελούν εγγύηση ότι η παλαιότερη λειτουργία ή σύνταξη υποστηρίζεται σήμερα.

```
# Διευθύνσεις αναζήτησης προφίλ
facebook.com/search/people/?q=john%20smith
facebook.com/search/pages/?q=john%20smith

# Παραδείγματα παλαιότερων αναζητήσεων Graph Search — περιορισμένη υποστήριξη
People named "John" who work at "Company"
People who live in "City" and like "Page"
```

### Εργαλεία ανάλυσης κοινωνικών δικτύων

Το [αρχικό έργο Twint](https://github.com/twintproject/twint) είναι αρχειοθετημένο. Τα παραδείγματα διατηρούνται ως περιεχόμενο του πρωτοτύπου και δεν παρουσιάζονται ως επιβεβαιωμένη λειτουργική πρόσβαση στο σημερινό X.

```bash
# Social Analyzer
pip3 install social-analyzer
social-analyzer --username "target" --metadata

# Twint για Twitter — δείτε τη σημείωση συμβατότητας
pip3 install twint
twint -u username --followers
twint -u username --following
```

| --------- | ----- | ---------- |

| **TinEye** | tineye.com | Εντοπισμός ίδιων εικόνων |
| **Yandex** | yandex.com/images | Αναζήτηση ομοιοτήτων προσώπων |
| **Bing Images** | bing.com/images | Εναλλακτική υπηρεσία αναζήτησης |
| **PimEyes** | pimeyes.com | Αναζήτηση ομοιοτήτων προσώπου |

### Αναζήτηση ομοιοτήτων προσώπου
```
1. Yandex Images — Αναζήτηση εικόνων και ομοιοτήτων προσώπων
```
