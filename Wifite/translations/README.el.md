## Πριν ξεκινήσετε

Το **Wifite2** συντονίζει άλλα εργαλεία για αυτοματοποιημένο έλεγχο WiFi. Η αυτοματοποίηση δεν σημαίνει ότι όλες οι συσκευές ή όλοι οι τύποι ασφάλειας υποστηρίζονται ούτε ότι θα βρεθεί ο κωδικός. Ξεκινήστε καταγράφοντας τους ακριβείς εγκεκριμένους στόχους και τη συμβατότητα της ασύρματης κάρτας.

**Βασικοί όροι:** interface = διεπαφή δικτύου, monitor mode = παρατήρηση πλαισίων 802.11 στο επιλεγμένο κανάλι, BSSID = αναγνωριστικό σημείου πρόσβασης, ESSID = όνομα δικτύου, wordlist = λίστα υποψήφιων κωδικών, PMKID = αναγνωριστικό που σχετίζεται με κλειδί· δεν είναι το ίδιο το μυστικό PMK. Το **WPS** είναι μηχανισμός ρύθμισης σύνδεσης, όχι ξεχωριστός τύπος κρυπτογράφησης.

Ορισμένες λειτουργίες προκαλούν ενεργές εκπομπές και αποσυνδέσεις. Απαιτείται κατάλληλο chipset/driver για monitor mode και τις αντίστοιχες ενεργές δοκιμές. Οι επιλογές του πρωτοτύπου προέρχονται από διαφορετικές εκδόσεις και χρειάζονται έλεγχο στη βοήθεια του εγκατεστημένου εργαλείου. Δεν εκτελούνται εντολές ή ασύρματες δοκιμές κατά τη μετάφραση.

## 🎯 Τι είναι το Wifite

**Wifite** (Wifite2) είναι εργαλείο αυτοματοποιημένου ελέγχου ασύρματων δικτύων που προσφέρει:

- 🤖 **Αυτοματοποίηση δοκιμών** — συνδυασμός επιμέρους εργαλείων χωρίς πληκτρολόγηση κάθε εντολής
- 🎯 **Πολλαπλοί στόχοι** — επιλογή περισσότερων εγκεκριμένων δικτύων
- 🔓 **WPA/WPA2/WEP και WPS** — υποστήριξη των αντίστοιχων σεναρίων, όχι όλων των τύπων ασφάλειας
- 💾 **Αποθήκευση στοιχείων εργασίας** — εξαρτάται από λειτουργία και έκδοση
- 🔄 **Καταγραφή PMKID** — πιθανός έλεγχος χωρίς ήδη συνδεδεμένο πελάτη

### Σύγκριση Wifite και Wifite2

| Χαρακτηριστικό | Αρχικό Wifite | Wifite2 |
| --------- | ------------------- | --------- |
| Κατάσταση συντήρησης κατά το πρωτότυπο | Όχι | Ναι |
| Python | Python 2 | Python 3 |
| PMKID | Όχι | Ναι |
| Κωδικός | Παλιότερη δομή κώδικα κατά το πρωτότυπο | Επανεγγραφή κώδικα κατά το πρωτότυπο |
| Χρήση | Δεν προτείνεται κατά το πρωτότυπο | **Προτεινόμενο** |

### Δυνατότητες

| Χαρακτηριστικό | Περιγραφή |
| --------- | ------------- |
| **Αυτοματοποιημένο** | Αυτοματοποίηση επιμέρους βημάτων ελέγχου WiFi |
| **Επιλογή βάσει χαρακτηριστικών στόχου** | Επιλογή βάσει έντασης σήματος |
| **Κατηγορίες δοκιμών του οδηγού** | WPA, WEP και έλεγχοι WPS/PMKID· διαφορετικοί μηχανισμοί |
| **Έλεγχος υποψήφιων κωδικών** | Συνεργασία με Hashcat και aircrack-ng |
| **Συνέχιση εργασίας όπου υποστηρίζεται** | Συνέχιση εργασίας όπου υποστηρίζεται |

## 🚀 Εγκατάσταση

> **Έκδοση και προέλευση:** Η διανομή, το upstream Wifite2 και forks μπορεί να έχουν διαφορετικές επιλογές. Η εγκατάσταση setup.py και τα πακέτα εξαρτήσεων του πρωτοτύπου είναι ιστορικά παραδείγματα. # Ενημέρωση στην έκδοση που διαθέτει το αποθετήριο πακέτων

```bash
# Λήψη αντιγράφου αποθετηρίου

cd wifite2

# Άμεση εκτέλεση
sudo python3 wifite.py

# Εναλλακτικά, εγκατάσταση
sudo python3 setup.py install
```


## 🎯 Επιλογή στόχου

> **Μη ισοδύναμες επιλογές:** Στο upstream, το 5ghz συμπεριλαμβάνει κανάλια 5GHz· δεν σημαίνει υποχρεωτικά «μόνο 5GHz». Πολλαπλά essid δεν εγγυώνται λίστα, αφού μπορεί να κρατηθεί μόνο η τελευταία τιμή. Power/2ghz και άλλες επιλογές του οδηγού μπορεί να μην υπάρχουν στη συγκεκριμένη έκδοση. Πηγή: [ορισμοί επιλογών του upstream Wifite2](https://github.com/derv82/wifite2/blob/master/wifite/args.py).


### Επιλογή βάσει αριθμού

```bash
# Μετά την αναζήτηση, επιλογή στόχων βάσει αριθμού
# Παράδειγμα επιλογής στόχων 1 και 3
1, 3

# Επιλογή εύρους αριθμών
1-5

# Επιλογή όλων των εμφανιζόμενων στόχων του παραδείγματος
all
```

### Επιλογή βάσει ονόματος ESSID

```bash
# Επιλογή συγκεκριμένου ονόματος δικτύου
sudo wifite --essid "TargetNetwork"

# Πολλαπλές τιμές ESSID κατά το πρωτότυπο
sudo wifite --essid "Network1" --essid "Network2"
```

### Επιλογή βάσει BSSID

```bash
# Επιλογή συγκεκριμένης διεύθυνσης MAC
sudo wifite --bssid AA:BB:CC:DD:EE:FF
```

### Επιλογή βάσει τύπου ασφάλειας

```bash
# Μόνο επιλεγμένα δίκτυα WPA
sudo wifite --wpa

# Μόνο δίκτυα WEP
sudo wifite --wep

# Μόνο δίκτυα με WPS
sudo wifite --wps
```

### Επιλογή βάσει καναλιού

```bash
# Συγκεκριμένο κανάλι
sudo wifite -c 6

# Συμπερίληψη ζώνης 5GHz στο upstream· όχι απαραίτητα αποκλειστική επιλογή
sudo wifite --5ghz

# Μόνο ζώνη 2.4GHz
sudo wifite --2ghz
```

### Επιλογή βάσει σήματος

```bash
# Ελάχιστο σήμα· στις συνήθεις αρνητικές τιμές dBm, κοντά στο 0 είναι ισχυρότερο
sudo wifite --power -50
```

```bash
# Χρήση Reaver, με προεπιλογή που εξαρτάται από έκδοση

```

### Έλεγχος WPS Pixie-Dust

```bash
# Ενεργοποίηση ελέγχου WPS Pixie-Dust, όπου υπάρχουν οι προϋποθέσεις
sudo wifite --wps --pixie

# Χρονικό όριο Pixie-Dust
sudo wifite --wps --pixie-timeout 300
```

### Επιλογές WPS

> **Η σημασία των ορίων διαφέρει:** Το upstream wps-time αφορά συνολικό χρόνο Pixie-Dust, όχι γενικά χρόνο ανά προσπάθεια PIN όπως αναφέρει το πρωτότυπο. Οι παράμετροι pixie, wps-only και οι λοιπές επιλογές χρειάζονται έλεγχο στη βοήθεια της έκδοσης.


```bash

# Μέγιστες επαναλήψεις WPS κατά το παράδειγμα
sudo wifite --wps-fails 10

# Συνολικό χρονικό όριο WPS
sudo wifite --wps-timeout 300
```

## 🔐 Έλεγχοι PMKID

> **PMKID, όχι PMK:** Το αναγνωριστικό που συλλέγεται δεν είναι το μυστικό κλειδί. Η δυνατότητα συλλογής χωρίς ήδη συνδεδεμένο πελάτη εξαρτάται από AP και μηχανισμό ταυτοποίησης· δεν λειτουργεί σε κάθε WPA2 δίκτυο και δεν εγγυάται ανάκτηση κωδικού. Η λειτουργία παραμένει ενεργή επικοινωνία με το AP.


### Τι είναι το PMKID;

Έλεγχος PMKID (Pairwise Master Key Identifier):
- ✅ Συλλογή PMKID από κατάλληλο σημείο πρόσβασης· όχι του ίδιου του PMK
- ✅ Δεν απαιτείται πάντοτε ήδη συνδεδεμένος πελάτης
- ✅ Η μέθοδος PMKID δεν απαιτεί υποχρεωτικά deauthentication
- ✅ Εξαρτάται από το σημείο πρόσβασης· δεν λειτουργεί σε κάθε WPA2 δίκτυο

### Επιλογές PMKID

```bash
# Παράδειγμα επιλογής PMKID· ελέγξτε τη σημασία της επιλογής στην έκδοσή σας
sudo wifite --pmkid

# Χρονικό όριο PMKID
sudo wifite --pmkid-timeout 120
```

### Βασική ιδέα του ελέγχου PMKID

```
1. Στέλνεται αίτημα συσχέτισης στο εργαστηριακό AP
2. Κατάλληλο AP μπορεί να παρέχει PMKID σε πλαίσιο της ανταλλαγής
3. Καταγράφεται το PMKID, όχι το μυστικό PMK
4. Ελέγχονται υποψήφιοι κωδικοί εκτός σύνδεσης με Hashcat
```

## ⚙️ Προχωρημένες επιλογές

> **Μορφές και επιλογές του πρωτοτύπου:** Το cracked στο upstream εμφανίζει προηγούμενα αποτελέσματα και δεν επιλέγει αυθαίρετα αρχείο εξόδου. Οι διαδρομές cracked.txt/hs/pmkid είναι ενδεικτικές. Quiet, scan-time, attack-timeout, skip-crack και επιπλέον flags μπορεί να ανήκουν σε άλλη έκδοση ή να μην υποστηρίζονται. Τυχαία MAC και λίγη έξοδος δεν εξασφαλίζουν αφάνεια.


### Επιλογές διεπαφής

```bash
# Ορισμός διεπαφής
sudo wifite -i wlan0

# Ορισμός διεπαφής monitor
sudo wifite -i wlan0mon
```

### Επιλογές αποτελεσμάτων

```bash
# Αναλυτική έξοδος
sudo wifite -v
sudo wifite --verbose

# Πολύ αναλυτική έξοδος
sudo wifite -vv

# Περιορισμένη έξοδος
sudo wifite --quiet
```

### Επιλογές χρονισμού

```bash
# Χρόνος αναζήτησης σε δευτερόλεπτα
sudo wifite --scan-time 30

# Συνολικό χρονικό όριο ανά στόχο
sudo wifite --attack-timeout 300
```

### Κωδικοί που εντοπίστηκαν

```bash
# Ενδεικτική διαδρομή αποθήκευσης αποτελεσμάτων:
# ~/.config/wifite/cracked.txt

# Εμφάνιση αποθηκευμένων αποτελεσμάτων
cat ~/.config/wifite/cracked.txt

# Εναλλακτικά, επιλογή αρχείου αποτελεσμάτων κατά το πρωτότυπο
sudo wifite --cracked cracked_passwords.txt
```

### Επιλογές παράλειψης βημάτων

```bash
# Παράλειψη ελέγχου υποψήφιων κωδικών· διατήρηση της συλλογής
sudo wifite --skip-crack

# Παράλειψη στόχων για τους οποίους έχει βρεθεί κωδικός
sudo wifite --skip-cracked
```

### Τυχαία διεύθυνση MAC

```bash
# Επιλογή τυχαίας MAC
sudo wifite --random-mac

# Διατήρηση MAC
sudo wifite --no-random-mac
```

## 🔓 Επιλογές ελέγχου υποψήφιων κωδικών

> **Η βοήθεια της έκδοσης καθορίζει τη λειτουργία:** Το upstream crack παρουσιάζει εντολές για καταγεγραμμένο handshake και δεν ταυτίζεται απαραίτητα με την έτοιμη εκτέλεση που υπονοεί το παράδειγμα. Πολλαπλά dict μπορεί να κρατούν μόνο την τελευταία τιμή. Hashcat/aircrack-path και επιλογές εξωτερικών εργαλείων χρειάζονται έλεγχο.


### Έλεγχος υποψηφίων από λίστα λέξεων

```bash
# Ορισμός λίστας υποψήφιων κωδικών
sudo wifite --dict /usr/share/wordlists/rockyou.txt

# Πολλαπλές λίστες υποψήφιων κωδικών
sudo wifite --dict wordlist1.txt --dict wordlist2.txt
```

### Συνδυασμός με Hashcat

```bash
# Χρήση Hashcat για έλεγχο υποψήφιων κωδικών
sudo wifite --hashcat

# Διαδρομή Hashcat
sudo wifite --hashcat-path /usr/bin/hashcat
```

### Επιλογές Aircrack-ng

```bash
# Χρήση aircrack-ng κατά το παράδειγμα
sudo wifite --aircrack

# Διαδρομή aircrack-ng
sudo wifite --aircrack-path /usr/bin/aircrack-ng
```

### Λειτουργία ελέγχου ήδη καταγεγραμμένων δεδομένων

```bash
# Έλεγχος ήδη αποθηκευμένων handshakes
sudo wifite --crack

# Ορισμός αρχείου καταγραφής
sudo wifite --crack --dict wordlist.txt /path/to/capture.cap
```

```bash
# Παράδειγμα συμπερίληψης ζώνης 5GHz κατά την επιλογή στόχων
sudo wifite --5ghz --wpa
```

### Καταγραφή χωρίς έλεγχο υποψήφιων κωδικών

```bash
# Καταγραφή για μεταγενέστερο έλεγχο υποψήφιων κωδικών
sudo wifite --skip-crack
```

### Επανέναρξη ελέγχου

> **Αποθήκευση αποτελέσματος και επανέναρξη διαφέρουν:** Η επανεκκίνηση δεν εγγυάται ακριβή συνέχιση στο ίδιο βήμα ή στην ίδια καταγραφή. Εξετάστε τα αρχεία και την κατάσταση του συγκεκριμένου εργαλείου πριν θεωρήσετε ότι συνεχίστηκε μια προηγούμενη δοκιμή.


```bash
# Το πρωτότυπο αναφέρει αποθήκευση στοιχείων εργασίας
# Το πρωτότυπο προτείνει επανεκκίνηση· δεν εγγυάται ακριβή συνέχιση κάθε βήματος
sudo wifite

# Παράλειψη στόχων με ήδη καταγεγραμμένο αποτέλεσμα
sudo wifite --skip-cracked
```

### Αναλυτική έξοδος

```bash
# Αναλυτική εμφάνιση πληροφοριών
sudo wifite -vv --dict rockyou.txt
```

### Περιορισμός εξόδου και αιτημάτων· χωρίς εγγύηση αφάνειας

```bash
# Λίγα πλαίσια αποσύνδεσης και περιορισμένη έξοδος· δεν συνεπάγεται αφάνεια
sudo wifite --num-deauths 1 --quiet
```

## 📊 Γρήγορη αναφορά

### Βασικές εντολές

| Σκοπός | Εντολή |
| --------- | --------- |
| Βασική σάρωση | `sudo wifite` |
| Επιλογή βάσει ονόματος | `sudo wifite --essid "Name"` |
| Επιλογή βάσει MAC | `sudo wifite --bssid MAC` |
| Μόνο WPA | `sudo wifite --wpa` |
| Μόνο WPS | `sudo wifite --wps-only` |
| Έλεγχος PMKID | `sudo wifite --pmkid` |
| Με λίστα υποψήφιων κωδικών | `sudo wifite --dict wordlist.txt` |
| Παράλειψη ελέγχου υποψήφιων κωδικών | `sudo wifite --skip-crack` |

### Τρόποι συνδυασμού δοκιμαστικών δεδομένων

| Τρόπος ελέγχου | Σημαία | Στόχος |
| -------- | ------ | -------- |
| Handshake WPA | `--wpa` | WPA/WPA2-PSK |
| PMKID | `--pmkid` | WPA/WPA2-PSK |
| Έλεγχος WPS Pixie-Dust | `--wps --pixie` | Ενεργοποιημένο WPS |
| Δοκιμή υποψήφιων PIN WPS | `--wps-only` | Ενεργοποιημένο WPS |
| WEP | `--wep` | WEP — παρωχημένο |

### Συνήθεις λίστες υποψήφιων κωδικών

| Διαδρομή | Περιγραφή |
| ------ | ------------- |
| `/usr/share/wordlists/rockyou.txt` | Συλλογή συνηθισμένων κωδικών |
| `/usr/share/wordlists/fasttrack.txt` | Σύντομος έλεγχος |
| `/usr/share/seclists/Passwords/WiFi-WPA/` | Ειδική συλλογή για WiFi |

### Αρχεία καταγραφών

```
~/.config/wifite/
├── cracked.txt          # Κωδικοί που εντοπίστηκαν
├── hs/                  # Καταγραφές handshakes
│   └── handshake_*.cap
└── pmkid/               # Καταγραφές PMKID
    └── pmkid_*.22000
```

### Γρήγορη αναφορά επιλογών

| Σημαία | Περιγραφή |
| ------ | ------------- |
| `-i` | Διεπαφή δικτύου |
| `-c` | Κανάλι |
| `-v` | Αναλυτική έξοδος |
| `--wpa` | Μόνο WPA/WPA2 |
| `--wep` | Μόνο WEP |
| `--wps` | Ενεργοποιημένο WPS |
| `--pmkid` | Έλεγχος PMKID |
| `--dict` | Λίστα λέξεων |
| `--kill` | Διακοπή διεργασιών |
| `--power` | Ελάχιστο σήμα |
| `--5ghz` | Συμπερίληψη ζώνης 5GHz στο upstream |
| `--2ghz` | 2.4GHz: ζώνη συχνοτήτων |

### Διερεύνηση προβλημάτων

```bash
# Η διεπαφή δεν βρέθηκε
sudo airmon-ng check kill
sudo wifite -i wlan0

# Δεν εντοπίστηκαν δίκτυα
# - Έλεγχος υποστήριξης monitor mode από τον προσαρμογέα
# - Έλεγχος διαφορετικής ζώνης μέσω --5ghz ή --2ghz, όπου υποστηρίζεται
# - Μείωση απόστασης από τα εγκεκριμένα σημεία πρόσβασης

# Δεν καταγράφηκε handshake
# - Το παράδειγμα αυξάνει τις αποσυνδέσεις: --num-deauths 10
# - Παράδειγμα χρονικού ορίου: --wpa-deauth-timeout 60
# - Εξέταση διαφορετικών εργαστηριακών πελατών

# Αποτυχία εντοπισμού κωδικού
# - Έλεγχος καταλληλότητας λίστας υποψήφιων κωδικών
# - Έλεγχος υποστήριξης Hashcat/GPU και επιλογής --hashcat
```
