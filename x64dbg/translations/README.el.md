## Πριν ξεκινήσετε

Το **x64dbg** αποσφαλματώνει εφαρμογές Windows σε **user mode**, δηλαδή έξω από τον πυρήνα του λειτουργικού. Το x32dbg αφορά εφαρμογές 32-bit και το x64dbg εφαρμογές 64-bit. Το γραφικό περιβάλλον συνδυάζει εντολές assembly, καταχωρητές, bytes μνήμης και στοίβα.

**Βασικοί όροι:** breakpoint = σημείο παύσης, stepping = βηματική εκτέλεση, trace = καταγραφή διαδρομής εκτέλεσης, patch = τροποποίηση bytes ή εντολών, module = φορτωμένη μονάδα όπως EXE/DLL, flag = σημαία κατάστασης επεξεργαστή. Τα αγγλικά ονόματα μενού παραμένουν δίπλα στις ελληνικές οδηγίες.

Ξεκινήστε με δικό σας μικρό εκτελέσιμο και βεβαιωθείτε ποια ενέργεια απλώς μετακινεί την προβολή και ποια συνεχίζει την εκτέλεση. Ο οδηγός διατηρεί ορισμένες ανακριβείς αρχικές εντολές για αντιστοίχιση με το πρωτότυπο· οι σχετικές διορθώσεις επισημαίνονται πριν από τα παραδείγματα.

## 🎯 Τι είναι το x64dbg

Το **x64dbg** είναι debugger ανοιχτού κώδικα για εφαρμογές Windows 32/64-bit, με περιβάλλον που θυμίζει το OllyDbg και σύγχρονες δυνατότητες:

- 🔍 **Αποσφαλμάτωση user mode** — εξέταση εφαρμογών Windows.
- 🦠 **Ανάλυση κακόβουλου λογισμικού** — μελέτη ύποπτων εκτελέσιμων.
- 💥 **Εργαστηριακή διερεύνηση** — κατανόηση εκμεταλλεύσεων Windows.
- 🔧 **Αντίστροφη μηχανική** — κατανόηση συμπεριφοράς δυαδικού κώδικα.
- 🧩 **Επεκτάσεις** — πρόσθετες λειτουργίες μέσω plugins.

### Δυνατότητες

| Χαρακτηριστικό | Περιγραφή |
| --------- | ------------- |
| **GUI** | Σύγχρονο προσαρμόσιμο περιβάλλον |
| **Υποστήριξη x64** | Αποσφαλμάτωση 64-bit |
| **Εκτέλεση σεναρίων** | Ενσωματωμένη γλώσσα scripts |
| **Πρόσθετα (plugins)** | Πολλές διαθέσιμες επεκτάσεις |
| **Symbols — σύμβολα** | Υποστήριξη συμβόλων PDB |
| **Ανοιχτού κώδικα** | Ελεύθερα διαθέσιμο και υπό ανάπτυξη |

## 🚀 Εγκατάσταση

### Λήψη

```
# Επίσημος ιστότοπος
https://x64dbg.com/

# Εκδόσεις από GitHub releases
https://github.com/x64dbg/x64dbg/releases

# Ενδεικτικό όνομα λήψης: snapshot_YYYY-MM-DD_HH-MM.zip
```

### Προετοιμασία περιβάλλοντος

```
1. Αποσυμπιέστε το ZIP σε μόνιμη θέση, π.χ. C:\x64dbg\
2. Εκκινήστε το x96dbg.exe, κοινό launcher των δύο εκδόσεων
   - x32dbg.exe → 32-bit debugging
   - x64dbg.exe → 64-bit debugging
3. Προαιρετικά, προσθέστε στο PATH ή δημιουργήστε συντομεύσεις
```

### Ενδεικτικές επεκτάσεις του πρωτοτύπου

> **Δεν είναι όλα απλά DLL στον ίδιο φάκελο:** Επεκτάσεις χρειάζονται συμβατή αρχιτεκτονική, έκδοση και δικές τους οδηγίες. Το TitanHide χρησιμοποιεί driver πυρήνα και δεν εγκαθίσταται ως ένα συνηθισμένο plugin αντιγράφοντας μόνο DLL. Καμία επέκταση δεν εγγυάται απόκρυψη όλων των ενδείξεων debugger.


| Πρόσθετο | Σκοπός |
| -------- | --------- |
| **ScyllaHide** | Απόκρυψη ορισμένων ενδείξεων debugger |
| **SwissArmyKnife** | Διάφορα βοηθητικά εργαλεία |
| **x64dbgpy** | Scripts Python |
| **TitanHide** | Παρέμβαση σε ελέγχους εντοπισμού debugger μέσω driver πυρήνα |
| **OllyDumpEx** | Αποθήκευση μνήμης σε αρχείο |
| **Multiline Ultimate Assembler** | Τροποποίηση πολλών εντολών |

### Εγκατάσταση επέκτασης

```
1. Κατεβάστε το αρχείο DLL της επέκτασης
2. Αντιγράψτε στο: x64dbg\release\x32\plugins\ (32-bit)
           x64dbg\release\x64\plugins\ (64-bit)
3. Επανεκκινήστε το x64dbg
```

│                 │                  │
└─────────────────┴──────────────────┘
```

```
[Module.Address] | [Flags] | [EIP/RIP] | [Status]
```

## 💻 Βασική χρήση

### Έναρξη αποσφαλμάτωσης

```
# Άνοιγμα εκτελέσιμου
File → Open (F3) — άνοιγμα εκτελέσιμου

# Σύνδεση σε διεργασία
File → Attach (Alt+A) — σύνδεση σε διεργασία

# Άνοιγμα και εκτέλεση
Debug → Run (F9) — εκτέλεση

# Επανεκκίνηση αποσφαλμάτωσης
Debug → Restart (Ctrl+F2) — επανεκκίνηση

# Διακοπή αποσφαλμάτωσης
Debug → Stop (Alt+F2) — διακοπή
```

### Γραμμή εντολών

> **Σημαντική διαφορά από πλοήγηση:** Τα g/r είναι aliases του run στο x64dbg. Με διεύθυνση, το g ορίζει προσωρινό breakpoint και συνεχίζει την εκτέλεση· δεν μετακινεί απλώς την προβολή. Τα /s, /x και /p του πρωτοτύπου χρειάζονται επιβεβαίωση ως εντολές ή πρόσθετα. Βλ. [επίσημο run/go/r/g](https://help.x64dbg.com/en/latest/commands/debug-control/run.html).


```
# Εισαγάγετε εντολές στη γραμμή εντολών κάτω

# Μετάβαση σε διεύθυνση
g 0x401000
goto 0x401000

# Αξιολόγηση έκφρασης ή μετάβαση· ελέγξτε τη σημασία της εντολής
g GetProcAddress
g kernel32.LoadLibraryA

# Αναζήτηση συμβολοσειράς
/s "password"

# Αναζήτηση δεκαεξαδικών bytes
/x 90 90 90 90

# Αναζήτηση μοτίβου
/p "8B ?? 89"
```

### Πλοήγηση

```
# Μετάβαση σε διεύθυνση
Ctrl+G → εισαγωγή διεύθυνσης

# Μετάβαση στο σημείο εισόδου
Debug → Entry Point — σημείο εισόδου, κατά το πρωτότυπο

# Ακολούθηση στην προβολή κώδικα
Δεξί κλικ → Follow in Disassembler — εμφάνιση της θέσης ως κώδικα

# Πίσω
- — πλήκτρο μείον για πίσω

# Μπροστά
+ — πλήκτρο συν για μπροστά
```

## 🔴 Breakpoints — σημεία διακοπής

### Σημεία διακοπής λογισμικού INT3

```
# Εναλλαγή σημείου διακοπής στην τρέχουσα διεύθυνση
F2

# Ορισμός σημείου διακοπής με εντολή
bp 0x401000
bp kernel32.LoadLibraryA
bp module.function

# Παράδειγμα συνθήκης του πρωτοτύπου· δείτε διευκρίνιση σύνταξης bp
bp 0x401000, "eax==0"
bp 0x401000, "[esp]==0x12345"

# Παράδειγμα φόρτωσης μονάδας του πρωτοτύπου· ελέγξτε την κατάλληλη λειτουργία
bp $module(kernel32)
```

### Σημεία διακοπής υλικού

> **Τύπος και ευθυγράμμιση:** Το r εδώ σημαίνει read/write, όχι μόνο ανάγνωση. Το μέγεθος 8 bytes αφορά x64 και η διεύθυνση πρέπει να είναι ευθυγραμμισμένη στο μέγεθος. Βλ. [SetHardwareBreakpoint](https://help.x64dbg.com/en/latest/commands/breakpoint-control/SetHardwareBreakpoint.html).


```
# Ορισμός breakpoint υλικού, με περιορισμένο αριθμό θέσεων
Δεξί κλικ → Breakpoint → Hardware → Execute — διακοπή σε εκτέλεση
Δεξί κλικ → Breakpoint → Hardware → Access — διακοπή σε πρόσβαση
Δεξί κλικ → Breakpoint → Hardware → Write — διακοπή σε εγγραφή

# Με εντολή
bph 0x401000, x, 1    # Εκτέλεση
bph 0x401000, r, 4    # Πρόσβαση ανάγνωσης/εγγραφής 4 bytes για breakpoint υλικού· δείτε σημείωση
bph 0x401000, w, 4    # Εγγραφή 4 bytes

# Μεγέθη: 1, 2, 4 ή 8 bytes, ανά αρχιτεκτονική και τύπο
```

### Σημεία διακοπής μνήμης

> **Περιοχή, όχι μόνο ένα byte:** Τα memory breakpoints βασίζονται σε GUARD_PAGE και καλύπτουν ολόκληρη σχετική περιοχή. Διαφέρουν από τα hardware breakpoints. Βλ. [SetMemoryBPX](https://help.x64dbg.com/en/latest/commands/breakpoint-control/SetMemoryBPX.html).


```
# Διακοπή σε πρόσβαση μνήμης
Δεξί κλικ στην προβολή μνήμης → Breakpoint → Memory → Access
Δεξί κλικ στην προβολή μνήμης → Breakpoint → Memory → Write

# Με εντολή
bpm 0x401000, r       # Ανάγνωση
bpm 0x401000, w       # Εγγραφή αποτελέσματος
bpm 0x401000, x       # Εκτέλεση
```

### Σημεία διακοπής με συνθήκη

> **Λανθασμένη ερμηνεία του bp:** Το δεύτερο όρισμα της bp είναι όνομα breakpoint, όχι λογική συνθήκη. Το τρίτο αφορά τύπο, όχι απλώς αριθμό ενεργοποιήσεων. Επομένως οι αρχικές γραμμές δεν υλοποιούν όσα περιγράφει ο τίτλος. Η συνθήκη και η συμπεριφορά καταγραφής ρυθμίζονται χωριστά. Βλ. [SetBPX](https://help.x64dbg.com/en/latest/commands/breakpoint-control/SetBPX.html).


```
# Παράδειγμα λογικής συνθήκης· ελέγξτε τη σύνταξη
bp 0x401000, "eax==0"
bp 0x401000, "eax!=ebx"
bp 0x401000, "[esp+4]>0x100"
bp 0x401000, "byte:[eax]==0x90"

# Παράδειγμα πλήθους ενεργοποιήσεων· ελέγξτε τη σύνταξη
bp 0x401000, "", 5    # Το πρωτότυπο το περιγράφει ως πέμπτη ενεργοποίηση· το bp δεν το ορίζει έτσι

# Καταγραφή χωρίς παύση κατά το πρωτότυπο· ελέγξτε τις επιλογές breakpoint
bplog 0x401000, "EAX={eax}, EBX={ebx}"
```

### Διαχείριση σημείων διακοπής

```
# Λίστα όλων των σημείων διακοπής
Παράθυρο Breakpoints (Alt+B) — σημεία διακοπής

# Διαγραφή σημείου διακοπής
bc 0x401000          # Διαγραφή συγκεκριμένου
bc                   # Διαγραφή όλων

# Ενεργοποίηση ή απενεργοποίηση
bd 0x401000          # Απενεργοποίηση
be 0x401000          # Ενεργοποίηση

# Απενεργοποίηση όλων
bd *

# Ενεργοποίηση όλων
be *
```

## ▶️ Βηματική εκτέλεση και συνέχιση

### Βηματική εκτέλεση

| Action (ενέργεια) | Συντόμευση | Περιγραφή |
| -------- | ---------- | ------------- |
| Step Into — βήμα με είσοδο σε κλήση | F7 | Εκτέλεση μίας εντολής |
| Step Over — βήμα χωρίς είσοδο σε κλήση | F8 | Βήμα χωρίς είσοδο στις κλήσεις |
| Step Out — εκτέλεση μέχρι επιστροφή | Ctrl+F9 | Εκτέλεση μέχρι επιστροφή |
| Run to Selection — εκτέλεση μέχρι επιλογή | F4 | Εκτέλεση μέχρι τη θέση δρομέα |
| Run to User Code — εκτέλεση μέχρι κώδικα εφαρμογής | Alt+F9 | Έξοδος από κώδικα βιβλιοθηκών συστήματος |

### Εκτέλεση

> **Ασυμφωνία συντομεύσεων:** Το πρωτότυπο αποδίδει Ctrl+F7 και στο Trace Into και σε διαφορετική έννοια Run Skipping. Η παράλειψη εξαιρέσεων, η καταγραφή και η παράλειψη εντολής είναι διαφορετικές ενέργειες. Επιβεβαιώστε το πραγματικό μενού και τις δικές σας ρυθμίσεις πλήκτρων.


| Action (ενέργεια) | Συντόμευση | Περιγραφή |
| -------- | ---------- | ------------- |
| Run — εκτέλεση | F9 | Συνέχιση εκτέλεσης |
| Run Skipping — περιγραφή πρωτοτύπου που χρειάζεται έλεγχο | Ctrl+F7 | Παράλειψη τρέχουσας εντολής |
| Pause — παύση | F12 | Παύση εκτέλεσης |
| Restart — επανεκκίνηση | Ctrl+F2 | Επανεκκίνηση αποσφαλμάτωσης |
| Close — διακοπή | Alt+F2 | Διακοπή αποσφαλμάτωσης |

### Trace — καταγραφή διαδρομής εκτέλεσης

```
# Καταγραφή βημάτων με είσοδο σε κλήσεις
Debug → Trace Into (Ctrl+F7) — καταγραφή με είσοδο σε κλήσεις

# Καταγραφή χωρίς είσοδο σε κλήσεις
Debug → Trace Over (Ctrl+F8) — καταγραφή χωρίς είσοδο σε κλήσεις

# Καταγραφή διαδρομής εκτέλεσης
Debug → Trace Record — καταγραφή διαδρομής

# Διακοπή καταγραφής
Debug → Stop Trace — διακοπή καταγραφής
```

### Παράλειψη εντολής

```
# Αλλαγή δείκτη εκτέλεσης χωρίς εκτέλεση της τρέχουσας εντολής
Δεξί κλικ → Set New Origin Here — αλλαγή της επόμενης θέσης εκτέλεσης

# Ή
Ctrl+Shift+O — συντόμευση του πρωτοτύπου, ελέγξτε τις ρυθμίσεις
```

## 🔍 Ενέργειες μνήμης

### Προβολή bytes μνήμης — dump

```
# Ακολούθηση διεύθυνσης στην προβολή bytes
Δεξί κλικ → Follow in Dump → Address/Selection — εμφάνιση bytes

# Μετάβαση σε διεύθυνση στην προβολή μνήμης
Ctrl+G μέσα στο παράθυρο μνήμης

# Αλλαγή μορφής προβολής μνήμης
Δεξί κλικ → Hex → [Byte/Word/Dword/Qword/ASCII/Unicode] — μορφή προβολής
```

### Memory Map — χάρτης μνήμης

```
# Άνοιγμα χάρτη μνήμης
View → Memory Map (Alt+M) — χάρτης περιοχών μνήμης

# Εμφανίζει περιοχές μνήμης με:
- Address — διεύθυνση
- Size — μέγεθος
- Section — ενότητα
- Type (Image/Private/Mapped) — τύπος περιοχής

- Module name — όνομα μονάδας
```

### Αναζήτηση μνήμης

```
# Αναζήτηση από τη γραμμή εντολών κατά το πρωτότυπο

/s L"string"          # Συμβολοσειρά Unicode

# Αναζήτηση αναφορών
Δεξί κλικ → Find references to → Selected Address — αναφορές στην επιλεγμένη διεύθυνση

# Αναζήτηση συμβολοσειρών
Δεξί κλικ → Search for → All Strings — συμβολοσειρές
```

### Δικαιώματα περιοχών μνήμης

```

# Συνήθεις σταθερές δικαιωμάτων
PAGE_EXECUTE_READ
PAGE_EXECUTE_READWRITE
PAGE_READONLY
PAGE_READWRITE
PAGE_NOACCESS
```

### Αποθήκευση μνήμης

```
# Αποθήκευση μνήμης σε αρχείο
Δεξί κλικ στο Memory Map → Dump Memory to File — αποθήκευση σε αρχείο

# Αποθήκευση μέσω επεκτάσεων
Plugins → OllyDumpEx → Dump — αποθήκευση μέσω επέκτασης
```

## 📊 Καταχωρητές

### Πίνακας καταχωρητών

```
# Γενικής χρήσης x64
RAX, RBX, RCX, RDX
RSI, RDI, RBP, RSP
R8-R15, RIP

# Γενικής χρήσης x32
EAX, EBX, ECX, EDX
ESI, EDI, EBP, ESP
EIP

# Καταχωρητές τμημάτων
CS, DS, SS, ES, FS, GS

# Σημαίες EFLAGS/RFLAGS
CF, PF, AF, ZF, SF, TF, IF, DF, OF
```

### Τροποποίηση καταχωρητών

> **Το r δεν είναι γενική εντολή εγγραφής καταχωρητών:** Είναι alias του run, άρα τα αρχικά παραδείγματα r eax=... δεν πρέπει να χρησιμοποιηθούν ως έτοιμη σύνταξη αλλαγής τιμών. Το επίσημο σύστημα εντολών διαθέτει άλλες λειτουργίες ανάθεσης. Βλ. [mov/set](https://help.x64dbg.com/en/latest/commands/general-purpose/mov.html) και [run](https://help.x64dbg.com/en/latest/commands/debug-control/run.html).


```
# Διπλό κλικ σε καταχωρητή για επεξεργασία
# Ή δεξί κλικ → Modify Value

# Μέσω γραμμής εντολών κατά το πρωτότυπο
r eax=0
r rax=0x12345678
r eip=0x401000
r zf=1            # Ορισμός σημαίας μηδενικού αποτελέσματος
```

### Σημαντικές σημαίες

| Σημαία | Όνομα | Τι εκφράζει |
| ------ | ------ | ---------- |
| ZF | Σημαία μηδενικού αποτελέσματος | Το αποτέλεσμα είναι μηδέν |
| CF | Σημαία κρατουμένου | Υπερχείλιση χωρίς πρόσημο |
| SF | Σημαία προσήμου | Ένδειξη αρνητικού αποτελέσματος |
| OF | Σημαία υπερχείλισης | Υπερχείλιση με πρόσημο |
| DF | Σημαία κατεύθυνσης | Κατεύθυνση λειτουργιών συμβολοσειρών |
| TF | Σημαία βηματισμού | Βηματική εκτέλεση |

### Αλλαγή σημαιών

```
# Κλικ στο γράμμα της σημαίας στον πίνακα καταχωρητών
# Ή μέσω εντολών, σύμφωνα με το πρωτότυπο:
r zf=!zf         # Εναλλαγή σημαίας μηδενικού αποτελέσματος
r cf=0           # Μηδενισμός σημαίας κρατουμένου
r sf=1           # Ορισμός σημαίας προσήμου
```

## 📚 Ανάλυση στοίβας

### Πίνακας στοίβας

```
# Εμφανίζει περιεχόμενα στοίβας με:
- Address — διεύθυνση
- Value — τιμή
- Comments — σχόλια, αν υπάρχουν

# Επιλογές δεξιού κλικ:
- Follow DWORD in Disassembler — ακολούθηση τιμής ως διεύθυνσης κώδικα
- Follow DWORD in Dump — ακολούθηση τιμής ως διεύθυνσης δεδομένων
- Modify — τροποποίηση
```

### Call Stack — αλυσίδα κλήσεων

```
# Άνοιγμα αλυσίδας κλήσεων
View → Call Stack (Alt+K) — αλυσίδα κλήσεων

# Εμφανίζει:
- Return Address — διεύθυνση επιστροφής
- From (caller) — καλούσα συνάρτηση
- To (callee) — καλούμενη συνάρτηση
- Size — μέγεθος
- Comment — σχόλιο
```

### Ενέργειες στοίβας

> **Αλλαγή δείκτη δεν σημαίνει push/pop:** Η μεταβολή ESP/RSP αλλάζει μόνο τη θέση στοίβας και δεν γράφει ή διαβάζει αυτόματα την τιμή που θα χειριζόταν μια πραγματική εντολή. Ισχύει επίσης η διόρθωση της σύνταξης r που αναφέρεται στους καταχωρητές.


```
# Μετάβαση σε διεύθυνση στοίβας
Δεξί κλικ → Follow DWORD in Stack — ακολούθηση διεύθυνσης στη στοίβα

# Τροποποίηση τιμής στοίβας
Δεξί κλικ → Modify → Edit — επεξεργασία τιμής

# Παράδειγμα αλλαγής δείκτη· δεν εκτελεί πραγματικό push/pop
r esp=esp-4      # Αλλαγή δείκτη κατά 4 bytes προς χαμηλότερη διεύθυνση
r esp=esp+4      # Αλλαγή δείκτη κατά 4 bytes προς υψηλότερη διεύθυνση
r rsp=rsp-8      # Αλλαγή δείκτη κατά 8 bytes προς χαμηλότερη διεύθυνση
r rsp=rsp+8      # Αλλαγή δείκτη κατά 8 bytes προς υψηλότερη διεύθυνση
```

### Διάταξη στοίβας stdcall 32-bit

```
[ESP]      → Διεύθυνση επιστροφής
[ESP+4]    → Όρισμα 1
[ESP+8]    → Όρισμα 2
[ESP+C]    → Όρισμα 3
...

Μετά τις PUSH EBP; MOV EBP, ESP:
[EBP]      → Αποθηκευμένη τιμή EBP
[EBP+4]    → Διεύθυνση επιστροφής
[EBP+8]    → Όρισμα 1
[EBP-4]    → Τοπική μεταβλητή 1
```

```

## 📝 Εκτέλεση σεναρίων

### Σύνταξη εντολών script

```
# Μεταβλητές
$var = 0x401000

# Σύγκριση
cmp eax, 0

# Υπό συνθήκη
je label
jne label

# Ετικέτες
label:

# Σχόλια
; Αυτό είναι σχόλιο
```

### Βασικό script

> **Δεν ταυτοποιεί τη WinMain:** Το μοτίβο 8B EC είναι MOV EBP, ESP σε συγκεκριμένο πλαίσιο x86· δεν περιλαμβάνει PUSH EBP και δεν είναι μοναδικό στη WinMain. Η διαχείριση της διεύθυνσης αποτελέσματος και οι σχολιασμοί του script χρειάζονται έλεγχο πριν χρησιμοποιηθεί. Τα literals διατηρούνται όπως στο πρωτότυπο.


```
; Παράδειγμα script που το πρωτότυπο παρουσιάζει για εύρεση WinMain· δεν την ταυτοποιεί
mov $addr, 0x401000        ; Αρχική διεύθυνση
loop:
  find $addr, "8B EC"       ; Αναζήτηση του μοτίβου του πρωτοτύπου· δεν περιλαμβάνει PUSH EBP
  cmp $result, 0
  je notfound
  msg "Found at: {$result}"
  add $addr, $result
  add $addr, 1
  jmp loop
notfound:
  msg "Pattern not found"
ret
```

### Εντολές script

| Εντολή | Περιγραφή |
| --------- | ------------- |
| `msg "text"` | Εμφάνιση μηνύματος |
| `log "text"` | Καταγραφή στην κονσόλα |
| `find addr, "pattern"` | Αναζήτηση μοτίβου |
| `bp addr` | Ορισμός σημείου διακοπής |
| `bc addr` | Αφαίρεση σημείου διακοπής |
| `sti` | Βήμα με είσοδο σε κλήση |
| `sto` | Βήμα χωρίς είσοδο σε κλήση |
| `run` | Run — εκτέλεση |
| `ret` | Επιστροφή ή τερματισμός script |

### Εκτέλεση script

```
# Φόρτωση και εκτέλεση script
Scripts → Run Script — φόρτωση και εκτέλεση script

# Ή από τη γραμμή εντολών
scr "scriptfile.txt"
```

## 📊 Γρήγορη αναφορά

### Βασικές εντολές

| Εντολή | Περιγραφή |
| --------- | ------------- |
| `bp addr` | Ορισμός σημείου διακοπής |
| `bc addr` | Αφαίρεση σημείου διακοπής |
| `bph addr, x` | Σημείο διακοπής υλικού |
| `g addr` | Συνέχιση εκτέλεσης με προσωρινό breakpoint στη διεύθυνση |
| `r reg=val` | Ανακριβές αρχικό παράδειγμα· το r είναι alias του run |
| `sti` | Βήμα με είσοδο σε κλήση |
| `sto` | Βήμα χωρίς είσοδο σε κλήση |
| `run` | Run — εκτέλεση |

### Συνηθισμένα μοτίβα ελέγχου

| Bytes | Εντολή |
| ------- | ------------- |
| `90` | NOP |
| `CC` | INT3 — σημείο διακοπής |
| `C3` | RET |
| `55` | PUSH EBP |
| `8B EC` | MOV EBP, ESP |
| `74 XX` | JE — σύντομο σχετικό άλμα |
| `75 XX` | JNE — σύντομο σχετικό άλμα |
| `EB XX` | JMP — σύντομο σχετικό άλμα |
| `E8 XX XX XX XX` | CALL — κοντινή σχετική κλήση |
| `E9 XX XX XX XX` | JMP — κοντινό σχετικό άλμα |

### Ροή ανάλυσης

```
1. Φόρτωση εκτελέσιμου → F3
2. Σημείο διακοπής στην είσοδο → F2 στη σχετική θέση

4. Βηματική εξέταση → F7/F8
5. Εξέταση καταχωρητών και μνήμης στα αντίστοιχα τμήματα

7. Συνέχιση ανάλυσης
8. Τροποποίηση αν απαιτείται → Space
9. Αποθήκευση τροποποιημένου αρχείου
```
