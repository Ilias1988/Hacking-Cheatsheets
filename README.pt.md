## Como utilizar os guias

Escolhe uma categoria e abre um guia. Adapta os exemplos ao teu laboratório: as versões, os requisitos e as permissões podem variar. Os nomes das ferramentas, as opções, os caminhos e os termos técnicos necessários mantêm a forma original. Para consultar o conteúdo sem ligação à Internet, descarrega ou clona o repositório.

```bash
git clone https://github.com/Ilias1988/Hacking-Cheatsheets.git
cd Hacking-Cheatsheets
```
